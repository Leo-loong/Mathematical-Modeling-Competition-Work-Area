# 04-3 · 实验决策链（方法学论证 + 模型评价节的金矿素材）

> 五个建模决策点全部以"先行判据 + 数据实验"定案。失败分支原汁原味保留——它们是模型可靠性与问题3 叙事的论证材料。

## 决策链总览

| 决策 | 问题 | 胜出方案 | 关键数据 | 落选方案与死因 |
|---|---|---|---|---|
| U1 界面相位 | φ₁₂ 取 0 / π / 自由？ | **自由参数**（φ̂₁₂≈−0.28π） | 自由设定 RMSE 最优且跨角度稳定（差 0.025）；固定 0/π 使 d 偏移 0.6~1.0 μm | 固定 0/π：AIC 差 600~1200 被否定；物理上=把 Drude 界面相位硬编码 |
| U2 折射率 | 常数 / 数据表 / 参数式色散？ | **常数 n=2.55** | 参数化色散与 d 简并（n·d 乘积不变、n̂=2.30 撞物理下界、σ̂=13 无意义）；残差改善仅 0.13% | 参数化色散（Cauchy）：可辨识性失败（S12 预言应验） |
| U3 偏振 | s / p / 非偏振平均 / 标量？ | **标量（不分偏振）** | 四设定 χ² 差 <4%（12.12~12.59），统计不可判别；s/p 角度依赖仅 1~3% | 名义最优"仅 p"无统计意义，按简约性取标量 |
| U4 衬底模型 | 常数反射 / Drude 频变？ | **常数 ρ₁₂+常数相位** | Drude：γ 误差棒 ±3700%、d 漂移 +31%、高波数段残差反恶化 | Drude 自由拟合：可辨识性失败（**教训转化为 v2.0 固定文献参数路线**） |
| V-2 背景 | poly7 / 频域高通 / ALS 稳健基线？ | **poly7 非振荡拟合** | 高通方案条纹幅度畸变 709%、极值位移达半周期（Gibbs 振铃）→ 触发红线出局；poly7 零伪峰、E1 跨角度极差最小 | 频域高通：红线出局；ALS：伪峰 1 个 |

## 方法学要点（论文"模型讨论"可引用）

1. **判据先行**：每个决策的胜出判据在实验前写死并公开（防"试到好看为止"）；
2. **选择与验证分离**：模型选型只用 10° 数据，15° 数据独立验证；
3. **负结果入预算**：落选方案不丢弃——Drude 失败的量化（d 漂移 +31%）直接构成系统误差区间与 v2.0 路线；
4. **可辨识性意识**：n-d 简并、Drude-d 纠缠两次实证——说明"参数越多越准"在此类反问题中不成立。
