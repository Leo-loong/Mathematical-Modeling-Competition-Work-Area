# 04-1 · 可靠性分析（论文"误差与可靠性分析"节底稿）

> 迁移自 results/final/可靠性分析_v1.5.md（含审计补充 §7）。硬结论层。

## 1. 结论及其可靠性声明

**SiC 外延层厚度 d = 8.03 ± 0.05 (stat) μm，模型系统区间 [8.0, 8.9] μm**，由三种独立算法（极值回归/谱域FFT/全谱拟合）在两个入射角（10°/15°）上分别估计、逆方差融合得到；两角度结果在经验误差棒内一致（X²=0.20，dof=1）；算法经合成数据闭环验证（恢复偏差 ≤0.06 μm）。

## 3. 误差传播路径

噪声/模型误差 → 三估计器各自 d̂ᵢ 与 σᵢ → 偏差校正（合成闭环 bias）→ 逆方差加权融合 → bootstrap 实证误差棒（诚实条款：三估计器共享数据、误差强相关，闭式低估——统计 σ 0.006 vs 经验 0.050）→ 与模型系统误差合成。

## 4. 算法间交叉验证（D4）

| 对照 | 差值 | 归因 |
|---|---|---|
| E1 vs E3（同角度） | 0.03~0.24 μm | E1 极值定位离散 + E3 模型基线差异 |

## 5. 适用条件与局限（诚实边界）

1. 适用前提：轻掺透明外延层/重掺光学厚衬底（GB/T 42905 与 S03/S05 条件）、界面锐利、单晶无散射；
2. 常数 n=2.55 取自 S06；若需优于 ±0.4 μm 精度必须显式色散建模——单晶圆双角度数据不可辨识（EXP-2），需外部色散数据或变角测量系列；
3. 残差结构（D2 🟡）表明双光束+常数 n 未穷尽物理：多光束高阶项（~2.7%，ρ₁₂≈0.165）与 Drude 频变是 v2.0 的定量方向；
4. 未做仪器绝对反射率校准（无参照片）——绝对反射率不进入厚度公式，仅影响幅度类观测量；
5. 结果适用于被测光斑区域；面内均匀性未验证（无重复测量数据）。

## 6. 一致性检验记录（判别器存档）

- L1（三估计器，每角度）：X²=0.24 / 0.99 ≤ 5.99 → PASS；
- L2（双角度，统计 σ）：X²=6.08 > 3.84 → FAIL（如实记录：统计 σ 低估角度间系统差）；
- L2（经验 σ）：X²=0.20 → PASS；
- 判读：双光束+常数 n 模型未被"证伪到需要 v2.0 才能解释厚度"，但残差结构为问题3 升级提供定量触发证据（**已追认**，D-03）。

## 7. 系统误差的不对称性声明（审计补充）

接受模型集合散布 **[8.03, 8.91] μm**，融合中心 8.03 位于下缘——对称表述"±0.4"低估向上风险。**修正表述：区间 [8.0, 8.9] μm 或不对称 −0.0/+0.9 μm。** 上偏物理来源：色散相位 chirp 与衬底 Drude 相位曲率均使有效光程随波数系统增大，常数 n 模型下被吸收为厚度上偏；该不对称性是 v2.0 预期修正方向的定量预告。
