# 03-4 · 论文图表交接规格（数据包 + 复核基准 + 任务卡）

> **分工**：写作者拥有图表风格与渲染；建模组提供图数据、结构规格与复核基准。
> **真值锚**：`data/*.csv` 是双方共享的唯一数据源——写作者的图与建模组的基准图都由它生成，天然可对。

## 一、每张图的三件交付物

| 交付物 | 位置 | 用途 |
|---|---|---|
| **① 图数据 CSV** | `data/` | 写作者自绘的唯一数据依据；全量档 `_full.csv` 随附 |
| **② 复核基准图** | `figures/`（MATLAB 原生 .fig/.png/.pdf/.svg） | 供与写作者成品做**比对复核**；不是风格基准 |
| **③ 绘图任务卡** | 本文件 §三 | 规定结构、必须呈现要素、禁止事项、口径 |

写作者可完全无视 LaTeX 模板（`latex/`，可选用礼品）与基准图风格，自绘即可。

## 二、复核规程（图稿完成后走一遍，约 10 分钟/图）

1. **叠加自检（写作者自做）**：把自己渲染的曲线与 `data/*.csv` 同图叠画——理论上完全重合；不重合 = 渲染错误（列取错/轴换错/抽稀越界），与建模无关；
2. **数字核对（建模组审）**：图上所有标注数字逐一对照 03-1 总表；
3. **要素核对（建模组审）**：任务卡"必须呈现"清单逐项打勾；
4. **红线检查**：无平滑、无删点、无截断数据范围。

## 三、绘图任务卡

### 【图卡 F2】实测谱与背景
- 数据：`data/fig2_data.csv`（列 sigma10/R10/bg10/sigma15/R15/bg15；全量 `_full`）
- 结构：10°、15° 实测谱两条 + 背景虚线（至少画 10° 的）+ 条纹区下界竖线（1100 cm⁻¹）
- 必须呈现：条纹区外（σ<1100）的剩余射线带起伏可见（说明剔除理由）；两角度条纹周期差异（厚度互证伏笔）
- 禁止：平滑实测谱；截断 σ 范围

### 【图卡 F3】联合拟合与残差
- 数据：`data/fig3_data.csv`（sigma/F_meas/F_fit/residual）
- 结构：拟合曲线与实测散点（上图）+ 残差（下图，同 σ 轴）
- 必须呈现：① 残差子图且结构性趋势**可见**（这是模型升级叙事的视觉证据，属预期而非缺陷）；② 残差 std≈0.50% vs 噪声 0.012% 的对比标注
- 禁止：平滑残差；只用残差绝对值

### 【图卡 F4】多算法交叉与系统区间
- 数据：`data/fig4_data.csv`（method/angle/d_hat_um/sigma_stat_um/…）
- 结构：11 行估计的误差棒点列 + 系统区间带 [8.0, 8.9] μm + 融合中心线 8.03 μm
- 必须呈现：① 区间带（**区间，非对称 ±0.4**）；② 每点误差棒（统计 σ）；③ 各点均落带内的事实可见
- 禁止：省略误差棒；把 8.027/8.026/8.03 混用（查 03-1）

### 【图卡 F5】合成闭环 / bootstrap 分布（✅ 已补全）
- 数据：`data/fig5_spread.csv`（d0_um/E1/E2/E3）+ `data/fig5_boot.csv`（fused10/fused15，N=200）
- 基准图：`figures/fig5_closedloop.*` 四件套已导出
- 结构：左 闭环恢复离散（三档×三算法柱状）；右 融合厚度 bootstrap 分布直方（两角度重叠）

### 【图卡 F1】测量原理示意图（纯示意图，无数据）
- 要素：三层结构（空气/外延层 n₁,d/衬底）、两束反射光路、θ/θ₁、φ₁₂ 标注
- 模板：`latex/fig1_schematic.tex`（TikZ 已写，合并编译验证见断点登记）
- 说明：此图为示意，无复核基准；结构经建模组确认即可
