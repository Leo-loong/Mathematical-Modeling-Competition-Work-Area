# 03-2 · 最终结果与结论（论文结果节底稿）

> 硬结论层。数字口径以 03-1 总表为准。

## 1. 主结果

**碳化硅外延层厚度 d = 8.03 μm（统计不确定度 ±0.05 μm；模型系统区间 8.0~8.9 μm）。**

- 三种独立算法（极值回归 / 谱域 FFT / 全谱拟合）在两个入射角（10°、15°）上分别估计，逆方差融合；
- 分角度结果：10° → 8.042 μm，15° → 8.011 μm，相对差 0.4%，一致性检验通过（X²=0.20，经验误差棒）；
- 双角度联合全谱拟合：8.036 μm（与融合值自洽）。

## 2. 结果合理性

- 落在 GB/T 42905-2023 适用厚度区间（3~200 μm）内；
- 落在工业漂移层典型区间（5~30 μm，Onto DoE 与 A*STAR 产线锚点）内；
- 与 1200V 级 SiC MOSFET 漂移层（~10 μm）同量级。

## 3. 误差结构（概述，全文见 04-1）

- 统计项 ±0.05 μm：bootstrap 实证，含估计器间误差相关性处理；
- 系统项（主导）：常数折射率近似下的色散相位调制与衬底界面模型选择，以接受模型集合散布 [8.0, 8.9] μm 给出（**区间表述，非对称**）；
- 残差存在结构（std≈0.50% vs 噪声 0.012%），已归因（色散 chirp + 幅度形状近似），作为问题3 模型升级的定量触发证据。

## 4. 结论句（论文可直接化用）

1. 厚度确定：红外双光束干涉模型 + 三域互证融合算法可在无标定参照的条件下给出稳健厚度估计；
2. 可靠性：结果的统计不确定度远小于系统不确定度——**进一步提升精度的关键在模型层（色散/Drude 显式建模）而非算法层**，这由合成闭环（算法恢复偏差 ≤0.06 μm）与残差结构归因共同支撑；
3. 方法普适性：三域互证+两级一致性检验的框架天然输出"模型是否需要升级"的判据，可推广至多层结构（问题3）。

## 5. 问题3 扩展结果（指针）

- **Si 外延层厚度**：d = 3.43 ± 0.01 (stat) ± 0.15 (sys) μm（v2.0 Airy+固定 Drude，双角度互证 0.7%）——详见 03-1 §E1 与 `results/final/硅外延层厚度结果_v2.0.md`；
- **SiC 判定与修正**：多光束可忽略（q≈0.002~0.005）；残差主因为衬底 Drude 相位频变；v2.0 重算修正 +0.61 μm（8.03→8.63 μm），落于 v1.5 系统区间 [8.0, 8.9] 上缘——详见 03-1 §E2 与 `results/final/SiC修正结果_v2.0.md`；
- 效应分离的决策链与证据：04-4（问题3 效应分离与决策链）。
