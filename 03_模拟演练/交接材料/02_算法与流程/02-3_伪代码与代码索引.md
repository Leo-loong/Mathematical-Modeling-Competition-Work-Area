# 02-3 · 伪代码与代码索引（论文附录选材依据）

## 核心伪代码（论文附录可直接改写为规范伪代码）

```
算法: 三域互证厚度反演 (sic_e1_e2_e3.m)
输入: 波数轴 Df, 反射率 F, 噪声 sigN, 入射角 angle, 折射率 nref
参数: cosθ₁ = cos(asin(sinθ/n₁))

# ---- E1 极值回归（多假设周期竞争）----
预计算 FFT 谱 (Hann窗 + 8×零填充)
候选周期 ← GB/T物理窗 [d=2, 250]μm 内 top-5 局部峰
for each 候选周期:
    检测极值 (robust + 亚像素细化 + 交替约束)
    if 极值数 ≥ 8:
        全谱线性模型 [cos, sin, 1, slope] 裁决 (固定 d=d_c)
        保留 chi² 最小者
d̂₁ ← k/(4·n₁·cosθ₁);  σ₁ ← 回归残差折算

# ---- E2 谱域法 ----
峰搜索窗 ← E1±50% (否则 GB/T 窗)
d̂₂ ← 峰位频率/(2·n₁·cosθ₁);  σ₂ ← FWHM/2.355 折算

# ---- E3 全谱拟合 ----
模型 R(σ) = c₀ + A·2|r₀₁|·cos(2πpσ+φ₁₂π) + a₁·(σ−σ̄)/1000
初值 ← {E1, E2} 中位数, 双起点 φ₁₂∈{−0.3, 0.7} (防假分支)
lsqnonlin 加权拟合 (权重 1/σ_noise)
d̂₃ ← p/(2·n₁·cosθ₁)·10⁴;  σ₃ ← Jacobian 协方差

# ---- 融合与检验 (run_v15_pipeline.m) ----
d̂_fusion ← Σ wᵢd̂ᵢ,  wᵢ ∝ 1/σᵢ²          # 逆方差
X²_L1 ← Σ(d̂ᵢ−d̂)²/σᵢ²  vs χ²(2)           # 估计器间
X²_L2 ← (d̂₁₀°−d̂₁₅°)²/(σ₁₀°²+σ₁₅°²)        # 角度间
误差棒 ← 分块 bootstrap (N=200)            # 实证, 替代闭式
```
