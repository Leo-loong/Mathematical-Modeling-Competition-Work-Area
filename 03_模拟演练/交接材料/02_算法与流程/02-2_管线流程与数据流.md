# 02-2 · 管线流程与数据流（论文流程图绘制依据）

> 硬结论层：流程顺序与判定分支不得改动。本文件也是论文"流程图"的绘制规范。

## 端到端数据流

| 步骤 | 输入 | 处理 | 输出 | 代码位置 |
|---|---|---|---|---|
| P1 体检 | 附件1/2.xlsx | 波数轴均匀性、缺失、尖峰检查（只记录） | 体检记录（EXP 报告与 V4 报告内） | 管线数据准备段 + work/src/ 实验脚本 |
| P1b 预处理 | 原始谱 | 必要坏点处理；**禁止平滑** | 条纹分量（背景扣除后） | run_v15_pipeline.m 开头段（poly7, σ≥1100） |
| P2 背景扣除 | 干净谱 | poly7 非振荡拟合（σ轴标准化），条纹区 σ≥1100 cm⁻¹ | 条纹分量 + 背景 | EXP5 定稿 |
| P3 噪声估计 | 残差 | 相邻差分稳健估计 | σ̂_noise = 0.0117%/0.0118% | 同上 |
| V-3 三域估计 | 条纹分量+σ̂ | E1 极值回归 / E2 谱域FFT / E3 全谱拟合 | d̂ᵢ, σᵢ (i=1,2,3) × 两角度 | src/model/sic_e1_e2_e3.m |
| V-3 融合 | d̂ᵢ,σᵢ | 逆方差加权 | d̂_fusion, σ_fusion | 同上 |
| V-3 检验 | 融合结果 | L1（估计器间）/ L2（角度间）X² 检验 | PASS/FAIL + 证据 | 同上 |
| V-4 误差实证 | 残差 | 分块 bootstrap N=200 | 统计误差棒 | run_v15_pipeline.m |
| V-4 闭环验证 | 合成谱（10/30/100 μm×30次） | 全管线反演 | 恢复偏差 ≤0.06 μm | 同上 |
| V-5 汇总 | 全部 | 交叉对照表 + 系统误差区间 | 最终结果 | results/final/ |

## 论文流程图绘制规范

1. **主流程**（建议横向三段）：数据预处理段（P1→P3）→ 三域并行估计段（E1‖E2‖E3 → 融合 → 两级检验）→ 输出段（误差实证 → 结果）；
2. **判定分支必须画出**：L1 不通过 → 模型判别分支（指向问题3）；L2 经验σ下通过（如实画"统计σ FAIL → 经验σ PASS"的双标注，这是诚实性加分点）；
3. E1/E2/E3 三框标注各自数据域（光谱域/二次频域/模型域）与同源出处（v1.0 推导）；
4. 建议在融合框旁小字标注权重公式 wᵢ∝1/σᵢ²。
