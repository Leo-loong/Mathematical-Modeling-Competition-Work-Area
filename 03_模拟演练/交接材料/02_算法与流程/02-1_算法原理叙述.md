# 02-1 · 算法原理叙述（论文问题2"算法设计"节底稿）

> 来源：模型设计/02 规格 + 实际实现。硬结论层：算法结构与参数不得改动。
> 设计哲学：三个算法从同一 v1.0 模型推导（模型与算法同源），在不同数据域运行，互为验证。

## 2.1 总体架构：三域互证 + 逆方差融合 + 一致性检验

```
附件谱（10°/15° 各一条）
   │  体检级清洗 → 背景扣除(poly7) → 噪声估计(σ̂≈0.012%)
   ▼
┌─────────────────────────────────────────────┐
│ E1 极值回归（光谱域）  E2 谱域FFT（二次频域）  E3 全谱拟合（模型域） │
│  输出 d̂₁,σ₁           输出 d̂₂,σ₂          输出 d̂₃,σ₃      │
└─────────────────────────────────────────────┘
   │  逆方差加权融合（每个角度内）→ 一致性检验 L1
   ▼
10°融合值 ↔ 15°融合值 → 一致性检验 L2（双角度互证）
   ▼
最终结果 + bootstrap 实证误差棒 + 系统误差区间
```

## 2.2 E1 极值回归法（光谱域，与 ASTM F95/工业 CARIS 同源）

- 原理：由 01-1 §S-5.4，条纹极值满足 m = k·σ_m + c（k=4n₁d·cosθ₁，c=φ₁₂/π）。检测**全部**极值 (σ_m, m) 做线性回归——用满所有条纹而非只取相邻两条，精度随极值数提升。
- 实现要点：robust 极值检测（抗噪）+ 亚像素抛物线细化 + 交替约束 + **多假设周期竞争**（在 GB/T 物理窗 2~250 μm 内取 top-5 候选周期，全谱模型裁决 chi² 最小者胜——防周期跳变/假分支）。
- 输出：d̂₁、回归残差折算 σ₁、副产品界面相位估计 φ̂₁₂。

## 2.3 E2 谱域频率法（二次频域，工业 Cepstrum 的简化同源）

- 原理：背景扣除后的条纹分量做 FFT（Hann 窗 + 8 倍零填充插值），厚度轴 d = f₀/(2n₁cosθ₁)——峰位即厚度。整条谱参与（相当于全谱平均），故对局部噪声稳健。
- 峰宽（FWHM/2.355）折算为 σ₂；同时隐含"n 恒定"假设，色散致峰偏移（已归因，见 04-1 §4）。
- 搜索窗：E1 可用时取 d̂₁±50%，否则 GB/T 物理窗。

## 2.4 E3 全谱拟合（模型驱动主力）

- 模型：v1.0 定稿正演 R(σ) = c₀ + A·2|r₀₁|·cos(2πpσ + φ₁₂π) + a₁·(σ−σ̄)/1000（A 为幅度、a₁ 吸收幅度缓变；c₀/p/φ₁₂ 自由）。
- 求解：lsqnonlin 加权非线性最小二乘（权重 = 1/σ̂_noise）；初值由 E1/E2 供给并做双极小轮廓校验（EXP-2/4 教训：存在 8.6/9.25 μm 假分支）。
- 输出：d̂₃、Jacobian→协方差→σ₃、全谱残差（D2 诊断素材）。
- 唯一正面处理色散的算法候选——但 EXP-2 证明参数化色散与 d 简并不可辨识，故 v1.5 定稿取常数 n，色散并入系统误差区间。

## 2.5 逆方差融合与两级一致性检验

- 融合：d̂_fusion = Σwᵢd̂ᵢ，wᵢ = (1/σᵢ²)/Σ(1/σⱼ²)——最小方差意义下的最优权重。
- L1 检验（每角度，三估计器间）：X² = Σ(d̂ᵢ−d̂)²/σᵢ² 对照 χ²(k−1)；通过 → 融合可信。
- L2 检验（两角度融合值之间）：双角度互证。
- 诚实条款：三估计器共享同一数据、误差强相关（统计 σ 0.006 vs 经验 0.050），故最终误差棒用**分块 bootstrap（N=200）实证**，闭式仅作参考。

## 2.6 系统误差区间（模型集合法）

全部通过先行判据的模型变体（EXP-1/2/4 的接受设定）各自给出厚度，其散布 [8.03, 8.91] μm 构成模型系统不确定度——**以区间形式报告**（中心在下缘，上偏风险不对称，见 04-1 §7）。

## 2.7 v2.0 扩展（问题3）：框架不变，内核升级

问题3 的算法**不另起炉灶**：三域互证 + 逆方差融合 + 两级一致性检验的框架原样保留，仅正演内核由双光束式升级为 Airy+固定 Drude（M-A，见 01-4；实现 `src-new/model/v20_airy_forward.m`）。要点：

1. **Si 判定（EXP-6）**：四条件核对 + 数据证据三选三（残差 250×噪声、可见度衰减 24-28×、厚度差 51σ）→ Si 出现多光束，v2.0 内核对 Si 数据**必要**；
2. **SiC 判定（EXP-7）**：2×2 效应分离——多光束可忽略、衬底 Drude 相位频变主导（red-chi² −23%）；
3. **Si 反演的特殊性**：E1/E2 对 Si 形态不适用（条纹周期非恒定，P1_Si §3），反演以 v2.0 E3 为主 + 双角度互证 + 合成闭环（框架的退化使用，已在记录中声明）；
4. **无偏性**：v2.0 在 SiC/Si 两形态合成闭环中 |bias| ≤ 0.005 μm（EXP-8/闭环Si）。

完整推导与结论：01-4（模型）、04-4（效应分离决策链）、03-1 §E（数字）。
