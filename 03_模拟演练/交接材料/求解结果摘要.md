# 第二部分 问题1：双光束干涉模型

## 2.1 物理设置

三层结构：空气(n₀=1) / 外延层(n₁=2.55 实常数，厚度 d) / 重掺衬底（光学厚半空间，固定文献 Drude）。斜入射 θ=10°/15°，层内折射角 θ₁ 由 Snell 定律给出。

## 2.2 正向模型（定稿公式）

```
衬底界面反射：r₁₂(σ) = ρ₁₂·e^{iφ₁₂}        （v1.0：常数有效相位）
往返相位差：  Δφ(σ) = 4π·n₁·d·cosθ₁·σ + φ₁₂ = 2π·p·σ + φ₁₂   （p = 往返光程 OPD）
双光束合成：  E_r/E₀ = r₀₁ + ρ₁₂·e^{iΔφ}
反射率谱：    R(σ) = r₀₁² + ρ₁₂² + 2·r₀₁·ρ₁₂·cos(2π·p·σ + φ₁₂)
```

**厚度确定原理**：条纹极值条件 cos(·)=±1 → 级数关系

```
m = 4·n₁·d·cosθ₁·σ_m + φ₁₂/π     （线性回归斜率 k=4n₁d·cosθ₁ → d = k/4n₁cosθ₁）
```

## 2.3 四项物理设定的实验拍板（判据先行，EXP-1~4）

| 决策 | 候选 | 数据结果 | 定稿 | 落选原因 |
|---|---|---|---|---|
| U1 界面相位 | 0 / π / 自由 | 自由设定 RMSE 最优、φ̂₁₂ 跨角度稳定（差 0.025） | **自由参数**（≈−0.28π） | 固定 0/π 被 AIC 否定（ΔAIC>600），且使 d 偏移 0.6~1.0 μm |
| U2 折射率 | 常数 / 数据表 / 参数式色散 | 参数化色散与 d 简并（n̂ 撞物理下界、σ̂=13），残差改善仅 0.13% | **常数 n=2.55** | 可辨识性失败（S12 预言应验） |
| U3 偏振 | s / p / 平均 / 标量 | 四设定 χ² 差 <4%，统计不可判别 | **标量** | 简约性；s/p 差 <3% |
| U4 衬底反射 | 常数 / Drude 频变 | Drude：γ 误差棒 ±3700%、d 漂移 +31% | **常数+声明** | 不可辨识（教训→v2.0 固定文献参数路线） |

## 2.4 假设清单（9 条，每条含真实差异与去向）

A1 双光束近似（高阶束→问题3）｜A2 n₁ 实常数（色散→系统区间）｜A3 衬底常数反射+相位（Drude→v2.0）｜A4 衬底光学厚（S05）｜A5 界面锐利无过渡层（→问题3 讨论）｜A6 平面波/横向均匀｜A7 偏振不敏感（EXP-3）｜A8 噪声平稳（EXP-5 定稿）｜A9 谱可分解为背景+条纹（EXP-5）。

# 第三部分 问题2：算法与计算结果

## 3.1 算法总体框架

```
附件1/2（10°/15° 反射率谱）
   │ ①体检级清洗（禁平滑——条纹即信号）
   │ ②背景扣除（poly7 非振荡拟合，条纹区 σ≥1100 cm⁻¹）
   │ ③噪声估计（σ̂≈0.012%）
   ▼
┌─────────────────── 三域并行估计 ───────────────────┐
│ E1 极值回归        E2 谱域 FFT       E3 全谱拟合      │
│ (ASTM F95 同源)    (Cepstrum 简化)   (模型驱动主力)    │
│ → d̂₁,σ₁           → d̂₂,σ₂          → d̂₃,σ₃         │
└────────────────────────────────────────────────────┘
   ▼ 逆方差加权融合（wᵢ ∝ 1/σᵢ²）
   ▼ 两级一致性检验：L1（估计器间）→ L2（双角度间）
   ▼ 分块 bootstrap（N=200）实证误差棒
   ▼ 最终结果 + 系统误差区间
```

## 3.2 三域估计器要点

| 估计器 | 数据域 | 原理 | 输出 | 工业同源 |
|---|---|---|---|---|
| E1 极值回归 | 光谱域 | 全部极值 (σ_m, m) 线性回归（多假设周期竞争+亚像素细化防周跳） | d̂₁, σ₁, φ̂₁₂ | CARIS（ASTM F95 基础） |
| E2 谱域频率法 | 二次频域 | 条纹分量 FFT（Hann+8×零填充），峰位即厚度，峰宽折算 σ₂ | d̂₂, σ₂ | Cepstrum 简化版 |
| E3 全谱拟合 | 模型域 | v1.0 正演式非线性最小二乘（双角度共享 d），初值由 E1/E2 供给 | d̂₃, σ₃, 残差 | 工业.Model Based Analysis |

## 3.3 主结果（SiC，附件1/2）

| 量 | 值 | 说明 |
|---|---|---|
| **融合厚度** | **8.03 μm** | 三算法逆方差融合 + 双角度汇总 |
| 统计不确定度 | ±0.05 μm | 分块 bootstrap N=200 实证 |
| 模型系统区间 | **[8.0, 8.9] μm** | 接受模型集合散布（中心在下缘，上偏风险，**区间表述非对称 ±0.4**） |
| 分角度 | 10° 8.042 / 15° 8.011 μm | 差 0.031 μm（0.4%），X²=0.20 PASS |
| 联合全谱拟合 | 8.036 μm | 双角度共享 d |
| 复现值 | 8.026 μm | 管线重跑无漂移 |

## 3.4 可靠性四线验证

| 验证线 | 设计 | 结果 | 意义 |
|---|---|---|---|
| V1 合成闭环 | 真厚度 10/30/100 μm × 30 次噪声实现 → 全管线反演 | 恢复偏差 ≤0.06 μm | 算法自身精度上限远小于声称精度——排除"蒙对" |
| V2 双角度互证 | 附件1/2 独立反演 | 差 0.031 μm（0.4%），经验 σ 下 X²=0.20 PASS | 数据间自洽；统计 σ 下 FAIL 如实记录并归因 |
| V3 残差诊断 | 拟合残差 vs 噪声 | std 0.50% vs 0.012%，lag-1=0.999 → **有结构** | 已归因（色散 chirp+幅度形状）；作为问题3 升级触发证据 |
| V4 多算法交叉 | 6 个独立估计两两对照 | 全部 ≤0.24 μm，逐一归因 | 无未解释超差 |

**误差预算（9 项，GUM 风格）**：噪声 <0.01 ｜ 估计器统计 0.009~0.10 ｜ 极值定位 ≤0.10 ｜ **色散 chirp ±0.3~0.4（主导）** ｜ 衬底模型（散布 8.03~8.91）｜ 背景 ≤0.05 ｜ 角度间 0.031 ｜ 波数轴 <0.01 ｜ 闭环验证 ≤0.06。

## 3.5 数值口径警示

文档中出现过 8.026（复现）/ 8.03（融合主数字）/ 8.036（联合拟合）/ 8.042、8.011（分角度）——口径不同，**使用前必须查 03-1 总表**，禁止混用。

# 第四部分 问题3：多光束干涉

## 4.1 物理升级：从两束到多束

光在上下界面间往返反射不止一次（图2：束1 表面反射，束2/3/4 为往返 1/2/3 次后透出），所有束相干叠加 → **Airy 分布**取代简单余弦。

**两材料关键差异（命题人选材动机）**：

| 量 | SiC | Si |
|---|---|---|
| n₁ | 2.55 | 3.42 |
| 空气/层反射 \|r₀₁\| | ≈0.44 | ≈0.55 |
| 衬底界面 \|r₁₂\| | ≈0.016~0.204（σp 依赖） | 低波数段趋 1（Drude 金属化，R 谷值 0%） |
| 往返因子 q=\|r₁₀r₁₂\| | **≈0.002~0.005（弱）** | **低波数段 ≫0.1（强）** |

## 4.2 任务A · 必要条件推导（审核定稿 + 三重数值验证）

**可观测多光束干涉的四个必要条件**（缺一退化为双光束）：

| # | 条件 | 数学表述 | 核对结果 |
|---|---|---|---|
| ① | 结构：界面平行（往返束同向出射） | 器件几何 | PASS（条纹规整即证据） |
| ② | 相干/可分辨：条纹周期 ≫ 仪器分辨；OPD 在扫描窗内 | Δσ_fringe≈245~450 cm⁻¹ ≫ 4 cm⁻¹ | PASS（**口径修正**：谱域测量的相干条件是"可分辨性"而非光源全带宽相干长度——Agent 修正、主对话确认采纳） |
| ③ | 透明：外延层 κ₁≈0 | 轻掺（GB/T N<10¹⁶） | PASS |
| ④ | 幅度：q=\|r₁₀r₁₂\| ≥ 0.1（冻结阈值） | SiC 灰区→数据定夺；Si 预期超阈 | SiC 可忽略 / Si 显著（EXP-6/7） |

**Airy 合成式（v2.0 正向模型 M-A）**：

```
E_r/E₀ = r₀₁ + (1−r₀₁²)·r₁₂(σ)·e^{iΔ} / (1 + r₀₁·r₁₂(σ)·e^{iΔ})，R = |·|²
其中 r₁₂(σ) 由固定文献 Drude 介电函数 ε(σ)=ε∞−σp²/(σ(σ+iγ)) 经 Fresnel 计算（零自由参数）
```

**三重数值验证（verify_T1.m，确定性）**：

| 验证 | 结果 | 结论 |
|---|---|---|
| V1 闭式 ≡ 逐束求和 | N=30 束差异 9.4×10⁻¹⁶；逐束误差按 q 几何衰减 | Stokes 关系与级数正确 |
| V2 截断误差阶数 | 双光束截断误差/自身条纹幅度 vs q 斜率 **1.09/1.01**（≈1）；三束 **2.07/2.03**（≈2） | **双光束截断误差为 O(q)**（审核修正：原稿 O(q²) 标签错误已数值证伪） |
| V3 倍频签名 | Airy−双光束残差主 FFT 分量 = **2.02×基频** | 2Δ 倍频签名成立——EXP-6 证据②的物理依据 |

## 4.3 任务B · 精度影响量化（EXP-8）

双光束式反演 Airy 真值谱的系统偏差（SiC 形态，15 次实现）：

| σp (cm⁻¹) | q̄ | d₀=5 μm | d₀=8 μm | d₀=30 μm |
|---|---|---|---|---|
| 700 | 0.0016 | +0.033 | **+1.378** | **+6.942** |
| 1500 | 0.0089 | +0.023 | +1.350 | +6.804 |
| 4000 | 0.1006 | +1.378 | +1.134 | +6.914 |
| （v2.0 全工况） | — | ≤0.005 | ≤0.005 | ≤0.005 |

**结论**：① v2.0 全工况无偏；② 双光束偏差为正（高估）且随条纹数增长，主因是 Drude 相位 chirp 的累积**而非多光束幅度**（q 最小时偏差依旧大）；③ 偏差方向以衬底模型档位为条件（Si +0.33 高估 vs SiC 闭环 −0.14 低估），禁止一概而论。

## 4.6 任务F/G · SiC 判定与修正

**EXP-7 效应分离（2×2 对照，附件1）**：

| 模型 | d̂ (μm) | RMSE(%) | red-chi² | 结论 |
|---|---|---|---|---|
| M00 双光束+常数 r₁₂（=v1.5） | 8.043 | 50.39 | 1862 | 基准 |
| M01 Airy+常数 r₁₂ | 8.055 | 50.04 | 1836 | **多光束无可辨改善 → 可忽略** |

**任务G 结论**：v2.0 修正 **10° 8.665 / 15° 8.601 μm（+0.61 μm）——落于 v1.5 系统区间 [8.0, 8.9] 上缘，问题2 结论无需撤回**；其系统误差主项被定量化为衬底 Drude 相位频变。σp 双口径张力（幅度反演 700 vs 跨角度一致 4600）如实入档 → SiC 厚度全区间 [8.03, 9.15] μm。

## 6.3 一致性解读（分歧根源可归因）

1. **SiC 厚度分布 6.99~8.83 μm 的分歧，根源是折射率处理方式**：
   - 数据反演 n(ω)（包络法，S27；退火反演 n≈2.627，S28）→ 吸收部分系统效应 → 7.2~7.6 μm；
   - 文献常数 2.55 + Drude 相位修正（我方 v2.0）→ 8.6~8.7 μm；
   - 我方 8.03 居分布中部，v2.0 修正方向与色散物理最完整的 S30 一致——**交叉印证"衬底 Drude 相位频变是系统误差主因"**；
2. **Si 厚度**：我方 3.43 [3.28,3.58] 完全落于 S27 置信区间 [3.32,3.81]；S30 偏低且其"无显著多光束"判断缺乏强证据；
3. **多光束判定**：Si 出现（我方=S27，证据强度更高）；SiC 可忽略（我方=S27=S30；S28 相反但其 50 μm 异常结果自损可信度）。

## 6.4 优势与弱点（诚实评估）

**优势（评分支撑）**：
1. **双角度互证一致性全场最优**（0.4%/0.7% vs 基准 0.82%~4.6%）——直接源于 Drude 相位频变的定量化处理；
2. **验证深度无基准可及**：推导级数值验证（O(q) 斜率、倍频签名）+ 全工况无偏闭环 + 2×2 效应分离——外部基准均未做；
3. **诚实性**：σp 双口径张力、统计σ下 L2 FAIL、偏差方向条件依赖——全部如实入档而非掩盖；
4. **判据先行机制**：10 项决策预注册定案，可复核可审计。

**弱点（改进方向）**：
1. 折射率依赖文献值——S27 的包络自反演路线在文献缺失场景更鲁棒（EXP-2 已证不可辨识，包络法是未实现的替代路线）；
2. σp 系统区间较宽（[700,4600] cm⁻¹ → 厚度 [8.03,9.15]）——S30 的 Lorentz 振子模型（显式建模剩余射线带 793.9/970.1 cm⁻¹）可能收窄；
3. E1/E2 对 Si 形态失效——三域互证在 Si 上降级为单算法+双角度；
4. v2.0 拟合残差 8~10%（Si）仍含结构——过渡层/粗糙度未建模（M-C 挂起）。
