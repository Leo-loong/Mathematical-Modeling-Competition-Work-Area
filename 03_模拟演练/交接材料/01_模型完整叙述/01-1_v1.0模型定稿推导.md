# 01-1 · v1.0 双光束模型定稿推导（论文问题1 节底稿）

> 来源：模型设计/01（实验包-1 第1块定稿）。硬结论层：公式与参数不得改动。
> 每个物理设定都经过数据实验拍板（EXP-1~4），证据链见 04-3。

## S-5.1 物理设置与记号

- 层 0：空气，n₀ = 1；层 1：外延层，n₁ = 2.55（实数常数，定稿依据见下），厚度 d（待测）；层 2：衬底，重掺 SiC 半空间（自由载流子吸收强，红外"光学厚"——无底面回波）。
- 平面波以入射角 θ 入射（θ = 10°/15°），层 1 内折射角 θ₁ 满足 Snell 定律：n₁ sinθ₁ = sinθ。
- 波数 σ（cm⁻¹）为光谱横轴；真空相位随 σ 线性增长。

## S-5.2 双光束复振幅叠加

- 表面反射振幅（空气→外延层 Fresnel，近法线标量形式）：
  r₀₁ = (1 − n₁cosθ₁)/(1 + n₁cosθ₁)
- 衬底界面反射振幅写作 ρ₁₂·e^{iφ₁₂}：重掺衬底为 Drude 型强反射界面，其反射相位是频率的缓变函数；实验（EXP-1/EXP-4）证明在测量带内以**有效常数相位 φ₁₂** 描述最优（自由拟合，φ̂₁₂ ≈ −0.28π，跨角度稳定）。
- 第二束光相对第一束的相位差（往返光程 OPD = 2n₁d·cosθ₁ ≡ p）：
  **Δφ(σ) = 4π·n₁·d·cosθ₁·σ + φ₁₂ = 2π·p·σ + φ₁₂**
- 双光束合成反射场：E_r/E₀ = r₀₁ + ρ₁₂·e^{iΔφ(σ)}

## S-5.3 反射率谱与厚度的显式关系

**R(σ) = r₀₁² + ρ₁₂² + 2·r₀₁·ρ₁₂·cos(2π·p·σ + φ₁₂)**

即"常数背景 + 余弦条纹"：条纹幅度 2|r₀₁ρ₁₂|，条纹角频率 2πp，条纹周期 Δσ = 1/p = 1/(2n₁d·cosθ₁)。

## S-5.4 条纹级数与厚度确定原理（问题1 核心交付）

极值条件 cos(·) = ±1，即 Δφ(σ_m) = mπ（m 为整数级数）：

**m = 4·n₁·d·cosθ₁·σ_m + φ₁₂/π**

- 斜率 k = 2p = 4n₁d·cosθ₁ → **d = k/(4·n₁·cosθ₁)**（历史稿曾漏因子 2，实验纠正，注意校验）；
- 截距 c = φ₁₂/π 给出界面相位（存在 mod-1 起始奇偶简并，需全谱拟合定奇偶）；
- 由此导出三种反演算法（见 02-1）：E1 极值回归、E2 谱域傅里叶法、E3 全谱拟合。

**可解性/唯一性讨论（论文加分项）**：
1. d 与 φ₁₂ 由"斜率+截距"分离，要求极值级数覆盖 ≥2 个条纹（本题约 11.6 个条纹，充分）；
2. 极值序列 max/min 起始奇偶造成 φ₁₂ 的 mod-π 简并 → 由条纹幅度符号消除；
3. n₁ 与 d 在相位中仅以乘积 nd 出现，双角度 cosθ₁ 差异仅 0.28% 提供弱辨识 → n₁ 取文献值、其偏差计入系统误差（实验 EXP-2 证实不可辨识）；
4. 周期跳变（周跳/双极小分支）风险 → 初值须由 E1/E2 供给并做轮廓校验。

## S-5.6 v1.0 定稿参数总表

| 参数 | 取值 | 来源 |
|---|---|---|
| n₁ | 2.55（常数） | S06（Goldberg 2001 红外值）+ EXP-2 |

## S-5.7 多光束的一般化（v2.0 预告，问题3 接口）

v1.0 只计两束。考虑层内多次往返反射，反射场为几何级数叠加（Airy 型）；ρ₁₂ ≈ 0.165 时高阶项约 2.7% 量级——v1.5 残差中的结构成分与之相符，是问题3 的定量入口（详见 04-1 §5.3 与 04-3 EXP-4/记录）。
