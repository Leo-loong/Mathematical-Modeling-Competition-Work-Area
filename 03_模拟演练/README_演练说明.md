# 03_模拟演练 使用说明

> 模拟比赛专用工作区（复制自 01_当前赛题 模板）。演练结束后**整个文件夹删除或归档**，不干扰正式比赛；知识库 00_ 依然只读。

## 模拟怎么做（三步）

1. **放题**：把模拟题（建议用往年国赛真题，如 2025 年 A/B/C 题）PDF 和附件放进 `00_赛题原文/`。
2. **按真比赛节奏走**：参照 `README_使用说明.md` 的三天节奏和记录模板。
   - 建议掐表：3 天（72 小时）或压缩为 1 个周末两天，全程按比赛纪律（不查现成答案、不交流）。
3. **结束复盘**：对照 `02_输出产物/README_交付清单.md` 检查交付物，写一份复盘（见下）。

## 演练重点检查什么（比做出题更重要的）

- [ ] 分工配合顺不顺（各自负责的环节有没有卡点）
- [ ] 知识库查起来快不快、缺什么资料（缺的赛后补进 00_ 知识库）
- [ ] AI 提示词好不好用（AI使用规范/提示词模板库.md、提示词详版/）
- [ ] LaTeX 流程通不通：复制 `00_知识库/论文写作/LaTeX模板_2026国赛版/` 到 `04_论文素材/LaTeX论文/`，边写边编译
- [ ] 代码规范执行情况（每个问题一个 solve_qx.py，结果全由脚本产出）
- [ ] 去 AI 味：写完跑一遍 `00_知识库/论文写作/痕迹检测.md`
- [ ] 合规红线：交稿前过 `00_知识库/AI使用规范/红线自查表.md`

## 复盘模板（演练完花 30 分钟写）

- 时间分配：计划 vs 实际，哪个环节超时了
- 协作卡点：最耽误事的三件事
- 工具问题：知识库/提示词/LaTeX/代码哪里不顺
- 正式比赛要改什么：每人列 1~2 条改进
