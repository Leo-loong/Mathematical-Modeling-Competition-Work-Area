# 01_当前赛题 使用说明（比赛时读我）

> 比赛第一天：把本文件夹复制到工作区并改名（如 `01_赛题B`），
> 把赛题 PDF 和附件放入 `00_赛题原文/`，然后按本说明开始干活。

---

## 一、目录用途速查

| 文件夹 | 放什么 | 什么时候更新 |
|---|---|---|
| `00_赛题原文/` | 题目 PDF + 附件数据（原始，**不动**） | 第一天 |
| `01_数据分析/` | 数据清洗记录.md、数据字典.md、探索性分析图/ | 第一天 |
| `02_建模过程/` | 模型方案对比.md、模型假设.md、公式推导、代码脚本/ | 全程 |
| `03_结果与图表/` | 最终图表/（图1~图N）、结果数据表 | 第二天起 |
| `04_论文素材/` | 论文大纲.md、各章节草稿/、参考文献.bib | 第二、三天 |

## 二、每天结束前必做的 3 件事（防止三天后失忆）

1. 更新 `02_建模过程/模型方案对比.md`：今天讨论了什么方案、选了什么、为什么。
2. 在 `02_建模过程/代码脚本/Qx/说明.md` 里记录：这个脚本做什么、参数怎么设、运行顺序。
3. 在 `01_数据分析/数据清洗记录.md` 里记录：今天处理了多少数据、怎么处理的。

> **为什么？** 论文"建模部分"要写"为什么放弃 A 选 B"，评阅老师也看重思考过程——这些记录就是你论文最好的素材，也是去 AI 味的关键。

## 三、三天节奏参考

| 时间 | 任务 | 产出 |
|---|---|---|
| 第一天上午 | 赛题分析 + 数据 EDA | 数据清洗记录、数据概况图 |
| 第一天下午 | 问题一建模 + 求解 | 代码 Q1 + 结果 + 图 |
| 第二天上午 | 问题二建模 + 求解 | 代码 Q2 + 结果 + 图 |
| 第二天下午 | 问题三建模 + 求解 | 代码 Q3 + 结果 + 图 |
| 第三天上午 | 灵敏度分析 + 论文主体 | 各章节草稿 |
| 第三天下午 | 摘要 + 全文整合 + 附录 | 论文 v1 |
| 第三天晚上 | 终审（格式/匿名/AI声明/查重） | 论文 v2 + 支撑材料 |

## 四、代码规范（代码要进附录！）

1. 每个问题一个文件夹：`Q1/`、`Q2/`、`Q3/`，主脚本命名 `solve_q1.py`。
2. 每个脚本开头写注释：用途、输入文件、输出文件、依赖库。
3. 所有结果（数字/图）由脚本生成并保存，**不做任何手动修改**（保证论文与代码一致）。
4. 画图统一调用知识库的 `matplotlib_中文画图模板.py` 或复制的模板。
