## 运行环境与说明

- Python 3.9+，依赖：`numpy scipy openpyxl SALib numba`
- 安装：`pip install -r requirements.txt`
- 各问独立运行：`python code/q1_solver.py`（Q1）/ `q2_solver.py`（Q2，默认C核）/ `q3_solver.py`（Q3）/ `q4_solver.py`（Q4）
- Q4一键复现：`python code/run_chain.py`
- 本包代码与论文结果逐值一致，执行日志见代码内注释和 `code/innov/logs/`
