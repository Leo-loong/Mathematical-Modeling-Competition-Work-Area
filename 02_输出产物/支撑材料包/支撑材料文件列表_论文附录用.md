## 五、运行环境

- Python 3.9+，依赖见 `requirements.txt`
- 安装：`pip install -r requirements.txt`
- 各问入口：`python code/q1_solver.py` / `q2_solver.py` / `q3_solver.py` / `q4_solver.py`
- 一键复现：`python code/run_chain.py`（Q4）；Q1-Q3各问独立运行
