# 02_输出产物 交付清单（交稿前 3 小时逐项检查）

> 依据《全国大学生数学建模竞赛论文格式规范（2026 年修订稿）》。

---

## 需要提交的东西

| 文件 | 要求 | 状态 |
|---|---|---|
| 论文 PDF | 单独文件，≤ 20 MB，**第一页为摘要页**（不含承诺书/编号页） | [ ] |
| 支撑材料（RAR/ZIP） | ≤ 20 MB，含全部源代码 + 自主查阅的数据 + 中间结果图表 | [ ] |
| 纸质版（如赛区要求） | A4，含承诺书+编号页（打印签名）+摘要页+正文+附录 | [ ] |

## 电子版论文格式检查表

- [ ] 电子版第一页是摘要页（承诺书/编号页不能出现在电子版里）
- [ ] 摘要 ≤ 1 页，含标题和关键词
- [ ] 页码从摘要页开始编号（电子版摘要页=第 1 页，正文从第 2 页起；纸质版才是第 3 页摘要、第 4 页起正文）
- [ ] 正文 ≤ 30 页（2026 规范），无目录
- [ ] 页边距 ≥ 2.5 cm，A4
- [ ] 附录包含全部可运行的源代码（缺失=取消评奖资格）
- [ ] 全文无学校、姓名、赛区信息（含页眉页脚、图片水印、代码注释！）
- [ ] 代码注释里也不要写学校/姓名（常见漏网之鱼）
- [ ] 参考文献规范，正文有 [1][2] 标注
- [ ] AI 使用声明已附上（近年强制要求，以官网最新规定为准）

## 支撑材料检查表

- [ ] 所有可运行源代码（和论文附录一致）
- [ ] 代码能直接运行（环境说明写清楚：Python 版本、依赖库）
- [ ] 运行结果与论文数字一致（不一致=取消评奖资格）
- [ ] 文件列表已放入论文附录
- [ ] 不含承诺书、编号页
- [ ] 无身份信息

## 交稿前流程（最后 3 小时）

```
1. 终稿锁定（不再改内容，只查格式）
2. 用 AI 跑一遍"交稿前总检"提示词（见知识库提示词模板库）
3. 三人交叉检查：一人读格式清单、一人翻页检查、一人核对代码
4. 生成 PDF（从 Word 导出或 LaTeX 编译）
5. 打支撑材料压缩包
6. 按赛区要求提交
```

## 常见致命失误（每年都有队伍犯）

- ❌ 电子版论文第一页放成了承诺书 → **第一页必须摘要页**
- ❌ 论文里出现学校名/队员名 → 取消评奖资格
- ❌ 附录没有代码，或代码跑不出来 → 取消评奖资格
- ❌ 论文结果和代码运行结果不一致 → 取消评奖资格
- ❌ 压缩包超 20MB / 论文超 20MB → 无法提交
- ❌ 忘记写 AI 使用声明 → 近年起违规，可能被取消评奖资格
