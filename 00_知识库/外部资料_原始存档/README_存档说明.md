## 口径提示（读这些资料时注意）

1. 机构资料普遍写"正文 25-30 页"——这是**建议**口径；官方 2026 格式规范只有上限：正文（不要目录）**不超过 30 页**。
2. 摘要字数（800-1000 / 800-1200）为机构口径，官方只要求**不超过一页**。
3. 评分分值、获奖比例、真题年份等在不同讲义里互相矛盾（原文如此），以组委会官方文件为准。
4. 资料中的"国奖级""拿奖"等宣传语与学员语境已被剔除；不要被"AI 一键生成论文/图表"的卖点误导——本队铁律：模型人拍板、代码人运行、图表 Python 画、数据不许编。
