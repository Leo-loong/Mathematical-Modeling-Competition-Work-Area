# 提示词模板库（比赛中直接复制使用）

> 用法：把【】里的内容替换成你们赛题的信息。
> 原则：提示词越具体，AI 输出越可用。永远要求 AI **给出理由和来源**，不要只给结论。

---

## 1. 赛题分析（比赛开始第一件事）

```
你是数学建模竞赛指导。请帮我分析这道赛题【粘贴赛题全文】，输出：
1. 用一句话概括每个子问题的目标
2. 每个子问题的关键约束/已知条件/数据
3. 每个子问题建议的建模方法（2~3 个候选，说明理由和优缺点）
4. 数据需要注意的地方（缺失、单位、异常）
5. 列出一份 3 天工作清单（按小时安排）
注意：只是建议，最终选择由我们团队决定。
```

## 2. 模型方案讨论（决策前）

```
针对问题【编号】，我考虑用【A模型】和【B模型】。
请对比：1. 两者假设条件 2. 数据要求 3. 精度 4. 实现难度 5. 评阅视角的优劣
最后给出你的推荐及理由。请引用教材或文献依据。
```

## 3. 代码生成（提需求模板）

```
请用 Python 实现【任务描述】，要求：
1. 输入数据格式：【列名/单位/样例】
2. 输出：打印【什么结果】+ 保存【什么文件】
3. 使用 scipy/numpy/pandas/matplotlib，代码加中文注释
4. 处理边界情况：【缺失值/除零/数据长度不足】
5. 写完检查一遍代码逻辑，指出可能出错的 2 个点
```

## 4. 代码调试（报错时）

```
这段代码报错【粘贴报错】。请：
1. 解释错误原因（用一句话）
2. 给出修改后的完整代码
3. 提醒我这类错误的常见场景
【粘贴代码】
```

## 5. 论文初稿（框架先行）

```
请帮我写论文【章节】部分初稿。要求：
1. 结合我们的结果【粘贴结果数据】
2. 遵循格式规范：【粘贴格式规范要点】
3. 每段要有具体数字，禁止空话套话
4. 全文不用"首先、其次"这类词，用逻辑连接
5. 长度控制在【字数】字
```

## 6. 去 AI 味改写（重点！）

```
请改写下面这段论文文字，要求：
1. 加入思考过程：解释为什么选这个方案、试过什么其他方案、遇到什么困难
2. 所有结论用具体数值支撑（误差、偏差、对比）
3. 去掉模板化表达（首先/其次/综上/值得注意的是）
4. 语气像人类研究者在认真讲述自己的工作
5. 保留所有公式和数字不变
原文：【粘贴】
```

## 7. 审稿人挑刺（写完必做）

```
请扮演严格的数学建模竞赛评阅老师，逐段审阅下面论文【粘贴论文】，
挑出：1. 逻辑漏洞 2. 没有证据支撑的结论 3. 空话段落
4. 数值可疑之处 5. 格式违规（对照格式规范）
每个问题标注严重程度（致命/重要/建议），并给出修改方案。
```

## 8. 灵敏度分析辅助

```
我的模型参数：【参数名+基准值+含义】。
请设计一份灵敏度分析方案：
1. 选哪 2~3 个参数最合适，为什么
2. 扰动范围（按实际意义）
3. 输出表格模板和结论句式
4. 如果结果对某参数敏感，怎么在论文里合理化
```

## 9. 摘要打磨（最后一步）

```
请审阅我的摘要【粘贴】，检查：
1. 是否包含：问题→方法→结果（具体数值）→验证→价值
2. 是否超一页
3. 是否有空话（改掉）
4. 关键词是否准确
给出修改建议（不要直接重写，我要自己定稿）。
```

## 10. 交稿前总检（最后 1 小时）

```
请对照以下清单检查我的论文【粘贴或说明】：
1. 摘要 ≤ 1 页且第一页
2. 正文 ≤ 20 页
3. 附录含全部可运行代码
4. 全文无学校/姓名/赛区信息
5. 图表都有编号且正文有引用
6. 参考文献规范
7. AI 使用声明已附
逐项报告通过/不通过。
```

---

## 提示词通用技巧（背下来）

1. **给上下文**：把题目、数据格式、已有结果都粘给 AI，别让它猜。
2. **要理由**：任何建议都要求"给出依据"，防止 AI 瞎编。
3. **分步问**：一次只问一件事，比一次问五件事效果好十倍。
4. **限制输出格式**：要求表格化/分点，便于直接抄进论文。
5. **复核一切数字**：AI 会说"计算得 3.2"，但你没让它跑程序，它就是编的。
6. **AI 给代码必须跑一遍**：不跑的代码等于不存在。
