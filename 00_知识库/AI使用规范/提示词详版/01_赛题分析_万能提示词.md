**数学建模国赛【赛题分析】万能提示词**

**（检测/修改/撰写三模式完整版）**

**第1步：对赛题进行深度分析，输出分析报告+8列速查表+获奖级模型推荐+标准化交接包。支持检测评估模式。**

> 注：本提示词支持三种运行模式，自动检测适配：本步为全流程第一步（无前序交接包），完成后输出「赛题分析标准化交接包」供下一步读取；独立模式无需依托任何前序提示词，直接基于题目和附件数据进行分析（默认模式），输出质量与串联模式一致；检测整改模式对上传的已有成果（赛题分析报告/解题思路文档）先与获奖级标准多维度对比检测，再按优先级（P0→P1→P2）自动整改并复检，强制输出整改后成果+HTML整改报告（含检测结果总览、多维度评分可视化、分维度详细分析、标准对照表、优先级整改清单、整改前后对比、复检结果、底部信息栏），不得只检测不整改；如只需检测不需整改，则只输出HTML检测报告。评估等级：获奖级≥90 / 一等奖80-89 / 二等奖70-79 / 省一60-69 / 省二50-59 / 需大幅改进<50。无论哪种模式，输出质量标准一致，不得因模式不同而降低质量。

**检测整改模式运行细则**

- 触发条件：检测到输入为已有成果（赛题分析报告/解题思路文档），而非原始题目+数据时，自动进入检测评估+自动整改模式
- 功能：①将上传成果与获奖级标准多维度对比检测，评估题型判断/隐含条件挖掘/模型推荐/创新点质量/评分点覆盖/题意理解6个维度；②基于检测出的问题按提示词要求自动修改优化，消除问题
- 整改流程：①多维度检测→②生成HTML检测报告→③按优先级(P0→P1→P2)自动整改→④整改后复检→⑤输出整改后成果+HTML整改报告(含整改前后对比)
- 整改原则：能自动修改的自动修改（格式/排版/公式/图表/代码），不能自动修改的给出详细修改方案（如模型重构/创新点设计），不得只检测不整改
- 报告要求：HTML整改报告文件名「整改报告_成果名称.html」，报告最开始给出检测结果总览，然后列出整改清单+整改前后对比+复检结果
- 默认执行检测+自动整改一体化；如只需检测不需整改，则只输出HTML检测报告

**「赛题分析标准化交接包」输出格式（强制）**

本步完成后必须输出以下结构化交接包（JSON格式），供下一步自动读取：

```json
{
  "题型": "A/B/C/D/E/混合",
  "各小问国奖版推荐模型": "问题一:XXX模型; 问题二:XXX模型...",
  "核心创新点清单": "创新点1:XXX(怎么做+效果+验证); 创新点2:XXX...",
  "关键隐含条件清单": "隐含条件1:XXX(数学表达); 隐含条件2:XXX...",
  "数据预处理重点": "缺失值处理/异常值处理/特征工程/防泄露要点",
  "检验方向建议": "问题一:灵敏度分析; 问题二:误差分析...",
  "评分点与易错点": "评分点:XXX; 易错点:XXX..."
}
```

**一、输入（三模式）**

- 串联模式：无（本步是第一步）
- 独立模式：赛题题目+附件数据（默认模式）
- 检测整改模式：上传的赛题分析报告/解题思路文档

**二、输出**

- 解题模式：①赛题分析报告 ②8列速查表 ③国奖版推荐模型 ④核心创新点清单 ⑤隐含条件清单 ⑥数据预处理重点 ⑦标准化交接包
- 检测整改模式：HTML整改报告（强制）

**三、优秀论文赛题分析共性特点**

- 隐含条件挖掘深度：隐含条件数量≥显性条件50%，每条有数学表达和建模影响
- 模型推荐精准：直接给出获奖级创新模型，而非泛泛的「可以用优化模型」
- 创新点具体：每个创新点说明「创新什么+为什么+怎么做+预期效果+如何验证」五要素
- 评分导向：明确指出每个小问的评分点(3-5个)和易错点(2-3个)
- 题型判断准确：A题机理优化/B题机理优化/C题数据分析/D题运筹优化/E题机理预测

**四、题意理解的常见误区（必须避免）**

- 误区1：只看显性条件，忽略隐含条件（最致命）
- 误区2：把问题想简单，用过于基础的模型（如只用线性规划解决复杂优化）
- 误区3：模型推荐泛泛而谈，不具体到算法和创新点
- 误区4：忽略题目中的约束条件（如额定功率、时间限制、资源约束）
- 误区5：不区分省奖版和国奖版，直接给最简单的模型

**五、8大分析维度**

| 维度 | 核心内容 |
| --- | --- |
| 1 题目背景 | 领域+核心问题+现实价值+评委考察意图 |
| 2 已知条件 | 逐句列出显性条件+数据+参数+约束+附件信息 |
| 3 隐含条件(最高优先级) | 6维度挖掘：物理定律/数学约束/数据特征/边界条件/常识假设/评分导向 |
| 4 核心要求 | 每小问核心目标+评分点(3-5个)+易错点(2-3个) |
| 5 数学本质 | 问题类型(优化/预测/分类/评价/机理)+数学工具+变量目标约束 |
| 6 数据特征 | 数据质量+分布+相关性+时空特征(C题重点) |
| 7 难点挑战 | 建模/求解/数据/创新难点+解决策略 |
| 8 创新空间 | 算法改进/跨领域迁移/多模型融合+省奖国奖策略 |

**六、隐含条件挖掘**

隐含条件数量必须≥显性条件的50%！每条按五要素：描述+来源+数学表达+建模影响+遗漏后果

- 6维度：①物理/实际定律 ②数学约束 ③数据特征 ④边界条件 ⑤常识假设 ⑥评分导向

**七、省奖/国奖双轨思路**

| 版本 | 要求 |
| --- | --- |
| 省奖版 | 经典成熟模型，实现简单稳妥，有基本问题特化处理 |
| 国奖版(最终建模以此为准) | 经典模型基础上有针对性改进，至少1个真创新点(五要素：什么+为什么+怎么做+效果+验证) |

**八、8列速查表（强制输出）**

| 列 | 内容 |
| --- | --- |
| 1 | 小问编号 |
| 2 | 核心要求 |
| 3 | 数学本质 |
| 4 | 省奖版模型 |
| 5 | 国奖版模型 |
| 6 | 核心创新点 |

**九、检测评估模式评估维度**

| 维度 | 标准要求 | 评估要点 |
| --- | --- | --- |
| 题型判断 | 准确判断题型(A/B/C/D/E) | 是否正确判断题型，是否说明判断依据 |
| 隐含条件挖掘 | ≥显性条件50%，每条有数学表达 | 隐含条件数量、深度、数学表达、建模影响 |
| 模型推荐 | 直接给出获奖级创新模型 | 模型是否具体到算法，是否有创新点，是否适配题目 |
| 创新点质量 | 每个创新点五要素完整 | 创新点是否真创新(非简单应用)，五要素是否完整 |
| 评分点覆盖 | 每问3-5个评分点 | 是否覆盖主要评分点，是否指出易错点 |
| 题意理解 | 无明显误解 | 是否误解题目要求，是否忽略约束条件 |

**十、本提示词整改能力（检测+自动整改）**

| 整改类型 | 可自动整改的内容 | 整改方式 |
| --- | --- | --- |
| P0致命 | 题型判断错误、隐含条件严重不足、模型推荐过于简单 | 重新判断题型+补充隐含条件+升级为获奖级创新模型 |
| P1重要 | 创新点不具体、评分点覆盖不全、题意理解有偏差 | 补充创新点五要素+补充评分点+修正题意理解 |
| P2优化 | 格式排版、表述不够学术、结构不够清晰 | 优化格式+学术化表述+调整结构 |
| 需手动 | 模型完全错误需要重构、核心思路完全偏离 | 给出详细的重构方案和建议，确认后执行 |

整改后输出：修改后的赛题分析报告_已整改.docx + HTML整改报告（含整改前后对比+复检结果）
