**数学建模国赛【论文写作】万能提示词**

**（检测/修改/撰写三模式完整版）**

**第5步：基于前面所有步骤产出，按优秀论文结构规范输出七章结构论文+四件套+标准化交接包。支持检测评估模式。**

> 注：三种运行模式自动适配：串联模式自动读取「赛题分析/数据预处理/建模求解/模型检验」四个交接包并严格遵循其方案，输出「论文写作标准化交接包」；独立模式无交接包时自行完成赛题分析+数据预处理+建模求解+模型检验（简要但完整）后再完整写作，质量与串联一致；检测整改模式对上传的已有论文/论文章节/论文草稿先检测再按优先级（P0→P1→P2）自动整改并复检，强制输出整改后成果+HTML整改报告（8部分：检测结果总览/评分可视化/分维度分析/标准对照表/整改清单/前后对比/复检结果/底部信息栏），不得只检测不整改；只需检测则只输出HTML检测报告。评估等级：获奖级≥90/一等80-89/二等70-79/省一60-69/省二50-59/需大幅改进<50。三种模式质量标准一致。

**「论文写作标准化交接包」输出格式（强制）**

本步完成后必须输出以下结构化交接包（JSON格式），供下一步自动读取：

```json
{
  "Word论文路径": "paper.docx",
  "LaTeX源文件路径": "paper.tex",
  "LaTeX编译PDF路径": "paper.pdf",
  "HTML要点解析路径": "论文题目_要点解析.html",
  "论文结构": "问题重述→问题分析→模型假设→符号说明→(数据侧写)→建模求解→模型评价",
  "字数/页数": "正文XX页，字数XX",
  "图表数量": "图XX张，表XX个",
  "公式数量": "XX个公式"
}
```

**一、输入（三模式）**

- 串联模式：自动读取「赛题分析交接包」+「预处理交接包」+「建模求解交接包」+「检验交接包」
- 独立模式：题目+原始数据(自行简要完成前四步)
- 检测整改模式：上传的完整论文/论文章节/论文草稿

**二、输出**

- 解题模式：①Word论文 ②LaTeX源文件 ③LaTeX编译PDF ④HTML要点解析 ⑤标准化交接包
- 检测整改模式：HTML整改报告（强制）

**三、论文诊断升级流程（检测评估模式专用）**

①全面诊断：逐模块扫描论文，输出《论文诊断报告》，各模块评定等级(获奖/一等/二等/省一/省二/不合格)；②分模块升级：按优先级(P0致命/P1重要/P2优化)给出各模块具体升级方案；③全文校验：确保结构完整、格式规范、逻辑闭环；④三格式交付：输出Word+LaTeX+PDF。默认只输出HTML评估报告，不自动修改论文；要求升级时再执行上述流程。

**四、论文标准结构（对标优秀论文）**

用「问题重述」而非「引言」，用「问题分析」而非「总体分析」，模型检验嵌入每个问题的5.X.5子节而非单独成章！

结构顺序：封面(1页：题目+分段式摘要+关键词，「针对问题一」开头、≥8个数字)→一 问题重述(1.1问题背景/1.2问题重述逐问列出，≥1页)→二 问题分析(2.1/2.2…每问单独分析，≥1页)→三 模型假设(3-9条，每条加粗+内容，≥0.5页)→四 符号说明(表1符号说明，三线表，含单位列，≥0.5页)→五 数据侧写(C题必做：数据概况+分布分析+相关性分析+可视化，≥1页)→五/六 模型建立与求解(5.1问题一/5.2问题二，每问五子结构，≥12页)→末章 模型评价(优点/缺点/改进方向/推广，≥1页)。C题必须有数据侧写；A/B/D/E题数据探索放在对应问题的模型准备中。

**五、摘要规范（初审核心）**

总字符≤1000(建议800-900)，单倍行距1页以内。首段写背景(120-150字)，禁止「本文研究了…」空洞开头；其后每段段首必须是「针对问题一」「针对问题二」…，逐段写方法+量化结果(每段100-130字，至少1-2个精确数字)；收尾段写3个创新点+三类检验关键词+应用价值(80-120字)。必须含量化结果≥8个数字、3个创新点、三类检验关键词；禁止「较好」「一定程度」等模糊表述，必须用精确数字；关键词5-7个，用分号分隔；可嵌入关键结果表格(如对比表)增强说服力。

**六、每个问题固定五子结构+8步内容闭环**

| 子结构 | 内容 | 篇幅 |
| --- | --- | --- |
| 5.X.1 具体分析 | 问题本质+难点+流程图 | 0.3-0.5页 |
| 5.X.2 模型准备 | 方法选型+方法对比表+数据准备+原理示意图 | 0.3-0.5页 |
| 5.X.3 模型建立 | 步骤1/2...+LaTeX公式+变量解释+完整模型给出 | 1-1.5页 |
| 5.X.4 模型求解 | 参数+算法步骤表+结果表+数据图+结果分析 | 0.5-1页 |
| 5.X.5 模型检验 | 灵敏度/误差/鲁棒性分析(智能选择)+检验图表+结论 | 0.3-0.5页 |

每个小问内容深度8步闭环：问题分析→方法选型→模型建立→公式推导→编程求解→结果分析→模型检验→小结。

**七、论文三大特色元素（必须包含）**

- 示意图丰富：每个模型建立前必须有1张原理/示意图，全文5-8张
- 算法步骤表格：启发式算法必须用三线表列出Step1/Step2...
- 完整模型给出：优化类问题必须有完整的「模型给出」公式块(目标函数+s.t.约束)

**八、公式与图表规范**

- 公式：LaTeX渲染，全文连续编号(1)(2)(3)...，总数≥30个，零乱码，Word中OMML对象
- 表格：全部三线表，表题在表上方居中，短表不跨页，长表重复表头标注「(续)」
- 流程图：白色方框+黑边框1pt+直角+4-6字节点+正交箭头，matplotlib绘制
- 示意图：matplotlib绘制，线条清晰，标注完整，有图题

**九、正文排版规范**

- 正文宋体小四(12pt)，1.5倍行距，首行缩进2字符，两端对齐
- 一级标题居中黑体三号，二级三级左对齐，步骤标题加粗在行首不缩进
- 禁止大段空白和空白页，正文25-30页，全文匿名
- 参考文献标注[1][2]在行末，格式规范

**十、四件套输出规范**

| 格式 | 生成方式 |
| --- | --- |
| Word版 | python-docx + pandoc从LaTeX转换确保公式OMML |
| LaTeX源 | ctexart文档类，amsmath公式，graphicx图片 |

**十一、检测评估模式评估维度**

| 维度 | 标准要求 | 评估要点 |
| --- | --- | --- |
| 结构完整性 | 七章结构完整，无目录 | 章节是否完整，是否有目录，顺序是否正确 |
| 摘要质量 | 分段式，≥8数字，3创新点 | 摘要是否分段，是否有量化数字，是否有创新点 |
| 公式规范 | ≥30个，连续编号，零乱码 | 公式数量是否足够，编号是否连续，是否有乱码 |
| 图表规范 | 三线表，流程图规范，示意图丰富 | 表格是否三线表，流程图是否规范，是否有示意图 |
| 排版规范 | 宋体小四，1.5倍行距，标题格式正确 | 排版是否规范，标题格式是否正确，是否有大空白 |
| 创新性 | 至少1个真创新点，要素完整 | 是否有真创新，创新点是否具体，要素是否完整 |
| 学术规范 | 引用规范，匿名，无抄袭 | 引用是否规范，是否匿名，是否有学术不端 |
| 内容深度 | 四层分析，≥3组对比，检验完整 | 分析是否深入，对比是否充分，检验是否完整 |

**十二、本提示词整改能力（检测+自动整改）**

| 整改类型 | 可自动整改的内容 | 整改方式 |
| --- | --- | --- |
| P0致命 | 结构缺失(无问题分析/模型检验)、公式乱码、图片不显示、目录未删除 | 补充缺失章节+LaTeX重写公式+重新生成嵌入图片+删除目录 |
| P1重要 | 摘要无量化数字/创新点、结果分析只罗列数字、检验缺失、创新点不足 | 优化摘要(补充数字+创新点)+完善四层分析+补充检验+补充创新点 |

| 需手动 | 模型完全错误需要重构、核心结论错误、数据完全错误 | 给出论文重构方案和核心修改建议，确认后执行 |
