**数学建模国赛【问题求解】万能提示词**

**（检测/修改/撰写三模式完整版）**

**第3步：基于国奖版推荐模型和预处理后数据，进行建模、编程、求解，输出标准化交接包。支持检测评估模式。**

> 注：本提示词支持三种运行模式，自动检测适配：串联模式自动读取上一步「赛题分析+数据预处理标准化交接包」(国奖版推荐模型+创新点+预处理方案)并严格遵循其方案，不得随意降级或更换模型，完成后输出本步「建模求解标准化交接包」；独立模式在无交接包时自行简要完成赛题分析(确定国奖版推荐模型+创新点)和数据预处理(适配性处理)，再进行完整建模求解，输出质量与串联模式一致；检测整改模式对上传的已有成果（模型代码/求解结果/建模报告）先与获奖级标准多维度对比检测，再按优先级（P0→P1→P2）自动整改并复检，强制输出整改后成果+HTML整改报告（含检测结果总览、多维度评分可视化、分维度详细分析、标准对照表、优先级整改清单、整改前后对比、复检结果、底部信息栏），不得只检测不整改；如只需检测不需整改，则只输出HTML检测报告。评估等级：获奖级≥90 / 一等奖80-89 / 二等奖70-79 / 省一60-69 / 省二50-59 / 需大幅改进<50。无论哪种模式，输出质量标准一致，不得因模式不同而降低质量。

**检测整改模式运行细则**

- 触发条件：检测到输入为已有成果（模型代码/求解结果/建模报告），而非原始题目+数据时，自动进入检测评估+自动整改模式
- 功能：①将上传成果与获奖级标准多维度对比检测，评估模型选择合理性/创新点质量/公式推导严谨性/代码质量/结果分析深度/对比实验完整性/图片质量7个维度；②基于检测出的问题按提示词要求自动修改优化，消除问题
- 整改流程：①多维度检测→②生成HTML检测报告→③按优先级(P0→P1→P2)自动整改→④整改后复检→⑤输出整改后成果+HTML整改报告(含整改前后对比)
- 整改原则：能自动修改的自动修改（格式/排版/公式/图表/代码），不能自动修改的给出详细修改方案（如模型重构/创新点设计），不得只检测不整改
- 报告要求：HTML整改报告文件名「整改报告_成果名称.html」，报告最开始给出检测结果总览，然后列出整改清单+整改前后对比+复检结果
- 默认执行检测+自动整改一体化；如只需检测不需整改，则只输出HTML检测报告

**「建模求解标准化交接包」输出格式（强制）**

本步完成后必须输出以下结构化交接包（JSON格式），供下一步自动读取：

```json
{
  "各小问模型": "问题一:XXX模型; 问题二:XXX模型...",
  "核心公式": "公式编号+公式内容(LaTeX)",
  "代码路径": "code/solve.py",
  "求解结果": "问题一结果:XXX; 问题二结果:XXX...",
  "中间过程数据": "迭代日志/参数扫描/多方案对比",
  "创新点落实情况": "创新点1已落实(XXX改进); 创新点2已落实...",
  "检验建议": "问题一:灵敏度分析; 问题二:误差分析..."
}
```

**一、输入（三模式）**

- 串联模式：自动读取「赛题分析交接包」(国奖版推荐模型+创新点)+「预处理交接包」(预处理后数据+特征清单)
- 独立模式：题目+原始数据(自行简要赛题分析+预处理，确定推荐模型)
- 检测整改模式：上传的模型代码/求解结果/建模报告

**二、输出**

- 解题模式：①模型(含LaTeX公式) ②完整Python代码 ③求解结果 ④结果分析 ⑤中间过程数据 ⑥专业级图片 ⑦标准化交接包
- 检测整改模式：HTML整改报告（强制）

**三、获奖级建模求解标准**

- 三大创新方向必须落实：参数自适应/多模型对比/算法升级/同领域融合/跨领域迁移，至少选2个
- 必须避免的网红模型：盲目使用深度学习(如Transformer/GPT)解决小数据问题、盲目使用集成模型不说明理由
- 公式推导严谨：每步标注依据，不跳步，公式后有变量解释
- 图片专业级：配色专业(Nature风格)，标注完整，分辨率≥300dpi，中文字体正常
- 结果分析四层：呈现/规律/原因/建议，≥3组对比

**四、模型选择（串联模式铁律）**

串联模式下必须严格遵循赛题分析交接包中的国奖版推荐模型，不得随意降级或更换！独立模式下按六大原则自行选择：贴合题意/适度复杂/可解释性/可求解性/可创新性/可评价性

**五、五大创新方向（至少选2个）**

| 方向 | 示例 |
| --- | --- |
| 1 参数自适应 | 自适应学习率/滚动窗口自适应权重 |
| 2 多模型对比 | ≥3种模型对比择优 |
| 3 算法升级 | GA→AGA/DE；PSO→自适应权重PSO |
| 4 同领域融合 | ARIMA+LSTM残差修正；主客观赋权博弈论组合 |
| 5 跨领域迁移 | 物理熵增→系统有序度；生物Logistic→市场渗透 |

**六、模型建立规范**

- 步骤化推导：步骤1/步骤2...，每步有LaTeX公式，公式后紧跟变量解释
- 完整模型给出：优化类问题必须有完整的「模型给出」公式块(目标函数+s.t.所有约束)，用一个编号
- 原理示意图：每个模型建立前必须有1张原理/示意图(坐标系/几何关系/系统原理)
- 公式全文连续编号(1)(2)(3)...，总数≥30个，零乱码
- 公式字体规范：变量斜体，向量粗体，运算符正体，函数名正体

**七、编程求解规范**

- Python实现，固定随机种子，分模块(data_loader/model/solve/visualize)
- 先跑通基础模型验证逻辑正确性，再实现创新模型
- 算法步骤表格：使用启发式算法时必须用三线表列出步骤(Step1/Step2...)，每步有具体操作
- 记录求解日志：运行时间/迭代次数/收敛Gap/最优值
- 提供run_all.py一键运行脚本和requirements.txt

**八、图片质量规范（专业级）**

- 配色专业：Nature风格低饱和配色，禁止jet彩虹渐变和高饱和原色
- 标注完整：标题/坐标轴名称/单位/图例/数据标签，缺一不可
- 分辨率≥300dpi，保存为PNG格式，嵌入Word时宽度12-14cm
- 中文字体正常：matplotlib.use('Agg')+中文字体多级回退，axes.unicode_minus=False
- 多子图用gridspec布局，间距均匀，字号协调

**九、结果分析四层深度**

| 层次 | 内容 |
| --- | --- |
| 第一层 结果呈现 | 表格+图表，数据准确单位明确 |
| 第二层 规律发现 | 对比/趋势/结构分析 |
| 第三层 原因解释 | 结合题目背景和模型机制 |
| 第四层 建议提炼 | 具体可操作有优先级 |

禁止只罗列数字！每个结果表/图后必须有分析文字！每个问题必须≥3组对比分析！

**十、中间结果强制展示**

- 迭代算法每次迭代的关键变量值+收敛判断；参数扫描每个参数值对应输出；多方案对比各指标

**十二、本提示词整改能力（检测+自动整改）**

| 整改类型 | 可自动整改的内容 | 整改方式 |
| --- | --- | --- |
| P0致命 | 公式错误/乱码、代码无法运行、模型完全无法求解 | 修复公式(LaTeX重写)+修复代码bug+调整模型参数使可求解 |
