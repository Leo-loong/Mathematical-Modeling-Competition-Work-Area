**数学建模国赛【图表美化】万能提示词**

**（检测/修改/撰写三模式完整版）**

**第6步：对论文中所有图表(含示意图)进行专业美化，智能补充缺失图表，替换回论文，输出最终交付包。支持检测评估模式。**

> 注：三种运行模式自动适配：串联模式自动读取上一步「论文写作交接包」(论文路径+图表清单)+图表数据+代码并严格遵循其方案，完成后输出「图表美化标准化交接包」；独立模式无交接包时自行完成论文写作(简要)，再对所有图表进行完整美化，质量与串联一致；检测整改模式对上传的已有图表/图表代码/图表图片先与标准多维度对比检测，再按优先级（P0→P1→P2）自动整改并复检，强制输出整改后成果+HTML整改报告（8部分：检测结果总览/评分可视化/分维度分析/标准对照表/整改清单/整改前后对比/复检结果/底部信息栏），不得只检测不整改；只需检测则只输出HTML检测报告。评估等级：获奖级≥90 / 一等80-89 / 二等70-79 / 省一60-69 / 省二50-59 / 需大幅改进<50。三种模式质量标准一致，不得因模式不同降低质量。

**一、输入（三模式）**

- 串联模式：自动读取「论文写作交接包」(论文路径+图表清单)+图表数据+代码
- 独立模式：论文(含图表)+图表数据+代码(自行简要写作)
- 检测整改模式：上传的论文图表/图表代码/图表图片

**二、输出**

- 解题模式：①美化后所有图表 ②更新后的论文 ③智能补图 ④质量验证报告 ⑤最终交付包
- 检测整改模式：HTML整改报告（强制）

**三、五项不可逾越的硬性规则**

规则1【数据保真】：每个数据点/数值/标签/刻度必须与原图完全一致，不得擅自修改！规则2【类型保留】：原图是柱状图就保留柱状图，不得擅自转换类型。规则3【结论保留】：原图呈现的统计结论、显著性、趋势必须完全可见可读。规则4【比例保真】：柱高、扇区、坐标轴比例、颜色映射必须与原数据成比例。规则5【标注完整】：注释、图例、单位、来源、显著性符号必须全部保留并提升可读性。

**四、10条黄金设计法则**

①少即是多，去除不必要的装饰(3D效果/阴影/渐变)；②配色专业，用低饱和学术配色，禁高饱和原色和彩虹渐变；③标注完整，标题/坐标轴/单位/图例缺一不可；④字体统一，全文同一字体，字号协调；⑤网格克制，仅在需要时用浅色网格线；⑥对比清晰，不同数据系列用颜色+线型+标记三重区分；⑦比例正确，柱状图Y轴从0开始，颜色映射有colorbar；⑧分辨率达标，≥300dpi，PNG格式；⑨排版协调，多子图用gridspec，间距均匀；⑩中文字体正常，Agg+中文字体回退，负号正常。

**五、12套配色方案**

| 方案 | 色值 | 适用 |
| --- | --- | --- |
| Nature(推荐) | #0072B2 #009E73 #D55E00 #CC79A7 #F0E442 #56B4E9 | 通用首选 |
| Science | #1B4F72 #117A65 #B9770E #922B21 #6C3483 | 严肃学术 |
| 蓝橙绿 | #4472C4 #ED7D31 #70AD47 #C00000 #7030A0 | 工程类 |
| IEEE | #006BA4 #FF800E #ABABAB #595959 #5F9ED1 | 工程技术 |

| 连续色板-RdBu_r | #67001F→#053061 | 热力图(双向数据，center=0) |

禁止：tab10默认配色、jet彩虹渐变、高饱和原色(纯红/纯绿/纯蓝)、3D柱图/饼图、爆炸饼图、阴影效果、渐变填充！

配色选择决策树：分类数据→离散色板(Nature)；连续单向数据→viridis/plasma；连续双向数据→RdBu_r(center=0)；≥8类数据→避免用颜色区分，改用形状+小图。

**六、字体与排版规范**

字体：英文Arial/Helvetica，中文宋体/黑体，公式Times New Roman；字号：标题14-16pt，坐标轴标签10-12pt，刻度标签8-10pt，图例8-10pt；排版：图表居中，宽度12-14cm，图题在图下方居中，表题在表上方居中；网格仅在需要时使用，浅色虚线(#E0E0E0)，不喧宾夺主。

**七、图表元素与组件规范**

| 元素 | 规范 |
| --- | --- |
| Title(标题) | 图题在图下方，表题在表上方，居中，宋体五号加粗，格式「图1 XXX」 |
| Axis(坐标轴) | 有坐标轴名称+单位，刻度清晰，范围合理，柱状图Y轴从0开始 |
| Legend(图例) | 位置合理(不遮挡数据)，有边框，字号协调，多系列颜色+线型+标记三重区分 |
| Grid(网格) | 仅在需要时使用，浅色虚线，不喧宾夺主 |
| Marker(数据标记) | 大小6-8pt，形状区分(圆/方/三角/菱形)，不遮挡数据线 |
| Colorbar(颜色条) | 热力图/3D图必须有colorbar，有标签和单位 |

**八、各类图表美化要点**

柱状图：柱宽=间距60-80%，Y轴从0开始，柱顶标注数值，禁3D。折线图：线宽1.5pt，数据点标记，多系列颜色+线型+标记三重区分，95%CI置信带。散点图：alpha=0.6-0.8，趋势线虚线+95%CI，>500点用hexbin。热力图：双向RdBu_r center=0，单向viridis/plasma，禁jet，必须有colorbar。箱线图：alpha=0.5-0.7，中位线加粗白色，可叠加stripplot，标注n=XX。饼图：仅≤5类时用，起始90°，推荐环形图，禁3D/爆炸。雷达图：3-8维，填充alpha=0.15-0.25，数据标准化。

**九、流程图与示意图美化**

流程图：白色方框+黑边框1pt+直角+4-6字节点+正交箭头，matplotlib绘制。示意图：线条清晰(1.2-1.5pt)，标注完整(坐标轴/角度/距离/阴影区域)，字体清晰，有图题。示意图配色：黑白为主，如需强调用极浅灰色填充，禁止花哨配色。

**十、智能补图**

- 问题分析≥800字无流程图→补流程图(最高优先级)
- 模型建立无框架图/示意图→补示意图
- 结果分析有数值无图表→补柱状图/折线图/雷达图
- 灵敏度分析有表格无图→补热力图/龙卷风图

补图不虚构：数据必须来源于论文原文，禁止编造数值！

**十一、替换回论文与质量验证**

美化后图表替换回Word对应位置，保持原编号和图题，补图续接编号；图片嵌入型居中对齐，锁定纵横比，与图题同页无跨页。12项图片自检：代码实际生成/Agg+中文字体/负号正常/验证存在/Word可见/尺寸正确/同页/流程图风格/有标注/配色专业/全文统一/替换无误。

**十二、检测评估模式评估维度**

| 维度 | 标准要求 | 评估要点 |
| --- | --- | --- |
