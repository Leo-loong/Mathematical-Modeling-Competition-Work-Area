# 00_知识库使用说明

> 本文件夹是**静态知识库**：比赛前备好，比赛时只读。
> 目标：让 AI 在**一次对话内**读完所有文档并记住，之后所有回答都基于这些资料。

## 一、文档索引（给 AI 的定位表）

| 文件 | 内容 | 什么时候用 |
|---|---|---|
| `算法库/算法库_速查表.md` | 全部常用模型的适用场景、优缺点、Python 实现（最重要） | 赛题分析后选模型时 |
| `算法库/评价模型.md` | AHP、TOPSIS、熵权法详解 | 评价类问题 |
| `算法库/预测模型.md` | 回归、时间序列、灰色预测详解 | 预测类问题 |
| `算法库/优化模型.md` | 线性/整数/非线性规划、启发式算法详解 | 优化类问题 |
| `算法库/统计模型.md` | 假设检验、方差分析、聚类、PCA 详解 | 数据分析类问题 |
| `画图模板/matplotlib_中文画图模板.py` | 直接可用的画图代码（已处理中文字体） | 任何图表 |
| `画图模板/图表规范checklist.md` | 图表质量自查清单 | 出图时 |
| `编程工具/数据处理与算法速查.md` | pandas/numpy/scipy 常用代码片段（直接复制） | 处理数据时 |
| `论文写作/论文结构与摘要写法.md` | 论文完整结构、摘要五要素与句式模板 | 写论文时 |
| `论文写作/模型假设与灵敏度分析写法.md` | 假设句式库、灵敏度分析步骤与写法模板 | 写正文时 |
| `AI使用规范/AI使用声明模板.md` | 2025 竞赛 AI 使用声明（强制要求） | 交稿前 |
| `AI使用规范/提示词模板库.md` | 赛题分析/模型推荐/代码/润色/审稿等提示词 | 全程 |

## 二、给 AI 的读取指令（每次开新对话先发）

```
请完整阅读 00_知识库/ 目录下的所有 .md 和 .py 文件，然后总结：
1. 算法库包含哪些模型，各自的适用场景
2. 画图代码的中文字体设置方式
3. 论文格式规范与摘要写法要点
4. AI 使用声明的格式要求
确认理解后，后续所有回答请基于这些资料进行。
```

## 三、文档维护规则

- 每个文档控制在 **2000~3000 字**，方便 AI 一次读完。
- 统一用**表格**罗列方法、场景、优缺点——AI 读表格比读散文快得多。
- 比赛时如发现新方法/新坑，赛后补充回来，形成迭代。
- 比赛期间知识库**不要改动**（AI 读的是旧版本会导致混乱），新东西记到 `01_当前赛题/` 里。
