## 4. 傅里叶变换 FFT（找周期/频率，竞赛高频）

```python
# 输入：等间距采样信号 y（N 个点），采样间隔 dx
dx = np.mean(np.diff(x))
nfft = 2**int(np.ceil(np.log2(len(y))))     # 取 >= N 的 2 的幂，自动补零提分辨率（数据再长也不会被截断）
Y = np.fft.rfft(y * np.hanning(len(y)), n=nfft)   # 加窗减泄漏
freqs = np.fft.rfftfreq(nfft, d=dx)         # 频率轴（单位：1/dx 的单位）
amp = np.abs(Y)
# 找基频（排除直流和趋势泄漏：只保留 > 1/(N*dx*5) 的频率；趋势强时先做"去趋势"再 FFT）
m = freqs > 1/(len(y)*dx*5)
f0 = freqs[m][np.argmax(amp[m])]
print("基频:", f0, " 周期:", 1/f0)          # 周期单位 = dx 的单位
```

## 5. 找峰/找极值

from scipy.signal import find_peaks

# 先平滑再找峰，否则噪声全是"峰"

## 6. 相位提取（Hilbert 变换，用于干涉/振荡分析）

```python
from scipy.signal import hilbert

# 输入振荡信号 osc（已去趋势），提取瞬时相位
z = hilbert(osc)                      # 解析信号
phi = np.angle(z)                     # 相位
phi_unwrapped = np.unwrap(phi)        # 解卷绕（去跳变）
# 相位-自变量线性拟合，斜率即"相位随自变量变化率"
k, b = np.polyfit(x, phi_unwrapped, 1)
```

## 7. 曲线拟合（求参数）

```python
from scipy.optimize import curve_fit

# 定义模型：cos 拟合（周期信号参数估计）
def model(x, a0, a1, a2, f, phi):
    return a0 + a1*x + a2*np.cos(2*np.pi*f*x + phi)

p0 = [y.mean(), 0, (y.max()-y.min())/2, 1.0, 0.0]   # 初值很重要！
popt, pcov = curve_fit(model, x, y, p0=p0, maxfev=200000)
perr = np.sqrt(np.diag(pcov))         # 参数标准误差
print("参数:", popt, " 误差:", perr)
# 注意：初值离谱会拟合失败；多试几组初值
```

## 排错速查（比赛中 80% 的错误）

| 报错 | 原因 | 解决 |
|---|---|---|
| `ModuleNotFoundError` | 没装库 | `pip install 包名` |
| 中文显示方框 | 字体没设置 | 运行画图模板的 `set_chinese_font()` |
| `nan` 传播 | 数据有缺失/除零 | 先 `df.isnull().sum()`，加 `+1e-10` |
| 拟合失败/发散 | 初值差 | 换几组初值，或先用 FFT 估频率再拟合 |
| FFT 基频不对 | 没去趋势/没加窗 | 先去趋势再加 `np.hanning` 窗 |
| 数据点数不够 | 窗口参数超数据量 | 窗口设小些或改 padding |
