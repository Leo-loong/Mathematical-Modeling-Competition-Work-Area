# 预测模型详解

> 适用：预测未来值、趋势外推类问题。
> 套路：**先用简单模型（回归/灰色）拿到基线，再用复杂模型（ARIMA/ML）提升，最后对比误差选最优**。
> 建议先读 `算法库_速查表.md` 了解全貌。

## 1. 数据分割与误差指标（预测题必做）

```python
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

# 时间序列必须按时间顺序切分，不能随机切分！
train, test = data[:int(0.8*len(data))], data[int(0.8*len(data)):]

# 三件套指标：MAE、RMSE、R²（所有预测题都要报）
def report(y_true, y_pred):
    print(f"MAE = {mean_absolute_error(y_true, y_pred):.4f}")
    print(f"RMSE = {np.sqrt(mean_squared_error(y_true, y_pred)):.4f}")
    print(f"R²  = {r2_score(y_true, y_pred):.4f}")
```

**注意**：预测类题目论文必须包含「模型对比表」：每个模型的 MAE/RMSE/R² 放一张表。

## 2. 多元线性回归

**适用**：多自变量预测连续因变量；需要解释"哪个因素影响大"。

```python
from sklearn.linear_model import LinearRegression
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test  = scaler.transform(X_test)
model = LinearRegression().fit(X_train, y_train)
print("系数:", model.coef_)   # 标准化后系数可比较影响大小
```

**要点**：做**相关性热图**看共线性；用**标准化系数**说明因素重要性；报告 R² 和显著性（p 值）。

## 3. 灰色预测 GM(1,1)

**适用**：数据点少（≥4 个）、单调趋势、短期预测（**小样本神器，竞赛高频**）。

```python
import numpy as np

def gm11(x0, n_pred=5):
    """GM(1,1)：x0 原始序列，返回预测序列。"""
    x0 = np.asarray(x0, dtype=float)
    n = len(x0)
    # 累加生成
    x1 = np.cumsum(x0)
    # 均值生成 B 矩阵
    B = np.column_stack([-0.5 * (x1[:-1] + x1[1:]), np.ones(n-1)])
    y = x0[1:]
    # 最小二乘求参数 a, b
    a, b = np.linalg.lstsq(B, y, rcond=None)[0]
    # 累减还原预测
    t = np.arange(n + n_pred)
    x1_hat = (x0[0] - b/a) * np.exp(-a * t) + b/a
    x_hat = np.concatenate([[x0[0]], np.diff(x1_hat)])
    return x_hat, a, b
```

**要点**：必须做**后验差检验**（C = S2/S1 < 0.35 好，<0.5 勉强）和**残差检验**；只适合短期。

## 4. ARIMA 时间序列

**适用**：单变量时序、有明显自相关和季节成分、数据量 ≥ 30。

```python
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
import pmdarima as pm

# 自动定阶（p,d,q）——比赛推荐用自动
model = pm.auto_arima(train, seasonal=True, m=12, stepwise=True, trace=False)
print(model.order)
fit = ARIMA(train, order=model.order).fit()
pred = fit.forecast(len(test))
```

**要点**：先做**ADF 平稳性检验**（不平稳就差分）；看残差的 ACF 是否白噪声；图：原始+拟合+预测一张图。

## 5. 神经网络（MLP / LSTM）

**适用**：大样本（>1000）、非线性强、特征多。

```python
from sklearn.neural_network import MLPRegressor

model = MLPRegressor(hidden_layer_sizes=(64, 32), max_iter=2000,
                     early_stopping=True, random_state=42)
model.fit(X_train, y_train)
```

**LSTM（长时序）**：tensorflow/keras，数据量大才用。**如果数据 < 500 条，别用 LSTM，会过拟合被评委质疑。**

## 6. 竞赛实战套路（预测题万能流程）

```
1. 画时序图/散点图，看趋势、季节、异常
2. 数据分割（时序按顺序切 8:2）
3. 做 2~3 个模型：灰色（小样本）/ 回归 / ARIMA / ML
4. 全部算 MAE、RMSE、R²，画模型对比表
5. 选最优模型 + 解释为什么（数据特性 vs 模型假设）
6. 用全量数据重训，预测未来 N 期，画预测图（带置信区间更好）
7. 灵敏度分析（如训练集比例变化）
```

**加分项**：
- 预测图带**置信区间**（ARIMA 自带，回归用 bootstrap）。
- 多个模型做**加权组合预测**（权重由误差倒数确定）。
- 报告「模型假设与数据特性匹配性」——"数据呈指数增长，故灰色模型优于线性回归"。
