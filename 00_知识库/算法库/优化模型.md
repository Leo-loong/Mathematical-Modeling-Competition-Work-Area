# 优化模型详解

> 适用：选址、分配、调度、路径、资源利用最大化/最小化类问题。
> 套路：**建模（目标函数+约束）→ 判断线性/整数/非线性 → 小规模精确解 → 大规模启发式近似解 → 验证可行性**。
> 建议先读 `算法库_速查表.md` 了解全貌。

---

## 1. 建模规范（评委第一眼看这里）

优化模型必须三要素齐全，缺一不可：

```
1. 决策变量（x_ij：什么可调）
2. 目标函数（max/min 什么）
3. 约束条件（≤/=/≥ 什么，每条都要有理由）
```

**写法格式（论文里要这样排版）**：
```
min Z = Σ_i Σ_j c_ij · x_ij                    (目标函数)
s.t.
      Σ_j x_ij = 1,   ∀i                        (约束1：每个需求点只服务一次)
      Σ_i x_ij ≤ C_j,  ∀j                       (约束2：容量限制)
      x_ij ∈ {0,1}                              (约束3：0-1变量)
```

## 2. 线性规划 LP（scipy）

**适用**：目标函数与约束全线性、连续变量。

```python
from scipy.optimize import linprog

# min c^T x  s.t.  A_ub x <= b_ub,  A_eq x = b_eq,  bounds
c = [-3, -2]                      # 例：max 3x1+2x2 → 取负
A_ub = [[2, 1], [1, 1]]           # 2x1+x2<=100, x1+x2<=80
b_ub = [100, 80]
bounds = [(0, None), (0, None)]
res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method='highs')
print("最优值:", -res.fun, "最优解:", res.x)
```

**注意**：`max` 要转 `min`（取负）；scipy 默认 ≥ 0 用 bounds 控制。

## 3. 整数规划 / 0-1 规划（pulp，推荐）

**适用**：变量必须取整（台数、个数、是否选中）。

```python
import pulp

prob = pulp.LpProblem("选址", pulp.LpMinimize)
x = {i: pulp.LpVariable(f"x{i}", cat="Binary") for i in range(10)}      # 0-1变量
y = {j: pulp.LpVariable(f"y{j}", lowBound=0, cat=pulp.LpInteger)
     for j in range(5)}                                                 # 非负整数（必须指定 cat！）
prob += pulp.lpSum(c[i]*x[i] for i in range(10))                        # 目标
prob += pulp.lpSum(x[i] for i in range(10)) >= 3                        # 约束
prob.solve()
print(pulp.value(prob.objective))
for i in range(10):
    if pulp.value(x[i]) > 0.5:
        print("选中:", i)
```

**要点**：pulp 语法友好，写起来快；结果一定要**回代验证可行性**并汇报最优值。

## 4. 非线性规划

**适用**：目标或约束含非线性项（乘积、平方、指数）。

```python
from scipy.optimize import minimize

def obj(x):
    return x[0]**2 + x[1]**2 + x[0]*x[1]

cons = [{"type": "ineq", "fun": lambda x: 10 - x[0] - x[1]}]   # x0+x1<=10
res = minimize(obj, x0=[1, 1], method="SLSQP", constraints=cons)
print(res.fun, res.x)
```

**注意**：非线性规划只有**局部最优**——多用几个不同初值跑，取最优的；把初值敏感性写进论文（这就是灵敏度分析的一部分）。

## 5. 遗传算法 GA（大规模组合优化）

**适用**：整数/组合规模大（>30 变量），精确求解太慢。

```python
import numpy as np

def ga(fitness, dim, n_pop=50, n_gen=200, bounds=(0,1), is_binary=False):
    """简易遗传算法框架：fitness 为目标函数（越大越好）。"""
    if is_binary:
        pop = np.random.randint(0, 2, (n_pop, dim)).astype(float)
    else:
        lo, hi = bounds
        pop = np.random.uniform(lo, hi, (n_pop, dim))
    for _ in range(n_gen):
        fit = np.array([fitness(ind) for ind in pop])
        # 轮盘赌要求适应度非负：负值（如最小化问题取 -cost）要先平移
        fit = fit - fit.min() + 1e-10
        p = fit / fit.sum()
        idx = np.random.choice(n_pop, n_pop, p=p)
        new_pop = []
        for i in range(0, n_pop, 2):
            a, b = pop[idx[i]].copy(), pop[idx[i+1]].copy()
            if np.random.rand() < 0.8:  # 交叉
                k = np.random.randint(dim)
                a[k:], b[k:] = b[k:], a[k:]
            if np.random.rand() < 0.1:  # 变异
                a[np.random.randint(dim)] = 1 - a[np.random.randint(dim)] if is_binary else \
                    np.random.uniform(bounds[0], bounds[1])
            new_pop += [a, b]
        pop = np.array(new_pop)
    return max((fitness(ind) for ind in pop)), pop
```

**要点**：GA 没收敛指标，比赛要**对比多组参数**（种群数/代数）并汇报收敛曲线图；结果与 LP/pulp 精确解对比（小规模时）证明 GA 可用。

## 6. 竞赛实战套路（优化题万能流程）

```
1. 问题抽象：决策变量是什么？目标是什么？约束有哪些？
2. 判断类型：线性→LP；整数→pulp；非线性→SLSQP/GA
3. 小规模先精确求解（linprog/pulp），得到最优值作为"基准"
4. 大规模用启发式（GA/SA/PSO），画收敛曲线
5. 结果验证：回代约束检查可行性；用松弛下界验证近似解质量
6. 灵敏度分析：目标系数 ±10%、容量 ±10%，看最优解是否变化（稳定性分析）
7. 论文：模型三要素 + 求解过程 + 最优方案表 + 灵敏度表格
```

**加分项**：
- 画出**方案示意图**（布局图/路径图/甘特图）。
- 报告**求解时间**与**最优性差距**（"GA 结果比 LP 松弛下界高 2.3%"）。
- 多目标问题用**加权法或 NSGA-II**，给出 Pareto 前沿图。
