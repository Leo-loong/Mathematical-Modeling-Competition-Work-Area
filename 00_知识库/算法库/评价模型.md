# 评价模型详解

> 适用：评价、排名、评级、打分类问题。
> 组合套路：**熵权法（客观权重）或 AHP（主观权重）确定权重 → TOPSIS 排名**。
> 建议先读 `算法库_速查表.md` 了解全貌。

---

## 1. 层次分析法（AHP）

**适用**：指标 3~9 个、决策者主观偏好重要、无客观数据或数据难获取。

**步骤**：
1. 建立层次结构：目标层 → 准则层（指标）→ 方案层（待评价对象）。
2. 构造判断矩阵：两两比较指标重要性，用 1~9 标度。
3. 一致性检验：算一致性比例 CR = CI/RI < 0.1 才有效，否则重新调整判断矩阵。
4. 求权重：特征向量归一化。

**核心代码（含一致性检验）**：
```python
import numpy as np

def ahp_weight(A):
    """A: 判断矩阵 (n x n)。返回权重向量。"""
    n = A.shape[0]
    # 特征向量法
    w, v = np.linalg.eig(A)
    idx = np.argmax(w.real)
    weight = np.abs(v[:, idx].real)
    weight = weight / weight.sum()
    # 一致性检验
    CI = (w[idx].real - n) / (n - 1)
    RI = {1:0, 2:0, 3:0.58, 4:0.90, 5:1.12, 6:1.24, 7:1.32, 8:1.41, 9:1.45}
    CR = CI / RI[n]
    if CR >= 0.1:
        print(f"警告：CR={CR:.3f} >= 0.1，判断矩阵不一致，请调整")
    return weight, CR
```

**易错点**：判断矩阵必须满足"两两比较一致性"（a_ij · a_jk = a_ik 大致成立）；CR 超 0.1 必须重调。

## 2. 熵权法（客观权重）

**适用**：有完整数据、希望权重完全由数据决定、避免主观。**常与 TOPSIS 连用**。

**步骤**：
1. 数据归一化（正向指标越大越好：`x'=(x-min)/(max-min)`；负向指标越小越好：`x'=(max-x)/(max-min)`）。
2. 计算各指标熵值 e_j，信息效用 d_j = 1 − e_j。
3. 权重 w_j = d_j / Σd_j。

**核心代码**：
```python
import numpy as np

def entropy_weight(X):
    """X: (样本数, 指标数) 归一化后的数据，自动处理 0 值。"""
    n, m = X.shape
    # 归一化（正向）
    X = (X - X.min(axis=0)) / (X.max(axis=0) - X.min(axis=0) + 1e-10)
    # 归一化后加极小量避免 log(0)
    p = X / (X.sum(axis=0) + 1e-10)
    e = -np.sum(p * np.log(p + 1e-10), axis=0) / np.log(n)
    d = 1 - e
    w = d / d.sum()
    return w
```

**易错点**：归一化方向搞反；某列全相等时 log(0)（加 eps）；数据要先清洗。

## 3. TOPSIS（优劣解距离法）

**适用**：多方案、多指标的客观排序；数据已归一化并有权重。

**步骤**：
1. 加权规范化矩阵：`z_ij = x'_ij · w_j`。
2. 找正理想解 Z⁺（各列最大值）和负理想解 Z⁻（各列最小值）。
3. 算各方案到 Z⁺、Z⁻ 的欧氏距离 D⁺、D⁻。
4. 综合得分 C = D⁻/(D⁺+D⁻)，C 越大越优。

**核心代码**：
```python
import numpy as np

def topsis(X, w):
    """X: (样本, 指标) 已归一化；w: 权重向量。返回得分与排名。"""
    Z = X * w
    Zp = Z.max(axis=0); Zn = Z.min(axis=0)
    Dp = np.sqrt(((Z - Zp) ** 2).sum(axis=1))
    Dn = np.sqrt(((Z - Zn) ** 2).sum(axis=1))
    C = Dn / (Dp + Dn)
    return C, np.argsort(-C)
```

**易错点**：必须在 TOPSIS 前完成归一化和权重确定；正负向指标处理错会导致排名完全反了。

## 4. 灰色关联分析

**适用**：样本少、数据波动大、指标间关系不明。

**思路**：比较各方案序列与参考序列的几何相似度，关联度越大越优。
**代码**：十几行矩阵运算（关联系数 = (min+|Δ|)/(|Δ|+ρ·max)，ρ 取 0.5），按需让 AI 生成。

---

## 5. 模糊综合评价

**适用**：评语模糊（"好/中/差"）、定性指标多。
**思路**：隶属度矩阵 × 权重 → 综合评语。可配合 AHP 定权重。

## 评价类论文写法要点
1. **权重怎么来的要交代清楚**：主观（AHP 判断矩阵）还是客观（熵权法），为什么这样选。
2. **必须做灵敏度分析**：权重 ±10% 变化，排名是否稳定。
3. **结果表要好看**：最终排名表 + 得分柱状图，一图一表最加分。
4. **组合方法要说明理由**："单用 AHP 主观性强，单用熵权法忽略专家经验，故采用 AHP+熵权组合"。
