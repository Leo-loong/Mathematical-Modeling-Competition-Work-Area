# 算法库速查表（最重要的一张表）

> 用途：赛题分析结束后，根据问题类型从下表快速锁定候选模型。
> 用法：让 AI 读这张表，然后针对赛题推荐 2~3 个候选，说明理由，**由团队拍板**。
> 速查口诀：**评价看 AHP/TOPSIS，预测看回归/时序，优化看规划/启发式，数据看统计/聚类，机理看微分方程。**

---

## 一、先判断赛题类型

| 问题类型 | 典型问法 | 首选模型方向 |
|---|---|---|
| 评价类 | "对……进行评价/排名/评级" | 层次分析法、TOPSIS、熵权法、模糊综合评价 |
| 预测类 | "预测……的未来值/趋势" | 回归、时间序列、灰色 GM(1,1)、神经网络 |
| 优化类 | "如何安排/分配/调度使……最大/最小" | 线性规划、整数规划、遗传算法、模拟退火 |
| 统计分析类 | "分析……与……的关系/显著性" | 假设检验、方差分析、相关分析、回归 |
| 分类/聚类 | "把……分成几类" | K-means、层次聚类、决策树、随机森林 |
| 机理建模 | "建立……的数学模型"（物理/工程题） | 微分方程、偏微分方程、数值模拟 |
| 混合型（最常见） | 多个小问题，各问不同类型 | 每个子问题分别套用上述方法 |

## 二、全部模型速查表

### 评价类

| 模型 | 适用场景 | 优点 | 缺点 | Python 实现 |
|---|---|---|---|---|
| 层次分析法 AHP | 定性+定量结合、指标少（<9） | 简单直观、无需数据 | 主观性强、指标多时一致性难保证 | 手写即可（几十行） |
| TOPSIS | 有客观数据、多方案多指标排序 | 充分利用数据、结果稳定 | 需要权重（可配熵权法） | 手写或 scikit-criteria |
| 熵权法 | 确定指标权重（客观） | 完全由数据决定、避免主观 | 对数据分布敏感、需先归一化 | 手写（十几行） |
| 模糊综合评价 | 评价边界模糊、语言性指标 | 处理模糊性、结果直观 | 隶属函数选择主观 | 手写 |
| 灰色关联分析 | 小样本、数据不完整 | 小样本可用 | 需要分辨系数（取 0.5） | 手写 |

**黄金组合**：熵权法定权重 + TOPSIS 排名（客观且好写，评阅老师认可度高）。

### 预测类

| 模型 | 适用场景 | 优点 | 缺点 | Python 实现 |
|---|---|---|---|---|
| 多元线性回归 | 多自变量→连续因变量 | 可解释性强 | 要求线性关系 | sklearn.linear_model |
| 多项式回归 | 非线性但有趋势 | 简单 | 阶数高易过拟合 | numpy.polyfit |
| 指数平滑 | 单变量时间序列 | 简单、适合短中期 | 只捕捉趋势+季节 | statsmodels |
| ARIMA | 单变量时序、有自相关 | 经典、可解释 | 需平稳化、参数整定 | statsmodels.tsa |
| 灰色 GM(1,1) | 数据少（≥4 个点） | 小样本神器 | 只适合单调指数趋势 | 手写 |
| 神经网络/MLP | 大样本、非线性强 | 拟合能力强 | 黑箱、易过拟合 | sklearn.neural_network |
| LSTM/RNN | 长时序、模式复杂 | 时序特征捕捉好 | 需要大数据量+调参 | tensorflow/pytorch |
| 随机森林/XGBoost | 表格数据预测 | 精度高、抗过拟合 | 可解释性差 | sklearn / xgboost |

**竞赛套路**：多个模型都做 → 用误差指标（MAE/RMSE/R²）对比 → 选最好的，或做加权组合。

### 优化类

| 模型 | 适用场景 | 优点 | 缺点 | Python 实现 |
|---|---|---|---|---|
| 线性规划 LP | 目标函数和约束都是线性 | 有全局最优解、快 | 线性假设 | scipy.optimize.linprog |
| 整数规划/0-1 | 决策变量必须是整数 | 适合选址/分配/调度 | NP 难、大规模难解 | pulp、scipy.milp |
| 非线性规划 | 目标或约束非线性 | 适用范围广 | 局部最优、依赖初值 | scipy.optimize.minimize |
| 动态规划 | 多阶段决策 | 全局最优、思路清晰 | 状态爆炸 | 手写 |
| 遗传算法 GA | 大规模组合优化 | 全局搜索、不依赖初值 | 收敛慢、参数多 | 手写或 DEAP |
| 模拟退火 SA | 组合优化、跳出局部最优 | 简单通用 | 调参（退火计划） | 手写 |
| 粒子群 PSO | 连续优化 | 简单、收敛快 | 可能早熟 | 手写 |
| 多目标（NSGA-II） | 多个冲突目标 | 得到 Pareto 前沿 | 复杂、计算量大 | pymoo、DEAP |

**竞赛套路**：小规模问题精确求解（linprog/pulp），大规模问题启发式算法 + 与下界比较验证。

### 统计与数据挖掘

| 模型 | 适用场景 | 优点 | 缺点 | Python 实现 |
|---|---|---|---|---|
| 描述统计 | 数据概况 | 必做第一步 | — | pandas.describe() |
| 假设检验（t 检验等） | 两组数据是否有显著差异 | 严谨 | 需满足正态性假设 | scipy.stats |
| 方差分析 ANOVA | 多组均值比较 | 判断因素影响 | 需正态+方差齐性 | scipy.stats.f_oneway |
| 相关分析 | 变量间线性相关程度 | 简单 | 只反映线性 | scipy.stats.pearsonr |
| K-means 聚类 | 大样本自动分群 | 快、简单 | 要指定 K、对异常敏感 | sklearn.cluster.KMeans |
| 层次聚类 | 小样本、需要谱系图 | 无需指定 K | 计算量大 | scipy.cluster |
| 主成分 PCA | 降维、消除多重共线性 | 提取主要信息 | 解释性下降 | sklearn.decomposition |
| 决策树/随机森林 | 分类、可解释 | 不用预处理 | 过拟合（随机森林解决） | sklearn.tree |

### 机理/连续建模

| 模型 | 适用场景 | 优点 | 缺点 | Python 实现 |
|---|---|---|---|---|
| 常微分方程 ODE | 变化率建模（人口、传热、运动） | 机理清晰 | 参数难定 | scipy.integrate.solve_ivp |
| 偏微分方程 PDE | 场问题（热传导、流体） | 精确 | 求解难 | fenics / 有限差分手写 |
| 蒙特卡洛模拟 | 随机过程、数值积分 | 简单通用 | 收敛慢 | numpy.random |
| 有限差分/有限元 | 连续场数值解 | 通用 | 需要数值功底 | 手写 / fenics |

## 三、模型选择决策树（直接抄用）

```
拿到子问题 → 问自己：
1. 有物理机理吗？        → 有 → 微分方程/机理模型
2. 是评价还是排名？      → 是 → AHP/熵权+TOPSIS
3. 是预测未来值？        → 是 → 数据量<30 → 灰色；有季节 → ARIMA；大样本 → 机器学习
4. 是找最优方案？        → 是 → 规模小 → 规划；规模大 → 启发式
5. 是分类/聚类？         → 是 → 有标签 → 分类；无标签 → 聚类
6. 只是找关系/看显著性？ → 是 → 回归/检验
7. 都不是 → 把问题重新描述一遍，问 AI 更详细
```

## 四、竞赛常用「加分技巧」

1. **多模型对比**：同一问题用 2~3 个模型做，比单一模型有说服力得多。
2. **灵敏度分析**：任何模型都做参数扰动分析（±10%、±20%），这是必写部分。
3. **模型检验**：回归看 R²；时序看残差；优化看可行性；评价看一致性。
4. **误差指标表**：把所有模型的 MAE / RMSE / R² 放一张表里对比，评委最喜欢看。
5. **数据预处理必做**：缺失值、异常值、标准化、归一化——不做会扣印象分。
