# 算法技巧补充：小众高分算法与避坑算法

> 整理自外部讲义《十大小众高分算法》《十大避坑算法》，与 `00_知识库/算法库/算法库_速查表.md`（下称速查表）搭配使用。本文定位是补充：速查表已覆盖的算法只写要点并注明"速查表已有"，真正新增的内容才有阅读价值。
> 用前须知：避坑讲义与速查表存在冲突——速查表首推的 AHP、GM(1,1)、BP、K-means、模糊综合评价、多元线性回归、熵权法均在避坑名单上。处理原则：**这些方法不再单独作为核心方法**，改作组合成分、对比基线或小场景工具（见第二部分）。

## 一、小众高分算法（10 个）

核心思想：以一个主算法为核心，辅以一至两个算法做对比或融合，形成"方法创新 + 效果验证"闭环。

| 算法 | 类别 | 适用题型 | 知识库状态 |
|---|---|---|---|
| 1 LSTM | 深度学习/时序 | 时序预测、多变量回归 | 速查表已有，此处给使用要点 |
| 2 LightGBM | 集成学习 | 结构化分类/回归 | 速查表已有同族（XGBoost/随机森林），本条为新增 |
| 3 图神经网络 GNN | 深度学习/关系 | 网络结构建模、传播模拟 | 新增 |
| 4 NSGA-II | 智能优化 | 多目标优化 | 速查表已有 |
| 5 高斯过程回归 GPR | 贝叶斯非参数 | 小样本回归、不确定性量化 | 新增 |
| 6 孤立森林 | 无监督/异常检测 | 离群点、故障、欺诈检测 | 新增 |
| 7 DBSCAN | 无监督/密度聚类 | 空间聚类、任意形状簇 | 新增 |
| 8 元胞自动机 CA | 复杂系统/模拟 | 传播、交通流、城市扩张模拟 | 新增 |
| 9 Copula 函数 | 统计/相依结构 | 多变量联合分布、风险度量 | 新增 |
| 10 小波-LSTM（WLSTM） | 混合模型 | 非平稳时序预测、信号去噪 | 新增 |

### 1. LSTM 长短期记忆网络（速查表已有）

| 项 | 内容 |
|---|---|
| 适用题型 | C 题时序预测（疫情、交通流量、能源负荷）、多变量回归、动态系统演化预测 |
| 核心思路 | 输入门/遗忘门/输出门门控，细胞状态跨时间步传递，解决 RNN 梯度消失，捕捉长期依赖 |
| 实现要点 | keras/tensorflow 或 pytorch；可叠加注意力机制，可视化各时间步贡献权重；与 ARIMA、Prophet 做 MSE/MAE 对比表；滚动验证增强可信度 |
| 注意点 | 门控公式推导可展开写；拟合曲线图是主要视觉亮点；数据量小则易过拟合（知识库提示数据不足 500 条慎用） |

### 2. LightGBM（速查表已有 XGBoost/随机森林同族）

| 项 | 内容 |
|---|---|
| 适用题型 | C 题分类（疾病诊断、客户流失、信用评分）、结构化数据回归（房价、销量、设备寿命）、特征重要性排序 |
| 核心思路 | 直方图算法降低内存与计算量；Leaf-wise 按叶子生长比 Level-wise 精度高；GOSS 单边梯度采样保留大梯度样本，提速不降精度 |
| 实现要点 | lightgbm 包；原生支持缺失值、类别特征、早停和 GPU；五折交叉验证报告均值与标准差；与随机森林、SVM、逻辑回归对比 AUC/F1 |
| 注意点 | 输出特征重要性排序图；用 SHAP 值做可解释性分析（区别于 XGBoost 的差异点是理论叙述重点） |

### 3. 图神经网络 GNN（GCN/GAT，新增）

| 项 | 内容 |
|---|---|
| 适用题型 | B 题网络优化（交通、通信、电力网络）、传播模拟（疫情扩散、信息传播、谣言溯源）、C 题关系数据分类 |
| 核心思路 | 消息传递机制聚合邻居节点信息，同时利用节点特征与拓扑结构；GCN 基于谱卷积，GAT 基于注意力机制 |
| 实现要点 | 常用框架：PyTorch Geometric 或 DGL；半监督即可训练，少量标注节点可用；堆叠多层捕捉高阶结构 |
| 注意点 | 对比实验要做"忽略拓扑的 MLP"，证明结构信息的价值（消融实验）；GAT 注意力权重可画边热力图；网络拓扑图按分类结果着色 |

### 4. NSGA-II 非支配排序遗传算法（速查表已有）

| 项 | 内容 |
|---|---|
| 适用题型 | B 题资源分配（物资调配、生产调度）、路径规划（VRP/TSP）、设施选址、投资组合；多目标参数校准 |
| 核心思路 | 快速非支配排序 + 拥挤度估计保持种群多样性 + 精英保留，一次运行得一组 Pareto 最优解，无需求导 |
| 实现要点 | pymoo、DEAP（速查表已列）；画二维/三维 Pareto 前沿散点图 |
| 注意点 | 多数队伍只做单目标加权求和，权重主观且只得一个解；与加权求和法对比可凸显优势；用 TOPSIS 从 Pareto 集选出最终方案；对种群规模、交叉率做敏感性分析 |

### 5. 高斯过程回归 GPR（新增）

| 项 | 内容 |
|---|---|
| 适用题型 | A 题小样本回归（实验数据拟合、物理量预测、工程参数估计）、需不确定性量化的预测、代理模型替代昂贵仿真 |
| 核心思路 | 在函数空间上设高斯过程先验，结合观测得后验；核函数刻画样本相似度；天然输出预测均值与方差（95% 置信带） |
| 实现要点 | scikit-learn 的 gaussian_process；核函数选 RBF、Matern、Periodic 等，可做核对比实验；用对数边际似然优化超参数 |
| 注意点 | 小样本下优于参数模型与神经网络（后者易过拟合）；"预测曲线 + 置信区间阴影图"是最有辨识度的可视化；与线性回归、SVR 对比突出不确定性输出优势 |

### 6. 孤立森林 Isolation Forest（新增）

| 项 | 内容 |
|---|---|
| 适用题型 | 数据清洗与离群点检测（传感器异常、录入错误、异常交易）、故障检测、欺诈检测 |
| 核心思路 | 异常点"少数且不同"，随机切分下更易被孤立；在随机二叉树上平均路径长度更短，据此打异常分数 |
| 实现要点 | scikit-learn 的 ensemble.IsolationForest；画异常分数分布图并标注阈值 |
| 注意点 | 无监督、无需标注；线性时间复杂度；高维友好、不依赖正态分布假设——对比对象是只适用单变量正态数据的 3σ 原则和箱线图；可做 PCA 降维后可视化异常点，及异常移除前后模型性能对比 |

### 7. DBSCAN 密度聚类（新增）

| 项 | 内容 |
|---|---|
| 适用题型 | B 题空间聚类（城市功能分区、犯罪热点、地震区划）、C 题客户分群、地理空间分析、图像分割 |
| 核心思路 | 核心点/边界点/噪声点划分；密度相连的区域成一簇；任意形状簇，自动识别噪声，无需预设簇数 |
| 实现要点 | scikit-learn 的 cluster.DBSCAN；参数 eps 与 MinPts 用 k-distance 图科学确定 |
| 注意点 | 对比对象是 K-means（球形簇假设、需指定 K、对噪声与初值敏感）；可视化"彩色簇 + 黑色噪声点"；结合经纬度做地图可视化 |

### 8. 元胞自动机 CA（新增）

| 项 | 内容 |
|---|---|
| 适用题型 | A 题传播模拟（疫情、森林火灾、谣言扩散）、交通流模拟、城市扩张、人群疏散 |
| 核心思路 | 时间、空间、状态全离散；元胞按自身与邻居状态依统一局部规则同步更新；简单规则涌现复杂全局行为 |
| 实现要点 | numpy 手写网格迭代即可，天然适合并行/GPU；制作 t=0、10、20 等时刻演化热力图序列 |
| 注意点 | 对比对象是微分方程模型——后者假设均匀混合、难以处理空间异质性；与 SIR 等模型对比展示空间异质性影响；对感染率、传播半径做敏感性分析，引入随机因素做蒙特卡洛平均 |

### 9. Copula 函数（新增）

| 项 | 内容 |
|---|---|
| 适用题型 | C 题多变量风险评估（金融、灾害损失、环境风险）、极端事件同现概率、多物理量联合分布（如风速与波高）、组合 VaR |
| 核心思路 | Sklar 定理保证：把各变量的边缘分布与相依结构完全分离再连成联合分布；Gaussian、t、Clayton（下尾）、Gumbel（上尾）各有不同相依特征 |
| 实现要点 | 讲义未指定代码库，需自行选用统计包或手写；用 AIC/BIC 选择最优 Copula；蒙特卡洛抽样做情景分析 |
| 注意点 | 对比对象是 Pearson 相关——只能捕捉线性关系、对极端值敏感、无法刻画尾部相依；画 Copula 密度等高线图对比各族差异；基于联合分布计算 VaR/CVaR 并与正态假设对比 |

### 10. 小波-LSTM 融合模型 WLSTM（新增）

| 项 | 内容 |
|---|---|
| 适用题型 | A/C 题非平稳时序（能源负荷、气象、水质、股价、交通流量）、含噪信号的预测与去噪 |
| 核心思路 | "分解-预测-重构"：离散小波变换把非平稳序列分解为多个频率子序列，各子序列分别建 LSTM，再小波重构得最终预测；各频率对应趋势、周期、噪声，可解释性强 |
| 实现要点 | 小波变换库 + LSTM 框架组合成管线；可试 db4、sym8、coif3 等小波基与不同分解层数；可扩展为 CEEMDAN-LSTM、VMD-LSTM |
| 注意点 | 讲义称精度通常优于单一 LSTM（未给量化数值，需自己跑对比验证）；画小波分解图（原始信号 + 近似系数 + 各层细节系数）；与单一 LSTM、ARIMA 用 MAPE 对比；分解阶段可加入小波阈值去噪 |

### 选型速查（按赛题任务）

| 赛题核心任务 | 首选 | 备选或对比 | 融合建议 |
|---|---|---|---|
| 时序预测（平稳） | LSTM | ARIMA、Prophet | LSTM + 注意力 |
| 时序预测（非平稳） | 小波-LSTM | 单一 LSTM | 小波分解 + LSTM + 注意力 |
| 结构化数据分类 | LightGBM | XGBoost、随机森林 | LightGBM + SHAP 可解释 |
| 小样本回归 + 不确定性 | GPR | 贝叶斯线性回归 | GPR + 主动学习采样 |
| 网络/关系数据建模 | GNN | 传统图论算法 | GCN/GAT + 网络特征工程 |
| 多目标优化 | NSGA-II | 加权求和法 | NSGA-II + TOPSIS 决策 |
| 异常检测/离群点 | 孤立森林 | 3σ 原则、箱线图 | 孤立森林 + 特征工程 |
| 空间/密度聚类 | DBSCAN | K-means、HDBSCAN | DBSCAN + 地理可视化 |
| 复杂系统时空模拟 | 元胞自动机 | 微分方程模型 | CA + 蒙特卡洛随机模拟 |
| 多变量风险/相关性 | Copula | Pearson 相关 | Copula + VaR/CVaR 度量 |

## 二、十大避坑算法

避坑核心逻辑不是"老算法不能用"，而是**不能单独作为核心方法**；把老算法放进对比实验当基线、用更好的方法在相同数据上击败它，反而能凸显优势。选算法原则：由问题特征决定，不由代码难度决定；优先选能讲清原理、能做完整验证、能解释结果的方法。

| 算法 | 是什么坑 | 为什么 | 怎么避免 |
|---|---|---|---|
| 层次分析法 AHP | 主观赋权、判断矩阵靠拍脑袋；一致性检验 CR<0.1 几乎靠手动调整"调"到通过，等于造假 | 权重毫无客观性 | CRITIC 法、TOPSIS、熵权 + CRITIC 组合赋权 |
| 灰色预测 GM(1,1) | 假设数据指数增长，现实几乎不存在纯指数增长数据；只适合 1-2 步短期预测 | 超过 3 步误差急剧放大；无法融合多变量、信息利用率低 | LSTM、Prophet、小波 + LSTM |
| BP 神经网络 | 层数、神经元数、学习率全靠试；小样本必过拟合 | 黑箱不可解释，训练误差低而测试误差高、结果不稳定 | LightGBM、GPR、LSTM（加正则化） |
| 支持向量机 SVM | 大样本训练慢（约 O(n²) 至 O(n³)）；核函数靠猜、C 与 gamma 调参空间大 | 赛期短调不好；多分类靠一对多拆解、效率低 | LightGBM、XGBoost、随机森林 |
| K-means 聚类 | 必须预设 K；假设球形簇，环形、月牙形数据失效 | 对初始中心与噪声敏感，结果不稳定 | DBSCAN、层次聚类、高斯混合模型 |
| 模糊综合评价 | 隶属函数（梯形/三角/正态）全凭感觉；权重又落回 AHP 主观赋权 | 合成算子"哪个好看用哪个"；各等级隶属度接近、区分度差 | TOPSIS、灰色关联分析、VIKOR |
| 多元线性回归 | 线性假设过强、无建模深度；对异常值极度敏感 | 一个极端值拽偏整个回归面；R² 低、残差有模式是常态 | LightGBM、GPR、分位数回归 |
| 朴素贝叶斯 | 特征独立假设几乎不成立（如"数学"与"建模"相关、血压与年龄相关） | 概率估计失真；零概率问题；多数分类任务精度垫底 | LightGBM、逻辑回归、随机森林 |
| 单棵决策树 ID3/C4.5 | 过拟合是天性，一直分裂到叶子纯净等于记住噪声；数据微变树结构大变 | 信息增益偏向多值特征、剪枝难调；已被集成方法取代 | 随机森林、LightGBM、XGBoost |
| 熵权法（单独用） | "差异大 ≠ 重要"：评价学生时身高差异可能大于专业课成绩，熵权会给身高更高权重 | 极端值主导权重；标准化方法选择又引入主观性 | CRITIC 法、熵权 + AHP 组合赋权、TOPSIS |

### 与现有速查表的关系（重要）

1. **知识库速查表推荐的多个方法在避坑名单上**：AHP、GM(1,1)、神经网络/MLP、K-means、模糊综合评价、多元线性回归、熵权法。速查表的"黄金组合"（熵权定权 + TOPSIS 排名）与避坑意见并不矛盾——被批的是熵权**单独**赋权与 AHP 单独做主方法；组合使用、把权重当辅助手段仍可。
2. **速查表缺避坑提示的**：SVM、朴素贝叶斯、单棵决策树在速查表中未出现，本次新增"不宜单独作核心方法"的警示。
3. **避坑表替方案里出现、速查表未收录的新候选**：CRITIC 法、VIKOR 法、分位数回归、高斯混合模型、HDBSCAN、Prophet。讲义未展开细节，需要用时另查资料补充，不建议直接上手。

## 三、使用策略（两讲义的共性结论）

| 策略 | 要点 |
|---|---|
| 一主一辅 | 主算法 + 1 至 2 个备选做对比或融合；融合模型（小波+LSTM、GNN+注意力、NSGA-II+TOPSIS）天然带方法创新标签 |
| 理论推导 | 每个核心算法至少展开 2-3 个公式推导（如 LSTM 门控、GPR 核函数），结合赛题解释参数物理含义；只写"调用某库训练"档次很低 |
| 效果对比 | 与至少两个传统或常用方法在同一数据集对比，用 MSE、MAE、R²、AUC、F1 等量化指标 + 图表展示 |
| 可视化 | 每图配清晰标题、坐标轴标签、图例；各算法标志性图：LSTM 拟合曲线、GPR 置信带阴影、GNN 拓扑着色图、NSGA-II 的 Pareto 前沿、DBSCAN 任意形状簇、CA 热力图序列 |
| 稳健性 | 对关键参数做扰动实验（LSTM 隐藏层维度、DBSCAN 的 eps、NSGA-II 种群规模），展示结论在合理参数范围内稳定，证明结果非"调参调出来的" |
