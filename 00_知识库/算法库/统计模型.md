# 统计模型与数据处理详解

> 适用：数据分析类问题、做模型前的探索性分析、结果显著性验证。
> 铁律：**任何建模之前先做探索性数据分析（EDA）**——画图 + 描述统计 + 相关性，这一步能避免 80% 的模型选错。
> 建议先读 `算法库_速查表.md` 了解全貌。

## 1. 探索性数据分析 EDA（必做，写进论文）

```python
import pandas as pd
import numpy as np

df = pd.read_excel("附件.xlsx")
print(df.info())              # 数据类型、缺失情况
print(df.describe())          # 描述统计：均值/标准差/分位数
print(df.isnull().sum())      # 缺失值统计
print(df.corr())              # 相关系数矩阵
```

**必画图**：
- 每个变量的直方图/箱线图（看分布和异常）
- 变量间散点图矩阵（pandas `scatter_matrix`）
- 相关系数热图（`seaborn.heatmap`）
- 时间序列画折线图

**论文里写一段「数据概况」**：数据量、缺失、异常、分布特点——评委看了就知道你们认真做了。

## 2. 缺失值与异常值处理

| 情况 | 处理方式 | 适用 |
|---|---|---|
| 缺失少（<5%） | 直接删行 | 简单 |
| 缺失中等 | 均值/中位数/众数填充 | 常用 |
| 时序缺失 | 前后插值（线性/样条） | 趋势数据 |
| 重要变量缺失 | 用回归/ML 预测填充 | 慎用，说明理由 |
| 异常值 | 3σ 原则 / 箱线图 IQR 法识别，删除或 Winsorize 截断 | 必须说明依据 |

**代码**：
```python
# 3σ 剔除异常
mu, std = df["col"].mean(), df["col"].std()
df = df[(df["col"] - mu).abs() < 3 * std]

# 线性插值
df["col"] = df["col"].interpolate(method="linear")
```

**铁律**：任何剔除/填充都要在论文里写明**处理了多少条、依据什么原则**。

## 3. 归一化与标准化（建模前的标准动作）

```python
from sklearn.preprocessing import MinMaxScaler, StandardScaler

# 归一化（0~1）：适合距离类算法（聚类、TOPSIS）
df_norm = MinMaxScaler().fit_transform(df)
# 标准化（均值0方差1）：适合回归、PCA、神经网络
df_std = StandardScaler().fit_transform(df)
```

**注意**：测试集要用训练集拟合好的 scaler 转换（`fit_transform` 只用于训练集，测试集用 `transform`）。

## 4. 假设检验（判断差异是否显著）

| 场景 | 检验方法 | 代码 |
|---|---|---|
| 两组均值比较 | 独立样本 t 检验 | `scipy.stats.ttest_ind(a, b)` |
| 配对数据 | 配对 t 检验 | `scipy.stats.ttest_rel(a, b)` |
| 多组均值比较 | 方差分析 ANOVA | `scipy.stats.f_oneway(*groups)` |
| 两个变量相关 | Pearson 相关 | `scipy.stats.pearsonr(x, y)` |
| 分布是否正态 | Shapiro 检验 | `scipy.stats.shapiro(x)` |

**写法模板（论文）**：
> "对 A、B 两组数据做独立样本 t 检验，得 t = 3.21，p = 0.002 < 0.05，表明两组存在显著差异（显著性水平 α = 0.05）。"

**易错点**：p < 0.05 才显著；先做正态性检验（不满足就用 Mann-Whitney U 非参数检验）。

## 5. 聚类分析（K-means）

```python
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

X = StandardScaler().fit_transform(df)
# 用肘部法则/轮廓系数定 K
from sklearn.metrics import silhouette_score
ks = range(2, 9)
scores = [silhouette_score(X, KMeans(n_clusters=k, n_init=10).fit_predict(X)) for k in ks]
best_k = ks[np.argmax(scores)]
model = KMeans(n_clusters=best_k, n_init=10, random_state=42).fit(X)
df["cluster"] = model.labels_
```

**论文写法**：轮廓系数图（选 K 的依据）+ 聚类结果散点图（降维后画）+ 各簇特征均值表（给簇命名）。

## 6. 主成分分析 PCA（降维）

```python
from sklearn.decomposition import PCA

X = StandardScaler().fit_transform(df)
pca = PCA(n_components=0.95)   # 保留 95% 信息量
X_pca = pca.fit_transform(X)
print("方差解释率:", pca.explained_variance_ratio_)
```

**论文写法**：碎石图（各主成分方差占比）+ 累计贡献率表 + 载荷矩阵（解释每个主成分含义）。**注意**：PCA 前必须标准化。

## 7. 统计题论文结构模板

```
1. 数据概况（描述统计表 + EDA 图）
2. 数据预处理（缺失/异常/标准化，写明数量与依据）
3. 分析方法（检验/聚类/PCA，说明为什么选这个方法）
4. 结果（统计量 + p 值表 / 聚类结果表 / 主成分载荷表）
5. 结论（显著性判断、分类命名、维度解释）
```

**加分项**：所有统计检验都报**检验统计量 + p 值 + 显著性结论**三件套；聚类结果画**降维散点图**并给每簇起名字（"高消费型""保守型"等）。
