# 论文图表美化规范（精炼版）

提炼自《数学建模论文图表 AI 国奖级美化提示词 v3.0》（原文约 8 万字符，宣称依据 Nature / Science / Lancet / Cell 等期刊图表规范整理）。本版只保留可执行规范与数值，删去营销话术。原文是"提示词/规范对照表"性质，非绘图教程，故本版同性质：作画图前自查清单、画图参数对照表、以及向 AI 提需求的提示词骨架使用。

## 一、总原则：美化不改数据（先于一切规则）

1. 五项硬性规则（不可逾越）：
   - 数据保真：数据点、数值、标签、刻度与原图/原数据完全一致；原图有错只能标注提示，不得擅自改。
   - 类型保留：原是什么图就是什么图，不得把柱状图改饼图等。
   - 结论保留：统计结论、显著性、趋势、聚类信息必须完整可读。
   - 比例保真：柱高、扇区、坐标比例、颜色映射必须与数据成比例。
   - 标注完整：注释、图例、单位、来源、显著性符号（ns、\*、\*\*、\*\*\*）全部保留。
2. 十条黄金法则中，第 1-5 条为硬约束，6-10 条为推荐：
   | 号 | 原则 | 要点 |
   |---|---|---|
   | 1 | 数据至上 | 深色数据点 + 浅色背景，配色让数据视觉权重最高 |
   | 2 | 少即是多 | 去掉顶/右边框、冗余网格、高饱和背景；留白即专业 |
   | 3 | 色彩克制 | 全图主色 3-5 种；优先色盲友好色板（viridis/plasma/RdBu）；避免红绿搭配 |
   | 4 | 对比鲜明 | 数据与背景明度差约 7:1；轴线/标签用深灰 #333 而非纯黑 |
   | 5 | 字体一致 | 全图 1-2 种字体；中文思源黑体/微软雅黑，英文 Arial/Helvetica；字号梯度不超过 3 级 |
   | 6 | 对齐精确 | 多子图严格对齐（坐标、colorbar、图例一致）；图例框不超过图区 25% |
   | 7 | 标注层级 | 主标题>副标题>轴标签>刻度>数据标签>脚注；字号按 2:1.5:1.2:1:0.85 递减 |
   | 8 | 比例正确 | 单图 4:3 或 3:2；多子图 16:9 或 2:1；热力图 1:1 方形 |
   | 9 | 可访问性 | 色盲友好、灰度打印仍可区分 |
   | 10 | 可复现性 | 提供完整绘图代码与参数说明，读者能 100% 复现 |

## 二、通用硬性规范数值速查

### 1. 字号与字体（正文图内元素，单位 pt）
| 元素 | 字号 | 字重 | 颜色 |
|---|---|---|---|
| 主标题 | 14-16 | Bold | #000000 |
| 副标题 | 11-12 | Regular | #333333 |
| 轴标签 x/y | 10-11 | Regular | #333333 |
| 刻度标签 | 9-10 | Regular | #555555 |
| 图例 | 9-10 | Regular | #333333 |
| 数据标签 | 8-9 | Regular | #222222 |
| 脚注/来源 | 8 | Italic | #666666 |
| 公式（LaTeX 渲染） | 10 | Italic | #000000 |

底线：图中最小字号不小于 7 pt（低于 6 pt 即不合格），推荐 8-10 pt。

### 2. 线条、网格与边框
- 主线宽 1.5-2.0 pt；网格线 0.5 pt；标记大小 4-8 pt。
- 默认去掉上边框和右边框；保留左/下边框，颜色淡灰 #999999、线宽 0.5-1.0 pt（参考实现用 #333333）。
- 只显示主网格线（minor grid 仅精细数据用）；通常只画 Y 向网格、X 向可省；样式 `linestyle='--'` 或 `':'`，颜色 #CCCCCC/#E0E0E0，alpha=0.4-0.6；`set_axisbelow(True)` 让网格在数据下层。
- 主图区背景纯白；刻度方向全图统一；刻度密度每轴 4-8 个主刻度为宜。
- 轴标签必须带单位，如 "Temperature (°C)"；对数轴须注明 "log scale" 并加 minor ticks，只有跨数量级数据才用对数。
- 图例放右上/底部/图外，不遮挡数据；无边框或淡灰边框；半透明白底（alpha≈0.85）；顺序与数据系列一致；图例框不超过图区 25%。

### 3. 子图与布局
- 子图间距 wspace 0.25-0.4、hspace 0.3-0.5。
- colorbar 宽度 0.3-0.5 cm、高度为主图 60-80%；标签含单位、字号 9-10 pt；主刻度 3-7 个；分类图用 BoundaryNorm + 离散 colorbar。
- 标题必须含信息量：研究对象 + 关键变量 + 区域/时间 + 方法；禁止用 "Figure 1""Results" 式空标题。

### 4. 导出参数
| 参数 | 要求 |
|---|---|
| DPI | 不低于 300（出版级）；屏幕预览可用 150 |
| 格式 | PDF/SVG 矢量优先，其次 PNG；个别期刊要求 TIFF（600 DPI） |
| 颜色空间 | RGB |
| 字体 | PDF 必须嵌入全部字体 |
| 图片宽度 | 单栏 8.5 cm（3.35 in）；双栏 17.5 cm（6.89 in） |
| 图片高度 | 不超过 22 cm |
| 文件大小 | 小于 10 MB |

导出代码（matplotlib）：
```python
fig.savefig('figure.png', dpi=300, bbox_inches='tight', facecolor='white')   # 300 DPI PNG
fig.savefig('figure.pdf', bbox_inches='tight', facecolor='white')            # 矢量，推荐
fig.savefig('figure.tiff', dpi=600, bbox_inches='tight', facecolor='white',
            pil_kwargs={'compression': 'tiff_lzw'})                          # 部分期刊要求
```
多子图导出加 `pad_inches=0.2`。

### 5. 数据标记与误差棒
- 标记组合：1 系列用圆点+实线；2 系列圆点/方块+实线/虚线；3 系列圆/方/三角+三种线型；4 系列以上同时区分标记+线型+颜色，5 系列以上以色板区分优先。
- 数据点不超过 50 个时全部标点；超过 50 个只标关键点；标记大小 4-6 pt。
- 误差棒：capsize=4-6、elinewidth=1.2-1.5、capthick=1.2-1.5；颜色与系列同色略浅（alpha≈0.6）；须注明类型——SD 描述性统计、SEM 推断、95% CI 效应量、箱线图 IQR/1.5×IQR。
- 注释框：白底、灰边 #999、alpha≈0.9、圆角；箭头 #333、线宽 1.0；图中文字简明（不超过 8 词）。

## 三、图注、编号与统计标注规范

### 1. 图注与编号
- 图题格式全文统一，末尾句号结尾（如"图 5 某模型方法学流程图。"）。
- 编号按出现顺序连续，正文首次提及处写"如图 N 所示"与之呼应。
- 图注内容不超过 3 句话：图表含义 + 数据来源 + 关键结论提示。
- 样本量 n = XX 必须出现在图注或图中；误差棒类型（SD/SEM/95% CI/IQR）必须写明；显著性用符号 + p 值双标注，p 值的含义在图注说明。
- 建议配图密度（图文比阈值，超阈值即该补图）：问题分析/模型建立章节 800 字/图，结果分析 500 字/图，灵敏度/参数分析 400 字/图，前言 1000 字/图（可选）；结论章一般不配图。
- 流程类图优先自上而下或自左向右单一方向；分区至少 2-3 个并各自独立配色；节点文字精炼、以动词开头，关键技术术语中英对照，如"主成分分析 (PCA)"。

### 2. 显著性符号表
| 符号 | 含义 | p 值 |
|---|---|---|
| ns | 不显著 | p > 0.05 |
| \* | 显著 | p < 0.05 |
| \*\* | 高度显著 | p < 0.01 |
| \*\*\* | 极显著 | p < 0.001 |
| \*\*\*\* | 极其显著 | p < 0.0001 |

- 检验方法要写明：两组用 t 检验（配对/独立）、Mann-Whitney U、Wilcoxon；多组用 ANOVA（one/two-way）+ post-hoc（Tukey/Bonferroni/Dunnett）或 Kruskal-Wallis + Dunn；三组及以上不得用多重 t 检验代替 ANOVA；多重比较须校正（Bonferroni/FDR/Holm）。
- 相关性：Pearson（线性）/Spearman（单调）/Kendall（小样本），标 r 与 p。
- 效应量：OR/HR 必须附 95% CI（如 OR=2.3 (1.5-3.4)）；回归模型必标 R²（校正 R²）；Cohen's d 参照 0.2 小 / 0.5 中 / 0.8 大。

## 四、配色速查

- 全图主色不超过 3-5 种；禁用 jet / rainbow / HSV 彩虹色。
- 分类 3 类用 Set2（#66C2A5/#FC8D62/#8DA0CB）；4 类 Set1（#E41A1C/#377EB8/#4DAF4A/#984EA3）；5 类 Dark2；6 类 Set3；8 类 Tab10；12 类 tab20。
- 连续单值：首选 viridis，次选 plasma/magma。
- 双向数据（相关系数、残差、灵敏度正负影响）：RdBu_r 或 coolwarm；相关系数热力图设 vmin=-1、vmax=1、center=0；不推荐 RdYlGn（红绿含义易误导）。
- 地形/海拔：terrain / gist_earth。
- 期刊风格参考：Nature 偏冷色（蓝绿）、Science 偏暖（红橙）、Lancet 偏中性（灰/深绿）、Cell 偏明亮多色。核心色：#1F3A93 皇家蓝、#F39C12 金黄、#27AE60 森林绿、#C0392B 深红。
- 突出单个重点柱（Nature 风格）：重点柱用主色 #1F3A93，其余浅灰 #CCCCCC。
- 正负值柱：正值蓝 #1976D2、负值红 #D32F2F，零轴深灰加粗。

## 五、分图表类型的要点与检查项

### 1. 柱状图/条形图
- 柱宽取类别间距的 60-80%；分组柱图组内间距小、组间大（约 1:2 或 1:3）；按数值降序或时间/字母序排列。
- 柱边 #333、线宽 0.5-1.0；数值标签放柱顶上方 0.1-0.2 cm、8-9 pt。
- 检查：Y 轴必须从 0 起（否则夸大差异；除非明确标注断轴）；不用 3D 柱图（透视扭曲）；避免柱+折线双 Y 轴混乱；数据过多致柱宽小于 1 mm 时改用其他图。

### 2. 折线图/面积图
- 主线 1.5-2.0 pt；多系列每系列一色、线型辅助区分（- -- : -.）；观测线用实线，预测/拟合用虚线；95% CI 用同色低 alpha 填充（0.15-0.25）。
- 关键点（最高/最低/拐点）用注释框+箭头；事件用竖线+文字标记；回归方程、R² 用 LaTeX 放图内或图注。
- 检查：折线图 Y 轴可不从 0 起，但须明确标注；系列多于 5 条易乱；缺失数据显式留空或标 N/A；平滑曲线须保留原始数据点（防过度平滑掩盖波动）。

### 3. 散点图/气泡图
- 点大小 s=20-100、alpha=0.6-0.8、点边 #333 线宽 0.3-0.5；分类散点每类一色 alpha≈0.7。
- 点超过 500 个改用 hexbin / 二维直方图 / KDE 防重叠；气泡大小映射第三变量（s 范围 20-2000，alpha 0.5-0.7）。
- 回归线用虚线 + 95% CI 半透明带，公式 + R² + p 值入图；聚类用半透明椭圆圈出；异常点红边+数字标签并说明。
- 检查：气泡大小须标准化后再映射；避免三维散点无可读视角。

### 4. 热力图/相关性矩阵
- 方格必须正方形（aspect='equal'）；相关系数用 RdBu_r、vmin=-1/vmax=1/center=0，显著性单元格叠 \* 号（7-9 pt）；单向数据用 viridis 系。
- 相关性矩阵可用 mask 隐藏上三角，或用 clustermap 做行列聚类加树状图；cell 边框线宽 0.5-1.0、白或浅灰。
- colorbar 必备且范围与数据匹配；行列标签过长要旋转 45/90 度。
- 检查：禁用 RdYlGn 表双向含义；cell 内数值与颜色映射必须一一对应（annot=True 时核对 fmt）。

### 5. 箱线图/小提琴图/分布图
- 箱体填充 #1F3A93、alpha 0.5-0.7、描边 0.5 pt；箱宽 widths=0.5-0.7；中位线黑色 2.0 pt；可叠加半透明原始点（stripplot，alpha≈0.4）。
- 离群点按 1.5×IQR 判定，飞点 fliersize=4；样本量 n 标在组标签下；组间比较 p 值用顶部横线 + 星号标注；小提琴图注明带宽（展示真实分布）。
- 检查：Y 轴截断会扭曲箱体；须标注样本量与检验方法。

### 6. 饼图/环形图
- 仅用于占比且类别不超过 7 类；超过 7 类或非 100% 构成数据改用柱状图。
- startangle=90（12 点方向起）、顺时针（counterclock=False）；扇区分隔白边线宽 2；百分比 autopct='%1.1f%%'、pctdistance=0.7-0.85。
- 关键扇区 explode=0.05 突出；环形图 ring 宽 0.3-0.4，中心放总值；禁 3D 饼图。

### 7. 雷达图
- 维度 3-8 个，超过 8 维改用平行坐标；类别（多边形）超过 4 组不可辨；不同量纲先标准化再画。
- 填充 alpha 0.15-0.25、轮廓线 2.0 pt 同色；刻度圈 3-5 个；图例放右/下。

### 8. 3D 图
- 视角 elev=20-30°、azim=30-60°；曲面网格 rstride=cstride=5-10 防过密；曲面下叠等高线投影到底面；colorbar 必备且含单位。
- 检查：不推荐 3D 柱图；视角不得遮挡关键数据。

### 9. 地图
- 底图浅灰填充 + 灰边界线；指北针、比例尺、图例/colorbar 必备。
- 中国地图必须包含台湾省、南海诸岛与九段线（政治红线）。
- 投影按范围选 Plate Carrée / Mercator / Albers（中国）；色带范围必须与数据匹配。

### 10. 流程图/方法学框架图（国赛最常用，务必会画）
- 节点形状语义化：平行四边形=数据输入（蓝系 #E3F2FD/#1565C0）、圆角矩形=过程（绿系 #E8F5E9/#2E7D32）、菱形=决策判断（橙系 #FFF3E0/#E65100）、矩形=模型/算法模块（紫系 #F3E5F5/#6A1B9A）、输出节点红系、反馈回路用虚线箭头（灰 #333）。
- 节点底色淡 + 描边深、线宽 1.5-2.0；圆角 boxstyle='round,pad=0.3-0.5'；节点严格网格对齐。
- 节点文字 9-10 pt、每节点不超过 5-8 词；节点总数控制在 20 个以内；整图主色不超过 5 种；箭头必须标流向语义（输入/输出/反馈/迭代），不同分区用淡色背景 + 虚线边框圈出。
- 检查：箭头无交叉混乱、文字不溢出节点。

### 11. 网络图/桑基图
- 节点不超过 50 个、边数不超过节点数的 5 倍；节点大小按度/中心性（s=50-3000）、边宽按权重（0.5-3.0）；关键节点才加标签（8-9 pt）；布局常用 spring/circular/kamada_kawai。

### 12. 统计专题图（ROC 等）
- ROC：每模型一色一条曲线，画 y=x 灰色虚线参考；AUC 放图例并降序排列；不平衡数据补画 PR 曲线。
- 火山图：x 为 log2(FC)、y 为 -log10(p)；显著上调红、下调蓝、不显著灰；阈值虚线 p=0.05 与 |FC|=1.5 或 2；基因名标注不超过 10 个。

## 六、让 AI 生成/修改图表的提示词骨架

可复用原文的角色定位与输出结构（把下面模板发给 AI，配合本文件作为规范附录）：

```
角色：资深科研可视化设计师。只美化、绝不修改数据。
流程：① 识别图表类型 → ② 检查数据完整性 → ③ 对照所附规范 → ④ 修改/写码 → ⑤ 结构化说明。
硬约束：不修改数据点/数值/类别/坐标范围；不改图表类型；结论必须保留。
输出格式：
【图表类型识别】...
【原图问题诊断】列出 2-4 个具体缺陷
【美化执行清单】颜色/字体/网格/边距/标记/标注逐项修改内容
【数据完整性检查】确认所有数据点/标签已保留
【生成结果】300 DPI PNG + 矢量 PDF，注明尺寸
【修改说明】逐项解释每处修改的作用与依据
```

- 生成新图（matplotlib 代码）时，把"二、三、四"节规范直接粘贴进提示词，并指定：数据以我方提供的 CSV/程序输出为准，图必须用 Python 按数据绘制，输出可复现代码。
- 检查 AI 返回结果时逐项对表：数据值有没有动、坐标范围有没有动、单位在不在、字号是否小于 7 pt、配色是否含 jet/红绿、colorbar/图例/显著性标注是否齐全、导出是否 300 DPI 且矢量。
- 涉及 AI"补图"（发现某章缺图建议补图）时，只采纳其"缺图判断"（图文比阈值）与"图注编号规范"，图本身一律由真实运行数据出图，不让 AI 凭文字描述直接画数据图。

## 七、matplotlib 全局配置参考（原文附录，可并入画图模板）

import matplotlib.pyplot as plt
from matplotlib import rcParams

rcParams['ytick.labelsize'] = 9

def style_axes(ax):
    ax.spines['top'].set_visible(False)
    ax.spines['right'].set_visible(False)
    ax.spines['left'].set_color('#333333')
    ax.spines['bottom'].set_color('#333333')
