# 图表规范 Checklist（出图前逐条自查）

> 每张图都要过一遍这张表。图表是论文的脸面，也是评阅老师第一眼看的。

---

## 一、硬性要求（不满足直接改）

| 检查项 | 要求 |
|---|---|
| 中文显示 | 图内无方框乱码（先运行 `set_chinese_font()`） |
| 分辨率 | 保存 PNG，`dpi=300` |
| 坐标轴单位 | 每个轴都带单位，如「时间 (天)」「浓度 (mg/L)」 |
| 图标题/图注 | 图下方统一「图 1 标题」格式，正文里必须引用（"如图 1 所示"） |
| 字体大小 | 不小于 10pt（论文打印后仍清晰） |
| 图例 | 多条曲线必须有图例，且图例与正文描述一致 |
| 颜色 | 全篇统一配色，避免红绿同现（色盲友好） |

## 二、内容要求（体现建模水平）

| 检查项 | 要求 |
|---|---|
| 有无误导 | 坐标轴不从非 0 起点夸张截断（如确需截断要标注） |
| 数据真实 | 图内数字必须来自程序运行结果，**禁止手绘/PS 改数** |
| 信息密度 | 一张图只讲一件事；信息过多就拆图 |
| 有对比 | 模型对比图（多条线/多组柱）比单条线有说服力 |
| 有依据 | 图要能直接支撑论文中的某个结论，不能是"装饰图" |

## 三、竞赛常用图类型对照

| 想表达什么 | 用什么图 |
|---|---|
| 趋势/时序 | 折线图 |
| 数据分布 | 直方图、箱线图 |
| 对比/排名 | 柱状图、横向条形图 |
| 两个变量关系 | 散点图（+拟合线） |
| 变量间相关性 | 热力图 |
| 两个变量对目标的影响 | 3D 曲面图、等高线图 |
| 优化/搜索过程 | 收敛曲线图 |
| 方案布局/流程 | 示意图（可以用 AI 生成 Mermaid 再截图） |
| 多模型对比 | 分组柱状图、误差棒图 |

## 四、图片管理规范（配合工作区）

1. 所有最终图放 `03_结果与图表/最终图表/`，命名 `图1_xxx.png`、`图2_xxx.png`……与论文编号一致。
2. 每张图配一个同名 `.txt`/`.md` 说明：**图注 + 数据来源 + 生成脚本**。
3. 初版图放 `探索性分析图/`，别污染最终图表文件夹。
4. 改图就改代码重新生成，**禁止在画图软件里手改数字**（防止论文与代码不一致被取消资格）。
5. 生成图的脚本代码，全部要能放进论文附录。

## 五、数据表规范

1. 大表（结果汇总、模型对比）用**三线表**（Word 里：上下粗线+中间细线）。
2. 表格编号「表 1 xxx」，正文必须引用。
3. 表内数值保留有效数字统一（如一律 3 位小数）。
4. 单位写在表头或说明里，不要每个格子重复写。
