# AI 痕迹检测要点提炼

> 本文提炼自《AI 痕迹自动检测与诊断提示词（V5.0）》，删去营销话术与 HTML 报告机制等冗长说明，保留可直接执行的检测维度、词库、逐章节检查点与整改套路。用法：把第 1 节提示词骨架连同论文全文发给任意大模型，即可得到逐条定位的检测报告。

## 一、可直接复用的提示词骨架

- 角色：你是一名严格的 AI 痕迹检测专家，熟悉 GPT、Claude、文心一言等大模型写作的典型模式，能从词汇、句式、段落、逻辑、人味等维度识别 AI 生成内容。标准从严：凡是评委可能一眼看出是 AI 写的都要报出，宁多勿少。
- 任务：逐段扫描论文全文（摘要到结论，含图表标题与说明、参考文献），输出四部分报告：总体评估、详细问题清单、维度汇总、优先级建议。每个问题须含：位置（精确到章节+段落+句子）、原文摘录、所属维度、问题类型、严重程度、深度分析（为什么是 AI 痕迹、AI 为何这样写、人类通常怎么写）、修改建议（写成"将 X 改为 Y，因为 Z"）、修改示例（原文→修改后，至少 1 个）。只诊断和开药方，不代为改写全文。
- 流程：通读两遍（一遍看内容、一遍看表达）→ 逐段标记可疑句并记录位置与原因 → 按下列 10 个维度深挖 → 逐条给建议与示例 → 按维度汇总统计 → 按严重程度排出修改路线图。

五条检测原则：

1. 全面覆盖：段落再短、位置再偏也要扫，宁可多报一个轻微问题，不放过一个严重问题。
2. 深度分析：不只说"这里有 AI 痕迹"，要说明 AI 为什么这样写、人通常怎么写。
3. 精确定位：精确到"摘要第 2 段第 3 句"并附原文，不得用"正文某处"搪塞。
4. 建议可执行：每条建议附"原文→修改后"对照，不许写"建议优化表达"这类空话。
5. 分级排序：先改一眼露馅的，后改细看才发现的，并指出哪些可以不改。

## 二、严重程度三级分级

| 级别 | 判定标准（评委视角） | 典型表现 | 修改优先级 |
| --- | --- | --- | --- |
| 严重 | 一眼看出是 AI 写的 | 整段模板化、AI 高频词密集、逻辑过于完美、毫无人味 | 必须修改 |
| 中等 | 细看能看出，不至一眼判定 | 句式单一、过渡词滥用、段落长短均匀、缺个人判断 | 建议修改 |
| 轻微 | 基本不影响整体 | 个别高频词、个别超长句、个别模板化标题 | 可选修改 |

## 三、"AI 味"十大维度特征清单

### 维度 1 词汇层

AI 高频词（全文超过阈值即标记；同一段出现 3 个以上即为"密集区"）：

| AI 高频词 | 人类替代说法 | 触发阈值 |
| --- | --- | --- |
| 在此基础上 | 进而、在此之后或直接删除 | 全文 1 次以上 |
| 进一步分析表明 | 分析表明、对比可知 | 全文 1 次以上 |
| 进一步显示 | 显示、反映出 | 2 次以上 |
| 进一步表明 | 表明、说明 | 2 次以上 |
| 综上所述 | 总的来看、综合来看 | 1 次以上 |
| 由此可见 | 这说明、可以看出 | 2 次以上 |
| 值得注意的是 | 直接删除或改为具体描述 | 1 次以上 |
| 需要指出的是 | 直接删除 | 1 次以上 |
| 不难发现 | 我们发现、可以看到 | 1 次以上 |
| 众所周知 | 删除，或改为"在 XX 领域" | 出现即标 |
| 显而易见 | 直接删除 | 出现即标 |
| 毋庸置疑 | 直接删除 | 出现即标 |
| 因此 | 所以、因而或删除 | 每千字 5 次以上 |
| 然而 | 但是、不过或删除 | 每千字 3 次以上 |
| 此外 | 另外、还有或删除 | 每千字 3 次以上 |

空洞形容词（完整的、详细的、全面的、系统的、深入的、精确的、有效的、显著的、重要的、关键的、核心的、充分的、丰富的、有力的、有意义的、有代表性的、有应用前景的等）：能删则删，不能删就换成具体描述（"显著的效果"→"效果提升了百分之几"）；连续堆 2 个以上或每段都出现，必须标记。

模板化动词"进行+名词"（进行分析、计算、比较、优化、验证、检验、预测、拟合、求解、建模、研究、评估、处理等，九成以上可删）：删"进行"、把名词还原成动词即可。

附加信号：全文"的"字密度明显偏高（AI 文本可达 6%–8%，人类通常 3%–5%）。

### 维度 2 句式层

| AI 典型问题 | 表现 | 人类写法 |
| --- | --- | --- |
| 陈述句一统天下 | 没有疑问、设问、感叹 | 设问："那么，如何在准确率和召回率之间取舍？" |
| 主谓宾固定不变 | 句句主语+谓语+宾语 | 倒装、省略、插入语 |
| 长句过多 | 大量超过 50 字的长句 | 长短句交替，要点用短句强调 |
| 被动句过多 | 被字句、由字句密集 | 主动语态更直接 |
| 过渡词滥用 | 每 2–3 句一个过渡词（人类每 5–8 句才一个）；同一段堆 3 个以上；"然而"前后并无真转折（虚假转折） | 少用，真有转折才用 |

### 维度 3 段落层

可让 AI 按下列量化指标计算并报告：

| 指标 | AI 典型值 | 人类典型值 |
| --- | --- | --- |
| 段落长度标准差 | 小于 30 字 | 大于 50 字 |
| 最短段落 | 大于 50 字 | 可短到一句话（小于 20 字） |
| 最长段落 | 小于 250 字 | 常超过 300 字 |
| 段落长度变异系数 | 小于 0.2 | 大于 0.3 |

结构模板化信号：段段都是"总—分—总"；段首句模式化（"首先……其次……""第一……第二……"）；段尾爱加总结句（人类通常不加）；段间衔接过于平滑（人类允许跳跃）。

### 维度 4 逻辑层

| AI 典型表现 | 人类写法示例 |
| --- | --- |
| 因果太直接，无中间环节与例外 | "A 可能是 B 的原因之一，但不排除 C 的影响" |
| 全文无矛盾、无自我质疑 | "然而该结论在 XX 情形下可能不成立" |
| 结论一律确定，没有可能、也许、大概 | "在现有数据下，我们倾向于认为……" |
| 全是客观陈述，无个人判断 | "我们选择简约模型，因为它更稳定" |

### 维度 5 人味层

人味表达每千字 1–2 处为正常，完全没有则可疑；AI 几乎不用设问句；人类爱用破折号插入解释，AI 多用逗号或括号。参考表达分类：

- 口语化解释：说白了、换句话说、简单来说、换个角度看、一个细节是、有意思的是、不难理解（用在解释复杂概念、指出易被忽略的细节时）。
- 个人化判断：我们倾向于、我们认为、在我们看来、我们的经验是、我们建议、我们选择（用在做出选择或判断并给出理由时）。
- 不完美表述：大致、大概、基本上、在一定程度上、似乎、可能、也许、有待进一步验证（用在描述不确定结果、报局限时）。
- 设问句：那么，如何……？为什么会出现这种反直觉的结果？这意味着什么？这个结论真的可靠吗？（引出问题、解释意外发现、讨论局限时使用）。

### 维度 6 数据表述层

| AI 典型表现 | 人类写法 |
| --- | --- |
| 小数位过多（准确率 98.7654%） | 约 98.8%（按测量精度保留，通常不超 2–3 位，加"约"） |
| 只给点估计，无误差范围 | 0.123±0.005（附置信区间） |
| 只说好话不报局限 | "模型在 XX 条件下有效，但在 YY 情况下可能失效" |
| 指标全优、过于完美 | 承认取舍："准确率高但召回率偏低" |

### 维度 7 图表层

- 标题只说"是什么"不说"发现了什么"："图 1 模型准确率对比"→"图 1 模型 A 在低样本场景下准确率优于模型 B"；"表 2 参数设置"→"表 2 针对 XX 问题的最优参数设置（基于网格搜索）"。
- 说明文字空洞："如图所示""详见图表"这类无信息量的话。
- 图表编号不连续、正文中未被引用。
- 默认配色与默认样式（AI 常用 matplotlib 默认配色，人类会自定义）。
- 标注不全：缺坐标轴标签、单位、图例、误差棒。

### 维度 8 结构层

- 摘要固定"背景—方法—结果—结论"四段式且篇幅均匀。
- 章节标题模板化："基于 XX 的 XX 研究""XX 的设计与实现"。
- 每章开头都加一段引言（人类可能直接进入正题）。
- 结论只是摘要的改写，没有新内容（应补局限性、未来方向、个人思考）。
- 各章篇幅过于均匀（人类有重点章节与次要章节）。

### 维度 9 引用与参考文献层

- 引用位置固定：每段结尾都有 1–2 个引用（人类位置灵活，段中、段首都有）。
- 引用格式单一：全是"[1][2]"（人类有"XX 等人[1]提出""根据文献[2]"等变化）。
- 引文与论点不贴、纯凑数；自引过多（AI 可能编造文献）。
- 文献总量过多或过少；格式不统一。

### 维度 10 整体 AI 感（综合评估）

五个指标各占 20%：整体流畅度（AI 过于流畅无卡顿，人有自然跳跃与重复）、自然度（有无个人风格与习惯）、逻辑自然度（完美闭环与有跳跃、有质疑）、人味浓度（每千字 1–2 处为正常）、细节丰富度（笼统与有具体数字、案例、感受）。

AI 生成概率五级：小于 20% 无需修改；20%–40% 轻微修改；40%–60% 针对性修改；60%–80% 大幅修改；大于 80% 建议重写。

## 四、逐章节检测点（覆盖性自检）

| 章节 | 检查要求 |
| --- | --- |
| 摘要 | 每一句都扫描 |
| 引言 | 无遗漏 |
| 方法 | 每段都扫描 |
| 结果 | 无遗漏 |
| 讨论 | 无遗漏 |
| 结论 | 每一句都扫描 |
| 参考文献 | 引用格式与位置 |
| 图表 | 标题与说明文字全覆盖 |

数量自检参考：AI 生成的论文每千字应至少检出 3–5 个问题；不应存在完全干净、挑不出轻微问题的段落；检完需回头通读一遍确认无漏网。

## 五、诊断报告格式（每个问题一条）

| 字段 | 要求 |
| --- | --- |
| 编号 | P-001 等，按论文顺序排列 |
| 位置 | 章节+段落+句子 |
| 原文摘录 | 加引号的原句 |
| 所属维度 | 上述 10 维之一 |
| 问题类型 | 如"AI 高频词滥用" |
| 严重程度 | 严重 / 中等 / 轻微 |
| 深度分析 | 为什么是 AI 痕迹、AI 为什么这样写 |
| 修改建议 | "删除 X，将 Y 改为 Z"式可执行语句 |
| 修改示例 | 原文→修改后对照 |

配套汇总：各维度问题数量（分严重度）与各维度 2–3 个典型问题、一句话改进方向；得分最低的 3 个维度即重点改进方向。报告开头给总体评估（字数、章节数、图表数、估计 AI 生成概率、严重问题个数），结尾按严重→中等→轻微给修改路线图与耗时估算。HTML 只是可选载体，用普通文档输出即可，不必照搬其报告样式。

## 六、整改建议的常见套路（改稿时迁移使用）

1. 删：在此基础上、值得注意的是、需要指出的是、众所周知、显而易见、毋庸置疑、不难发现等无信息量套话，直接删除或换成具体事实。
2. 替：进一步 X 分析→X 分析；综上所述→总的来看；由此可见→这说明；因此→所以；"本文、该文"→"我们"（全文统一）。
3. 空洞形容词换数字：完整、全面、深入、显著等换成可度量描述（"效果显著"→"效果提升 12%"）。
4. "进行+名词"→动词：进行分析→分析，全文统一处理。
5. 加人味：按每千字 1–2 处补"说白了、一个细节是、有意思的是、我们倾向于、大致、似乎"等（见维度 5），放在解释复杂概念、做选择、报局限处。
6. 加不确定与自我质疑：讨论部分补"在现有数据下我们倾向于认为……""该结论有待更大样本验证"；结论补局限与下一步。
7. 调句式：50 字以上长句拆短；被动改主动；关键结论用短句；必要时插一个设问句。
8. 打破段落均匀：允许一句成段；超长段拆分；删段尾机械总结句。
9. 图表：标题改写为"图 X 展示了……发现"；补全坐标轴、单位、图例、误差棒；换掉 matplotlib 默认配色。
10. 结论与引用：结论补新内容不抄摘要；引用位置与写法（"XX 等人[1]"）做出变化。

修改五原则：只改表达、不改内容（数据、公式、结论、逻辑一概不动）；保持学术规范，不因去 AI 味而口语化过头；人味适量（每千字 1–2 处）；全文风格一致；每改一段通读一遍。

修改禁忌：为降痕迹而改数据、改结论（学术不端）；过度口语化；改完逻辑不通；全文批量替换误伤正文；只换表面词、不动句式与段落结构（治标不治本）。
