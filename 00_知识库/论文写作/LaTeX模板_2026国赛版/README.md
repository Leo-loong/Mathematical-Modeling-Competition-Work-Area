# 2026 国赛论文 LaTeX 模板（推荐写作用）

> 本队论文统一用 LaTeX 排版（用户分工：论文写作）。此模板为**填空式骨架**：章节已按国赛论文结构拆成独立文件，每章留好格式与注释，比赛时直接往里填内容即可。
> 本机已验证可编译（xelatex，0 错误 0 字体警告）。已修正两处原模板问题：① 正文默认不生成目录（官方规范不要目录，需要时打开论文.tex 里注释）② 图表标题字体改为思源宋体加粗。

## 目录结构

```
论文.tex           主文档：组装各章节，改这里设置题目
format.cls         文档类（源自 cumcmthesis v2.6 改装：思源宋体正文、12pt、行距 1.38、页边距 25mm、首行缩进 2em）
fonts/             思源宋体（SourceHanSerifCN Regular/Bold），编译必须在模板目录内进行（字体用相对路径）
0.摘要.tex         摘要 + 关键词（第一页，≤1 页）
1.引言.tex         问题背景 + 问题重述（不要照抄题目）
2.总体分析.tex     总体分析（纯文字，不画流程图）
3.模型假设.tex     假设列表（每条要有理由）
4.符号说明.tex     符号三线表（longtable 可跨页）
5.模型的建立与求解.tex   各问题汇总，按 5.1 问题1……组织
5.1.问题1的建立求解.tex   问题一入口：分析与准备 + 建模与求解
5.1.1.分析与准备.tex     问题一分析
5.1.2.建模与求解.tex     问题一建模（问题二、三依此类推，自行复制成 5.2.x）
6.模型检验.tex     误差分析 + 灵敏度分析等（三线表模板已备好）
7.模型评价.tex     优缺点
8.模型改进推广.tex 改进与推广
9.参考文献.tex     thebibliography 手写格式，8~15 条，正文必须有引用
10.附录.tex        支撑材料文件列表（代码另见 01_当前赛题 代码脚本）
```

## 编译方法

必须在本目录内编译（format.cls 用相对路径 `./fonts/` 找思源宋体）：

```sh
# 方式一：两遍 xelatex（引用/交叉引用需要两遍）
xelatex 论文.tex
xelatex 论文.tex

# 方式二：latexmk（自动多遍）
latexmk -xelatex 论文.tex
```

产物：`论文.pdf`。提交前把文件名改为正式名。

## 模板自带的格式

- 正文：宋体小四（12pt），行距 1.38，首行缩进 2 字符
- 页边距上下左右 25mm（满足 ≥2.5cm）
- 标题：一级标题宋体加粗居中、编号中文（一、二、三），二三级阿拉伯编号
- 图表标题：思源宋体加粗小四；图题在图下、表题在表上（三线表用 booktabs）
- 公式：amsmath 环境自动编号；交叉引用用 `\cref`（自动出"图 1""表 2""式 (3)"中文前缀）
- 承诺书/编号页：`withoutpreface` 选项已关闭（电子版不要这两页）。纸质版需要时把 `\documentclass[withoutpreface,bwprint]{format}` 中的 `withoutpreface` 去掉，并在论文.tex 里用 `\tihao{}`、`\baominghao{}` 等命令填信息（见 format.cls 底部命令）

## 比赛时怎么用

1. 把整个文件夹复制到 `01_当前赛题/04_论文素材/LaTeX论文/`（保留 fonts 目录）
2. 改 `论文.tex` 标题
3. 从第一天晚上开始，每完成一问就填对应章节文件，边做边写，不要最后一天集中写
4. 摘要最后写（0.摘要.tex 骨架已按"开头 2 句 + 逐问一段 + 结尾 2 句"排好，每问必须有具体数值）
5. 附录 10.附录.tex 只放支撑材料文件列表；完整代码以附录形式另排或按赛区要求放支撑材料压缩包
6. 交稿前检查：无目录、摘要 ≤ 1 页、正文 ≤ 30 页、全文匿名（含 PDF 属性）、无占位符残留（搜索 `...`、`xxx`、`TBD`）
