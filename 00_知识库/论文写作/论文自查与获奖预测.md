# 论文全维度自查与获奖评估清单

> 本清单合并自《AI论文检查与获奖预测提示词》标准版（16 维度约 115 点，合格级）与进阶版（16 维度约 150 点，国奖级，含 43 篇国赛优秀论文共性分析）。重叠处取并集；标准冲突处以进阶版"官方修正"为准；进阶版独有要求标注【国奖】。核查对标国赛四大评分标准：假设合理性约 15 分、建模创造性约 25 分、结果正确性约 25 分、文字表述约 35 分（分值最高，务必重视）。

**口径裁定（两版冲突处，以此为准）**
- 摘要字数：国奖级 800-1200 字（标准版 800-1000 为合格底线）；不足 600 字或超一页为致命问题。
- 目录：官方不建议设目录，论文从摘要直接开始，不设不扣分。
- 正文页数：25-30 页最理想、不超过 30 页（附录不计入）；超过 30 页冗长，不足 20 页工作量不足。
- 模型检验：须有独立章节且至少 3 种检验（国奖级）；附录须内容丰富（结果表+补充图表+完整代码）。
- 表述用"改进"不用"创新"；获奖预测须审慎（国奖约 3%，国一约 0.5%，国二约 1.5%，省奖约前 25%）。

**使用方法**：逐项判定四档——达标【国奖】／合格／存在问题／严重问题；对问题项记录三件套：问题位置（页码/章节/段落）、简述（评委为何扣分）、整改建议（可执行）。若交 AI 执行，要求输出 6 列大表格（维度/检查点/判定/位置/简述/建议），全部检查点逐一列出不得省略，最后给整体评价与 Top 改进方向。

## 一、摘要与关键词（第一优先，一票否决级）

| 检查项 | 自查方法／看什么指标 |
|---|---|
| 摘要字数合规 | Word 选中摘要看字数统计，800-1200 字（国奖）、800-1000 为合格底线；不足 600 字或超一页→严重 |
| 结构完整 | "背景引入→问题一/二/三各自独立成段→关键词"，每问一段，逻辑清楚；混成一团→严重 |
| 方法名称专业 | 圈出摘要中每个方法词：必须是"NSGA-II""ACF 自相关函数"等确切名；出现"用了一个算法"类模糊表述→严重 |
| 结果精确数值 | 数摘要中的具体数字：每问至少 1 个关键数值，精确到小数点后 2-4 位（如 36.9945MW）；只有"较好的结果"→严重 |
| 改进点说明 | 是否有"对 XX 改进、引入先验知识"类表述，明确改了什么、为什么 |
| 对比/提升结果 | 是否带验证对比句（"与基准相比收益提升 15%"） |
| 关键词 3-5 个 | 覆盖"核心模型/方法+应用领域+关键技术"；"数学建模""优化"等过宽词→问题 |

## 二、选题理解与题型判断（对应维度十四）

| 检查项 | 自查方法／看什么指标 |
|---|---|
| 各小问完整回答 | 把题目每问要求逐条抄成清单，与正文小节一一打钩；遗漏或答非所问→严重 |
| 题型判断正确 | 确认题型：A 机理分析／B 综合优化／C 数据挖掘，解题思路与题型匹配；判错→严重 |
| 结合题目背景 | 把模型假设换成别的赛题背景是否依然成立？若"放之四海而皆准"→未结合背景，问题 |
| 难点把握 | 题目难点是否在建模与检验中被重点回应 |

## 三、论文结构与问题分析（对应维度二）

| 检查项 | 自查方法／看什么指标 |
|---|---|
| 标准 11 部分齐全 | 摘要→问题重述→问题分析→模型假设→符号说明→模型建立→模型求解→结果分析→模型检验→模型评价→参考文献→附录；缺关键部分→严重 |
| 问题重述不抄题 | 用数学语言重述；大段抄题目原文→严重 |
| 数学转化明确 | 是否点明决策变量、目标函数、约束条件、数据类型 |
| 子问题数学本质 | 每问判定：优化/预测/分类/评价/机理？线性还是非线性、确定还是随机 |
| 逻辑框架图 | 问题分析处是否有问题分解图/建模思路图/技术路线图 |
| 数据需求识别 | 是否识别数据来源、类型及缺失/异常/量纲问题 |
| 章节逻辑闭环 | 全篇是否"提出问题→分析→建模→求解→检验→评价"闭环、章节有过渡 |

## 四、模型假设与符号说明（对应维度三）

| 检查项 | 自查方法／看什么指标 |
|---|---|
| 假设数量适中 | 一般 3-8 条；A 题（机理类）可 8-15 条；过少考虑不周、过多冗余均为问题 |
| 假设四性 | 逐条问：合理吗（违背常识或物理定律→严重）、必要吗（删掉不影响模型→多余）、明确吗（"假设影响不大"类模糊表述→问题）、用了吗（模型里没用到该假设→严重） |
| 重要假设有依据 | 是否注明文献/数据/实际背景依据 |
| 符号表完整 | 对照正文查漏：所有符号都在表内，按决策变量/参数/集合/下标分类，每个有名称、含义、单位 |
| 符号全文统一 | 检索同一变量是否前后混用 x/X 等（不一致→严重） |
| 符号表格式 | 三线表、有编号和标题 |

## 五、模型建立与创造性（对应维度四，25 分创造性核心）

| 检查项 | 自查方法／看什么指标 |
|---|---|
| 推导严谨无跳步 | 每步有依据；出现"经过复杂计算可得""化简得"→严重 |
| 公式量与质【国奖】 | 国奖论文均值约 200 个公式；重要公式编号连续且右对齐；公式编辑器输入（非图片/文本）；变量与符号表一致；每个重要公式后有文字说明含义与由来 |
| 机理深入【国奖】 | A 题必查：是否从物理定律等基本原理出发推演（而非套现成模型）；A 题是否建立坐标系并写清坐标转换 |
| 问题特化策略【国奖】 | 有无"无效点判断""分区域规划"等针对本题特点的策略；纯通用模型套用→问题 |
| 算法改进深度【国奖】 | 对经典算法是否有针对性改进，并回答三问：改了什么、为什么改（依据）、效果如何（量化数据，如收敛加快 30%）；改进无效果数据→问题，伪创新→严重 |
| 模型与问题匹配 | 简单问题不用深度学习；黑箱不可解释模型慎用；模型不匹配→严重 |
| 多问题递进统一 | 问题一基础→问题二扩展→问题三深化，整体规划一致而非各自为政 |
| 目标函数明确 | 写明最大化/最小化及目标含义（缺失→严重） |
| 约束条件完整 | 资源/物理/逻辑约束逐条列出并有数学表达式（缺失→严重） |

## 六、算法选择与求解（对应维度五）

| 检查项 | 自查方法／看什么指标 |
|---|---|
| 求解过程透明 | 写清软件/语言（Python/MATLAB/Lingo）与算法步骤；模糊→问题 |
| 参数有依据 | 种群规模、迭代次数、学习率等说明设置理由，非随手写 |
| 收敛性分析 | 迭代算法给收敛条件并展示收敛曲线 |
| 复杂度分析 | 时间/空间复杂度，并说明在题目数据规模下可行 |
| 初始解与停止条件 | 启发式算法说明初始解生成方法；停止条件（最大迭代/阈值/时限）写明 |
| 结果完整 | 含中间结果（迭代过程、关键变量取值、约束满足情况），不只给终值 |
| 双方法验证 | 重要结果是否用第二种独立方法（或简化模型）互验（加分项） |
| 效率说明 | 运行时间、内存占用是否交代 |

## 七、模型检验与灵敏度分析（对应维度七，拉开档次的关键，国奖核心）

| 检查项 | 自查方法／看什么指标 |
|---|---|
| 独立章节【国奖】 | 灵敏度分析、稳健性检验、模型评价均独立成章，不藏在结果分析里；无独立灵敏度章节→严重 |
| 灵敏度覆盖与幅度 | 是否覆盖多个关键参数，各做 ±10% 和 ±20% 扰动；只做 1 个参数→问题，完全没做→严重 |
| 灵敏度可视化 | 有龙卷风图（参数影响排序）或折线图（变化趋势）；只有文字→问题 |
| 灵敏度有分析 | 说明哪些参数敏感、为什么、对结论影响多大 |
| 误差分析 | 计算 MAE/RMSE/MAPE/R² 等具体指标，说明误差来源并判断是否可接受；完全没有→严重 |
| 稳健性检验 | 数据扰动测试+方法对比测试观察结果稳定性；C 题（数据类）必查且须独立章节 |
| 交叉验证 | K 折交叉验证检验泛化能力（机器学习类必查） |
| 对比验证 | 与真实值/文献结果/简化模型解析解对比并解释差异原因 |
| 收敛性检验 | 迭代算法展示收敛曲线 |
| 检验全面性 | 至少 3 种（灵敏度+误差+稳健性/对比/交叉）；只做 1 种走过场→严重 |
| 检验有结论 | 结尾明确"模型可靠、误差可接受、哪些参数敏感"，不是只摆数据 |

## 八、结果分析、图表与可视化（对应维度六）

| 检查项 | 自查方法／看什么指标 |
|---|---|
| 结果对应题目 | 每问结果明确回应题目要求，无答非所问（违者→严重） |
| 分析有深度 | 解释"为什么是这个值、意味着什么、有什么规律"；只罗列数据→严重 |
| 图要素齐全 | 图题按章节编号（图3-1）、坐标轴标签含单位、图例、数据标注 |
| 表要素齐全 | 三线表、表题按章节编号（表2-2）、表头清晰、数据对齐 |
| 图类型匹配 | 趋势折线/对比柱状/占比饼图/分布散点或直方/空间热力 |
| 正文引用 | 每张图表在正文中被提到；存在未引用图表→问题 |
| 专业美观 | 不用 Excel 默认配色、不用截图；用 Tableau/ColorBrewer 类配色；粗糙无标签→严重 |
| 数量充足【国奖】 | 参考国奖均值：图被引用约 47 次、表约 27.6 次；过少→问题 |
| 多方案对比 | 多方案时对比目标值/计算时间/稳健性/实现难度并给推荐方案 |

## 九、创新点与差异化（对应维度九，创造性核心，国奖核心）

| 检查项 | 自查方法／看什么指标 |
|---|---|
| 明确列出 | 引言末尾或单独一节，"本文改进如下：①…②…"；全文找不到改进点→严重 |
| 数量适中 | 1-2 个真正有价值的即可；0 个或 4 个以上→问题 |
| 类型与常见度 | 算法改进类（约占优秀论文创新 45%：调算子/引入先验知识/混合算法）；问题特化策略类；跨领域迁移类（须说明适用性与适应性调整）；多模型融合类（须说明融合方式与提升） |
| 表述用"改进" | 43 篇优秀论文 5/5 用"改进"；用"创新""首创"等夸大表述→问题 |
| 创新三问 | 具体（改了什么、怎么改，非"提出一种新方法"）、有依据（为什么这样改）、有效果（量化：精度/速度/收益提升多少） |
| 非伪创新 | 换名字、堆砌复杂算法、无实际改进→严重（评委反感） |
| 正文展开 | 列出的改进点在正文有详细展开与对应，非口号（不对应→严重） |

## 十、数据预处理与数据真实性（对应维度十、十五部分）

| 检查项 | 自查方法／看什么指标 |
|---|---|
| 数据真实 | 不编造、不选择性报告。抽查 3-5 个表格数字用代码重算核对；检查代码中无手工硬编码的"答案" |
| 数据质量审计 | 量化缺失率、异常值数量、重复值、量纲不一致、时间戳错误 |
| 缺失值有策略 | 按缺失比例与类型处理：<5% 删除、5%-30% 插值/均值、>30% 模型预测；简单粗暴全删→问题 |
| 异常值区分处理 | 区分"错误数据"（修正/删除）与"真实极端值"（保留并分析）；一律删除→严重 |
| 探索性分析 | 描述性统计、相关性分析、分布可视化，是否发现数据规律 |
| 特征工程 | 时间/统计/交叉/滞后特征是否提取；特征选择有依据、无冗余 |
| 处理流程透明 | 论文写清方法、参数、处理前后数据量变化 |

## 十一、语言质量与去 AI 味（对应维度十三、十五部分）

| 检查项 | 自查方法／看什么指标 |
|---|---|
| 无错别字语病 | 全文检索；大量错别字/语法错误/口语化→严重 |
| 术语准确 | 用领域标准术语，不用大白话替代（"拟合曲线"不是"画条线"） |
| AI 痕迹轻 | 全文检索高频套话（"综上所述""值得注意的是""赋能""首先其次最后"等）逐一删除改写；无数字支撑的形容词（较好/显著/有效）段落标记补数据 |
| 人味浓度 | 是否有个人判断、具体细节、试错过程（"试了 X 不行改 Y，因为…"）；完全模板化→问题 |
| 表述克制 | 不夸大、不"模型完美无缺"；优点有数据、不足诚实具体 |

## 十二、格式与排版合规（对应维度十三）

| 检查项 | 自查方法／看什么指标 |
|---|---|
| 页面设置 | A4，页边距上下 2.5cm、左右 2-2.5cm |
| 字体统一 | 正文宋体小四、标题黑体、公式 Times New Roman；多字体混用→严重 |
| 行距缩进 | 1.5 倍行距、首行缩进 2 字符 |
| 页码页眉 | 连续、位置正确 |
| 不设目录 | 官方建议直接从摘要开始；若设目录则页码必须与正文对应且不占篇幅 |
| 公式编号 | 右对齐、与公式同一行 |
| 图表编号 | 按章节编号（图3-1），不是全文连续编号 |
| 版面无残缺 | 无大空白页、跨节图表、表格分页断开 |
| 页数达标 | 正文 25-30 页理想、≤30 页；>30→严重（冗长），<20→问题（工作量不足），附录凑页数→问题 |

## 十三、参考文献与附录（对应维度十一、十二）

| 检查项 | 自查方法／看什么指标 |
|---|---|
| 数量 10-20 篇 | 少于 5 篇或超过 30 篇→问题 |
| GB/T 7714 格式 | 文献类型标注正确（[J]/[M]/[D]/[C]）；格式乱→严重 |
| 时效性 | 近 5 年文献占比至少 50% |
| 文内文末对应 | 文内引用与文末列表一一对应；"引了列表没有/列表有没引"→严重 |
| 引用位置合理 | 分散在需要处，不集中某一段 |
| 文献质量【国奖】 | 含核心期刊、经典文献、领域权威文献 |
| 附录丰富【国奖】 | 详细求解结果表+补充图表+完整代码+灵敏度详细数据；只有几行代码→问题 |
| 代码完整可运行 | 非只贴关键代码；关键步骤有注释、变量命名清晰 |
| 可复现性 | 有随机种子、环境说明、数据说明；不可复现→严重 |
| 代码与论文一致 | 模型实现与论文描述对应；"论文一套代码一套"→严重 |
| 附录编号 | 附录 A/B/C 并各有标题 |

| 检查项 | 自查方法／看什么指标 |
|---|---|
| AI 使用说明 | 按 2026 国赛新规（以当年组委会通知为准）如实说明 AI 工具使用情况；未按要求说明→问题 |
| 查重率 | 一般 <15%-20%（以学校要求为准）；大段抄袭→严重 |

## 十五、打分与等级评估规则

**单项判定四档**：达标（达国奖级标准，是亮点加分项）／合格（无问题但不突出）／存在问题（需修改，不影响整体）／严重问题（硬伤，直接影响获奖，必须改）。四大核心维度（摘要、模型建立、模型检验、创新点）出现严重问题即无缘国奖。

**整体评价五档（按此表从严判定）**：

| 整体评价 | 判定条件 | 获奖预测（审慎） |
|---|---|---|
| 可能直接淘汰 | 摘要致命，或完全无创新，或排版混乱图表粗糙，或全文无检验，或核心维度≥3 个严重问题，或学术不端 | 可能未获奖（约 75% 队伍），一票否决不再评等级 |
| 需大幅提升 | 严重问题>5 个，或核心维度有 2-3 个严重问题，但摘要无致命问题 | 省三潜力，需大幅修改 |
| 基本合格 | 严重问题≤5 个，核心维度严重问题≤2 个，摘要无致命问题，结构完整 | 省二/省三潜力 |
| 省一水平 | 严重问题≤2 个，核心维度无严重问题，摘要达标，检验≥2 种，有明确改进点 | 省一潜力（约 5% 队伍） |
| 国奖级标准 | 严重问题=0，检验≥3 种且独立章节，有量化效果的算法改进类创新，附录丰富，全文无 AI 痕迹 | 国二潜力（约 1.5%，极慎重）；国一潜力（约 0.5%，极极慎重，另需突出特化策略、4 种以上检验、突破性结果、发表级写作） |

预测底线：获奖率极低（国奖约 3%、省奖约前 25%），预测必须基于逐项检查结果，不得乐观估计；绝大多数论文只宜预测省奖及以下。

## 十六、致命问题清单（一票否决，存在任一项直接判定"可能未获奖"）

1. 摘要致命问题：字数不足 600 字或超过一页；无任何具体数值、只有"较好的结果"式表述；结构混乱、无分问题描述；方法名称模糊。
2. 模型完全无创新：直接套用现成模型，无算法改进、无问题特化策略、无跨领域迁移（创造性 25 分全丢）。
3. 排版混乱、图表粗糙：贴截图、Excel 默认配色、图表无编号无标签、字体字号不统一、大量空白页（表述 35 分大幅扣分）。
4. 全文无任何模型检验：无灵敏度、误差、稳健性、对比验证中的任何一种（结果可信度直接降档）。
5. 核心维度（摘要/模型建立/模型检验/创新点）合计 3 个以上严重问题，或学术不端、严重格式问题。
