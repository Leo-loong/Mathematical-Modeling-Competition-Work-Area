# 论文结构与摘要写法（竞赛规范）

> 依据《全国大学生数学建模竞赛论文格式规范（2025 年修订稿）》。
> 核心：**正文 ≤ 20 页**，**摘要 ≤ 1 页**，附录放全部代码。

---

## 一、论文完整结构

| 部分 | 页数 | 内容要点 |
|---|---|---|
| 摘要页 | 1 页 | 见下方"摘要写法"（论文门面，最重要） |
| 一、问题重述 | 0.5~1 页 | 用自己的话复述题目，突出要解决的问题 |
| 二、问题分析 | 1~1.5 页 | 每个子问题的思路、准备用什么方法、难点在哪 |
| 三、模型假设 | 0.5 页 | 5~8 条合理假设（见《模型假设与灵敏度分析写法》） |
| 四、符号说明 | 0.5 页 | 表格：符号、含义、单位 |
| 五、模型建立与求解 | 10~14 页 | 核心，每个子问题：建模→求解→结果→分析 |
| 六、灵敏度分析 | 1~2 页 | 参数扰动对结果的影响 |
| 七、模型评价与改进 | 1 页 | 优点、缺点、可改进方向 |
| 参考文献 | 1 页 | 规范格式，正文引用处标注 [1][2] |
| 附录 | 不限 | 全部源程序 + 中间结果图表（缺代码会被取消资格！） |
| AI 使用声明 | 半页 | 2025 年新增强制要求（见《AI使用声明模板》） |

## 二、摘要写法（决定命运的一页）

**评阅老师 30 秒看摘要定印象分。摘要必须自成一个完整故事：**
**针对什么问题 → 做了什么模型 → 得到什么结果 → 结果多可信。**

### 摘要五要素模板

```
【第一句】针对……问题，建立了……模型。
【第二句】方法细节：对问题一，采用……方法（公式/算法名），解决了……；
                 对问题二，采用……，得到……结果；
                 对问题三，……
【结果句】得到……（关键数值，必须具体！）
【验证句】通过……（交叉验证/误差分析/灵敏度分析），结果可靠，误差在……以内。
【收尾句】模型具有……优点，对……有参考价值。
```

### 摘要范例（通用骨架，替换内容即可）

> 针对太阳能电池板倾角优化问题，本文建立了基于辐射传输机理的**角度-发电量数学模型**。对问题一，建立了日辐射量计算模型，利用数值积分求得最优倾角为 **32.4°**；对问题二，……；对问题三，……。通过**双角度交叉验证**，模型结果与实际测量值的平均相对误差为 **2.1%**，验证了模型的可靠性；灵敏度分析表明，当地纬度每变化 1°，最优倾角变化约 0.8°，模型对参数扰动不敏感，具有较好的鲁棒性。

**关键词**：3~5 个，如：数学模型；数值积分；灵敏度分析；优化

### 摘要禁忌（评阅老师最反感的）

| 禁忌 | 改正 |
|---|---|
| "我们用层次分析法分析了问题" | 写明：层次结构几层、判断矩阵规模、CR 值多少 |
| "结果较为准确" | 写明：误差具体多少 % |
| "首先……其次……最后" 流水账 | 按问题一/二/三的逻辑讲 |
| 满页公式没有结果 | 结果数值必须出现 |
| 用"大约/约" | 精确到有效数字 |

## 三、正文各部分写法要点

### 问题重述
- 用自己的话重写，**不要照抄题目**（照抄会被扣分）。
- 突出：已知什么、要求什么、约束什么。

### 问题分析
- 用**文字+箭头图**展示思路：问题 → 拆解 → 方法。
- 对每个子问题写 3~4 句：用什么方法、为什么、难点在哪。

### 模型假设（见专文）
### 符号说明
- 表格三列：符号 | 含义 | 单位。
- 符号全篇统一，第一次出现时解释。

### 模型建立与求解（正文主体）
每个子问题按固定节奏写：
```
1. 建模思路（1 段文字）
2. 模型公式（编号，如 (1)(2)(3)）
3. 求解算法（算法步骤 + 关键代码逻辑，不用贴全部代码）
4. 结果（表/图 + 数字结论）
5. 分析（结果为什么合理、与预期是否一致）
```

### 灵敏度分析（见专文）

### 模型评价
- 优点 3~5 条（具体！）："考虑了 XX 因素""误差小到 XX""算法复杂度 O(nlogn)"。
- 缺点 2~3 条 + 改进方向："未考虑 XX，可引入 XX 模型改进"。

## 四、格式硬性要求（违反可能被取消资格）

| 项目 | 要求 |
|---|---|
| 页边距 | ≥ 2.5 cm |
| 页码 | 摘要页起，页脚中部，阿拉伯数字 |
| 正文页数 | ≤ 20 页（不含附录） |
| 附录 | 全部可运行源代码，缺代码→取消评奖资格 |
| 匿名 | 全文（含附录）不得出现学校/姓名/赛区 |
| 参考文献 | 按科技论文规范，正文标注 [1][2] |
| 电子版 | PDF 或 Word ≤ 20MB，第一页必须是摘要页 |
| AI 声明 | 必须如实声明 AI 使用（2025 强制） |
