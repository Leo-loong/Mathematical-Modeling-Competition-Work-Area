# LaTeX 工程四项问题 · 原因分析与解决方案（诊断轮，未改动任何文件）

> 本轮按用户指令**不修复**，只出根因与方案。下列每条根因均**静态取证**，非推测；证据为生成物原文。

## 问题 1：图无法链接（**根因：候选名自带扩展名 ⟹ 查文件时变成双后缀**）

**证据**
- 生成物候选链首项（`sections/05_模型建立与求解.tex`）：
  `\fgphchain{0.82\textwidth}{../../05_成品图/图01-总体建模流程图.pdf, …}`（**已带 `.pdf`**）
- `preamble.tex` 的查文件逻辑（对每个候选 **再拼一次扩展名**）：
  `\IfFileExists{\fcand.pdf}{…}{\IfFileExists{\fcand.png}{…}{…}}`

**推理**：候选 `图01-总体建模流程图.pdf` → 实际查找 `图01-总体建模流程图.pdf.pdf` ✗；
回落候选 `../../05_成品图/图01` → 查找 `图01.pdf` ✗（成品图真实名为 `图01-总体建模流程图.pdf`，**带题名后缀**）
⟹ **全部候选必然落空**，永远走占位分支。故"图仍无法链接"与相对路径无关，是**后缀拼接 + 猜名**两个缺陷叠加。

**方案（按优先级）**
1. **候选一律不带扩展名**；`\fgphchain` 内按 `不带后缀 → +.pdf → +.png` 三路查（即修 `\fcand.pdf` 之前先试 `\fcand`）。
2. **候选名由"扫描 `50_论文/05_成品图/` 实况"生成，去掉 `.pdf` 后缀**（现有 `scan_figfiles()` 已能取到实况名，只需在拼接前 `os.path.splitext` 去后缀）。
3. 分幅图（`图05a-…`／`图05b-…`）**显式并列**（同号多文件 → 并排两幅或取 a 幅并在注中声明 b 幅，二选一，需你定口径）。
4. 备选（更稳）：**改用 `\graphicspath` + `\includegraphics{图01-总体建模流程图}`**（不查存在性，直接交给 graphicx；缺图会报错而非静默占位）。若你更看重"缺图也编译通过"，则保留 `\IfFileExists` 三路查。
5. 验收：编译后 `main.log` 中应出现被读取的图形文件路径（本轮该证据为空 ⟹ 佐证"从未读到图"）。

## 问题 2：代码仍附着在文末（**根因：开关只关掉了 B.13，未关掉 B.1–B.12**）

**证据**：`sections/10_附录.tex` 中 `\srcfile{…}` **59 处**、`\lstinputlisting` 0 处（后者在 `preamble` 宏内）、`\texttt{代码名}` 0 处。
本轮新增的 `EMBED_CODE=False` 只作用于 `apx_tail.append(...)`（B.13 段），而 **B.1–B.12 的循环走的是另一个写入点** ⟹ 十二块代码照旧逐块嵌入。

**方案**：把**两处写入点统一走 `src_line()`**（单一出口，杜绝再漏）；`EMBED_CODE=False` 时附录 B 只留"文件名清单 + 说明"；
并在生成结束时打印 `\srcfile` 计数与 `EMBED_CODE` 状态（**自检而非我以为**）。

## 问题 3：表题显示"（表题待补）"（**根因：题注行在识别前已被转成 `\ref`**）

**证据**：`sections/*.tex` 中"表题待补" **恰好 27 次 ＝ 全部表数**。

**推理**：表题识别是"在已处理行里回溯找以 `表 ` 开头的行"，但该行已先经交叉引用转换 ⟹ 变成
`表~\ref{tab:3}　3 小时内药材的温度…`（以 `\ref` 结束而非 `表 ` 开头）⟹ **回溯永远失败**，于是每张表都落到兜底题注，
且原题注行**留在正文**里成为孤立段落（重复呈现）。

**方案**：题注识别**提前到交叉引用转换之前**（或识别式放宽为 `表~?` ＋ 序号）；
兜底文案由"（表题待补）"改为**不设题注**（`\caption*` 或直接无题注）并**只对确有题注的行编号**，避免污染表计数器。

## 问题 4：公式量过多、编号极大（**根因：全部展示式都进了编号序列**）

**证据**：`sections/*.tex` 中 `\begin{equation}` **74 处**、`\begin{equation*}` **0 处**。
本轮为满足"编号动态化"把**所有**展示式改为编号式，而第五章本身式量最大（含《公式展开方案》的展开式）
⟹ 出现 (5-60) 量级的编号，且大量式在正文中**从未被引用**却占用编号。

**方案（业内常规做法，建议采纳）**
1. **只编号被正文引用的式**：源侧标记（如 `$$…\tag{5-9}$$` 视为"需编号"、其余转 `equation*`／`\[…\]`）。
   —— 既回到"只编号被引用的式"的既有纪律，又不违反"编号由计数器动态生成"。
2. **多行推导合编一号**：`align`（或 `aligned`）内多行共用一个 `\label`，避免一行一号。
3. **可选**：编号仍按节（`\numberwithin{equation}{section}` + 连字符风格），使第五章编号上限受限；
   若你希望**全篇连续**（(1)…(n)）或**按章连续**，口径你可指定，方案可切换。
4. 验收：生成结束打印"编号式/未编号式/被引用式"三计数，三者关系应满足 **被引用 ≤ 编号 ≤ 展示式总数**。
