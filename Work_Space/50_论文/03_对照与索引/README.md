# 03_对照与索引 · **立规**（本目录只准放两种东西）

> **为什么单独立规**：本目录最容易长出"**第二份权威**" —— 把题录表、图表清单、符号表的内容**又抄一遍**，从此不同步。
> 本文件就是**防这件事**：**本目录只允许"指针表"与"派生视图"**；**禁止手写内容拷贝**。
> **上位**：`50_论文/01_写作计划/A_论文工作区设计与文档职责.md` **§〇 多权威防治**。
> 按项目约定，本文件不引用／不记载资料中出现的日期。

---

## 一、两种允许形态（**二选一，且必须在文首声明**）

| 形态 | 文首标识（**机检**） | 规则 | 权威内容改了怎么办 |
|---|---|---|---|
| **甲 · 指针表**（手写） | `[指针表]` | 只存「**论文位置 ↔ 权威 ID**」，**不复述内容** | **不用改** |
| **乙 · 派生视图**（脚本生成） | `[自动生成 · 勿手改]` | 由 `01_写作计划/code/build_indexes.py` 从**章节稿＋权威表**生成 | **重跑即同步** |
| ❌ **禁止** | — | 手写的、**含权威内容的第二份拷贝** | ＝多权威，**必然漂移** |

**一句话判据**：**"权威侧改了内容，这份表是否也必须改？"**
—— **必须改** ⟹ 它是**第二权威** ⟹ **删掉，改指针或改派生**；**不用改／重跑即恢复** ⟹ 合规。

> **★ R-22 豁免（形态乙）**：文首声明 `[自动生成 · 勿手改]` 的**派生视图不受 <20 行限制** ——
> 它**重跑即同步**，**不构成第二权威**。反之：**甲·指针表若 ≥20 行 ⟹ 必须改派生**
> （这正是 `A_图表编号对照.md` **由甲改乙**的原因：51 个 F 号天然 > 20 行）。

## 三、生成方式（**形态乙**）

```bash
python 50_论文/01_写作计划/code/build_indexes.py            # 读取 02_章节稿/基线/ 与各权威表，重写三张派生表
python 50_论文/01_写作计划/code/build_indexes.py --check    # 只做一致性核对，不写文件
```

- **输入**：`50_论文/02_章节稿/基线/A_*.md`（正文）＋ 三张权威表；
- **输出**：本目录下的**四张** `A_*.md`，**每次重写**（幂等）；其中 **`A_图表编号对照.md` 不依赖章节稿**，**0 份章节稿时亦可生成**；
- **触发时机**：① 每写完一节；② 每次改动数字／图号／文献之后；③ **交付前**（与 `paper_lint.py` 一起跑）。

## 六、图表编号：**三套口径与正文引用纪律**（**原《A_图表编号对照》散文部分 · 已迁入**）

> **迁入缘由**：`A_图表编号对照.md` **由甲·指针表改判为乙·派生**（51 个 F 号 > 20 行，撞 R-22）⟹
> **派生文件不得含手写散文**（会被重跑覆盖）⟹ 其散文部分迁至本立规文件，**表格部分交脚本生成**。

### 6.1 三套编号的分工（**别混用**）

| 编号 | 形态 | 谁在用 | 用途 |
|---|---|---|---|
| **论文内索引号** | `图5-1`（**带连字符**） | **正文写作**（我方） | **唯一写进论文的图号**；与 PDF 文件名无关 |
| **PDF 文件索引号** | `图01`–`图51`（无连字符） | 交付的 PDF 文件名 | 定位文件 |
| **F 号** | `F-01`–`F-51` | 规格卡／数据 CSV／催办 | 设计与溯源口径 |

**分配规则（论文内索引号）**：`图<章号>-<序>` —— 模块号取《A_章节计划与素材映射》的**章号**（图基本落在**第五章／第六章**）；序＝该章内**正文引用顺序**（1 起）。
> **模块内增删 ⟹ 只重排本模块的序**；**跨模块不动**。

### 6.2 正文引用纪律（**三条**）

1. **每张图／表都必须在正文被引用**，且**紧跟一句"这意味着…"**（说清这张图说明了什么）—— 机检 **R-15**；
2. **正文只写「论文内索引号」**（`图5-1`）：**不写 PDF 文件索引号、不写 F 号**（那两套**只出现在每节稿末的「占位清单」**里）；**不内嵌图片、不指定版式**（版式归排版成图方）；
3. **图数据只认** `20_交付包/04_图表包/data/*.csv`；与《A_数值口径总表》冲突 ⟹ **停并回询**。

### 6.3 定稿时的"一次机械动作"（**派生表是唯一桥梁**）

1. **按论文内索引号的出现顺序**，给 `50_论文/05_成品图/` 的 PDF **统一改名**为最终图号；
2. 正文**一次机械替换**：`图<章号>-<序>` → 最终图号；
3. 删除各节稿末的「占位清单」块。

> **缺口**：见 → `30_图表/05_交付清单/A_图表缺口清单.md`（**已闭合**）；**残余问题**见 → `30_图表/05_交付清单/A_图表残留问题清单.md`。
> **收取与命名**：见 → `50_论文/05_成品图/README.md`。
