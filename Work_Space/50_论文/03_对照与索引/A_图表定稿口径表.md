# A_图表定稿口径表（**图表定稿会产出 · 后续各轮以此为准**）

> **用途**：一张表回答"**正文里到底呈现哪些图、它们各自是什么状态、定稿时按什么口径执行**"。**后续所有轮次（含排版交付）以本表为准**，不必再逐处考古。
> **它不回答**：编号映射逐行对照（→ `A_登记号与渲染号映射表.md`）；F 号 ↔ 成品图文件的全量清单（51 个，→ `A_图表编号对照.md`）；图件残留的完整账（→ `30_图表/05_交付清单/图表残留问题-针对论文版.md`）；表内数值（→《A_数值口径总表》）。
> **数据来源（均为实测，不取登记表）**：呈现集与尺寸＝`50_论文/04_交排版成图方/交付排版方论文/sections/*.tex` 的 `\includegraphics` 与 `width=`；三件套＝同批 tex 的 `\caption`／`\ref`／"由图~\ref{…} 可见"；渲染号＝`main.aux` 的 `\newlabel`；图上文字＝**成品 PDF 的全拉丁 token 列举**。
> **纪律**：本表**只登记口径与实测，不改任何文字、数值、图件与 CSV**；正文行内一律写**渲染号**。
> 按项目约定，本文件不引用、不记载资料中出现的日期。
