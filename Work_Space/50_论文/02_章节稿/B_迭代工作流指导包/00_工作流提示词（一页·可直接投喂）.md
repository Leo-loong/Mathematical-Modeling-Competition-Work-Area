# 00_工作流提示词（一页 · 可直接投喂）

> **定位**：**唯一需要读的一页**。执行者（人或 AI）开工前照此行事；**方向、批次与"本轮源"由用户指定**，本页只替他重复几条基础约束。
> **本页不预设任何"源"**（源每轮由用户给出）。
> **不做什么**：不建候选池、不算收益分、不记轮次台账、不停留于讨论。**每次直接在原文件上修改。**
> 按项目约定，本文件不引用／不记载资料中出现的日期。

---

## 一、提示词正文（可直接复制投喂）

```
【角色】你是本文档的内容执行者。**方向、批次与"本轮源"由用户指定**；
        你自主完成"读源 → 比对 → 出清单 → 落笔 → 编译 → 报数"，
        并替他守住下面这些"不需要每次重申"的基础约束。

【四步流程】
S1  用户指定**本轮源**（1 份或多份：文档／代码／数据／历史素材皆可；本提示词不预设）。
S2  **你自主分析比对，先给用户两份清单**（格式见 A_01 §三）：
     ① **值得保留／补入模型的内容** —— 每条必须写得出**出处**（文件＋节/行）与**拟落点**（章-节）
     ② **现有模型内容中应删除或简化的部分** —— 每条写**位置（章-节＋首句）＋ 理由 ＋ 替代说法**
        另单列 **"正文有、源中无出处"的存疑项**（标注"未在源中核实"，处置为待核实／待删）
     两张清单各给"合计行数"，并给出**净预算 = 补入 − 删简**
S3  用户过目；**若用户未打断，直接跑四链路**（顺序不可逆、不可跳层）：
     ① 基线/  → ② 章节内容库/  → ③ 成文/  → ④ 生成 → 编译 ×2 → PDF
     （若已从成文层直改，须在基线与内容库的变更记录里如实补账）
S4  收批只报四项（不要长篇过程记录）：
     · **正文 PDF 页数**（★硬门槛：**不得超过 32 页**）与摘要页页数
     · 六项硬指标：Float too large 0 ｜ Overfull vbox 0 ｜ Overfull hbox 0 ｜
       超页宽 0 ｜ 无表号/无表题的表 0 ｜ multiply defined 0
     · **题面表 1–表 6 的数值与行列未动**（**其余一切表可增删改**）✅
     · **改了哪几处**（章-节＋首句即可）／**删简了哪几处**／**护栏项未动**的声明

【判据（用于取舍与排序）】
     · 评分权重：表述清晰性 ＞ 建模创造性 ＝ 结果正确性 ＞ 假设合理性
       ⟹ **删"重复与过程"，保"解释与论证"**；不得为腾版面删掉图表的引用句与结论落点
     · **护栏（不可删、不可改）**：**题面表 1–表 6** 的数值与行列（**其余一切表可增删改**；
       **`50_论文/05_成品图/` 内 51 个 F 号任意可用，降级 ≠ 删件**）；全部结论、误差带、
       合成口径（两类不确定度分列报告、不得相加）；全部量级对照；界面取法（积分平均）
       与低含水率端外推两条口径声明
     · **数值唯一真值链**：正文数字 ←《A_数值口径总表》← 结果文件；对不上则**停下回询**
     · **冲突裁决**：代码 > 文档；口径表 > 其他一切数值来源
     · 各问 X.5 只给要点，证据与图表归第六章，**两处不复述同一结果**

【每次都守的格式硬约束】
        1. 表题行 `表 N　题` **必须紧邻表格**（中间不插正文）；图注行 `图 X-n　题` **单独成行**
        2. 段落之间**留空行**（不留 ⟹ 会被合并成一大段、不换行）
        3. 公式写 `$$…\tag{5-n}$$`，**只给被正文引用的式编号**；表下注写 `> 注：…`
        4. 正文**禁加粗**、**禁分点符号**、**禁内部代号与文件名**、**只写论文内索引号**（不写 F 号）
        5. 数值**写普通文本**（不用行内数学包裹），便于逐符号回表
        6. 派生量写"可由表 N 复算"，**不落裸数**
        7. **不改** main.tex／preamble.tex 的版式区；确需改生成器，走 `GEN_VERSION` 升版（自动 .bak）

【越界即回询，不要自行决定】
        · 涉及**表号体系**（题面表已呈现为 **表 1…表 6**；补充表按章编号 表 4-1／表 5-1／表 5-2）
       · 需**新建／重画图件**（新增 F 号）——**启用已有 F 号（含已降级图）不需回询**
        · 需改**版式**（字号／行距／页边距／图表列宽与混排）· 与用户方向不一致的"顺手优化"
```

## 二、页数门槛说明（**务必看**）

| 项 | 值 |
|---|---|
| **本轮硬门槛（用户设定）** | **正文 ≤ 32 页**（**硬**）；**页数口径＝附录起始页 − 2**（摘要 1 页、正文含参考文献）⟹ **当前实测 30 页**；**★ 用户后定口径：正文 ≤31 即不必再反复压缩** ⟹ **≤29 的净压缩目标不再强制**（官方红线 ≤30 仍须在**定稿版式环节**收口；细则与自证见 `A_03 §一之二`） |
| 官方红线 | **正文 ≤ 30 页**（官方《论文格式规范》第四条） |
| 二者关系 | 内容侧跑到 **31–32 页**时**仍在用户门槛内**，但**超官方红线** ⟹ **须在定稿手动混排环节收进 ≤30** |
| 收口手段（**现在不启用**） | ① 行距 `1.06→1.02`；② 图宽 `0.66→0.60`；③ 表格字号 `\small`；④ **图表混排**。**各约 −1 页**，且**都不消耗内容预算** |

> **总则（自本轮起 · 打磨优先）**：**不做基线维护与状态维护**；每轮按 `04 §一` 的**三步**走（**确认 3–5 处 → 三步编写（基线→内容库→成文）→ 编译报页码**）；工作重心放在 **内容打磨（`04 §四`）与图表打磨（`04 §五`）**；**收批只报三项**（页码／六项硬指标／打磨处）。
>
> 因此：**内容侧按 `A_03 §一之二` 的本阶段目标跑（净压缩约 2 页 → ≤29）**；**定稿环节务必回落到 ≤30**（官方口径）。二者不可混记。
> **手段边界**：本阶段**只许内容手段**（删过程句／并重复口径／降级冗余图／并表行）；**行距、图宽、字号、混排属排版方**，另计入定稿收口，**不得用来充抵本阶段指标**。

## 三、使用方式

| 场景 | 怎么做 |
|---|---|
| **开一批** | 用户给"**本轮源**"（＋可选：限定范围）；执行者按 S2 出两份清单，再按 S3 落笔 |
| **执行中** | 用户随时改方向；**不要求**记录过程，只要求"改在哪、删在哪、没动什么" |
| **收一批** | 执行者按 S4 报四项；用户决定是否进下一批 |
| **回退** | 直接改回即可（删减前快照在外部备份目录，可整段取回） |
