# 02 · 本轮提示词（**自主复查 · 修复 · 优化**）

> **怎么用**：本页**可直接复制投喂**给执行者。
> **本页只携带"判据"，不携带"状态"** —— 状态以执行者自己的实测为准。
> **流程见 `00_工作流提示词`；格式见 `A_02`；口径见 `A_03`；规则见 `00_规则/`**（本页不重述）。
> 按项目约定，本文件不引用、不记载资料中出现的日期。

---

## 〇、本轮性质与授权边界

**性质**：不是新任务，而是**对上一轮（清源批 ＋ 回归批）的自我复查与收口**。三件事，顺序固定：

| 序 | 事 | 允许的动作 |
|---|---|---|
| ① | **复查** | 只读；**必须输出"检查项 → 结论（0 处／n 处）"的完整表格** |
| ② | **修复** | **最小改动**（改值／改引用／改计数／加状态注）；**不得**重写段落、改结论、改推导 |
| ③ | **优化** | 把本轮经验**固化为"可机检的例检项"**（写进规则／脚本），**不是再写一段说明文字** |

**硬边界（违反即越权）**
1. **不重跑任何求解／批量实验**（`00_规则/工作约束.md §12`，最高优先；不得以"验证一下"为由）。
2. **不直接编辑交付工作区**；推送由 `tools\wsdiff.py` 执行，**`apply --yes` 仍须用户批准**。
3. **不改**：题面表 1–表 6 的数值与行列、`result*.xlsx`、成品图与 CSV、《口径表》的**登记值**、`00_规则/`、`10_赛题/`。
4. **不改版式**；**不新建图件**（新增 F 号须回询）。
5. **删除／移动文件（除已批准项）须回询**。

## 一、复查清单（**四类，逐类给表**）

> 每条都要给"**检查项 / 方法 / 命中数 / 处置**"。**0 处命中就如实报 0 处** —— **不得为了"复查有产出"而制造改动**。

### A. 编号与渲染回环（**本轮新增发现的那一类，必须做全套，不只做补丁点**）

| 检查项 | 方法 | 合格判据 |
|---|---|---|
| **A1 表号回环** | 建立**三列对照表**：登记号 ↔ 呈现号（从实测 PDF 取） ↔ 正文引用号（从生成后 tex 的 `\ref` 解析） | **三列逐行相等**；**覆盖全部表**（题面 6 ＋ 全部补充表 ＋ 附录表），**不得只核"题面表组之前"的那一张** |
| **A2 生成器边界回归** | 针对**上一轮改动的编号机制**，构造/核对边界情形：题面表组**之前／之中／之后**各至少一张补充表；跨章（第五、六章）；附录表；同一节内连排两表 | 各边界下补充表仍呈**登记号**；题面表仍**全篇连续** |
| **A3 图号与式号** | 图注号 ↔ 正文引用；式号连续性（第五、六章） | 无缺号、无重号、无悬空引用 |
| **A4 引用完整性** | 编译日志中的 `Reference`／`Undefined` 类警告 | 均为 **0** |

> **若 A1–A4 发现新的编号缺陷**：**只报不擅改**（编号机制属"渲染修复"边界；改法须回询确认）——**除非**该缺陷与上一轮同因同解（则按同法修，并在 `A_02 §六` 追加陷阱行）。

### B. 口径副本回环（**防"改一处漏三处"再度发生**）

| 检查项 | 方法 | 合格判据 |
|---|---|---|
| **B1 口径清单 ↔ 实际** | 用 `A_03 §一／§二` 的每一条，反查全库**生效性语句**（跳过"变更记录"区段） | 无与现行口径冲突的生效性语句 |
| **B2 本轮涉及的三类表述** | 关键词扫描：**表号体系**（补充表编号）、**冻结面**（哪几张表不可动）、**图件可用面**（F 号是否需回询） | 三者表述在**全部**相关文件里一致（含各层 图表登记／内容库总纲／写作基线） |
| **B3 作废行可读性** ***（本轮特别授权）*** | 检查 `A_03 §二` 是否仍有"**已被后续行推翻、但自身仍读作现行**"的旧行 | 允许在**被作废行尾部追加"⚠ 已作废，见 #N"状态标注**（**只加标注，不改写原行文字**）——这是**状态标注**，不算回改历史 |

### C. 修复完备性（**"半边改"自查**）

| 检查项 | 方法 | 合格判据 |
|---|---|---|
| **C1 同源扩散** | 对**每一个**本轮改过的值／表述，做一次全库同源检索（不限 `11_建模`，含论文侧、增量包、台账） | 命中项**全部**已改或已明确标注"仅为历史／过程证据" |
| **C2 检查脚本覆盖度** | 列出本轮**实测类**检查各自覆盖了什么、漏了什么（尤其：只覆盖正常路径、未覆盖边界的） | 给出**覆盖度表**，并指出尚存盲区 |
| **C3 未采纳与计划态** | 扫描是否有"计划态／未采纳"被读作"已完成" | 0 处 |
| **C4 留痕** | 本轮改动过的每个文件是否都有变更记录追加 | 逐文件列出追加行；缺失者补建（只追加） |

### D. 风险面（**外部副作用与残留**）

| 检查项 | 方法 | 合格判据 |
|---|---|---|
| **D1 推送核验单** | 对 `wsdiff diff` 结果做**分类计数**：归档类／临时垃圾类／重复与重命名类／**未知类**；对交付范围的**每个删除项**给一句理由；**单文件变更项逐项列出**（已知缺陷涉及） | **未知类 = 0**；且**推送前先做一次快照**（`wsdiff snap`）以便回退；**`apply --yes` 不自行执行** |
| **D2 陈旧脚本残留** | 扫描"脚本已归档／已失效，但其产物（报告／日志／缓存）仍留在工作区"的成对项（含你上轮提出的那一件） | 给出**清单 ＋ 建议处置**；**归档须批准**（已批准的同批次一并执行） |
| **D3 工作区卫生** | 临时目录、缓存（`__pycache__` 等）、一次性产物 | 清出工作区（或明确列出为何保留） |
| **D4 定稿前置项** | `A_03 §一` 登记的**图件残留 P0** 是否已有新到件（绘图方可能已改） | 逐项给"已到／未到"；**未到的照旧挂账**，不删不改 |

### E. 图表收口（**本轮追加**：图号映射与图表本体）

| 检查项 | 方法 | 合格判据 |
|---|---|---|
| **E1 图号四方对齐表** | 对**正文全部呈现图**逐张列四列：**论文号 ↔ F 号 ↔ 成品图文件名 ↔ 正文引用／图注**；文件名一列同时给**存在性 ＋ 哈希**（与《A_图表交付清单》§七／规格卡登记对拍） | 逐行标"**一致／不符**"；不符项**必须给处置**；**未启用的降级图不受影响** |
| **E2 登记号 ↔ 渲染号映射表**（**定稿前置件**） | 成文里的**登记号**与 PDF 里的**渲染号**（按出现顺序）**目前并存且不一致** ⟹ 出一张**双向映射表**，落 `50_论文/03_对照与索引/`，并登记变更记录 | 覆盖**正文全部呈现图**；**定稿机械排号时直接可用**；表侧沿用 §一 A1 的三列对照（不必重复做） |
| **E3 图件残留 P0 到件状态** | 逐项报"**已到／未到**"；已到者按字符级判据（图内中文／字体族／图内无自带编号）核；未到者**挂账并催办** | **不改图、不降级**；**是否降级留待定稿前由用户裁定**；状态回写《图表残留问题-针对论文版》 |
| **E4 明确不做**（**防范围蔓延**） | ① **不用余量恢复图**：正文 31 页／硬门槛 32，**余量 1 页须留给官方红线 30 的收口**；② **不做 CSV／二进制逐格核**（属 T2／T3 规模，需出申请单） | 二者若被提出 ⟹ **回询**，不得自行执行 |

> **E 类的定位**：它**不是"再补图"的回归轮**，而是**图号与图表本体的收口**；**并入本轮执行，不得另开批次**（单写者：同一时间只允许一个执行者改同一批文件）。
> **图表本体纪律**：本轮**不得改动任何成品图 PDF、图数据 CSV、规格卡**；若需给"未改动"的证据，**用 E1 的哈希对拍，而不是凭声明**。
> **本轮唯一可能新增的图表侧文件**：E2 的映射表（新增件，非改件）。

## 二、修复规则

1. **最小改动**；改完在**该文件变更记录追加一行**（版次 ＋ 一句话 ＋ 依据）；**无变更记录的补建**。
2. **数值只来自《口径表》**；**派生量写"可由表 N 复算"**。
3. **进入论文侧的每一句仍须过 `01_本轮提示词 §四` 的防污染红线 13 条**（有出处才写／旧值禁入／未采用只能写未采用／内部代号禁入／未决不落笔）。
4. **不许"顺手优化"**：与本次复查无关的措辞／结构／缩减一律不做；**但若本轮触及论文侧，须满足 `A_03 §一之二` 的本阶段页数目标（净压缩约 2 页 → ≤29）**，且**只许内容手段**（版式手段不得充抵）；**不涉及论文侧时，收批须显式声明"本轮不适用"**。

## 三、优化规则（**把经验变成机检项，而不是又一段文字**）

**合格形态**（择一或数项）：
1. **例检项**：把"三列对照（登记号↔呈现号↔引用号）"写进 `A_02 §四` 的收批实测例检，使**每轮**都跑；
2. **陷阱行**：新发现的失败模式写成 `A_02 §六` 的一行（症状 → 根因 → 处置 → 证据）；
3. **规则化**：把本届新约定写进 `A_02`／`A_01`／`A_03` 的对应条（**不新开文件、不复制口径**）；
4. **定稿前置件**：`§一 E2` 的**登记号 ↔ 渲染号映射表**属**定稿件**，落 `50_论文/03_对照与索引/`（与既有编号对照索引同址），供定稿机械排号直接使用。

**不合格形态**：只写"本轮已注意…""后续将加强…"等**不可机检**的话。

## 四、自证要求（**收批时必须给，缺一不算完成**）

## 五、可自决 / 须回询

| 可自决 | 须回询 |
|---|---|
| 数值／引用／计数与现状不符的更正（以《口径表》为准） | 两个权威打架（数值真值之间） |
| 同源扩散的补齐、留痕补建 | **编号机制的改法**（除与上轮同因同解） |
| 工作区卫生、陈旧残留的**清点** | **归档／删除／移动**文件 |
| 口径清单的**状态标注**（§一 B3） | `wsdiff apply --yes`、任何版式／图件新增 |
| 把经验固化为例检项／陷阱行 | 需要改动 `00_规则/` |

## 六、收批（只报四项 ＋ 未决）

1. **正文页数／摘要页数**（口径见 `A_03 §一 #8`）；
2. **六项硬指标**（各 0）＋ **A1 三列对照是否全等**；
3. **题面表 1–表 6 数值与行列未动**；
4. **本轮改动处（含"0 处"的检查项列表）／删简（应为 0）／护栏未动 ＋ 未决项**；并在本项内含 **E 类三项结论**（图号四方对齐是否全等／映射表是否已落／图件 P0 到件状态）与 **"图表本体未改动"的哈希对拍结论**。

**收批后**：若本轮**作废了新口径** ⇒ `A_03 §二` 追加一行；若**新发现失败模式** ⇒ `A_02 §六` 追加一行。
