## 一、符号说明（**只列全局变量**）

### 表 0-1　主要符号一览

| 符号 | 含义 | 单位 |
|---|---|---|
| $t,\ r$ | 时间；到药材中心的径向距离 | s；cm |
| $R_0,\ R(t)$ | 药材初始半径；时变半径（仅问题四出现） | cm |
| $L$ | 药材长度 | cm |
| $\xi$ | 归一化径向坐标 $r/R(t)$（问题四物料坐标） | — |
| $T(r,t)$ | 药材温度 | ℃ |
| $C(r,t)$ | 干基含水率 | kg/kg |
| $T_0,\ C_0$ | 初始温度；初始干基含水率 | ℃；kg/kg |
| $T_\infty(t),\ C_\infty(t)$ | 烘房温度；烘房水分浓度 | ℃；kg/kg |
| $C_{\rm crit}$ | 烘干达标阈值 | kg/kg |
| $t_{\rm dry}$ | 烘干所需时间 | h |
| $\rho,\ c_p,\ k$ | 密度；比热容；热传导系数 | kg/m³；J/(kg·K)；W/(m·K) |
| $D$ | 水分扩散系数 | m²/s |
| $h,\ k_m$ | 对流换热系数；对流传质系数 | W/(m²·K)；m/s |
| $\alpha$ | 热扩散率 | m²/s |
| $Bi_T,\ Bi_m$ | 传热毕奥数；传质毕奥数 | — |
| $Fo$ | 傅里叶数 | — |
| $\Delta r,\ \Delta t,\ N$ | 空间步长；时间步长；径向区间数 | mm；s；— |
| $\tau_T,\ \tau_C$ | 热扩散特征时间；质扩散特征时间 | s |
| $\mathbf A,\ E,\ G_0,\ G_1$ | 温度半离散系统矩阵；矩阵指数；分段线性推进系数 | s⁻¹；—；s；s² |
| $\mathbf d^{n},\ \omega$ | 后向欧拉的右端向量；Picard 欠松弛因子 | —；— |
| $i,\ n$ | 空间节点下标；时间层下标 | — |

> **单位口径**：表 0-1 按**论文呈现口径**列出（长度用 cm／mm、温度用 ℃、时间用 s）；**模型内部计算一律采用 SI**，且附录 4 中扩散系数经验式的 $T$ **必须以 K 代入**（第五章相应处已声明）。
>
> **取值说明**：上述参数的具体取值（$R_0=2$ cm、$L=25$ cm、$T_0=28$ ℃、$C_0=2.55$ kg/kg、$h=25$ W/(m²·K)、$k_m=8\times10^{-7}$ m/s、$C_{\rm crit}=0.15$ kg/kg、$\Delta r=0.25$ mm、$N=80$ 等）**在第五章首次使用处逐一给出，并标明其附录或附件来源**；本节只作符号定义。

### 分组说明（便于排版分块）

| 组 | 符号 | 说明 |
|---|---|---|
| **自变量与几何** | $t,\ r,\ R_0,\ R(t),\ L,\ \xi$ | 问题四才出现 $R(t)$ 与 $\xi$ |
| **场量与初值** | $T,\ C,\ T_0,\ C_0,\ T_\infty,\ C_\infty,\ C_{\rm crit},\ t_{\rm dry}$ | 两个待求场量与边界／判据量 |
| **物性参数** | $\rho,\ c_p,\ k,\ D,\ h,\ k_m,\ \alpha$ | 前三套物性按问题分套（见假设 3） |
| **无量纲数与数值参数** | $Bi_T,\ Bi_m,\ Fo,\ \Delta r,\ \Delta t,\ N,\ \tau_T,\ \tau_C$ | 用于模型选型与精度预算 |
| **问题一温度侧专用** | $\mathbf A,\ E,\ G_0,\ G_1,\ h$（分段步长） | **仅在该格式推导处出现**，与上表 $\Delta t$ 区分场景 |
| **下标与集合** | $i,\ n$ | — |

> **两处易混**：① 符号 $h$ 兼指对流换热系数与温度侧精确推进的分段步长，**两者出现场景不同**，正文按上下文区分并在首用处注明；② 问题一温度场使用**时间方向精确推进**（无时间步 $\Delta t$），问题一含水率与其他各问全部场量使用**后向欧拉全隐式**（步长 $\Delta t$），**不得混写**。
