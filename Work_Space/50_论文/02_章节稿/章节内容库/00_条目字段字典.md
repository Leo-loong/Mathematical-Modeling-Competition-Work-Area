# 00_条目字段字典（第二环节 · 章节内容库）

> **定位**：本文件是「章节内容库」的**格式权威**——13 个字段的定义、取值规则与正反例。**各模块内容条目文件一律照此填写**。
> **上游**：`A_第二环节实施方案_内容条目与图表登记.md` §2.3／§2.4／§6.1。
> **纪律**：字段**逐条必须齐备**；确不适用的写 `不适用（理由）`，**不得留空**。
> 按项目约定，本文件不引用／不记载资料中出现的日期。

## 一、条目 ID 与节号规则

### 1.1 ID 形态

```
<模块号>-<节号>-<序>          例：08-5.2.3-004     例：02-00-03     例：04-1-02
  两位      点分或 00       两位（跨 99 用三位）
```

### 1.2 节号取值（**唯一规则，避免自造**）

| 模块类型 | 节号 | 例 |
|---|---|---|
| **主体章**（模块 8／9／10） | 直接取论文节号 | `5.1.1`、`5.5`、`6.4`、`6.11` |
| **有中文序号节的模块**（4／5／6／7／11） | 章内**一级**中文序号 → 数字；其下**阿拉伯子节照写** | `一、问题重述` → `04-1-*`；`2.1 问题一的分析` → `05-2.1-*`；`一、模型优点` → `11-1-*` |
| **无节号的模块**（1／2／3／12／13／14） | `00` | `02-00-03`（摘要第 3 条） |
| **章内中文一级序号**（`一、`／`二、`／`三、`） | 章号 ＋ 序号 | 04 章 `一、问题重述` → `04-1-01`；11 章 `三、模型的推广` → `11-3-09` |
| **基线自带字母后缀的节**（如 `5.1.1b`） | **照写**（忠实基线） | `08-5.1.1b-010` |
| **章末管理区**（占位清单／本章图表去向等内部块） | `9` | `10-9-046`、`08-6-072` |

> **不得**新造节号；需要新增节时，走「变更登记」并同步回改基线（见 §五-3）。
> **跨模块指向**：条目如需提及**他章**的图／表，在「关联图表」字段写"（见第 X 章 `图X-n`）"并在本模块图表登记文件的 §三 前以"**跨模块说明性提及**"一句声明——**不得**把他人图表登记为本模块插图。

## 二、13 个字段

| # | 字段 | 定义 | 取值规则 | 正例 | 反例 |
|---:|---|---|---|---|---|
| 1 | **条目 ID** | 唯一标识 | 见 §1 | `08-5.2.3-004` | `条目4`、`5.2.3-4` |
| 2 | **所属节** | 该条目落在哪一节 | 章-节名（与基线 §三 节级骨架一致） | `第五章 5.2.3 离散格式与求解算法` | `第五章` |
| 3 | **类型** | 九类之一 | 叙述／数值结论／公式／表／图／引用／对照实验／边界声明／自查 | `数值结论` | `内容` |
| 4 | **条目** | **该段要写什么** | 一句话；**必须可验收** | `给出问题三的达标时间及其离散误差带，并写明合成口径` | `介绍结果` |
| 5 | **依据** | 事实／数值的出处 | **文件 ＋ 节／行**；数值类**必须**指《数值口径总表》对应节 | ``20_交付包/05_数值口径总表/A_数值口径总表.md`` §10.2／§10.4 | `口径表`、`素材` |
| 6 | **数值口径** | 涉及数字时的完整口径 | `登记值 ＋ 误差带 ＋ 合成口径 ＋ 位数`；无数字写 `—` | `57.53 h；±0.08 h（空间 GCI 与时间上界取较大者）；四位小数口径见表 5` | `约 57 小时` |
| 7 | **关联图表** | 该条引用的图／表 | 论文内索引号（`图<章号>-<序>`／`图A-n`／`表 n`／`表 X-Y`）；无则 `无` | `表 5、表 6` | `F-33`、`图29` |
| 8 | **关联文献** | 该条挂的文献上标 | `[n]`（$n\le18$）；无则 `无` | `[9][10]` | `文献9` |
| 9 | **目标篇幅** | 该条的体量预算 | `N 行` 或 `N 字`（与基线 §三 该章篇幅相容） | `3 行` | `简短` |
| 10 | **状态** | 生命周期 | 草稿／已取证／已冻结／已用于成文 | `已取证` | `完成` |
| 11 | **验收判据** | **可机械判定**的一句话 | 例：含 ≥2 个已登记数值／该图必被引用且紧跟"这意味着…" | `含 2 个已登记数值，且写明合成口径` | `写好即可` |
| 12 | **风险／备注** | 暂定口径、待裁项、外部依赖 | 引 C-xx；外部依赖写"成品待补""数据待导出" | `C-06 去重：证据归第六章` | `无` |
| 13 | **变更痕** | 冻结后修改痕迹 | `—`（未改）或 `v2：改 X（来源）` | `v2：误差带由 ±0.05 改 ±0.08（口径表 §10.4）` | `改过` |

## 三、类型词表（九类，唯一取值）

| 类型 | 判据 | 典型落点 |
|---|---|---|
| 叙述 | 机理／思路／方法说明，不含关键数字 | 5.x.1 分析与建模思路 |
| **数值结论** | **含已登记数值**的结论句 | 5.x.4、6.x、摘要 |
| 公式 | 需编号的推导式或结论式 | 5.x.2／5.x.3 |
| 表 | 承载题面表或本文补充表 | 5.x.4 |
| 图 | 承载图素材及其引用句 | 5.x、6.x |
| 引用 | 需挂文献上标的方法／物理依据句 | 5.x.1／5.x.2／5.x.3 |
| **对照实验** | 自研对照（格式／口径／退化／简化代价／临界／参数对照） | 5.x.3、6.x（见基线 §八） |
| **边界声明** | 误差带、外推区间、适用域、不确定度分列 | 5.x.4 末、6.x、第七章 |
| 自查 | 与题面交付物的逐项对应 | 模块 9／14 |

## 四、状态词表与流转

| 状态 | 进入条件 |
|---|---|
| 草稿 | 条目已写，但依据／数值口径尚未定位 |
| **已取证** | 依据可定位 ＋ 4–8、11 字段齐备 |
| **已冻结** | 所属模块**覆盖矩阵全部回勾** ＋ 机检（`paper_lint --mode doc` ＋ `check_contentlib`）**❌ 0** |
| 已用于成文 | 第三环节已按该条落笔 |

> 冻结后修改：状态**回退为"已取证"**，并在「变更痕」留痕；同步回改图表登记与总纲覆盖矩阵（见方案 §2.6）。

## 五、填写纪律（五条）

1. **依据必须可定位**——写不到"文件 ＋ 节／行"的条目，一律视为**未取证**；
2. **数值只认口径表**——正文数字与结果文件已逐格一致，但**登记口径在《数值口径总表》**；**不重算、不推断、不四舍五入成更少位**；
3. **图表号只写论文内索引号**——`F-xx` 与 PDF 索引号**只出现在图表登记文件与「占位清单」**（机检 C-6）；
4. **术语同形**——按题录表 §五 统一定名；问次用汉字；用"改进"不用"创新"；
5. **不确定度分列**——两类不确定度**分列报告、不得相加**；合成口径＝**取较大者**，且须在正文写明。
