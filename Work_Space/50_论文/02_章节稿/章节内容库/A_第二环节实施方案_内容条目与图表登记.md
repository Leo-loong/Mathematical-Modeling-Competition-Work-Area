## 〇、为什么需要「内容库」（问题诊断与设计原则）

### 0.1 现状：第一环节产物的**性质与边界**

`02_章节稿/基线/` 的 15 份基线稿是**模块级概览**：每节给出"要点一句 ＋ 图表占位清单 ＋ 自查勾选项"，足以**定框架、定口径、定基调**，但**不足以直接成文**——成文时仍要逐段临场回忆"这句结论的出处是哪个文件哪一节""这个数是否已登记""这张图的引用句怎么写"。

### 0.2 若按"写到哪缺哪补"推进，必然出现三类碎片化风险

| 风险 | 典型表现 |
|---|---|
| **漏项** | 某问的某项检验、某条边界声明在成文末期才想起，只能临时插入，破坏该节已定的结构与篇幅 |
| **口径漂移** | 同一数字在不同段落出现两种写法（位数／单位／基准不同）；同一术语两种称呼 |
| **图表失控** | 图号与正文引用不同步；"每图必被引用"到成文末期才发现缺口，被迫回改多节 |

### 0.3 设计三原则（本环节的立身之本）

1. **一次性建库**——把成文所需的**全部**内容条目**一次列全**；"零星补充"**不作为常规模式**，只作为经变更登记的例外。
2. **条目即合同**——成文阶段**只允许**从条目抄写。条目必须把"依据（文件＋节）／数值口径／关联图表／关联文献／引用句"写到**可直接落笔**的程度。
3. **冻结与留痕**——条目集**冻结为版本号**；此后任何新增／修改一律走**变更登记**，并同步回写受影响模块与图表总账。

## 二、任务清单构建方案

### 2.1 三级结构：章 → 节 → 条目

```
模块（=章，A_01…A_14）
  └─ 节（与《00_全文写作基线》§三「节级骨架」逐节一致；主体章为 5.0／5.1.1–5.1.5／…）
       └─ 条目（最小写作单元：≈ 一个自然段 ／ 一张三线表 ／ 一组图）
```

**节号纪律**：节号**必须**取自基线 §三 与骨架落地的节级绑定；本环节**不得新造节号**（需要新节时走变更登记，并同步回改基线）。

### 2.2 粒度判据（三条，同时满足才立项）

1. **成段性**：一条目 ≈ 论文中一个自然段，或一张表／一组图的完整呈现；
2. **可独立验收**：能单独判定"是否已写、是否符合要求"；
3. **不可再拆**：若再拆则无法独立成段（如"某数值的出处""某符号的单位"**不单列条目**，填在字段里）。

### 2.3 条目字段字典（13 字段 —— 逐条必须齐备，不适用者写"不适用 ＋ 理由"）

| # | 字段 | 填写规则 |
|---:|---|---|
| 1 | **条目 ID** | `模块号-节号-序`，例 `08-5.2.3-004`（序为两位序号，全模块连续） |
| 2 | **所属节** | 章-节，例 `5.2.3 离散格式与求解算法` |
| 3 | **类型** | 叙述／数值结论／公式／表／图／引用／对照实验／边界声明／自查（九类，见 2.4） |
| 4 | **条目（写什么）** | **一句话**说清该段要写的内容；禁止只写"介绍 XX"这类不可验收的表述 |
| 5 | **依据（权威源＋定位）** | **文件 ＋ 节／行**，必须**可定位**；数值类必须指向 `20_交付包/05_数值口径总表/A_数值口径总表.md` 的对应节 |
| 6 | **数值口径** | 涉及数字时填：登记值 ＋ 误差带 ＋ **合成口径**（取大者）＋ 位数（跟口径表走）；无数字写"—" |
| 7 | **关联图表** | 图／表号（论文内索引号），并指向本章图表登记文件的对应行；无则"无" |
| 8 | **关联文献** | 正文上标 `[n]`（$n\le18$，与题录表双向一致）；无则"无" |
| 9 | **目标篇幅** | 行数／字数，须与基线 §三 的节级篇幅相容（见 2.7） |
| 10 | **状态** | 草稿 → 已取证 → **已冻结** → 已用于成文（状态机见 2.6） |
| 11 | **验收判据** | 一句**可机械判定**的话（例："含 $\ge2$ 个已登记数值""该图必被引用且紧跟一句'这意味着…'"） |
| 12 | **风险／备注** | 暂定口径编号（C-xx）、待裁决项、外部依赖（成品图／数据） |
| 13 | **变更痕** | 冻结后修改时填：变更条目、来源、影响面 |

### 2.4 条目类型（九类）与配额参考

| 类型 | 判据 | 参考占比 |
|---|---|---|
| 叙述 | 机理／思路／方法说明 | 主体 |
| 数值结论 | 含已登记数值的结论句 | 高 |
| 公式 | 需编号的推导式或结论式 | 见 §五-12（公式密度为**暂定口径**） |
| 表／图 | 承载题面表或本文补充表／图 | 见 §三 图表总账 |
| 引用 | 需挂文献上标的方法／物理依据句 | 18 条覆盖 |
| 对照实验 | 自研对照（格式／口径／退化／简化代价／临界／参数对照） | 中 |
| 边界声明 | 误差带、外推区间、适用域、不确定度分列 | 每问 ≥1 |
| 自查 | 与题面交付物的逐项对应 | 模块 9／14 为主 |

> **配额说明**：本表只作**建库时的工作量参考**，**不构成门禁**；全库条目总量以"6 源覆盖矩阵全部回勾"为准（见 2.5）。

### 2.5 覆盖清单的构建法：**6 源交叉「并入法」**

**六源**：
| 源 | 提供什么 |
|---|---|
| **S1** 基线 `00_全文写作基线.md` §三 | 章／节结构 ＋ 节级篇幅 |
| **S2** 基线 §七 | **10 项内容要素覆盖清单**（模型／代码／实验／表／图／结果分析／成果／结论／决策链／对标） |
| **S3** `A_章节计划与素材映射.md` §一 ＋ §二 | 14 模块**必写要点** ＋ 检验章 **10 节结构** |
| **S4** `A_论文写作骨架_本题落地.md` §节级绑定 ＋ §5.1 | 每节"必写"清单 ＋ **图表去向与配额** |
| **S5** `40_复核/01_复核记录/*全面复核*.md` §四 §五 | 四问**检验项与改善项落点**矩阵 ＋ kb 对标缺口 |
| **S6** `40_复核/05_成绩评定/A_成绩评定总报告.md` ＋ `A_章节计划与素材映射.md` §〇 | 成绩评定**检查点** ＋ 赛题官方**21 条**要求 |

**并入法三步**：
1. **立项**：以 S1（节）为主干，把 S3／S4 的"必写要点"逐条挂在对应节下，形成初版条目；
2. **回勾**：用 S2／S5／S6 逐条回勾——**每一条覆盖项必须落到某条目**，或**显式登记为"不写 ＋ 理由"**；
3. **闭环**：把回勾结果写入 `00_内容库总纲.md` 的覆盖矩阵；**存在"未回勾且无理由"的行 ⟹ 该模块不得冻结**。

> **这条是"杜绝碎片化"的核心机制**：覆盖项**要么有条目承接，要么有登记的弃写理由**，不允许第三种状态（"暂时没想到"）。

### 2.6 状态机与冻结规则

```
草稿 ──(依据已定位、字段齐)──▶ 已取证 ──(模块覆盖矩阵回勾通过)──▶ 已冻结 ──(成文引用)──▶ 已用于成文
                          ▲                                            │
                          └────── 变更登记（回退重走）◀────────────────┘
```

- **冻结粒度**：**按模块**冻结，全库冻结形成 `内容库 v1`；
- **冻结条件**：该模块 ① 条目字段齐全；② 覆盖矩阵该模块行全部回勾；③ 图表登记与总账一致；④ 机检 `doc` 模式 ❌ 0；
- **冻结后修改**：必须写"变更登记"（变更条目／来源／影响面），并同步回改：图表登记 → 总纲覆盖矩阵 → 受影响模块条目 →（必要时）基线。

### 2.7 篇幅平衡规则

- 每模块条目"目标篇幅"之和，须落在基线 §三 该章篇幅的 **区间内**（非线性指标、不构成门禁，但**偏离必须写明理由**）；
- 主体章（模块 8＋9）合计为目标 **≈18–22 页**量级；若条目总和显著超出，优先"合并同构条目"（四问同构段落可共用条目模板而**不**合并内容）。
