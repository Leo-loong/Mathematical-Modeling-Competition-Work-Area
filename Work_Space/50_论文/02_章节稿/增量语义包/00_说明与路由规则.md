# 增量语义包（`50_论文/02_章节稿/增量语义包/`）说明与路由规则

> **定位**：本轮"内容级回归"从 `50_论文` 之外（`11_建模`／`20_交付包`／`30_图表`／`40_复核`）搬入的内容，
> **不再追加到既有基线／内容库文件**，而是**单独成立一套文件** —— **每个章节一件「增量语义包」**。
> 写入新发现的"缺口"时，**先判断其归属章节**，再添加到**对应章节的增量语义包**中。

## 一、文件命名（每章节一件）

与 `章节内容库/A_*.md` 的模块一一对应，命名固定：

`增量语义包/A_<模块>_增量语义包.md`
（如 `A_08_模型建立与求解_增量语义包.md`、`A_10_模型检验_增量语义包.md`、`A_04_问题重述_增量语义包.md` …）

每件头部固定一行状态：`> 状态：条目 <n> 条 ｜ 来源件 <m> 份 ｜ 最近更新批次 <Pn>`

## 二、条目格式（逐条可回指）

| 字段 | 要求 |
|---|---|
| `编号` | `IS-<模块号>-<三位序号>`（按写入顺序编，只增不改） |
| `来源` | **源文件相对路径 ＋ 锚**（§小节／表名／式号／函数名／数据列名）；**不接受"见全文"** |
| `批次` | `P1…P6` |
| `通道` | `doc`／`code`／`result` |
| `类型` | 结论／数值／方法／机理／取舍与代价／边界与不确定度／图表依据／代码设计 |
| `陈述` | 一句话讲清该语义单元（源文语义，**不引入新数值**；若含新数值，必须在来源栏写明其出处锚） |
| `建议落点` | 该章节内的具体小节或条目位（若能判断） |

## 三、路由规则（判断归属章节）

| 内容主题 | 归属增量语义包 |
|---|---|
| 题目／题名要素、摘要与结论要点、关键词 | `A_01_题目`／`A_02_摘要`／`A_03_关键词` |
| 问题重述、建模对象与给定数据 | `A_04_问题重述` |
| 问题分析、逐问思路、四问对照 | `A_05_问题分析` |
| 模型假设（含假设依据与松弛影响） | `A_06_模型假设` |
| 符号、约定、口径定义 | `A_07_符号说明` |
| **模型建立与求解**（控制方程、离散、算法、结果与分析、各问检验要点、工作流与实验方案） | `A_08_模型建立与求解` |
| **模型检验**（收敛性、对拍、互验、看门狗、守恒、灵敏度、对照实验、不确定度） | `A_10_模型检验` |
| 模型评价、不足与改进、推广 | `A_11_模型评价与改进` |
| AI 工具使用声明 | `A_12_AI工具使用声明` |
| 参考文献与题录 | `A_13_参考文献` |
| 附录（支撑材料清单、源程序、中间结果） | `A_14_附录` |
| 交付形态与工程细节（产出文件规格、运行环境与耗时、日志索引、打包与命名） | `A_14_附录`（若属"支撑材料/源程序"）或 `A_08`／`A_10`（若属"求解/检验实现细节"） |
| 跨模块的方法学、可靠性、口径与红线（如精度速度双轨、可删减部分） | 先入**最相关章节**；若确无归属，入 `A_11_模型评价与改进_增量语义包.md` 的"方法学与口径"节 |

> **一条不过两处**：同一语义单元只进**一个**章节的包（按"论文中最该出现的位置"决定）。
> 取舍（入论文与否、缩写与浓缩）**不在本轮**，留给减法阶段。

## 四、纪律

1. **只增不改**：已写入条目一律不改；同一条目重复发现时，只在其后追加 `（复见：<来源锚>）`；
2. **宁多勿少**：拿不准归口的，进**最相关**章节并在"建议落点"写明疑问；
3. **逐条带来源锚**：无锚不入包；
4. **不引入新数值**：数值必须在来源栏注明出处（文件＋锚）；
5. 本套文件**不是论文正文**（成文生成器不读取本目录），减法阶段统一评估其去留。
