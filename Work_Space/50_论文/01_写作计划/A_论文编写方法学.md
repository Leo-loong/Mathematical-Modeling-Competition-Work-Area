## 〇、总纲

### 0.1 四条"评委行为学"前提（决定工序的优先级）

| 评委行为 | 对我们的工序含义 |
|---|---|
| **摘要决定生死**（不过关则正文不被细看） | **摘要最后写、独立成遍打磨**；正文写完前不碰摘要定稿 |
| **前 3 页定基调**（问题重述／分析／假设／符号） | 骨架（模块 4–7）**先写、先审**，不能等主体写完再补 |
| **检验是加分位**（拉开档次的关键） | 检验**必须自成体系**（见 §2.8），不能顺手塞进结果分析 |
| **数据引用不准确最致命** | **"逐数字回表"必须是独立工序**（见 §3.1），不是顺手核对 |

**按权重分配打磨时间**（教材口径的评审权重 —— **权重高者先写、多改**）：

| 章节 | 权重 | 打磨策略 |
|---|---:|---|
| **摘要** | **20–25%** | **投入最多时间**；最后写、独立成遍、反复打磨（评委初筛平均只看 20–30 秒） |
| **模型建立** | **20–30%** | 推导与选型论证是"硬功夫"：**不得跳步、必须有对比论证** |
| 模型求解 | 15–20% | 方法与参数写全、结果可复现、合理性有验证 |
| 结果分析 | 10–15% | **每个结果都要有文字解释**；做小问横向对比 |
| 问题分析 | 5–10% | 用自己的语言逐问拆解；**不照抄原题**，突出关键约束 |
| 模型假设 | 5–10% | 每条配合理性说明与适用范围 |
| **误差/灵敏度/稳健性** | 5–10% | **权重不高但影响最大 —— 它是区分"普通"与"优秀"论文的关键维度** |
| 模型优劣＋推广 | 3–5% | 优点有依据、缺点诚实＋改进方案 |
| 论文规范 | 3–5% | **门槛分**（版式部分归排版方；我方保证编号与引用） |

### 0.2 工序总览：**五遍法**（每遍只做一件事）

```
第 1 遍 结构遍 —— 只搭骨架与占位，不追求句子（产出：可读大纲）
第 2 遍 数据遍 —— 只填数字与表格，全部回口径表（产出：数字无错的粗稿）
第 3 遍 表达遍 —— 只改句子与逻辑衔接，不动数字（产出：通顺稿）
第 4 遍 术语遍 —— 只查术语／符号／编号一致性（产出：一致稿）
第 5 遍 瘦身遍 —— 只删多余句与空洞形容词（产出：定稿）
```
> **铁律**：**一遍只做一件事**。混着改（边填数字边润色）必然导致"改了数字忘了改对应分析"的连锁错误。
> **两轮评审映射**：第 1–2 遍 ≈ "结构级评审（解决对不对）"；第 3–5 遍 ≈ "逐句精审（解决好不好）"。

### 0.3 人机分工铁律（**内容提供方的高危区**）

| 层 | 归属 | 说明 |
|---|---|---|
| **思想层**（逻辑、论证、判断、结论取舍） | **人** | AI 不能替代 |
| **表达层**（措辞、句式、初稿、表格排版文本） | 可用 AI 辅助 | 但**必须逐句过审** |

**三条协作盲区防线**（本项目必设）：

| 盲区 | 症状 | 防线 |
|---|---|---|
| **数字张冠李戴** | 把问题 2 的数字贴到问题 1 | **§3.1 逐数字回表**（每数字必须带"节号＋量名"两重锚） |
| **符号／术语漂移** | 前文 $\alpha$ 后文 $a$；前文"贴近度"后文"相似度" | **§3.2 术语遍**（机检＋人工各一遍） |
| **推导"看起来对"** | 系数抄错、公式跳步 | **每个公式回《A_符号表》与口径表核对变量与量纲** |

## 一、五遍法的操作细节

### 1.1 第 1 遍 · 结构遍（**只搭骨架**）

**动作**：按 **14 模块**建文件（**正文 11 ＋ 后置 3：AI 工具使用声明／参考文献／附录**；后置 3 项为**官方强制**，见 `A_章节计划与素材映射.md` §〇） → 每节写 **3–5 条要点式**内容（不写完整句） → 标出**图／表／公式占位**。
**完成判据**：把全部小标题读一遍，能看出"提出问题→分析→建模→求解→检验→评价"的链条，**无断点**。
**常见错误**：把"结构遍"写成"成稿"——导致后面无法大改。

### 1.2 第 2 遍 · 数据遍（**只填数字**）

**动作**：
1. 每个数字从《`A_数值口径总表`》**复制**（**禁手抄**）；
2. 复制时**同时写下两重锚**：`（量名，口径表 §x）`；
3. 表格**一次填满**（不留"待补"）；
4. 填完做一次 **§3.1 逐数字回表**。
**完成判据**：§3.1 回表 **0 处不一致**。
**常见错误**：先写句子再找数字 ⟹ 容易写出"5.2 h"这种来路不明的数。

### 1.3 第 3 遍 · 表达遍（**只改句子**）

**动作**：逐节回答三个问题并据此改写——
1. 这一段**要让读者知道什么**？（说不出来 ⟹ 删或重写）
2. 每句**能否从上一句推出来**？（跳跃处补证据链）
3. 每个结论**有没有数字或条件限定**？（没有 ⟹ 补或降级表述）
**完成判据**：**遮住段中任意一句，能从前句猜到它**（猜不到即逻辑跳跃）。
**禁止**：本遍**不得**改动任何数字。

### 1.4 第 4 遍 · 术语遍（**只查一致**）

**动作**：按 §3.2 执行（机检禁用词与代号 → 人工逐条比对 13 项统一定名 → 符号全表核对）。
**完成判据**：代号 0 命中、术语变体 0 出现、无表外符号。

### 1.5 第 5 遍 · 瘦身遍（**只删**）

**动作**：对每句问一句 —— **"删掉它，逻辑链还在吗？"** 在 ⟹ 删。
**重点删**：空洞形容词、"综上所述"式收尾、重复表述、无信息的过渡句。
**完成判据**：全文无"可删而不损"的句子；无连续空洞形容词。

## 二、逐模块编写方法（**细节主体**）

### 2.1 摘要（**最后写、独立成遍**）

#### 目标形态

| 项 | 口径 |
|---|---|
| **结构** | 开头段（2 句）→ **每问一段** → 收尾段（2 句）→ 关键词（1 行） |
| **字数** | **目标 800–850**；**硬上限 ≤900**；**须恰好 1 页**（内容侧以字数保页） **（暂定 · 不构成门禁；源无唯一证据，最终由用户在写作中或全稿完成后按具体情况决定）** → `A_判据源冲突记录表.md` **C-01** |
| **数字** | **全文 ≥8 个精确数字**；**每问 2–3 个**，且**必须带对比关系** |
| **改进点** | 收尾段列 **3 个**（对应正文 ①…⑦ 中最有区分度的三个） |
| **关键词** | **5 个**（分号分隔）——覆盖"领域词＋核心方法＋验证方法＋改进词" **（暂定 · 不构成门禁；源无唯一证据，最终由用户在写作中或全稿完成后按具体情况决定）** → **C-02** |

#### 填空模板（**逐空替换**）

```
【开头段】本文针对〔题目背景〕问题，提出了基于〔方法 1〕＋〔方法 2〕的〔总体方案名〕。
          （第二句必须点方法；禁"本文对 XX 进行了研究"这类空转句）

【每问段·复制 N 次】
针对问题〔X〕，本问是〔问题类型〕问题，需〔题目要求〕。
首先〔数据/口径准备〕，接着〔建模方法〕（关键参数与式号）。
然后〔求解方法〕，得到〔中间结果〕。
结果显示，〔数值 1〕（对比关系），〔数值 2〕（对比关系）——〔一句因果解释〕。

【收尾段】综上，本文通过〔改进 1〕〔改进 2〕〔改进 3〕三项改进，
          使〔结论的可靠性/精度/适用性〕得到〔量化提升〕；
          并以〔三类检验关键词〕交叉验证。
关键词：〔领域〕；〔方法 1〕；〔方法 2〕；〔验证方法〕；〔改进词〕
```

#### 六条硬规则

1. 每问段**必须以「针对问题 X」开头**（便于快速定位）；
2. 每问**至少 2–3 个带对比关系的数字**——"从 X 增至 Y"／"较 X 提升 Z%"／"A 与 B 差距为 C"；
3. **方法流程不跳步**（准备→建模→求解→结果→验证，每步都有）；
4. 必须出现**一句交叉验证或灵敏度**的话（证明不是"运气好"）；
5. **禁「较好」「一定程度」「效果理想」**等模糊表述；
6. 收尾段讲**方法论贡献**（"方法可复用"），不讲"结果好用"。

#### 摘要禁项（机检）

不出现：公式、参考文献标注、解释性连词（因为／所以／这是由于）、分点符号（1. 2. 3.）。

#### 本项目素材映射

`20_交付包/10_摘要与结论要点/摘要要点卡.md`（四问齐备，数值取口径表 §八／§九／§十／§十一）＋关键词候选 §四。

#### 四要素话术模板（**教材口径，可直接改写**）

| 要素 | 话术骨架 | 必须包含 |
|---|---|---|
| **问题** | "本文针对 XX 问题，考虑 XX、XX 等约束条件，从 XX 角度展开研究" | 核心问题 ＋ 关键约束条件 |
| **方法** | "首先建立 XX 模型（用于…）；其次采用 XX 算法（用于…）；最后构建 XX 体系" | **每小问对应的方法名称 ＋ 简要原理** |
| **结果** | "结果表明：XX 为 0.XX，相比基准提升 XX%；XX 的排序为…" | **每小问 1–2 个具体数字** |
| **结论** | "综上，XX 是影响 XX 的最关键因素；XX 方法在处理 XX 上具有优势" | 最重要的发现或建议（**并在此带出 3 项改进**） |

> **要素四的口径**：内部判据一处称"**创新（改进）**"、另一处称"**结论**" ⟹ **取并集**：写**结论**，并在其中**带出改进**（裁决见约束文档 §六）。

#### 摘要的四个致命问题（**逐条对照自查**）

1. **全是定性描述、没有数字** ——"效果良好""结果满意"等于什么都没说；
2. **只写做了什么、没写得到什么** ——"建立了 XX 模型"之后没有结果；
3. **篇幅分配不当** —— 大段讲背景与意义，关键方法与结果一笔带过；
4. **四要素不对应** —— 问题→方法→结果→结论各说各的，读者建不起链条。

### 2.2 问题重述

- **动作**：逐问**用自己的数学语言**重述，"删背景、留本质"，**每问 ≤2 行**；
- **必写**：该问的**输入／要求／输出**，以及题面给出的**约束与口径**（如"附录 3 的物性式""收缩律由附件 2 给定"）；
- **禁**：大段抄题；**不得**把"题面笔误更正"写成"本文假设"（属更正题目）。
- **判据**：不看原题，仅读本节能否准确复现题意。

### 2.3 问题分析

- **动作**：讲清 **数学本质 → 难点 → 技术路线 → 数据需求**；
- **必写**：本问为何是某类方程／为何必须用某类方法（如"变物性导致非线性，故不能用常系数解析解"）；
- **占位**：**本节不放流程图**（由**文字三段式**承担，见章节计划 模块 5 与 `A_判据源冲突记录表` **C-05**）；如确需图示，**只能引用既有图号**（**不得**自造图号），正文用**论文内索引号** `图<章号>-<序>`。
- **判据**：读者读完能预判"接下来要用什么方法、为什么"。

### 2.4 模型假设

- **动作**：按**四组呈现 13 条**（几何与介质／物性与耦合／表面系数与环境／几何演化与适用域）；
- **每条三要素**：**合理性依据 → 适用范围 → 模型落点**；
- **纪律**：**呈现条数可调、内容不得改**；每条**不得**写成"为了简化"（须写"依据是什么"）。
- **判据**：任取一条，能在正文找到它的落点；任取一条，能说出它放宽后会怎样。

**每条假设三步法**（教材口径，比"三要素"更具体）：
1. **假设内容**（是什么）；
2. **为什么可以这样假设**（文献／常识／数据 —— 至少其一）；
3. **什么情况下不成立**（适用范围）。
> **反面**：只写"假设 XX 恒定"而不解释 ⟹ 被判"**随机假设**"，**直接扣分**。

### 2.5 符号说明

- **动作**：三线表；按**类别分组**（几何／物性／环境／判据）；每个符号给**名称／含义／单位**；
- **必查**：**全文无表外符号**（正文出现的每个符号都能在表中查到）。
- **判据**：把正文所有符号抽出来比对，双向无缺。

### 2.6 模型建立与求解（**篇幅主体，细节最多**）

#### ★ 每问固定五子结构（**本项目直接套用**）

| 子节 | 内容 | 写作要点 |
|---|---|---|
| **X.1 具体分析** | 问题本质＋难点 | 与 §2.3 不重复：这里只讲**本问的**难点 |
| **X.2 模型准备** | 方法选型 ＋ **方法对比表** ＋ 数据与口径准备 ＋ **原理示意图占位** | 对比表要给出**选型依据的量化指标**（不是"因为更精确"） |
| **X.3 模型建立** | 步骤 1／2…＋ 公式 ＋ 变量解释 ＋ **完整模型给出** | **每个公式配文字说明**（含义与由来）；**禁"化简得／经过计算可得"** |
| **X.4 模型求解** | 参数 ＋ **算法步骤表** ＋ 结果表 ＋ 结果图占位 ＋ 结果分析 | 参数须给**取值与依据** |
| **X.5 模型检验** | 本问专属的检验（见 §2.8） | 一句话给"本问结果是否可信" |

**8 步内容闭环**（逐问自查）：问题分析 → 方法选型 → 模型建立 → 公式推导 → 编程求解 → 结果分析 → 模型检验 → 小结。

#### 三种"必须给出"的内容件（**内容侧产出，非排版**）

| 件 | 何时必须 | 本项目素材 |
|---|---|---|
| **方法对比表** | 每问模型准备 | 已有充足对照素材：**交替推进 vs 整体式联立 vs 分区式外层迭代**（同口径三方对照）／**BDF2 二阶时间格式**／**调和·算术·积分平均三种界面取法**／**一维 vs 二维量级估算** |
| **算法步骤表** | 求解含迭代／事件驱动／二分等过程时 | 追赶法、Picard 内迭代、**事件驱动终止＋子步级二分**、物料坐标预估–校正 |
| **完整模型给出** | 每问模型建立末尾 | **控制方程 ＋ 定解条件 ＋ 边界／界面条件**（含物料坐标变换后的守恒形式） |

#### 本项目最易写错的两处口径（**写前先看，写后必查**）

1. **界面变系数＝沿含水率的积分平均**（由控制体内稳态通量定义推出；旧"调和平均"仅作对照实验的失败臂，**不得**作为本文口径）；
2. **时间格式分问分场**——**问题 1 的温度＝时间方向精确推进**（矩阵指数＋分段线性 Duhamel），**其余全部**后向欧拉全隐式。**混写即错**。

**判据**：每个方程都能说清"离散后怎么解、误差几阶、为什么这样选"。

#### 选型对比论证（**必写的句式结构**）

```
〔问题〕的特点：(1) … (2) … (3) …
〔方法 A〕假设 …，〔方法 B〕需要 …，〔方法 C〕适用于 …
结合本文数据与口径，选择〔方法 X〕，理由是 …（量化指标）
```
> **反面**：直接写"本文采用 XX 方法"、不说为什么不用别的 ⟹ 命中"**选型无对比论证**"（高频反例之一）。

#### 公式三件套（**每式必备**）

**前置**"为什么引入这个式子" → **公式本体** → **后置**"符号含义与直观理解"。
> **反面**：公式堆砌、无文字解释 ⟹ 命中"**公式无解释**"。

#### A 题（机理类）六步建模路线（**每问推导骨架**）

```
假设 → 控制方程 → 定解条件 → 数值方法 → 评价 → 灵敏度
```
> 与本节"五子结构"**互为印证**：**五子结构管版面顺序，六步路线管推导链条**；写作时**两者都要满足**（A/B 题的共同核心是：**假设合理 ＋ 模型清晰 ＋ 求解有效 ＋ 灵敏度完整**）。

### 2.7 结果分析

- **顺序**：**表先于文字**（先给完整数值表，再写分析）；
- **节奏**：每图／每表后**紧跟"这意味着…"**；
- **四层分析**（本项目通用句式骨架）：
  1. **是多少**（值＋单位＋对比基准）；
  2. **什么规律**（单调？前慢中快后缓？极值在哪？）；
  3. **为什么**（从方程／边界／物性解释）；
  4. **对回答意味着什么**（是否达标、是否印证假设、对下一问的启示）。
- **横向对比**：四问之间做一次对比（如"问题 2 结束时中心含水率仍远高于达标阈值，说明 3 h 只走完前段"）。
- **禁**：只罗列数字；把检验结论混进结果分析。
- **判据**：任取一段，若删掉所有数字仍能读懂"结论"，说明分析到位；若删掉数字后无话可说，说明只是罗列。

#### 误差分析三步（**不得走过场**）

1. **量化误差**（给出具体数值与指标）；
2. **溯源分析**（**数据误差／模型误差／参数误差各贡献多少**）；
3. **改进建议**（下一步怎么改）。
> **反面**："误差在可接受范围内""整体表现良好" ⟹ 命中"**误差分析走过场**"。

#### 对比实验的最低要求（**至少一层**）

(1) **不同方法对比**；(2) **不同参数对比（灵敏度）**；(3) **与简单基准对比**。
> 本项目已有充足对照素材（见 §五 映射表）⟹ **必须成表**，不得只作口头说明。

### 2.8 模型检验（**双轨口径，见约束文档 §六裁决**）

**双轨并存 ＋ 去重**（暂定 · 不构成门禁；源无唯一证据，最终由用户在写作中或全稿完成后按具体情况决定 → C-06）：
- **问内**：每问 **X.5 子节**做**该问专属**检验（保证每问闭环、结论可信）；
- **独立章**：设独立"模型检验"章，做**跨问系统**检验（全局灵敏度、统一误差带、守恒总账、跨问一致性）；
- **★ 去重纪律**：两处**不得复述同一结果** —— 同一检验的数字与图表**只出现在其中一处**，另一处只作"见某节"的**交叉引用**。

**每节四段式**：

```
① 检查项 —— 为什么查它（它是不是本模型的"阿喀琉斯之踵"）
② 方法   —— 范围／步长／对照组／判据（判据必须给出阈值）
③ 结果   —— 表优先；给出最大变化幅度、趋势（单调？非单调？边际递减？）
④ 结论   —— 哪个最敏感／为什么（从模型结构解释）／参数可接受区间／误差是否在可接受范围
```

**三类检验的最低覆盖**（本项目实已达 8–10 项/问）：

| 类 | 本项目已有素材 |
|---|---|
| **误差／收敛** | 网格 GCI、时间步长无关性（精确推进）、Richardson 外推、误差带与不确定度 |
| **灵敏度／稳健性** | 单因素 OAT＋归一化灵敏度系数、全局灵敏度（筛选＋定量）、界面取法对照、边界扰动、数据平滑对照 |
| **对比验证** | 圆柱非稳态解析级数对拍、**独立实现互验**（另一套时间格式＋另一套代码路径）、退化自检、守恒核算 |

**必须**：误差**带**如实声明（不只报点值）；检验**不通过**时的处理（追因并如实报告，**不得**粉饰）。

### 2.9 模型评价

- **优点**：**每条带数据**；
- **不足**：**诚实＋具体＋有方向**（本项目已有：低含水率端外推的贡献占比区间、潜热简化的量化代价 0.07–0.10 ℃、端面效应占比、仿射收缩假设）；

- **禁**："完美""最优""绝对"。

## 三、三种"硬动作"（**独立工序，不许顺手做**）

### 3.1 逐数字回表（**最致命工序**）

**触发**：第 2 遍结束后、以及**每次改动数字之后**。
**操作**：把章节稿中**每个数值**抽出来，逐条完成三问：
1. 它在《A_数值口径总表》的**哪个节哪一行**？（写不出来 ⟹ **停**）
2. 它的**量名**是什么？小数位数**是否与该行一致**？
3. 它出现的**上下文（问、位置、单位）**是否与该行语义一致？（防"张冠李戴"）
**完成判据**：**0 处不一致**。
**禁止**：用"我记得口径表里是这个数"代替回表。

### 3.2 术语与符号一致（**第 4 遍专用**）

**操作**：
1. **机检**：代号模式 0 命中（规则见约束文档 §十 R-1）；禁用词表 0 命中；
2. **人检**：按 `A_题录表.md` §五 的 **13 项统一定名**逐条比对，**变体零出现**（重点："时间离散分问分场"这类易混表述）；
3. **符号**：正文符号集合 ↔《A_符号表》**双向无缺**。

### 3.3 瘦身（**第 5 遍专用**）

**删句三问**：① 删了逻辑链还在吗？② 这句能原封不动放进**别的**论文吗（能 ⟹ 是通用句，删/改）？③ 它是否只是重复上一句？
**量化门槛**：连续空洞形容词 ≤1；过渡词平均每 5–8 句一个、同段 ≤3 个。
