# 全题日志索引（各检验对应关系）

> 用途：把散落的运行日志与检验编号一一对应，避免"看日志不知道属于哪个检验"。
> **命名规则**：`q<问号>_<检验编号>_log.txt`；带"旧版／废弃"字样者为**留痕用途，不得作为结论依据**。
> 日志位于本目录根；脚本位于 `code/`；结果文件位于 `results/`。
> **⚠ 日志为「运行原文留证」**：其中可能出现我方工作区的**绝对路径**（形如 `C:\…\Work_Space\…`）——
> 那是运行时的**当前目录记录**，**不是取数路径**；改写会破坏与真源日志的逐字节一致，故**按原文保留**
> （依 `00_规则/交付包同步与职责边界.md` **§四 第 1 条例外③**）。**取数一律以 `04_图表包/data/` 与《A_数值口径总表》为准。**
> **⚠ 现行口径的唯一真值**：《A_数值口径总表》**§八（Q1）／§九（Q2）／§十（Q3）／§十一（Q4）**。凡日志与口径表冲突，**一律以口径表为准并回报**。
> **跨平台运行**：本目录代码可直接在 **Windows／macOS／Linux** 运行（Python 3.9＋；依赖见同目录 `requirements.txt`）；
> macOS／Linux 若无 `python` 命令请改用 `python3`。一键入口：`python run_all.py`（加 `--go` 实际执行）。
