# A 题 · 精度—速度双轨与变量登记（★2026-09-11 建立）

> **定位**：本表是**全题数值计算的"速度档位"总控**。凡为节省时间而偏离"最严谨设置"的做法，
> **一律在此登记为一个"变量"**，写明其 fast 取值、robust 取值、精度影响与论文写法。
>
> **上游**：《工作约束》§12（分级与纪律）、《建模求解流程总纲》（阶段门）。
> **下游**：《A_Q1/Q2/Q3 求解记录》《A_数值口径总表》《13_论文可删减部分》。
>
> **用途**：支撑**"先高效跑通全题（fast），后按需厚重复算（robust）"**的执行策略。

## 一、立论：为什么必须分轨，而不是"只用一套慢参数"

### 1.1 事实依据（本轮实测）

| 事实 | 数据 | 来源 |
|---|---|---|
| Q2 主力（3 h）优化后耗时 | **46.9 s** | `A_Q2求解记录` §1.2 |
| Q3 主力（约 26 h）**线性外推** | **约 407 s** | 《A_Q3求解思路与工作流》§4.2 |
| Q3 **全流程**运行次数 | **约 20–25 次**（主力＋收敛重验＋效率对照＋守恒＋灵敏度＋重叠段） | 同上 §4.5 |
| ⟹ Q3 若**全用最严谨设置** | 单次 407 s × 20–25 ≈ **2.3–2.8 h**（且未计 Q4） | 推算 |
| Q3 若 $t_{\rm end}$ 落在 45 h | 单次 **703.5 s** ⟹ **跨入 T3** | 同上 §七 第 3 栏 |

**⟹ 结论**：全题若"一步到位用最严谨设置"，**总机时与失败重试成本都不可接受**；
而**先跑通**能尽早暴露流程级问题（口径、接口、终止判据、输出格式），
这些问题的**修复成本**远高于"先算一遍快档"的成本。

### 1.2 关键洞察：**并非所有加速都是"精度换速度"**

| 加速手段 | 是否损失精度 | 处置 |
|---|---|---|
| **机会 A**（子步循环下沉 numba） | **否**（数学式不变，逐位一致） | **两轨都用** ✓ |
| **机会 B**（环境边界改预插值查表） | **否**（插值口径不变，逐位可比对） | **两轨都用** ✓ |
| **B 版核**（numba JIT） | **否**（`fastmath=False`，比特级一致） | 两轨都用 ✓ |
| **C 版核**（手写追赶法） | **否**（$\le1.8\times10^{-11}$） | 两轨都用 ✓ |
| **机会 C**（自适应步长） | **否** —— **已在 Q3 于真实时程上重验通过**（$C$ 剖面差 $1.0\times10^{-4}$ ＝ 4 位小数量化精度；加速 **177×**） | ✅ **已作为 V-3 登记并完成验证**（创新项 IN-1） |
| **BDF2 二阶格式** | **是**（阶跃处伪振荡） | ⚠ **登记为变量** |
| **网格／步长降档** | **是** | ⚠ **登记为变量** |
| **检验实验抽样化** | 否（但降低验证强度） | ⚠ **登记为变量** |
| **Picard 上限调低** | **是**（⚠ Q2 已证为实质缺陷） | ❌ **禁止降档** |

> **纪律**：上表前四项**不属本表登记范围**（零精度风险，正常实施）；
> 其余各项**逐条登记**（§二）。

## 二、★ 变量登记表（本表核心）

> 每条变量给出：**fast 取值**（探索档）、**robust 取值**（正式档）、
> **精度影响**（已有实测或明确估计）、**论文写法**（如何在论文中交代）、**切换方式**。

### V-1 空间网格 $\Delta r$

| 项 | 内容 |
|---|---|
| **fast** | $\Delta r=0.5$ mm（$N=40$ 区间） |
| **robust** | $\Delta r=0.125$ mm（$N=160$）或其更细 |
| **现有基准** | Q1／Q2 主力均为 $\Delta r=0.25$ mm（$N=80$） |
| **精度影响** | Q2 已验：主量 $T$ 中心／$C$ 中心对网格敏感性在 $0.25\to0.125$ mm 已 **$<0.1\%$**；$0.5$ mm 时估计 **$<1\%$** |
| **⚠ 例外（已更新）** | **Q3（修正口径后）空间网格不宜降到 $0.5$ mm**——低 $C$ 端扩散边界层远薄于网格，粗网格会放大离散误差；**正式口径保持 $0.25$ mm**（见 V-8） |
| **论文写法** | 作为"网格收敛性检验"的一部分：给出 $2$ 档网格对照表，说明"报告值已网格收敛" |
| **切换方式** | 脚本入参 `--dr`／常量 `DR` |

### V-2 内部时间子步 $\Delta t_{\rm in}$

| 项 | 内容 |
|---|---|
| **fast** | $1/16$ s |
| **robust** | $1/32$ s（**Q1／Q2 现行基线**） |
| **精度影响** | 格式为**时间一阶**（后向欧拉／IMEX）。Q2 的 W2 实测：$1/16$ 与 $1/32$ s 差异在关键量上 **$\le10^{-3}$ 量级** |
| **论文写法** | "时间步长收敛性检验"：给出 $1/8$／$1/16$／$1/32$ s 三档对照，验证一阶收敛 |
| **切换方式** | 入参 `--nsub`／常量 `NSUB`／`SUBT` |
| **⚠ 注意** | **不得**把"输出间隔"误当"内部步长"（Q3 曾险些把内部步长放大 60 倍，见 V-6 备注） |

### V-3 ★ 自适应步长（机会 C / E9）

| 项 | 内容 |
|---|---|
| **fast** | **开启** |
| **robust** | **关闭**（固定子步）——**交付口径一律用基线** |
| **实测收益** | Q2 内 **4.80×**；Q3 后段变化更慢 ⟹ **预计收益更大** |
| **精度影响** | ✅ **已在 Q3 于真实时程上完成重验**（创新项 IN-1）：容差 $5\times10^{-5}$ 时与固定步长解的 $C$ 剖面差 **$1.0\times10^{-4}$（＝4 位小数量化精度）**，墙钟 **1.4 s vs 156.8 s（177×）** ⟹ **可作为效率方案**；但**仍不得**以自适应结果**替代交付口径**（交付值取固定步长主力解） |
| **论文写法** | 作为"求解效率"方法学说明：给出**重叠段逐值比对**表（如 $10^{-6}$ 量级一致），说明"加速方案与基线在重叠段完全一致，故不影响结论" |
| **切换方式** | 入参 `--adaptive`／环境变量 `Q3_ADAPT=1` |
| **使用纪律** | ① 必须提供与基线的**重叠段逐值比对**；② fast 跑通的结论须**抽样用基线复算**（见 §四） |

### V-4 ★ BDF2 二阶时间格式

| 项 | 内容 |
|---|---|
| **fast** | 可选开启 |
| **robust** | 关闭 |
| **实测收益** | Q2 内约 **3.6×** |
| **精度影响** | 阶跃／突变处**伪振荡**风险；本题环境在 $14400$ s 处有"插值→常值"的斜率突变 ⚠ |
| **论文写法** | 同 V-3（作为效率方案，附重叠段比对） |
| **切换方式** | 入参 `--scheme=bdf2` |

### V-5 ★ 检验实验的规模（抽样 vs 全量）

| 项 | 内容 |
|---|---|
| **fast** | 收敛性检验用 **2 档**网格；灵敏度用 **OAT 5 参数 × 1 档**；省略 Sobol／Morris |
| **robust** | 收敛性用 **4 档 ＋ GCI**；灵敏度 **OAT ＋ 全局（Morris 筛选 ＋ Sobol 方差分解）** |
| **精度影响** | **不影响主结果**，仅降低**验证强度**（"证据厚度"下降） |
| **论文写法** | fast 期结论**只写定性**（如"OAT 显示 $T_\infty$ 最敏感"）；robust 期若做全量再升级为定量排序表 |
| **切换方式** | 各检验脚本的 `--levels`／`--full` 开关 |

### V-6 ⚠ 内层 Picard 迭代上限 —— **禁止降档**

| 项 | 内容 |
|---|---|
| **fast** | **仍有 $30$**（与 robust 相同） |
| **robust** | $30$ |
| **理由（硬）** | Q2 复核发现：$8$ 会被**截断**（每子步跑满 8 次），600 s 时程相对差异已达 $1.6\times10^{-5}$ 且**随时程累积** ⟹ 这是**实质缺陷**，**不属"可容忍的速度折衷"** |
| **论文写法** | 作为"迭代收敛性"说明："内层迭代上限经 A/B 诊断确定，保证每子步真正收敛" |
| **状态** | 已在 Q2 修正（`maxit` $8\to30$）；Q3 沿用 |

### V-7 输出时间间隔

| 项 | 内容 |
|---|---|
| **fast** | Q1／Q2：$1$ s（维持现状，成本极低）；Q3：$60$ s |
| **robust** | 同上 |
| **精度影响** | 对主量**无影响**；仅影响达标时刻的**定位精度**（需插值定位，见 RK-Q3-2） |
| **论文写法** | 无需专门交代（属标准做法） |

### V-8 ⚠ Q3 低 $C$ 端与表面网格口径 —— **独立登记（修正后更新）**

| 项 | 内容 |
|---|---|
| **物理背景** | Q3 深入低含水率区（表面 $C\to0.053$），$D=2.4\times10^{-3}e^{-0.45/C}e^{-3850/T}$ **骤降约两个数量级**；表面扩散边界层厚度 $\delta=D(C_R)/k_m$ 由初期的数**毫米**降到末端约 **$3.9\times10^{-6}$ m** |
| **关键认识（修正后）** | **"薄层远薄于网格"本身不会使格式失准**——常数 $D$＋Robin 圆柱与 Carslaw–Jaeger 解析级数对拍（$\mathrm{Bi}=2$–$20000$，即 $\delta/\Delta r$ 跨 4 个数量级）的误差 $\le3\times10^{-3}$ 且**与网格无关** |
| **真正的风险点** | **界面变系数的取法**——若用"两端点调和平均"，在胞内 $D$ 跨数量级时会严重低估有效扩散系数（实测使 $t_{\rm end}$ **高估约 52%**）。**已改为沿 $C$ 的积分平均**（口径 M6） |
| **修正后实测** | 空间：$0.25$ vs $0.125$ mm 的 $C(0)$ 相对变化 $2.15\times10^{-5}$、$C(R)$ $8.33\times10^{-5}$；网格裁决：$C(0)$ 相邻相对变化 $\le2.9\times10^{-4}$、**表面列 $\le9.8\times10^{-5}$** ⟹ **表 5 各列均达 4 位小数稳定** |
| **本表处置** | fast／robust 两轨**均采用 $\Delta r=0.25$ mm**；表 5 各列（**含 2.0 cm 表面列**）**均可作为交付值**；另以**表面加密非均匀网格**作独立交叉印证（$t_{\rm end}=57.5284$ h，与标准网格差 $0.005\%$） |
| **论文写法** | ① **正文**：报告"内部各点与表面列的相邻相对变化均 $\le10^{-4}$，表 5 各列达 4 位小数稳定"；② **模型评价必须声明**：（a）界面变系数取**沿 $C$ 的积分平均**；（b）**低 $C$ 端 $D$ 外推**贡献 43%–66% 的烘干时长 |
| **⚠ 红线** | **不得**沿用旧表述"表面值受网格分辨率限制、仅供趋势参考"——该结论系**修正前口径**所特有，**已撤销** |

## 三、fast 轨全题参数总表

> **fast 轨的定位**：**验证流程贯通、暴露接口与口径问题**；其数值**不得直接作为交付值**（除非经 §四 的抽样复核）。

| 问 | 时程 | $\Delta r$ | $\Delta t_{\rm in}$ | 自适应 | 检验规模 | 预计单次耗时 |
|---|---|---|---|---|---|---|
| **Q1** | $1800$ s | $0.5$ mm | $1/16$ s | 可选 | 2 档网格 | **$<5$ s** |
| **Q2** | $10800$ s | $0.5$ mm | $1/16$ s | 可选 | 2 档网格 | **$<15$ s** |
| **Q3** | 事件驱动（预计 26 h） | $0.25$ mm ⚠ | $1/16$ s | **开** | 2 档网格 | **约 30–90 s** |
| **Q4** | 同 Q3 ＋ 收缩 | 同 Q3 | 同 Q3 | 开 | 2 档网格 | 待估 |

> **⚠ Q3／Q4 的空间网格不降档**（保持 $0.25$ mm）——原因见 **V-8**：
> 表面问题主要在**低 $C$ 端**，粗网格会使其**显著恶化**；
> 而 Q3 的耗时主要由**时程**决定，网格减半仅省 $4\times$，风险收益比不佳。

### 3.1 fast 轨的**必须完成项**（不可省）

无论多赶，以下**必须**执行——它们**零额外成本**或**属缺陷防线**：

1. **机会 A／B 优化 ＋ 逐位比对**（零精度风险，且 fast 轨收益最大）；
2. **Picard `maxit=30`**（V-6，缺陷防线）；
3. **环境延拓口径 = $50.00$／$0.04999$**（**H6／N19／N20**，Q3 曾误用末值）；
4. **内部步长 $\ge1/16$ s**（不得与输出间隔混淆，V-2 备注）；
5. **达标判据严格 $<0.15$**（**N18**，RK-Q3-7）；
6. **熔断上界 $120$ h**（RK-Q3-3）。

## 四、双轨一致性要求（**防止 fast 结论污染交付**）

| 阶段 | 要求 |
|---|---|
| **fast 跑通后** | ① 对**每个问**做一次**抽样复核**：用 robust 档重算**关键量**（Q1：$T(0)$／$C(R)$；Q2：四关键量；Q3：$t_{\rm end}$），相对差异须 $<1\%$；② 若某量超差 ⟹ **该问的 fast 结论作废**，改用 robust 重算 |
| **写作时** | 论文中出现的所有数值，**必须**来自 robust 档或经抽样复核的 fast 档，并在论文中**标注档位** |
| **登记时** | 每次 fast 运行**必须**在 AI 登记中留痕（含档位参数） |

## 五、论文写法：如何把"变量"写进论文

> **原则**：**不隐瞒、不夸大**——把速度折衷写成"**已量化的方法学选择**"。

### 5.1 推荐写法（模板）

> "为在有限机时内完成全题贯通与多方案对照，本文采用**双档计算策略**：
> **探索档**（$\Delta r=0.5$ mm、$\Delta t=1/16$ s、自适应步长）用于流程验证与参数筛选；
> **正式档**（$\Delta r=0.25$ mm、$\Delta t=1/32$ s、固定子步）用于产出报告数值。
> 两档在重叠工况下的关键量相对差异均 **$<1\%$**（见附表），故探索档结论可安全用于方向性判断。"

### 5.2 各变量的论文落点

| 变量 | 论文落点 | 呈现形式 |
|---|---|---|
| V-1 网格 | 检验章节 | 网格收敛性对照表（$2$–$4$ 档） |
| V-2 步长 | 检验章节 | 时间步长收敛性对照表 |
| V-3 自适应 | 求解方法／模型评价 | 加速比 ＋ 重叠段比对表 |
| V-4 BDF2 | （可不写） | 若写，同 V-3 |
| V-5 检验规模 | 检验章节 | fast 期只写定性；robust 期给定量表 |
| V-6 Picard | 求解方法 | "迭代上限经诊断确定" |
| V-8 低 $C$ 端口径 | **模型评价／结果分析** | ⚠ **必须写**：界面取法（沿 $C$ 的积分平均）＋ 低 $C$ 端外推程度（贡献 43%–66% 时长） |

### 5.3 ⚠ 必须避免的三种写法

1. ❌ 把 fast 档数值当作"已收敛"报告；
2. ❌ 只字不提双档，让读者以为是单一设置；
3. ❌ 用"精度要求不高"作为不收敛的借口（应写"已量化、已声明边界"）。
