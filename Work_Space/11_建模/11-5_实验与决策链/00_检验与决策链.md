## 一、检验清单（至少做两种）
| 检验 | 方法 | 结果 | 结论 |
|---|---|---|---|
| 误差分析 | MAE/RMSE/MAPE | | |
| 灵敏度分析 | 参数 ±10%/±20% 扰动（龙卷风图展示影响排序）；数据灵敏度（随机删 5%/10% 重建模）；方法灵敏度（切换对比模型看结论） | | |
| 稳健性检验 | 换方法/换数据集 | | |
| 对比验证 | vs 真实值/文献/简化模型 | | |
| **守恒性核算** | **区域积分闭合**：质量（全域变化 vs 边界累计通量）＋ 能量各一条，报告**相对残差**并归因（输出分辨率／舍入／积分截断）；判据：两者残差应**同量级**（见《建模作业规范》§5） | | |

- 识别"核心控制变量"（微小扰动大幅影响结果）与"次要变量"
- 误差来源诊断要具体：哪些样本误差大、数据误差还是模型误差
