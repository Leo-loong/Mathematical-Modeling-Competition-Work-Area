# Q2 日志索引（各检验对应关系）

> 用途：把散落的运行日志与检验编号一一对应，避免"看日志不知道属于哪个检验"。
> **跨平台运行**：本目录脚本可直接在 **Windows／macOS／Linux** 运行（Python 3.9＋；依赖见
> `20_交付包/09_代码与复现/requirements.txt`）；macOS／Linux 若无 `python` 命令请改用 `python3`。

| 日志文件 | 对应检验 | 说明 |
|---|---|---|
| `q2_run_log.txt` | **主力求解** | 10800 步、6 项程序化断言；**结果文件 `result2.xlsx` 的生成日志** |
| `q2_run_orig_log.txt` | 主力求解（基线版） | 优化前核的前台运行日志（用户对照用，输出隔离至 `result2_orig.xlsx`） |
| `w2_foreground_log.txt` | **E1**（收敛性） | 空间／时间收敛预试验（9 组并行） |
| `q2_e1_log_废弃_早期未收敛.txt` | — | ⚠ **早期 coupled 版预试验，出现"未收敛"标记，结论已作废**，仅留痕 |
| `q2_checks_log.txt` | **E3 ＋ E7** | **现行有效**：E3 独立实现互验（同步长、端点对齐）＋ E7 守恒性核算 |
| `q2_e3_log_旧版对照.txt` | E3（旧版） | 端点未对齐的早期对照，仅留痕 |
| `q2_e7_log.txt` | E7（旧版） | 守恒核算的旧版输出 |
| `q2_e5_log.txt` | **E5**（灵敏度） | **现行有效**：OAT（含 $C_0$） |
| `q2_e5_log_旧版stdout.txt` | E5（旧版） | 不含 $C_0$ 的早期 stdout |
| `q2_e5_log_旧编号残留.txt` | — | ⚠ **旧编号体系（E4／E6）下的残留留痕，已作废**，仅追溯 |
| `q2_e5b_log.txt` | **E5-b**（全局灵敏度） | Morris ＋ Sobol |
| `q2_e3b_log.txt` | **E3-b**（强制解耦退化） | 单向耦合判据 |
| `q2_e8_log.txt` | **E8**（潜热对照） | 忽略 vs 计入蒸发潜热 |
| `q2_e9_log.txt` | **E9**（自适应时间步） | 固定 vs 自适应 |
| `q2_diag_picard_log.txt` | 诊断 | 内层 Picard 上限截断的影响（A/B） |
| `q2_opt_verify_log.txt` | 校验 | 性能优化的数值等价性（组件级 ＋ 端到端） |
| `q2_e5_S.csv` | E5 结果表 | 归一化灵敏度系数 $S$（供口径表取用） |

> **命名规则**：`q2_<检验编号>_log.txt`；带"旧版／废弃／旧编号／残留"字样者为**留痕用途，不得作为结论依据**。
> **本文件为 Q2 局部索引**；全题统一索引见 `20_交付包/09_代码与复现/README_日志索引.md`（其 §二 为同一张表，**冲突时以该表为准**）。
