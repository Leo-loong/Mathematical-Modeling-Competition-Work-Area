### 1.2 控制方程与定解条件（形式不变，系数变为场相关）

$$\rho(C)c_p(C)\frac{\partial T}{\partial t}=\frac{1}{r}\frac{\partial}{\partial r}\!\left(k(C)\,r\frac{\partial T}{\partial r}\right),\qquad \frac{\partial C}{\partial t}=\frac{1}{r}\frac{\partial}{\partial r}\!\left(D(C,T)\,r\frac{\partial C}{\partial r}\right)$$

初值 $T(r,0)=28$ ℃、$C(r,0)=2.55$ kg/kg；边界

$$\left.\partial_rT\right|_0=\left.\partial_rC\right|_0=0,\qquad -k\left.\partial_rT\right|_{R_0}=h\bigl[T_\infty(t)-T_R\bigr],\qquad -D\left.\partial_rC\right|_{R_0}=k_m\bigl[C_\infty(t)-C_R\bigr]$$

> **写法纪律（沿用 Q1）**：控制方程一律写 **散度形式**，$k$、$D$ 位于算子内部，
> **不得**在变物性下改写为 $k\nabla^2T$（M1 教训）；传质边界**不含 $\rho_s$**（K4）。

### 2.1 时间与网格步长策略

|---|---|---|

**格式选择说明（重要）**：W2 期间实测发现，若采用"**物性随外层迭代更新**"的严格同层格式，

$h=1/32$ s 时滞后误差约 $10^{-8}$ K 量级，**远小于后向欧拉自身的时间离散误差** ⟹
**整体仍为一阶精度，不损失精度**，且无需外层迭代。

**计算量提示**：若沿用更粗的内部步长（如 $h=1/8$ s）虽也满足判据（$4.78\times10^{-6}$），
但为**精度优先**，仍取 $h=1/32$ s。

### 2.3 双层迭代收敛策略

**结构（外层耦合 ＋ 内层线性化）**：

```
对每个时间步 n → n+1：
  外层循环 k = 0,1,2,…（耦合迭代）
    ① 用 C^(k) 更新物性 ρ(C), c_p(C), k(C)
    ② 解 T 方程（系数已冻结）→ T^(k+1)
    ③ 用 T^(k+1) 与 C^(k) 更新 D(C,T)
    ④ 内层 Picard 迭代解 C 方程 → C^(k+1)（欠松弛 ω=0.7，残差判据 1e-9）
    ⑤ 收敛判定：max|ΔC| 与 max|ΔT| 的相对残差均 < 1e-9 → 退出
  若 k 达上限（20）仍未收敛 → 记录并降 ω 重试
```

**关键纪律（Q1 血泪教训的直系继承）**：
1. **右端项固定取上一时层解**（$n$ 层），**绝不随迭代更新**——否则每次迭代在解"另一个问题"，永不收敛（Q1 的 P-1 缺陷）；
2. **物性取 $n{+}1$ 层值**（与 $\rho c_p$ 同层，L3-09），不得混用层；
3. **欠松弛必须保留**（Q1 实测：无欠松弛残差每步仅降约 7%，跑满上限不收敛）；
4. **两套判据须等价**（Q1 的 P-2 缺陷）：外层用**解的相对残差**，内层同样用解残差，**不得**混用"物性变化"。

**待实测确认项**：外层平均迭代次数（若常跑满上限 ⟹ 改为"物性滞后一步"格式或调 $\omega$）。

### 4.1 Q2-α：外层迭代内的时间推进必须"每轮从 $n$ 层出发"

**错误写法**：外层第 $k$ 轮的温度求解，从**上一轮的结果** $T^{(k-1)}$ 继续推进。

**症状**：由于每一轮都推进一个完整输出步，$k$ 轮后相当于推进了 $k\Delta t$ ⟹ **温度被过度推进**
（实测：恒定 50 ℃ 边界、1800 s 得 $T_0=49.99997$ ℃，而物理正解应为 ~40.8 ℃）。

**正确写法**：外层每一轮都**从 $n$ 层解 $T^n$ 出发**，重新做一次完整的后向欧拉推进；
**仅物性**随迭代更新。这与 Q1 的"**右端固定取上一时层解**"纪律是**同一条**（P-1 缺陷的再现）。

**同步修正**：外层收敛判据由"相对残差（除以 50）"改为**绝对增量**（K / kg/kg），
因温度量级 ~$5\times10^1$ K，相对判据 $10^{-9}$ 相当于绝对 $5\times10^{-8}$ K，**过严**导致平均 12.69 轮迭代；
改为绝对容差 $10^{-8}$ 后降至 **3.00 轮**，且耗时降至原来的 1/3.5。

### 4.2 Q2-β：C 方程子步的右端必须取"本子步起点"

**错误写法**：`base = rhs_C(..., Cold, ...)` 放在子步循环**外**（对全部 $\text{subC}$ 个子步都用 $n$ 层解）。

**症状**：每个子步都在解"从 $C^n$ 走一步 $\Delta t_C$"，$\text{subC}$ 个子步的结果**互相覆盖**，
最终有效推进量只有 $\Delta t_C$ ⟹ 制造出"步长越小、降幅越小"的**伪收敛**假象。

**正确写法**：每个子步开始时 `Cbase = Cit.copy()`，右端取 **Cbase**（本子步起点），子步间串行推进。
（Q1 的 `step_C` 本就是"单子步"函数、由驱动串行调用，故无此问题——**问题出在 Q2 把子步循环并入单函数时的重构**。）

**教训归并**：Q1 的 P-1（右端随迭代更新）与本次 Q2-α／Q2-β **同源**——
**凡"迭代／子步循环"，都必须明确每个循环的右端取"哪一层／哪一步"**。
⟹ 建议在 Q2 检验中增设**专项自检**：固定边界、单步推进，与手工单步结果逐位比对。
