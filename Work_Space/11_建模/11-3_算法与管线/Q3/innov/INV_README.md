# Q3 创新升级 · 副本机制与运行说明（INV）

> **建立缘由**：用户指令——"**为现有代码创建副本，产物也需要加上副本标记，完成后我们再进行比较与分析**"。
> **铁律**：**原代码与原产物零改动**；一切改动只发生在**副本**上；新产物一律带 **`INV`** 标记。

> 比对工作在全部跑完后另行进行。

## 二、执行纪律（与《工作约束》§12 衔接）

1. **规模声明**：每个创新脚本首行打印 `[SCALE]` 行（时程／步数／网格／预计耗时），便于事后审计；
2. **不覆盖**：任何创新脚本**不得写入**本目录之外的文件；
3. **失败即回退**：任一"双轨闸门"不过 ⟹ 该轨结论**不采纳**，如实登记；
4. **不比不改**：跑完前**不做**任何"用新结果替换旧结果"的操作；比对与裁定在**全部完成之后**统一进行；
5. **零外部来源**：不引入任何第三方针对本题的解法或数值。

## 三、双轨验收闸门（比对阶段执行）

| 闸门 | 阈值 |
|---|---|
| ① 重叠段一致性（vs 严格轨） | 场量 $\max\|\Delta C\|\le5\times10^{-5}$；$t_{\rm end}$ 差 $\le0.002$ h |
| ② 误差闭合 | 守恒残差同量级；解落入 GCI 误差带 |
| ③ 物理锚点 | 断言通过；落于解析上下界（$25.8$ h ＜ $t_{\rm end}$ ＜ $97.7$ h） |

> **红线**：**"多轨一致 ≠ 正确"**——一致只说明离散层无误，不验证模型假设。

>    修正后单步差异降至 $1.2\times10^{-5}$ —— 这正是"独立实现"的价值：**同核自洽无法暴露的问题，独立实现能暴露**。
> 2. **IN-4b·首版**：grid 与 LHS 的**结果索引冲突**（互相覆盖），致自校失败（$C_{\rm fr}=0$ 得 35.23 h）；改用全局唯一索引后自校通过。
> 3. **IN-1**：实现为一阶自适应（未用 BDF2）；**IN-3** 首版 μ\* 未归一化。

> **⚠ 实现方式如实更正**：IN-1 **未实现 IMEX-BDF2**（方案中的设想），而是实现为
> "**一阶格式 ＋ Richardson 半步后验误差控制**"——理由是**零格式改动**（复用现有核，风险最低），
> 且同样满足 kb 指出的要求（"自适应必须有误差判据"）。BDF2 可作为后续可选项。
> 该取舍**不影响**原目标（严格误差判据 ＋ 步长自适应 ＋ 步长轨迹图）。

> **辅助工具**：`q3_compare_INV.py`（双轨比对器，只读）——同时给出"$t_{\rm end}$ 差 → 等效 C 差"换算，
> 用于识别 **$t_{\rm end}$ 的高条件数放大**（后段 $dC/dt\approx1.2\times10^{-3}$/h）。
