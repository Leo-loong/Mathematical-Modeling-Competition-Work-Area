## 六、必须知道的约定

### 1. 工作区隔离（`00_规则/工作约束.md` §6）
方法论（`00_规则/` ＋ 各包 `00_*.md`、`00_模板.md`）**不随赛题变化**；
赛题产出从模板复制为 `<题号>_<名称>_<MMDD>.md`，**模板永不被覆盖**；过程文档进 `99_过程与归档/`。

### 2. 三条铁律
1. **内容权威归建模者，表达执行归写作者**——写作者不从过程文档"挖掘"内容，缺素材**回询**
