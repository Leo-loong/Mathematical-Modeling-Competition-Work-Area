# 图表规格卡：F-14 数据预处理对照（边界平滑 vs 不平滑）

| 要素 | 内容 |
|---|---|
| **图号/图名** | 图 F-14：边界数据预处理的敏感性（移动平均平滑 vs 不平滑） |
| **目的** | 回答评委可能提出的"边界数据是否做了平滑处理、是否借此美化结果"——用定量偏差证明**平滑与否不改变结论**，并佐证本文"**不做平滑**"的决策有据 |
| **图类型与理由** | 类型：**分组柱状图**（纵轴取对数）；理由：需展示"两种平滑窗口下、多个输出量各自偏差"的离线对比，柱状分组最直观；偏差跨 6 个数量级 ⟹ 必须对数纵轴 |
| **数据源** | `04_图表包/data/fig_smooth_check.csv`（**本包内**）；列：`case`（平滑方案：MA-3／MA-5）、`dT0`／`dTR`（中心／表面温度偏差，℃）、`dC0`／`dCR`（中心／表面含水率偏差，kg/kg）、`field_max_T`／`field_max_C`（全场最大偏差）、`snap_max_T`（快照最大偏差） |
| **坐标轴** | X：输出量分组（$\Delta T(0)$、$\Delta T(R)$、$\Delta C(0)$、$\Delta C(R)$、全场最大值）；Y：**偏差绝对值**，**对数轴**（建议 $10^{-7}$–$10^{-1}$）；单位随分组注明（℃，kg/kg 可并入同一对数轴但须在标签标明量纲，或改用双面板） |
| **标签文本（逐字，全中文）** | 图题「F-14 数据预处理对照（边界平滑 vs 不平滑）」；坐标轴与色标**逐字**采用本卡「坐标轴」行：X：输出量分组（$\Delta T(0)$、$\Delta T(R)$、$\Delta C(0)$、$\Delta C(R)$、全场最大值）；Y：**偏差绝对值**，**对数轴**（建议 $10^{-7}$–$10^{-1}$）；单位随分组注明（℃，kg/kg 可并入同一对数轴但须在标签标明量纲，或改用双面板）；**图内一律中文**（仅符号、单位、公认缩写可保留）；**禁止**出现 CSV 英文列值／裸代号 |
| **字体与公式** | 中文 **思源黑体／微软雅黑**（macOS `Heiti SC`／`PingFang SC`；Linux 须装中文字体）；西文 **Arial**；**图内公式 `Cambria Math`／Times，10 pt，Italic，`Interpreter='latex'`（禁截图）**；字号层级 2:1.5:1.2:1:0.85 且**最小 ≥7 pt**；**导出 300 DPI PNG ＋ 矢量 PDF 并嵌入全部字体**（`exportgraphics(...,'ContentType','vector')`）。依据：`00_规则/图表设计语言.md` **§2.1 六条硬约束** |
| **配色与尺寸** | 分组色：MA-3 用皇家蓝 `#1F3A93`、MA-5 用金黄 `#F39C12`；比例 **4:3**；柱宽一致、组间距 > 柱间距；参考线用灰虚线 `#9E9E9E`；见《图表设计语言》§1／§2 |
| **绘制注意点** | ① **必须用对数纵轴**：偏差从 $10^{-7}$ 到 $10^{-2}$ 跨 6 个数量级，线性轴会看不见小量级项；② **必须画一条"判定阈值"参考线**（建议取 $10^{-2}$ ℃，对应"是否影响 4 位小数输出"的容限），否则读者无法判断偏差"算大还是算小"；③ 须在图注中说明 `MA-3`／`MA-5` = 3 点／5 点移动平均；④ $\Delta C(0)$ 因中心含水率在 1800 s 内几乎不变而偏差为 0，**对数轴上的零值需标注"0（未变）"而不是丢弃** |
| **对应文字表述建议** | 图注："图 F-14 边界数据预处理对照：不同平滑窗口下各输出量的偏差（对数轴）。" 正文引用句："如图 F-14 所示，无论采用 3 点还是 5 点移动平均对边界时序进行平滑，各关键输出量的偏差均在 $10^{-2}$ ℃ 量级以内（全场最大 $1.08\times10^{-2}$ ℃，相对 $2.9\times10^{-4}$），**不足以影响 4 位小数的输出结果**，故本文直接采用附件原始数据、不做平滑。" |
| **支撑论证点** | 检验充分性（要点19）；数据预处理决策的依据（《建模作业规范》§9"不能数据没洗干净就开始建模"的反向自证——**不洗也无需洗**，且已量化） |
