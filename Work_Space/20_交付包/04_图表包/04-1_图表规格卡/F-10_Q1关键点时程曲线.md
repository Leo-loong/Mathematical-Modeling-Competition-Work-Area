# 图表规格卡：F-10 第一问中心／表面关键点时程曲线

| 要素 | 内容 |
|---|---|
| **图号/图名** | 图 F-10：第一问中心与表面温度／含水率时程 |
| **目的** | 定量呈现"两端差异有多大"以及"温度在动、含水率几乎不动"的时间尺度悬殊 |
| **图类型与理由** | 类型：**双纵轴折线**（左轴温度 ℃／右轴含水率 kg/kg）；理由：两个物理量量纲不同、数量级不同，共用一轴会互相压扁，双轴能在同一时间基准上对照演化节奏 |
| **数据源** | `04_图表包/data/fig_q1_curves.csv`（**本包内**）；列：`time_s`, `T_center`, `T_surface`, `C_center`, `C_surface` |
| **坐标轴** | X：时间 $t$（s），0–1800；左 Y：温度（℃），28–37；右 Y：含水率（kg/kg），1.5–2.60；两轴均需明确标注单位与颜色对应 |
| **标签文本（逐字，全中文）** | 图题「F-10 第一问中心／表面关键点时程曲线」；坐标轴与色标**逐字**采用本卡「坐标轴」行：X：时间 $t$（s），0–1800；左 Y：温度（℃），28–37；右 Y：含水率（kg/kg），1.5–2.60；两轴均需明确标注单位与颜色对应；**图内一律中文**（仅符号、单位、公认缩写可保留）；**禁止**出现 CSV 英文列值／裸代号 |
| **字体与公式** | 中文 **思源黑体／微软雅黑**（macOS `Heiti SC`／`PingFang SC`；Linux 须装中文字体）；西文 **Arial**；**图内公式 `Cambria Math`／Times，10 pt，Italic，`Interpreter='latex'`（禁截图）**；字号层级 2:1.5:1.2:1:0.85 且**最小 ≥7 pt**；**导出 300 DPI PNG ＋ 矢量 PDF 并嵌入全部字体**（`exportgraphics(...,'ContentType','vector')`）。依据：`00_规则/图表设计语言.md` **§2.1 六条硬约束** |
| **配色与尺寸** | 温度两线用冷色系（皇家蓝 #1F3A93 中心／金黄 #F39C12 表面）；含水率两线用绿／深红并加**标记形状区分**（○／△）；单图比例 3:2；线宽 1.5–2.0 pt；见《图表设计语言》§1／§2 |
| **绘制注意点** | ① **双纵轴必须用线的颜色与轴标签颜色呼应**，否则读者会串轴；② $C$ 的两条线几乎贴平（2.55 与 1.51 需分列），建议右轴范围 1.5–2.6 使差异可辨；③ 图例 ≤4 条并置于图外或右上；④ 可选：在 $t=1800$ 处加竖直参考线并标注四个终值 |
| **对应文字表述建议** | 图注："图 F-10 中心与表面温度（左轴，℃）与含水率（右轴，kg/kg）时程"。正文引用句："如图 F-10 所示，表面温度在 1800 s 内上升 8.79 ℃ 而中心仅上升 5.58 ℃；同期表面含水率下降 40.8%，中心几乎不变。" |
| **支撑论证点** | 结果规律（第二层）；两类物理过程时间尺度对比 |
