# 图表规格卡：F-08 第一问温度场时空分布

| 要素 | 内容 |
|---|---|
| **图号/图名** | 图 F-08：第一问温度场 $T(r,t)$ 时空分布 |
| **目的** | 一眼看出"**表面先热、热量由外向内渗透、1800 s 内未达热平衡**" |
| **图类型与理由** | 类型：**热力图**（可叠加等值线）；理由：$T$ 是"半径 × 时间"的二维连续场，色阶能一次呈现全部演化，胜过堆叠多条曲线 |
| **数据源** | `04_图表包/data/fig_q1_field_T.csv`（**本包内**）；列说明：`time_s`＝时间(s)，其余 21 列为到中心距离 0–2.0 cm（步长 0.1 cm）的温度(℃) |
| **坐标轴** | X：到药材中心距离 $r$（cm），0–2.0；Y：时间 $t$（s），0–1800；色标：温度（℃），范围 **28–37** |
| **标签文本（逐字，全中文）** | 图题「F-08 第一问温度场时空分布」；坐标轴与色标**逐字**采用本卡「坐标轴」行：X：到药材中心距离 $r$（cm），0–2.0；Y：时间 $t$（s），0–1800；色标：温度（℃），范围 **28–37**；**图内一律中文**（仅符号、单位、公认缩写可保留）；**禁止**出现 CSV 英文列值／裸代号 |
| **字体与公式** | 中文 **思源黑体／微软雅黑**（macOS `Heiti SC`／`PingFang SC`；Linux 须装中文字体）；西文 **Arial**；**图内公式 `Cambria Math`／Times，10 pt，Italic，`Interpreter='latex'`（禁截图）**；字号层级 2:1.5:1.2:1:0.85 且**最小 ≥7 pt**；**导出 300 DPI PNG ＋ 矢量 PDF 并嵌入全部字体**（`exportgraphics(...,'ContentType','vector')`）。依据：`00_规则/图表设计语言.md` **§2.1 六条硬约束** |
| **配色与尺寸** | 色阶 **viridis**（色盲友好、灰度可辨）；热力图比例 **1:1**；色标置于右侧并标注单位 ℃；见《图表设计语言》§1／§2 |
| **绘制注意点** | ① 温度跨度仅 28–37 ℃ ⟹ **必须用窄范围色标**，否则对比度不足看不出渗透结构；② 建议以白/灰虚线标出 $r=0$（中心）与 $r=2$ cm（表面）两处关键位置；③ 可选叠加"热扩散长度 $\sqrt{\alpha t}$"参考曲线，使"渗透深度有限"定量可见；④ 时间轴方向建议自上而下（$t=0$ 在顶部）以符合"向下推进"的直觉 |
| **对应文字表述建议** | 图注："图 F-08 第一问温度场 $T(r,t)$ 分布（单位：℃）"。正文引用句："如图 F-08 所示，热量自表面向中心渗透且梯度集中在表层：$t=1800$ s 时中心温度比表面低 3.21 ℃，径向剖面仍在演化。" |
| **支撑论证点** | 机理严谨性；结果规律（第一／二层分析） |
