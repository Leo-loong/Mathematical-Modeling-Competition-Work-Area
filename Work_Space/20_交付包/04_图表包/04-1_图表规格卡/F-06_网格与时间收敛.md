# 图表规格卡：F-06 网格与时间收敛（GCI）

| 要素 | 内容 |
|---|---|
| **图号/图名** | 图 F-06：网格与时间收敛性（Richardson 外推与 GCI） |
| **目的** | 让评委相信"结果与网格／时间步无关"，并看到**定量误差带**（不是"加密看了看"） |
| **图类型与理由** | 类型：**双联折线**（左：泛函值 vs 步长；右：观测阶／GCI）；理由：收敛性论证需要"值—步长"关系，双联可同时给出结论与判据 |
| **数据源** | `04_图表包/data/fig_gci_data.csv`（**本包内**）；列：`group`（spatial／temporal_T／temporal_C）、`case`、`idx`、`delta`（Δr mm 或 Δt s）、`Tc`、`Ts`、`Trms`、`Cc`、`Cs`、`Crms` |
| **坐标轴** | 左子图 X：Δr（mm）或 Δt（s），建议**对数轴**；Y：$T(0,1800)$／$T(R,1800)$（℃），可采用**断轴/相对偏差**放大小差异。右子图 X：同上；Y：观测阶 $p$（0–2.5）＋ GCI（%，次轴） |
| **标签文本（逐字，全中文）** | 图题「F-06 网格与时间收敛（GCI）」；坐标轴与色标**逐字**采用本卡「坐标轴」行：左子图 X：Δr（mm）或 Δt（s），建议**对数轴**；Y：$T(0,1800)$／$T(R,1800)$（℃），可采用**断轴/相对偏差**放大小差异。右子图 X：同上；Y：观测阶 $p$（0–2.5）＋ GCI（%，次轴）；**英文列值映射**：`group`：`spatial`→空间、`temporal_C`→时间（含水率）、`temporal_T`→时间（温度）；**图内一律中文**（仅符号、单位、公认缩写可保留）；**禁止**出现 CSV 英文列值／裸代号 |
| **字体与公式** | 中文 **思源黑体／微软雅黑**（macOS `Heiti SC`／`PingFang SC`；Linux 须装中文字体）；西文 **Arial**；**图内公式 `Cambria Math`／Times，10 pt，Italic，`Interpreter='latex'`（禁截图）**；字号层级 2:1.5:1.2:1:0.85 且**最小 ≥7 pt**；**导出 300 DPI PNG ＋ 矢量 PDF 并嵌入全部字体**（`exportgraphics(...,'ContentType','vector')`）。依据：`00_规则/图表设计语言.md` **§2.1 六条硬约束** |
| **配色与尺寸** | Nature 经典色板；多子图比例 **16:9**；标记区分形状（○△□）；参考线用灰 #9E9E9E 虚线（$p=1$ 与 $p=2$ 理论线）；见《图表设计语言》§1／§2 |
| **绘制注意点** | ① **必须标注 $p=1$（时间理论阶）与 $p=2$（空间理论阶）参考线**，否则"p 值"无意义；② 收敛量的差异极小（GCI ≤0.0064%），直接用原值画会看不出变化 ⟹ **改用相对偏差或双轴**；③ 对数轴刻度标注要清楚；④ 时间收敛须**分 T／C 两条**（两者时间步独立，不可混画） |
| **对应文字表述建议** | 图注："图 F-06 收敛性检验：空间（左）与时间（右）的 Richardson 外推结果"。正文引用句："如图 F-06 所示，空间离散呈**二阶**收敛（$p=2.00$–$2.09$，GCI ≤0.0064%），时间离散呈**一阶**收敛，与后向欧拉格式的理论精度一致。" |
| **支撑论证点** | 检验充分性（要点19）；创新点 C1（GCI 误差带报告） |
