# 图表规格卡：F-13 参数灵敏度龙卷风图

| 要素 | 内容 |
|---|---|
| **图号/图名** | 图 F-13：关键参数灵敏度龙卷风图 |
| **目的** | 一眼看出"**哪个参数最关键、哪个完全无关**"，并证明基础结论对参数扰动**稳健** |
| **图类型与理由** | 类型：**龙卷风图**（横向条形，按 $\lvert S\rvert$ 降序）；理由：单变量影响对比最直观，且能同时呈现**正负方向**与**不对称性** |
| **数据源** | `04_图表包/data/fig_tornado_data.csv`（**本包内**）；列：`output`（4 个输出量）、`parameter`、`y_minus`／`y_base`／`y_plus`、`delta_neg`／`delta_pos`（相对基准的变化量）、`S_norm`（归一化灵敏度系数） |
| **坐标轴** | Y：参数名（每个输出内按 $\lvert S\rvert$ 降序）；X：归一化灵敏度系数 $S$（**无量纲**，可直接跨参数比较）；建议 4 个输出用 **2×2 子图** |
| **标签文本（逐字，全中文）** | 图题「F-13 参数灵敏度龙卷风图」；坐标轴与色标**逐字**采用本卡「坐标轴」行：Y：参数名（每个输出内按 $\lvert S\rvert$ 降序）；X：归一化灵敏度系数 $S$（**无量纲**，可直接跨参数比较）；建议 4 个输出用 **2×2 子图**；**英文列值映射**：`parameter`→符号 $C_0,D_0,T_0,h,k_m$；`output`→中心／表面 × 温度／含水率；**图内一律中文**（仅符号、单位、公认缩写可保留）；**禁止**出现 CSV 英文列值／裸代号 |
| **字体与公式** | 中文 **思源黑体／微软雅黑**（macOS `Heiti SC`／`PingFang SC`；Linux 须装中文字体）；西文 **Arial**；**图内公式 `Cambria Math`／Times，10 pt，Italic，`Interpreter='latex'`（禁截图）**；字号层级 2:1.5:1.2:1:0.85 且**最小 ≥7 pt**；**导出 300 DPI PNG ＋ 矢量 PDF 并嵌入全部字体**（`exportgraphics(...,'ContentType','vector')`）。依据：`00_规则/图表设计语言.md` **§2.1 六条硬约束** |
| **配色与尺寸** | 正值与负值用双色（#1F3A93／#C0392B）；零参考线用灰 #9E9E9E 虚线；2×2 子图比例 16:9；见《A_设计语言实例》 |
| **绘制注意点** | ① 每个输出的 5 个参数中**有 3 个恒为 0**（严格解耦所致）——须**保留这些零条并加注"结构解耦，恒为 0"**，否则读者会误以为漏画；② $C\leftarrow C_0$ 的 $\lvert S\rvert\approx1.0$ 须加注"**初值直传（平凡敏感）**"，不得表述为"极度敏感"；③ $T(R)\leftarrow h$ 的正负**不对称**（$-0.810$ vs $+0.621$）须在图中体现，不可只画单侧；④ $T_0$ 行使用**相对幅度归一化**口径（分母含初始温度相对幅度 $1/28$），须在图注声明 |
| **对应文字表述建议** | 图注："图 F-13 关键参数对 Q1 终态输出的灵敏度（归一化系数 $S$；$T_0$ 按初始温度相对幅度归一化）"。正文引用句："如图 F-13 所示，温度场仅受初始温度与对流换热系数影响，含水率场仅受初始含水率、扩散系数与传质系数影响——两个物理场**严格解耦**，且无非零 $\lvert S\rvert$ 超过 1.1，说明结论稳健。" |
| **支撑论证点** | 检验充分性（灵敏度分析）；**不可删减**（灵敏度属必做检验） |
