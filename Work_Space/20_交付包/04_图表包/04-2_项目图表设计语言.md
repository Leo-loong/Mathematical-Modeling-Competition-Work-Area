## 一、配色板（定稿）

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色（主数据系列） | **#1F3A93** 皇家蓝 | Nature 经典色板色 1；温度"中心"、数值解主线 |
| 对比色 | **#F39C12** 金黄 | 温度"表面"；对照系列 |
| 第三色 | **#27AE60** 森林绿 | 含水率"中心" |
| 第四色 | **#C0392B** 深红 | 含水率"表面"；兼作**强调／告警**（关键结论、注错演示） |
| 参考线／辅助 | **#9E9E9E** 灰（虚线 1.0 pt） | 理论阶参考线（$p=1/2$）、初值线、零偏差线 |
| 轴线／文字 | **#333333** 深灰 | 禁纯黑 |
| 网格 | **#E0E0E0** 浅灰，0.4 pt，仅横向 | 可整体省略（法则 2"少即是多"） |
| 背景 | **#FFFFFF** | 去顶/右边框 |
| 连续色阶（场量） | **viridis** | 热力图 F-08／F-09（色盲友好、灰度打印可辨） |
| 发散色阶（残差/正负） | **RdBu** | 偏差图（按需） |

**禁用**：红绿搭配、彩虹配色、高饱和背景、Excel 默认样式、截图替代图表。

## 二、字体与字号

| 项 | 定稿 |
|---|---|
| 中文字体 | 微软雅黑（正文）／思源黑体（若环境可用）；**macOS 绘图侧用 `Heiti SC`（回退 `PingFang SC`）** |
| 西文与数字 | Arial（Helvetica 亦可） |
| **公式（图内）** | **Cambria Math ／ Times，Italic，10 pt，一律 LaTeX 渲染（禁截图）**；MATLAB 用 `Interpreter='latex'` |
| 字号（印刷后） | 标题 10 pt ／ 轴标签 9 pt ／ 刻度 8 pt ／ 图例 8 pt ／ 图内标注 7.5 pt（**最小 ≥7 pt**） |
| 层级比 | 主标题 : 副标题 : 轴标签 : 刻度 : 数据标签 = 2 : 1.5 : 1.2 : 1 : 0.85 |
| **字体嵌入** | 导出**300 DPI PNG ＋ 矢量 PDF（已嵌入全部字体）**；MATLAB `exportgraphics(...,'ContentType','vector')` |
| **MATLAB 落地**（绘图侧环境） | 脚本顶部集中设 `set(0,'defaultAxesFontName','Heiti SC')`／`defaultTextFontName`；**不得**依赖系统默认；`DefaultAxesFontSize=9` 与本文一致 |
| **图内文字语言** | **一律中文**；仅符号（$t_{\rm dry}$、$N$）、单位（h／cm／℃）、公认缩写（GCI）可保留；**数据列值为英文代号时按规格卡给的中文映射改写** |

## 三、尺寸基准

| 类型 | 尺寸 | 说明 |
|---|---|---|
| 单栏图 | 8 × 6 cm | 折线／柱状（3:2 或 4:3） |
| 通栏图 | 16 × 9 cm | 双联／三联（16:9） |
| 热力图 | 1 : 1（如 9 × 9 cm） | F-08／F-09，便于并排对照 |
| 示意图／流程图 | 16 × 8 cm（2:1） | F-01／F-02／F-07 |
| 导出格式 | **300 DPI PNG ＋ PDF 矢量** | 禁低分辨率位图与拉伸变形 |

## 四、本项目图类型选型记录

| 数据形态 | 选定类型 | 理由 |
|---|---|---|
| 径向 × 时间的二维连续场（$T$、$C$） | 热力图（viridis） | 一次呈现全部演化；两场同构便于并排对照时间尺度差异 |
| 时间序列关键点（中心／表面） | 双纵轴折线 | 物理量量纲不同（℃ vs kg/kg），共用一轴会相互压扁 |
| 收敛性（泛函值 vs 步长） | 双联折线（值 ＋ 阶数/GCI） | 收敛论断必须同时给出"值—步长"关系与判据参考线 |
| 数值 vs 解析对比 | 上折线 ＋ 下偏差（双联） | 只画重合曲线无法证明"误差可控"，须独立画出偏差 |
| 参数敏感度排序 | 龙卷风图（横向条形，降序） | 单变量影响对比最直观 |
| 物理对象与边界 | 矢量示意图 | 不含数据，传达几何／边界／离散结构 |
| 流程与方法链 | 流程图（节点规范，见全局 §4） | 节点类型与配色按全局规范执行 |

## 五、一致性规则（贯穿全部规格卡）

1. **系列配色与标记固定**：温度中心 #1F3A93 ○；温度表面 #F39C12 △；含水率中心 #27AE60 □；含水率表面 #C0392B ◇。
2. **线型语义固定**：实线＝数值解／主结果；虚线＝解析解／理论参考；点划线＝拟合或外推。
3. **单位写法统一**：温度 ℃；含水率 kg/kg（干基，首次出现处注明）；距离 cm；时间秒用 s（论文表格按交付口径用 h，须在表头注明）。
4. **图例位置统一**：优先右上或图外，条目 ≤6，不遮挡数据。
5. **编号与引用**：图按章节编号（图5-1、图5-2…），**图题在下**、**表题在上**；正文必须显式引用，否则删除该图。
6. **关键结论图必须带量化值**：F-06、F-08～F-11 须在图内或图注给出带单位的关键数值。
7. **偏差／残差图**：纵轴自适应量级并画零参考线，**禁止与主曲线共用纵轴**。
8. **热力图**：必须使用窄范围色标，并标注"初值／终值"参考，否则场内差异不可见。
9. **本图无数据时（示意图）**：几何与离散参数必须与正文完全一致（如 $\Delta r=0.25$ mm、$R_0=2$ cm），禁止示意与正文不符。

## 六、★配图判据（"这里该不该有图"的判定标准）

> **来源**：建模教材第 10 章《AI 论文插图与 LaTeX 排版》＋《国赛超精美图表 AI 优化升级提示词》§10。
> **本节是本项目新增／补充图表的**唯一依据**——不得凭手感决定要不要配图。

### 6.1 触发条件（命中任一即"应当配图"）

| 检测项 | 触发条件 | 推荐图型 | 优先级 |
|---|---|---|---|
| **问题分析流程图缺失** | 问题分析／模型构建章节无任何流程图 | 整体方法学流程图 | ★★★★★ |
| **模型框架图缺失** | 模型建立章节仅有文字无框架图 | 模型架构／关系图 | ★★★★★ |
| **算法步骤图缺失** | 算法／求解过程描述冗长但无流程图 | 算法步骤流程图 | ★★★★☆ |
| **结果对比无图** | 结果分析章节有数值对比但无图 | 对比柱状图／折线图 | ★★★★☆ |
| **灵敏度分析无图** | 灵敏度／参数分析章节**有表格无图** | **热力图／雷达图** | ★★★★☆ |
| **对比分析无图** | 多方案对比分析无图 | **雷达图／对比柱状图** | ★★★★☆ |
| 求解过程无图 | 有迭代／收敛数据但无图 | **迭代收敛图／帕累托图** | ★★★☆☆ |
| 守恒／核算无图 | 有收支数据但无图 | **瀑布图／堆叠柱状** | ★★★☆☆ |

### 6.2 图文比阈值（章节字数 ÷ 已有图数）

| 章节 | 阈值（超过则触发补图） |
|---|---|
| 问题分析／模型建立 | **> 800 字/图** |
| 结果分析 | **> 500 字/图** |
| 灵敏度／参数分析 | **> 400 字/图** |
| 结论 | 一般不补图（除非有总结性数值对比） |

### 6.3 **禁止补图**的场景（同样重要）

- 该模块**已有同类图表覆盖** ⟹ 不重复补图；
- 内容为**纯理论推导／公式证明**，难以可视化 ⟹ **不强行补图**；
- 已有**公式或三线表**充分表达信息、补图反而冗余 ⟹ 不补图；
- **无数据可支撑**（原文仅定性描述）⟹ 只能出**定性示意图**，**严禁编造数值**。

### 6.4 决策顺序（自上而下，逐级判定）

```
① 该章节是否有流程图／框架图？        无 ⟹ 优先补流程图（★★★★★）
② 逐章节算图文比，是否超阈值？        否 ⟹ 不补
③ 该章节内容是否适合可视化？          否（纯推导）⟹ 不补
④ 原文是否有足够数据支撑？            无 ⟹ 只出定性示意图（禁编造）
                                      有 ⟹ 出定量图
⑤ 是否与已有图重复？                  是 ⟹ 不补
```

## 八、视觉规范补充（来自教材与提示词，本项目已采纳）

### 8.1 十条黄金法则（**法则 1–5 为硬约束**）

| # | 法则 | 落地要求 |
|---|---|---|
| 1 | **数据至上** | 深色数据点 ＋ 浅色背景；装饰元素不得抢夺视觉权重 |
| 2 | **少即是多** | 去顶／右边框、去冗余网格、去高饱和背景；**留白＝专业感** |
| 3 | **色彩克制** | 全图**最多 3–5 种主色**；优先色盲友好（viridis／plasma／RdBu）；**避免红绿搭配** |
| 4 | **对比鲜明** | 数据与背景明度差 ≥ 7:1；轴线／文字用 **#333333** 而非纯黑 |
| 5 | **字体一致** | 全图 1–2 种字体；**字号梯度不超过 3 级** |
| 6 | 对齐精确 | 多子图横纵坐标／colorbar／图例严格对齐；**图例框不超过图的 25%** |
| 7 | 标注清晰 | 优先级：主标题 > 副标题 > 轴标签 > 刻度 > 数据标签 > 脚注 |
| 8 | 比例正确 | 单图 4:3 或 3:2；多子图 16:9 或 2:1；**热力图 1:1** |
| 9 | 可访问性 | 色盲友好、打印友好（灰度下仍可区分） |
| 10 | 可复现性 | 提供完整绘图代码／参数说明，**读者应能 100% 复现** |

### 8.3 流程图／示意图节点规范（用于 F-21、F-22）

| 论文要素 | 节点类型 | 形状 | 配色（浅底／深字） |
|---|---|---|---|
| 输入数据／已知条件 | 数据输入节点 | 平行四边形 | `#E3F2FD` / `#1565C0` |
| 分析步骤／处理过程 | 过程节点 | 圆角矩形 | `#E8F5E9` / `#2E7D32` |
| 决策判断／条件分支 | 决策节点 | 菱形 | `#FFF3E0` / `#E65100` |
| 模型／算法模块 | 模块节点 | 矩形 | `#F3E5F5` / `#6A1B9A` |
| 输出结果／结论 | 输出节点 | 圆角矩形（**加粗边框**） | `#FCE4EC` / `#AD1457` |
| 反馈／迭代回路 | 反馈箭头 | **虚线**箭头 | `#333333` |

**质量要求**：① 覆盖全部核心步骤；② 至少 2–3 个分区、每区独立配色；
③ 主流程方向**全图统一**；④ **每节点文字 ≤ 8 个词**、动词开头；
⑤ 箭头标注语义（输入／输出／反馈／迭代）；⑥ 300 DPI PNG ＋ PDF。

### 8.4 单图元素规范

| 元素 | 规范 |
|---|---|
| 标题 | 每个子图用 `(a)`／`(b)` 前置；总标题居中；**图题在图下方** |
| 坐标轴 | **必须含物理量 ＋ 单位**（如"时间 $t$ / s"）；刻度朝内；去顶／右边框 |
| 图例 | 右上或图外；条目 ≤6；**不遮挡数据** |
| 网格 | 仅横向、`#E0E0E0`、0.4 pt；可整体省略 |
| 标记 | 同一系列在全项目**固定形状**（见 §五.1） |
| 误差棒 | 有不确定度时必须画；须在图注说明是 std／CI／range |
| 注释 | 关键结论**必须带量化值**（见 §五.6） |
| 颜色条 | 热力图／3D 必须有 colorbar，**标注物理量与单位** |
| 导出 | **300 DPI PNG ＋ PDF 矢量**；禁用低分辨率位图与拉伸变形 |
