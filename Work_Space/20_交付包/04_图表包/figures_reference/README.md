# 参考图说明（figures_reference）

## 一、本目录是什么

**建模方自行绘制的参考图**（300 DPI PNG ＋ PDF 矢量），
用于让写作者**直观对照**每张图大致应呈现什么内容、什么样式。

## 二、本目录不是什么

- **不是**最终交付图件；
- **不是**要求逐像素照抄的样板；
- **不含**绘图代码（见 §四）。

## 三、最终出图由写作者执行

写作者按下列顺序自行绘制：

1. **规格卡** → `../04-1_图表规格卡/F-xx_*.md`（图型、坐标轴、要素、配色、尺寸）
2. **数据** → `../data/*.csv`（"拿卡 ＋ CSV 即可出图"）
3. **视觉规范** → `../04-2_项目图表设计语言.md`（配色板、字号、尺寸、一致性规则）

**若写作者有更好的画法**：在**规格卡与设计语言**的约束内可自行优化，
**无须与参考图逐像素一致**。参考图的作用是**消除理解偏差**，不是限制表达。

## 四、绘图代码的位置（重要）

**渲染代码不在本包内**——绘图属**写作侧**职责（见《交接说明》模块 9 的分工）。
本包只提供"**规格卡 ＋ 数据 ＋ 参考图**"三件套：

| 本包提供 | 位置 |
|---|---|
| 规格卡（怎么画） | `../04-1_图表规格卡/` |
| 数据（画什么） | `../data/` |
| **参考图**（画成什么样） | 本目录 |

建模方内部的渲染脚本存放于**工作区**（`30_图表/06_参考图渲染/`），**不复制进本交付包**；
如需重新生成参考图，由建模方执行，写作者无需关心。

## 五、数据一致性

参考图所用数据即 `../data/*.csv`，与《05_数值口径总表》**同源一致**。
**若两者出现不符，一律以《05_数值口径总表》为准**，并回报建模方。
