## 一、通用标准（全部素材）

- [ ] 内容自包含：不依赖过程文档即可理解；缺信息回询而不是臆测
- [ ] 数值以 `05_数值口径总表/` 为唯一真值；图表数据以 `04_图表包/data/*.csv` 为唯一真值
- [ ] 无身份/学校/赛区信息（官方匿名红线）
- [ ] 实例文件命名 `<题号>_<名称>_<MMDD>.md`；模板 `00_*.md` 永不被工作覆盖

## 三、交接流程

建模者自查（本表+验收清单）→ `40_复核/00_复核规程.md` 复核 → 交接说明（`01_交接说明.md`）随包更新 → 写作者按 `08_章节素材映射` 消费。

**变更通道（双工作区）**：交付后如需改动，一律**只改主工作区**，由 `tools/wsdiff.py run` 生成
`40_复核/03_变更报告/A_变更明细_自动.md` ＋ `增量更新包/`，经用户授权后推送（`apply --yes`）——
对方**照单覆盖、无需自查**（机制见 `00_规则/交付包同步与职责边界.md` **§〇**）。

## 五、同步与命名的**操作提示**（非规则层；规则层见 `00_规则/交付包同步与职责边界.md`）

> 本节是**操作做法**（当轮生效），**不改规则层**；规则是否改写另议。

1. **同步必须按类全树回验，不以任何"主表清单"为限** —— 每次同步后给出**双边计数**：`真源 n ↔ 包 n ｜ 缺 0 ｜ 哈希不符 0`，覆盖：四问 `code/`＋`innov/`、四问 `logs/`＋`innov/logs/`、`results/`、`innov/out/`、图数据 CSV、规格卡、图表总规划。
2. **复制一律二进制**（禁文本模式）—— 文本模式会把 CRLF 静默转为 LF，产生"内容同、字节不同"的**假一致**（实测 28 件）。
3. **方向判定**：真源 → 包单向；**发现包比真源新 ⟹ 以包回填真源**（`交付包同步与职责边界.md` §四 第 0 条）。
4. **命名规范为"建议、非强制"** —— 官方要求是"**支撑材料文件列表入附录 ＋ 源程序可运行**"，**未强制** `<题号>_<名称>_<MMDD>.md`；本项目**维持现状（`A_*` 命名）**，不再因命名反复回询。
