# 09 代码与复现（目录说明）

> 本目录是交付包的**代码与复现入口**：对应官方红线"论文附录须含**全部完整可运行源程序**（不裁剪）"。
> 逐问代码清单与详细复现指南见同目录 **`A_代码复现.md`**；日志与检验编号对应见 **`README_日志索引.md`**。

---

## 一、一键运行

```bash
pip install -r requirements.txt     # 依赖：numpy／scipy／openpyxl（numba／SALib 可选）
python run_all.py                   # 打印复现计划（不执行任何计算）
python run_all.py --go              # 按序执行：求解 4 ＋ 检验/诊断 67 ＋ 创新 14
python run_all.py -h                # 帮助
```

- **覆盖范围**由**目录扫描**得出（**递归包含 `code/innov/`**）；公共库／非入口模块
  （`*_lib`／`*_par`／`*core*`／`*exact*` 等）自动排除，不会误当成程序执行；
- 被测脚本自身遵守**规模闸门**：默认只打印 `[SCALE]` 声明并退出，须显式 `--go` 才计算，
  调度器会**把 `--go` 透传**给每个脚本；
- **跨平台**：Windows／macOS／Linux 均可直接运行（Python 3.9＋）；macOS／Linux 若无
  `python` 命令请改用 `python3`（`run_all.py` 内部通过 `sys.executable` 调用子脚本，不会串环境）。
  完整说明见同目录 `README_跨平台一键复现.md`（逐项核查表 ＋ 常见问题）。

## 二、目录导航

| 路径 | 内容 |
|---|---|
| `run_all.py` | **一键复现入口**（默认只出计划；`--go` 执行；`-h` 帮助） |
| `code/` | 全部源程序（求解核／主力求解／检验／创新；`code/innov/` 为创新项） |

| `requirements.txt` | 依赖清单（`numba`／`SALib` 为可选加速／扩展项，缺失自动降级） |
| `A_代码复现.md` | **代码清单与逐问复现指南**（权威说明） |
| `README_日志索引.md` | 全题日志 ↔ 检验编号对应表 |
| `*.txt`／`*.csv` | 各脚本运行日志与结果表（**原文留证**） |
