## 二、数据使用纪律（**容易出事的三条**）

1. **附件是唯一数据源**：所有环境量与几何量**直接取自附件**。
   **不要**用"拟合曲线／平滑／PCHIP"替换原始数据——本项目已实测：平滑与否**不改变结论**，
   故**采用原始数据**（对照数据见 `20_交付包/04_图表包/data/fig_smooth_check.csv`）。
2. **外推要声明**：附件1 只覆盖 0–14400 s。$t>14400$ s 的取值属**假设**（记为 H6），
   **不是题目给的数据**，须在"模型假设"中声明并在"模型评价"中交代代价。
3. **附录物性公式分套**：附录2（Q1 常物性）、附录3（Q2／Q3）、附录4（Q4）——
   **严禁跨问混用**（口径项 **K10** 已裁定 Q2/Q3 全程用附录3、内部不设阶段切换）。
