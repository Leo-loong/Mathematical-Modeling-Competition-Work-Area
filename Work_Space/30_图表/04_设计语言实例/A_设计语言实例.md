## 一、配色板（定稿）

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色（主数据系列） | **#1F3A93** 皇家蓝 | Nature 经典色板色 1；温度"中心"、数值解主线 |
| 对比色 | **#F39C12** 金黄 | 温度"表面"；对照系列 |
| 第三色 | **#27AE60** 森林绿 | 含水率"中心" |
| 第四色 | **#C0392B** 深红 | 含水率"表面"；兼作**强调／告警**（关键结论、注错演示） |
| 参考线／辅助 | **#9E9E9E** 灰（虚线 1.0 pt） | 理论阶参考线（$p=1/2$）、初值线、零偏差线 |
| 轴线／文字 | **#333333** 深灰 | 禁纯黑 |
| 网格 | **#E0E0E0** 浅灰，0.4 pt，仅横向 | 可整体省略（法则 2"少即是多"） |
| 背景 | **#FFFFFF** | 去顶/右边框 |
| 连续色阶（场量） | **viridis** | 热力图 F-08／F-09（色盲友好、灰度打印可辨） |
| 发散色阶（残差/正负） | **RdBu** | 偏差图（按需） |

**禁用**：红绿搭配、彩虹配色、高饱和背景、Excel 默认样式、截图替代图表。

## 二、字体与字号

| 项 | 定稿 |
|---|---|
| 中文字体 | 微软雅黑（正文）／思源黑体（若环境可用）；**macOS 绘图侧用 `Heiti SC`（回退 `PingFang SC`）** |
| 西文与数字 | Arial（Helvetica 亦可） |
| **公式（图内）** | **Cambria Math ／ Times，Italic，10 pt，一律 LaTeX 渲染（禁截图）**；MATLAB 用 `Interpreter='latex'` |
| 字号（印刷后） | 标题 10 pt ／ 轴标签 9 pt ／ 刻度 8 pt ／ 图例 8 pt ／ 图内标注 7.5 pt（**最小 ≥7 pt**） |
| 层级比 | 主标题 : 副标题 : 轴标签 : 刻度 : 数据标签 = 2 : 1.5 : 1.2 : 1 : 0.85 |
| **字体嵌入** | 导出**300 DPI PNG ＋ 矢量 PDF（已嵌入全部字体）**；MATLAB `exportgraphics(...,'ContentType','vector')` |
| **MATLAB 落地**（绘图侧环境） | 脚本顶部集中设 `set(0,'defaultAxesFontName','Heiti SC')`／`defaultTextFontName`；**不得**依赖系统默认；`DefaultAxesFontSize=9` 与本文一致 |
| **图内文字语言** | **一律中文**；仅符号（$t_{\rm dry}$、$N$）、单位（h／cm／℃）、公认缩写（GCI）可保留；**数据列值为英文代号时按规格卡给的中文映射改写** |

## 三、尺寸基准

| 类型 | 尺寸 | 说明 |
|---|---|---|
| 单栏图 | 8 × 6 cm | 折线／柱状（3:2 或 4:3） |
| 通栏图 | 16 × 9 cm | 双联／三联（16:9） |
| 热力图 | 1 : 1（如 9 × 9 cm） | F-08／F-09，便于并排对照 |
| 示意图／流程图 | 16 × 8 cm（2:1） | F-01／F-02／F-07 |
| 导出格式 | **300 DPI PNG ＋ PDF 矢量** | 禁低分辨率位图与拉伸变形 |

## 四、本项目图类型选型记录

| 数据形态 | 选定类型 | 理由 |
|---|---|---|
| 径向 × 时间的二维连续场（$T$、$C$） | 热力图（viridis） | 一次呈现全部演化；两场同构便于并排对照时间尺度差异 |
| 时间序列关键点（中心／表面） | 双纵轴折线 | 物理量量纲不同（℃ vs kg/kg），共用一轴会相互压扁 |
| 收敛性（泛函值 vs 步长） | 双联折线（值 ＋ 阶数/GCI） | 收敛论断必须同时给出"值—步长"关系与判据参考线 |
| 数值 vs 解析对比 | 上折线 ＋ 下偏差（双联） | 只画重合曲线无法证明"误差可控"，须独立画出偏差 |
| 参数敏感度排序 | 龙卷风图（横向条形，降序） | 单变量影响对比最直观 |
| 物理对象与边界 | 矢量示意图 | 不含数据，传达几何／边界／离散结构 |
| 流程与方法链 | 流程图（节点规范，见全局 §4） | 节点类型与配色按全局规范执行 |

## 五、一致性规则（贯穿全部规格卡）

1. **系列配色与标记固定**：温度中心 #1F3A93 ○；温度表面 #F39C12 △；含水率中心 #27AE60 □；含水率表面 #C0392B ◇。
2. **线型语义固定**：实线＝数值解／主结果；虚线＝解析解／理论参考；点划线＝拟合或外推。
3. **单位写法统一**：温度 ℃；含水率 kg/kg（干基，首次出现处注明）；距离 cm；时间秒用 s（论文表格按 O8 用 h，须在表头注明）。
4. **图例位置统一**：优先右上或图外，条目 ≤6，不遮挡数据。
5. **编号与引用**：图按章节编号（图5-1、图5-2…），**图题在下**、**表题在上**；正文必须显式引用，否则删除该图。
6. **关键结论图必须带量化值**：F-06、F-08～F-11 须在图内或图注给出带单位的关键数值。
7. **偏差／残差图**：纵轴自适应量级并画零参考线，**禁止与主曲线共用纵轴**。
8. **热力图**：必须使用窄范围色标，并标注"初值／终值"参考，否则场内差异不可见。
9. **本图无数据时（示意图）**：几何与离散参数必须与正文完全一致（如 $\Delta r=0.25$ mm、$R_0=2$ cm），禁止示意与正文不符。
