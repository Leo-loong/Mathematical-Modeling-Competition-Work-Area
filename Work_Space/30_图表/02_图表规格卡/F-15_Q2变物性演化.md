# 图表规格卡：F-15 Q2 变物性随含水率的演化

| 要素 | 内容 |
|---|---|
| **图号/图名** | 图 F-15：第二问物性随含水率的演化（$\rho,c_p,k,D$ 的相对变化） |
| **目的** | 回答"**所谓变物性到底变了多少**"——把"物性随 $C$ 变化"从文字断言变成**可读的量级图**；同时说明 $D$ 还额外依赖温度（附录3 的 $e^{-3850/T}$），为"双向强耦合"提供直观依据 |
| **图类型与理由** | 类型：**多线折线图**（横轴为含水率，纵轴为"相对初值的比值"，量纲归一化后可同图比较）；理由：四个物性量纲各异，**必须归一化**才能共图；横轴取 $C$ 而非时间，可让读者**脱离具体时刻**看清"物性—含水率"的函数关系 |
| **数据源** | 由 `q2_core.py` 的物性函数 $(\rho(C),c_p(C),k(C),D(C,T))$ 在**实测** $C$ 区间上求值并导出 CSV（拟定名 `fig_q2_props.csv`）；$C$ 区间取自 `result2.xlsx` 的实测范围（约 2.55 → 表面终值） |
| **坐标轴** | X：含水率 $C$（kg/kg，干基），范围按实测取；左 Y：**相对初值的比值** $\rho/\rho_0$、$c_p/c_{p,0}$、$k/k_0$、$D/D_0$（无量纲，初值取 $C_0=2.55$、$T_0=28$ ℃ 处）；右 Y（可选）：绝对量级（用于标注具体数值） |
| **标签文本（逐字，全中文）** | 图题「F-15 Q2 变物性随含水率的演化」；坐标轴与色标**逐字**采用本卡「坐标轴」行：X：含水率 $C$（kg/kg，干基），范围按实测取；左 Y：**相对初值的比值** $\rho/\rho_0$、$c_p/c_{p,0}$、$k/k_0$、$D/D_0$（无量纲，初值取 $C_0=2.55$、$T_0=28$ ℃ 处）；右 Y（可选）：绝对量级（用于标注具体数值）；**图内一律中文**（仅符号、单位、公认缩写可保留）；**禁止**出现 CSV 英文列值／裸代号 |
| **字体与公式** | 中文 **思源黑体／微软雅黑**（macOS `Heiti SC`／`PingFang SC`；Linux 须装中文字体）；西文 **Arial**；**图内公式 `Cambria Math`／Times，10 pt，Italic，`Interpreter='latex'`（禁截图）**；字号层级 2:1.5:1.2:1:0.85 且**最小 ≥7 pt**；**导出 300 DPI PNG ＋ 矢量 PDF 并嵌入全部字体**（`exportgraphics(...,'ContentType','vector')`）。依据：`00_规则/图表设计语言.md` **§2.1 六条硬约束** |
| **配色与尺寸** | 四条线按《图表设计语言》§1 顺序取色：#1F3A93（$\rho$）、#F39C12（$c_p$）、#27AE60（$k$）、#C0392B（$D$，兼强调）；比例 **3:2**；$D$ 另加一条虚线表示"在 $T=50$ ℃ 下的同函数"以显温度效应 |
| **绘制注意点** | ① **必须归一化**（否则 kg/m³ 与 W/(m·K) 无法共图）；② **须标注 $C_0=2.55$ 与 3 h 末的表面值**两条竖参考线（灰虚线），使读者知道实际走过多大区间；③ $D$ 的温度依赖需单独说明：同 $C$ 下 $T$ 由 28→50 ℃ 会使 $D$ 增大约数倍（$e^{-3850/T}$ 的效应），**这是"双向耦合"的来源**，须在图注写明；④ 图例条目 4 条，置于右上或图外，不遮挡数据 |
| **对应文字表述建议** | 图注："图 F-15 第二问物性随含水率的演化（相对 $C_0=2.55$ 处归一化）。" 正文引用句："如图 F-15，3 h 内含水率由 2.55 降至约 <表面终值>，相应 $\rho$、$c_p$、$k$ 分别变化约 <x>%、<y>%、<z>%；扩散系数 $D$ 除随 $C$ 变化外还随温度上升而增大（$e^{-3850/T}$），**两场因此构成双向强耦合，无法像第一问那样分开求解**。" |
| **支撑论证点** | 模型建立（"为什么必须用变物性、为什么必须耦合"的定量依据）；与《A_建模推论与判据》"两场严格解耦"一节的**对照**（Q1 解耦 vs Q2 强耦合） |
