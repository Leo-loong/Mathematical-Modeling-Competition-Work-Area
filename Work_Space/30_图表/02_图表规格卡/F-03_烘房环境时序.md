# 图表规格卡：F-03 烘房环境时序（附件1）

| 要素 | 内容 |
|---|---|
| **图号/图名** | 图 F-03：烘房空气温度与水分浓度随时间的变化（附件1，241 点） |
| **目的** | 让评委一眼看清**边界条件的来源与两阶段特征**（先升温后恒温），从而理解"为何第 1 问只算 0–1800 s、为何第 2 问起要用恒温段外推值" |
| **图类型与理由** | 类型：**双纵轴折线**（左轴温度 ℃，右轴水分浓度 kg/kg）；理由：两个量量纲与量级不同，双轴可同图对照其**同步变化**关系，且便于标注阶段分界 |
| **数据源** | `04_图表包/data/fig_env_timeseries.csv`（**本包内**）（由附件1 导出）；列：`t_s`（时间，s，0–14400）、`T_env_C`（烘房温度，℃）、`C_env_kgkg`（烘房水分浓度，kg/kg） |
| **坐标轴** | X：时间（s），0–14400（可加次要刻度标注小时）；左 Y：温度（℃），28–51；右 Y：水分浓度（kg/kg），0.019–0.051；**两条曲线用不同颜色 ＋ 不同线型**以区分轴归属 |
| **标签文本（逐字，全中文）** | 图题「F-03 烘房环境时序（附件1）」；坐标轴与色标**逐字**采用本卡「坐标轴」行：X：时间（s），0–14400（可加次要刻度标注小时）；左 Y：温度（℃），28–51；右 Y：水分浓度（kg/kg），0.019–0.051；**两条曲线用不同颜色 ＋ 不同线型**以区分轴归属；**图内一律中文**（仅符号、单位、公认缩写可保留）；**禁止**出现 CSV 英文列值／裸代号 |
| **字体与公式** | 中文 **思源黑体／微软雅黑**（macOS `Heiti SC`／`PingFang SC`；Linux 须装中文字体）；西文 **Arial**；**图内公式 `Cambria Math`／Times，10 pt，Italic，`Interpreter='latex'`（禁截图）**；字号层级 2:1.5:1.2:1:0.85 且**最小 ≥7 pt**；**导出 300 DPI PNG ＋ 矢量 PDF 并嵌入全部字体**（`exportgraphics(...,'ContentType','vector')`）。依据：`00_规则/图表设计语言.md` **§2.1 六条硬约束** |
| **配色与尺寸** | 温度用**金黄 #F39C12**（与全库"环境侧"语义一致），水分浓度用**森林绿 #27AE60**；比例 **3:2**；阶段分界线用灰虚线 `#9E9E9E`；见《图表设计语言》§1／§2 |
| **绘制注意点** | ① **必须标注第 1 问的时间窗口**（0–1800 s，可用浅色底纹或区间标注），否则读者无法把它与 Q1 联系起来；② 需标出**恒温平台起点**（约 $8.2\times10^{3}$ s，仅供叙述、**不作为模型假设**）；③ 数据为**带噪声的实测时序**，**禁止**做平滑或"美化"处理（本文已用对照实验证明不做平滑）；④ 右轴最小值不为 0，须在轴上明确标出下限，避免视觉夸大波动 |
| **对应文字表述建议** | 图注："图 F-03 烘房环境条件时序（附件1）：温度（左轴）与水分浓度（右轴）。" 正文引用句："如图 F-03 所示，烘房温度在前期快速上升、约 $8.2\times10^{3}$ s 后进入约 50 ℃ 的恒温平台；第 1 问（0–1800 s）**完全落在升温段内**，故其边界直接取自附件1 原始数据、**不涉及外推**。" |
| **支撑论证点** | 机理严谨性（边界条件来源可追溯）；题意适配（解释"预热平衡阶段"的时间窗口） |
