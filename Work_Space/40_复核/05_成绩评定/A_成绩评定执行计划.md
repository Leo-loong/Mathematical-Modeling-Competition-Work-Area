## 一、目标与范围

### 1.1 目标（回答三问）

1. 按**国赛四大评分标准**，我们大概在多少分（**区间**）？
2. 按**国奖级自查体系**，我们处在哪一档（国奖潜力／省一水平／需提升／不合格）？
3. 若要提一档，**最该改的 Top5／Top10** 是什么（按 权重 × 缺口 × 核心系数 排序）？

### 1.2 评估对象的二维结构（**v2 新增，防"只评全题不评小问"**）

| 层级 | 含义 | 覆盖内容 | 备注 |
|---|---|---|---|
| **全题层（P）** | 针对整篇论文的结构性单元 | 摘要与整体结构、参考文献、附录与代码、格式排版、整体印象、跨问一致性 | S3 的 16 维原生形态 |
| **分问层（Q）** | 针对 Q1／Q2／Q3／Q4 各自的单元 | 每问的假设、模型建立、求解、检验、创新、结果 | 本项目产物**按问组织** ⟹ 必须逐问判 |

**单元归属标注**：每个检查点标 `level ∈ {P, Q, B}`（P＝仅全题／Q＝仅分问／B＝两者都有）。
**B 类合并规则**：先逐问判，**全题判定取各问最差态**（保守）；报告中**必须同时给出分问明细**，
**禁止**只给合并值（否则"某一问拖后腿"会被平均掉）。

### 1.3 可判程度分层（素材侧／写作侧）

| 层 | 维度 | 处理 |
|---|---|---|
| **可完整判定** | 二、三、四、五、七、八、九、十、十一、十二、十四、十五、十六 ＋ 六（素材侧） | 正常判四级态 |
| **只判"素材齐备性"** | 一（摘要）、十三（排版）、六（成品呈现部分） | 判"交付到不到位"，**一律标 `◻`，不计入我方得分** |

## 三、评估单元与判定规格

### 3.1 单元定义

**评估单元 U = (层级 L, 问 q, 维度 d, 检查点 c)**，其中：
`L ∈ {P, Q}`；`q ∈ {全题, Q1, Q2, Q3, Q4}`；`d ∈ 1..16`；`c ∈ 该维度的检查点编号（如 4.7）`。

> **为什么写死**：v1 只说"逐检查点判"，未定义单元 → 无法保证**覆盖率可统计**、**分母可口径化**。

### 3.2 判定四态（＋一态）

| 记号 | 含义 | 计分含义 |
|---|---|---|
| 🏆 | 达到国奖级标准 | 满分 |
| ✅ | 合格（符合国赛基本要求） | 满分 |
| ⚠️ | 存在问题（可改，影响档次） | 扣 `FOLD.warn` |
| ❌ | 严重问题（硬伤，直接影响获奖） | 扣 `FOLD.severe` |
| ⬜ | **待取证**（无五类证据之一） | **不计入分母**（须在报告中单列） |
| ◻ | **写作侧／外部依赖** | **不计入我方得分**（只记"素材齐备性"） |

### 3.3 写作侧"素材齐备性"判据表（**v2 新增，可勾选**）

**（a）维度一 · 摘要素材**（底稿：`20_交付包/10_摘要与结论要点/摘要要点卡.md`）

- [ ] 四要素齐备（问题 → 方法 → 结果 → 结论）
- [ ] **每问 ≥1–2 个对比性数字**（如 t_dry 与误差带、T(R)、C(R)）
- [ ] 关键词已给 3–5 个且覆盖"模型/方法＋领域＋关键技术"
- [ ] 分问段落结构建议已给出（每问独立成段）
- [ ] 字数目标已标注（标准 800–1000／国奖 800–1200）
- [ ] 创新点已给"编号＋效果量化"清单

⟹ 全勾＝`◻ 素材齐备`；缺 1–2 项＝`⚠️`；缺 ≥3 项或**缺"每问数字"**＝`❌`。

**（b）维度六 · 成品呈现素材**（底稿：`04_图表包/`）

- [ ] 参考图已渲染或标注"待渲染"清单

**（c）维度十三 · 排版素材**（底稿：`00_规则/图表设计语言.md` §2.1、`04-2_项目图表设计语言.md`）

- [ ] 字体与公式硬约束（中文/西文/公式字体、最小 7 pt、**字体嵌入**）已落库
- [ ] 导出要求（**300 DPI PNG ＋ 矢量 PDF**）已写入规格卡
- [ ] 官方红线清单可执行（匿名／无目录／正文 ≤30 页／P3 摘要页）

### 3.4 分母口径（**保证"达标率"不被 ⬜ 稀释**）

```
分母 = Σ(单元) − Σ(⬜ 单元) − Σ(◻ 单元)
达标率 = (#🏆 + #✅) / 分母
```
**报告中必须同时披露**：`分母`、`⬜ 数`、`◻ 数` ⟹ 读者可自行核对口径。

## 六、计分规格（**v2 细化：公式＋算例＋校准**）

### 6.1 口径 A · S1 四大标准（满分 100）——折算规则

对每条标准：设其子项集合 \(S\)，各子项判 \(\in\{\text{✅},\text{⚠️},\text{❌},\text{⬜}\}\)，满分 \(M\)：

```
扣分下限 = Σ_{⚠️}(0.03·M) + Σ_{❌}(0.15·M) + Σ_{⬜}(0.00·M)
扣分上限 = Σ_{⚠️}(0.07·M) + Σ_{❌}(0.20·M) + Σ_{⬜}(0.10·M)     ← ⬜ 只抬高上界（"可能不达标"）
值域     = [ max(0, M − 扣分上限), M − 扣分下限 ]                  ← 保留 1 位小数
```
> **⬜ 的处理理由**：⬜ 在"达标率"里不进分母（§3.4），但在**分数区间**里必须体现不确定性 ⟹ 只抬高上界，下界不预留（避免用宽区间掩盖问题，符合 P-2"区间宽度＝证据强度"）。

**算例（示意，非真实结论）**：标准 3「结果的正确性」\(M=25\)，6 个子项中 0 个 ❌、1 个 ⚠️（"可视化"）、1 个 ⬜（"验证"待取证）：
```
扣分下限 = 0.03×25 = 0.75          → 上界 = 25 − 0.75 = 24.25
扣分上限 = 0.07×25 + 0.10×25 = 4.25 → 下界 = 25 − 4.25 = 20.75
⟹ 报告写「结果正确性 20.8–24.3 分」
```

### 6.2 口径 B · S3 档位（判定矩阵）

| 档位 | 判定条件（同时满足） |
|---|---|
| 🏆 **国奖潜力** | ❌=0 **且** ⚠️≤15 **且** 🏆达标 ≥30 **且** 四大核心维度无 ❌ |
| ✅ **省一水平** | ❌≤2 **且** ⚠️≤25 **且** 四大核心维度无 ❌ |
| ⚠️ **需提升** | ❌≤5，**或** 核心维度 1–2 个 ❌ |
| ❌ **不合格** | ❌>5，**或** 核心维度 ≥3 个 ❌，**或** L0 致命项触发 |

**四大核心维度**＝一 摘要 · 四 模型建立 · 七 模型检验 · 九 创新点。

### 6.3 口径 C · S6 九维度（45 分）

### 6.4 口径 D · S5 权重配平（**内部一致性检验，可计算**）

设各章得分率 \(r_c\)（由口径 A 的分项映射而来），则：

```
离散度 D = max(r_c) − min(r_c)
若 D ≤ 0.25 → 分布自洽，通过
若 D >  0.25 → 标记「存在高估/低估」→ 对 max/min 两章重新取证
```
> **注意**：权重为区间且各区间和 ≠100% ⟹ **只作排序与配平，不作归一化计分**（不得用它算总分）。

### 6.5 口径 E · S7 五标准（25 分，抽样）

抽样规则（**固定**，防挑样本）：
- 抽 4 处：`摘要要点卡`／`A_Q2模型叙述`（或 Q3）／`A_Q*结果与分析` 之一／`A_Q*可靠性与方法学` 之一；
- 每处各取 **1–2 段**，五标准各 0–5 分；
- 报告须写明抽样对象与段落位置。

### 6.6 计分的小、大、正、负、总、校（**P4 出口须逐项过**）

1. **小**：单元级扣分与 §3.4 分母口径正确；
2. **大**：四口径结果齐备（A 区间／B 档位／C 45 分／D 离散度／E 25 分）；
3. **正**：区间单调性正确（⬜ 越多区间越宽）；
4. **负**：无负值、无超满分（截断 `[0, M]`）；
5. **总**：四步裁定（一致性→保守→证据→回询）有书面留痕；
6. **校**：**规则校准检验** —— 以 **Q1 先例**（`A_Q1质量与成绩评估.md` 的 80–93）为**标定样本**，
   用本规则重算 Q1 范围，**须与 80–93 存在重叠**；不重叠则调整 `FOLD` 并**书面记录调整理由**。

## 八、质量保证

### 8.1 双轨盲评规格（**v2 新增**）

**序数刻度**：🏆=0，✅=1，⚠️=2，❌=3；⬜／◻ = 不参与比对（NA）。
**差异** \(\Delta = |\text{刻度}_A - \text{刻度}_B|\)：

| Δ | 定级 | 处置 |
|---|---|---|
| 0 | 同判 | 直接采纳 |
| 1 | **半档** | 对账（看证据），**取较保守者**，记入差异清单 |
| ≥2 | **跨档** | **必须回询**（登记 `02_差异台账/`），未回询不得定稿 |

**盲评纪律**：轨道 A **全量完成后**才开轨道 B；B 期间**不得回看** A 的判定记录与汇总；
两表**分别落盘**（`A_成绩评定明细表.csv` 与 `_B` 版）后再对账。

### 8.2 描述性一致性检查

- 报告中的每个数字 → 必须能在 D2 找到对应行；
- D2 的每行 `证据指针` → 必须能在 D3 找到证据 ID；
- ⬜/◻ 行 → 必须在报告第 11 节出现。

### 8.3 复现性（P7）

`python code\grade_lib.py --recompute <D2路径>`（执行阶段补该子命令）应能**独立重算**：
达标率、四口径分数、Top10 排序；输出与 D4 不一致即**判 FAIL**（改报告或改参数并声明）。
