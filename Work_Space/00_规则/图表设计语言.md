## 0. 十条法则（1–5 硬约束，6–10 软约束）

| # | 法则 | 内容 |
|---|---|---|
| 1 | 数据至上 | 数据是主角，深色数据点 + 浅色背景，视觉权重最高 |
| 2 | 少即是多 | 去顶/右边框、去冗余网格、去高饱和背景；留白=专业感 |
| 3 | 色彩克制 | 全图 ≤3–5 主色；色盲友好（viridis/plasma/RdBu）；禁红绿搭配 |
| 4 | 对比鲜明 | 数据与背景明度差 ≥7:1；轴线/标签深灰 #333，非纯黑 |
| 5 | 字体一致 | 全图 1–2 种字体；中文思源黑体/微软雅黑，英文 Arial/Helvetica；**公式 = Cambria Math/Times（LaTeX 渲染）**；字号梯度 ≤3 级；**图内文字一律中文**（详见 §2.1） |
| 6 | 对齐精确 | 多子图坐标/colorbar/图例严格对齐；图例框 ≤ 图面积 25% |
| 7 | 标注清晰 | 层级：主标题>副标题>轴标签>刻度>数据标签>脚注；字号 2:1.5:1.2:1:0.85 |
| 8 | 比例正确 | 单图 4:3 或 3:2；多子图 16:9 或 2:1；热力图 1:1 |
| 9 | 可访问性 | 色盲友好、灰度打印可区分 |
| 10 | 可复现性 | 提供绘图代码/参数说明，可 100% 复现 |

## 2.1 字体与公式（**全局硬约束**；2026-09-12 依知识库补齐）

> 来源：知识库《数学建模论文图表AI国奖级美化提示词》**§5.1 字体规范**（Nature/Science 出版级）＋
> 《第10章 AI 论文插图与 LaTeX 排版》**规范五（中文字体配置）**＋《2026国赛零基础获奖速成课讲义》**§9（正文/公式字体）**。
> 本项目实例（含字号折减）见 `30_图表/04_设计语言实例/` **§二** ↔ 交付侧 `04-2_项目图表设计语言.md`。

| 元素 | 字号（期刊级 → **本项目 8–9 cm 图幅**） | 字重 | 字体 | 颜色 |
|---|---|---|---|---|
| 主标题 | 14–16 pt → **10 pt** | Bold | **Arial ／ 思源黑体** | #000000 |
| 副标题 | 11–12 pt | Regular | Arial ／ 思源黑体 | #333333 |
| 轴标签 | 10–11 pt → **9 pt** | Regular | **Arial** | #333333 |
| 刻度标签 | 9–10 pt → **8 pt** | Regular | Arial | #555555 |
| 图例 | 9–10 pt → **8 pt** | Regular | Arial | #333333 |
| 数据标签 | 8–9 pt → **7.5 pt** | Regular | Arial | #222222 |
| 脚注／来源 | 8 pt | Italic | Arial | #666666 |
| **公式（图内）** | **10 pt** | **Italic** | **Cambria Math ／ Times** | #000000 |

**六条硬约束**：

1. **全图 1–2 种字体**；中文 **思源黑体／微软雅黑**，西文 **Arial／Helvetica**；**字号梯度 ≤3 级**（层级比 **2 : 1.5 : 1.2 : 1 : 0.85**）。
2. **公式一律 LaTeX 渲染，禁截图**；图内公式字体 **Cambria Math／Times**（MATLAB 用 `Interpreter='latex'`；若需与西文一致亦可关键标注改普通文本 ＋ Times New Roman）。
3. **最小字号 ≥7 pt**（< 6 pt 禁止）；文字溢出时**换行／缩写**，不得压到 8 pt 以下。
4. **导出必须嵌入字体**：**300 DPI PNG ＋ 矢量 PDF（嵌入全部字体）**；MATLAB 用 `exportgraphics(...,'ContentType','vector')`／`print -dpdf -vector`；**禁用屏幕截图与位图拉伸**。
5. **图内文字一律中文**（仅**符号**（$t_{\rm dry}$、$N$）、**单位**（h、cm、℃）、**公认缩写**（GCI、PDF）可保留）。**外部数据列值为英文代号时，规格卡必须给出"逐字中文标签映射"**（如 `space→空间`、`integral→积分平均`）——**CSV 数据列本身不改**（保持唯一真值）。
6. **跨平台中文字体回退链**（缺配置会显示方框）：Windows `Microsoft YaHei`／`SimHei`；macOS `Heiti SC`／`PingFang SC`／`STHeiti`；Linux 需装中文字体。
   - matplotlib：`rcParams['font.sans-serif']=['Microsoft YaHei','Heiti SC','SimHei']` ＋ `axes.unicode_minus=False`
   - **MATLAB**（绘图侧环境为 macOS）：脚本顶部集中设 `set(0,'defaultAxesFontName','Heiti SC')`、`set(0,'defaultTextFontName','Heiti SC')`（Windows 改 `Microsoft YaHei`）；**不得**依赖系统默认字体

## 2. 图表元素规范

| 元素 | 规范 |
|---|---|
| 线宽 | 主数据线 1.5–2.0 pt；参考线/拟合线 1.0–1.2 pt；网格 0.4 pt 浅灰 |
| 标记 | 散点标记尺寸 4–6 pt，系列间区分形状（○△□◇）；同系列散点可用半透明 |
| 误差棒 | 帽宽为线宽 2 倍；必须在图题或图内注明含义（σ / 95%CI） |
| 网格 | 仅横向浅网格（或都不用）；主刻度向内/外全文统一 |
| 图例 | 位置右上/图外；不遮数据；条目 ≤6，多则用颜色映射代替图例 |
| 标注 | 关键数值/区间带必须有文字标注（含单位）；字体同坐标轴 |
| 尺寸 | 单图 8×6 cm 或 9×6 cm（LaTeX 单栏宽 14–16 cm 内）；导出 300 DPI PNG + PDF 矢量 |
| 文字 | 图内所有文字最小 7 pt（印刷后仍可读）；上下标规范（σ、cm⁻¹、μm） |

## 3. 图表类型选型（数据 → 图）

| 要展示什么 | 用什么图 |
|---|---|
| 趋势/谱线/拟合 | 折线图（实测=散点，拟合=线） |
| 参数不确定性 | 散点 + 误差棒 + 区间带 |
| 多方法对比 | 误差棒点列 / 分组柱状 |
| 分布 | 直方 + 核密度 / 箱线 / 小提琴 |
| 相关/矩阵 | 热力图（viridis 或 RdBu） |
| 组成/占比 | 堆叠柱 / 环形（慎用饼图） |
| 流程/方法 | 流程图（§4 节点规范） |
| 原理/结构 | TikZ/矢量示意图 |
| 空间/地理 | 分级/散点地图 |

## 4. 流程图与方法学框架图规范

| 内容 | 节点类型 | 形状 | 配色（填充/边框） |
|---|---|---|---|
| 输入数据/已知条件 | 数据输入 | 平行四边形 | #E3F2FD / #1565C0 |
| 处理过程 | 过程 | 圆角矩形 | #E8F5E9 / #2E7D32 |
| 决策/分支 | 决策 | 菱形 | #FFF3E0 / #E65100 |
| 模型/算法模块 | 模块 | 矩形 | #F3E5F5 / #6A1B9A |
| 输出/结论 | 输出 | 圆角矩形加粗边框 | #FCE4EC / #AD1457 |
| 反馈/迭代 | 反馈箭头 | 虚线箭头 | 灰 #333333 |

- 分区 2–3 个（数据输入/模型构建/结果输出），每区独立底色
- 方向统一（自上而下或自左向右）；节点文字 ≤8 词、动词开头
- 覆盖该小问全部核心步骤，不遗漏关键环节

## 5. 表格规范

- **三线表为最佳实践**：仅顶线、栏目线、底线三条（0.75–1.5 pt），无竖线。
  （注：据知识库《20个热门问题答疑》#18，组委会并未强制三线表；但规范、直观是硬要求，三线表仍为首选。）
- 表题在**表上方**（表3-1 ×××）；按章节编号；正文必须引用
- 单位列名或表头注明；数值对齐（小数位全文统一）
- 需要强调的行可用浅灰底纹，禁止整表花色

## 6. 编号与引用

- 图按章节编号（图2-1、图3-2），**图题在下**；表题在**上**
- 正文必须显式引用（"如图3-2所示"）；无引用的图表一律删除
- 图题句式：对象 + 方法 + 结论（例："图3-2 实测反射率谱与联合拟合结果（残差呈周期结构）"）

## 7. 绘图工具约定

| 工具 | 用途 |
|---|---|
| MATLAB | 数值结果图（含 .fig 源文件，可复核） |
| matplotlib/seaborn | 统计与数据图（Python 侧） |
| TikZ/pgfplots | 示意图、流程图（LaTeX 内嵌，风格统一最佳） |

## 8. 国赛图表黄金规范（知识库表8-3 · 引擎定位自三天极限速成 §8.4）

| 项目 | 要求 | 违规低分 |
|---|---|---|
| 表格 | 三线表、无竖线 | 网格线、颜色、杂乱 |
| 图表标题 | 表题在上、图题在下 | 无标题、无编号 |
| 编号 | 连续编号（表8-1、图8-1） | 混乱、无编号 |
| 清晰度 | 矢量图、高清、无锯齿 | 截图、模糊、拉伸 |
| 标注 | 坐标轴、单位、图例齐全 | 缺标注、看不懂 |

**核心秘籍（四条）**：
1. 所有图表**原创绘制**，禁止软件截图
2. 图表结果与正文文字**一一对应**
3. 关键图表可适当放大、占满整行
4. 数据图表附**简要文字解读**，不甩图就走
