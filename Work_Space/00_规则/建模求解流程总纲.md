## 0. 流程总览

```
选题决策 → ①审题拆解 → ②方法路线(找坑) → ③假设与符号 → ④模型建立
→ ⑤求解实现 → ⑥检验分析 → ⑦评价改进 → 结果固化(数值口径/图表/交付)
```

- 阶段①-②是"找坑"主战场：题目理解坑 + 方法选择坑。
- 阶段⑥是拉开档次的关键（多数队伍只给结果不检验）。
- 每阶段的"常见坑"来自知识库原文归纳，执行时逐条对照。

### 0.1 评分风向（教材 §1.1.5，AI 时代新范式）
> AI 降低了技术门槛后，评委重心从"你用了什么高级方法"转向"方法选择有没有道理、结论经不经得起推敲"——**从"做出来"到"讲清楚"**。

| 加分项 | 差（省三/省二） | 好（冲国奖） |
|---|---|---|
| 模型选择论证 | "本文采用 AHP 法" | "选 AHP：层级清晰+主客观融合，CR 检验可信；并说明为何不用熵权法" |
| 交叉验证 | 只跑 TOPSIS 一种方法 | TOPSIS+灰色关联双验证，分析排名差异 |
| 误差/灵敏度 | "结果较好" | ±20% 扰动→排名稳定；RMSE=2.35，较 Baseline 提升 18.7% |
| AI 使用声明 | 不提或遮遮掩掩 | **诚实声明使用范围与方式，反而加分** |

### 0.2 AI 使用边界（教材 §1.1.6）
- 可以做：读题拆题/梳理约束、清洗代码框架、查算法原理参数含义、图表代码、LaTeX 排版、初稿润色与逻辑检查、对比候选算法优缺点（参考而非替代判断）
- 不能做（踩了必翻车）：直接复制 AI 论文段落（排比过分工整/回避具体数字/缺批判性讨论，评委能识别）；盲目信任 AI 数学推导（正确率不足 70%，积分/级数/矩阵每步手验）；用 AI 编造结果（每个数字必须实际跑出）；让 AI 判断模型适用性（它不懂你的数据分布）；核心论证用 AI（"为什么这样做/结果说明什么/局限性"必须是自己的思考）

## 1. 选题决策与题型识别（阶段0）

### 1.1 出题规律（速成讲义 §1.3，据 2012-2024 赛题统计）
- **优化类必出**（历年 A/B/C 均含优化主线）；常用模型：线性/非线性规划、遗传算法、单目标/多目标优化
- 难度：A > B ≥ C；擅长出题点：生产优化、交通优化；背景知识：力学、空气动力学、热传递
- 数据要求：一般不需要额外找数据

### 1.2 三类题特点与必备算法（速成讲义 §1.2）
| 题 | 特点 | 必备算法 |
|---|---|---|
| A | 数学物理/工程技术硬核建模：微分方程、优化理论、复杂数值计算 | 规划、动态规划、GA/SA、蒙特卡洛、微分方程+物理模型 |
| B | 开放性、出题点不固定，经济/管理/社会问题 | 规划、回归拟合、评价算法、GA/SA、图论、神经网络、微分方程 |
| C | 开放经管类，侧重机器学习、数据预处理、模式挖掘 | 评价/预测模型、规划、GA/SA、神经网络 |

### 1.3 选题四原则（速成讲义 §1.6）
1. **匹配团队优势**：数学强→A；编程/数据强→B；经管背景→C（新手避开 A）
2. **数据可获得性**：优先公开权威数据源；避开"数据黑箱"题
3. **难度适中**：A 需深入推导；B 接地气；C 灵活处理数据
4. **创新空间**：优先"半开放"题（方案设计/影响因素分析），避开纯理论证明题

### 1.4 题型-模型对照表（速成讲义 §2.2，识别题型后查此表定路线）
| 题型 | 题目特征 | 对应模型 |
|---|---|---|
| 评价 | 无数据定权 → 层次分析法；有数据定权 → 熵权法；因素影响程度/时变综合评价 → 灰色关联；排序/准则层过多 → TOPSIS；模糊环境 → 模糊综合评价；多指标+训练数据 → 神经网络；多投入多产出 → DEA | 按特征选 |
| 预测 | 单调时序 → Logistic/灰色/二次指数平滑/ARMA/季节指数/BP；周期时序 → ARMA/季节指数/BP；不规律时序 → 高斯回归/二次平滑/ARMA；多指标时序 → BP；无后效性 → 马尔可夫 | 按数据形态选 |
| 优化 | 线性目标+线性约束 → 线性规划；整数/0-1 变量 → 整数/0-1 规划；分阶段动态 → 动态规划；含非线性 → 非线性规划；多目标 → 多目标规划；凸目标 → 梯度法（最速下降/SGD/拟牛顿）；非凸 → 智能优化（连续→PSO，离散→GA，低维不限→SA） | 按函数性质选 |
| 预处理 | 缺失值 → 插值；异常值 → 3σ/箱线图；归一化 → 标准差/极值差/功效系数；分类变量 → 独热/标签编码；离散化 → 等宽/等频/聚类；高维 → PCA/t-SNE/UMAP | |
| 聚类 | 无监督 → K-Means/层次/高斯混合/SOM；有监督 → KNN/BP/决策树/朴素贝叶斯 | |
| 相关性 | 离散-离散 → 卡方；连续-连续 → 协方差/Pearson/Spearman；离散-连续 → 箱型图；等级变量 → Kendall | |
| 图网络 | 两点最短 → Dijkstra；多点最短 → Floyd；TSP → 图+规划 | |
| 微分方程 | 多变量满足基本规律（人口/战争/传染病等） | |

### 1.5 选题五维评估矩阵（教材 §15.1.2，D1 晚 21:45-22:15 使用）
对每道题按以下维度打 1-5 分，加权总分最高者入选；**选完即锁题**（后续"XX题好简单"一律忽略）：

| 维度 | 权重 | 打分要点 |
|---|---|---|
| 数据可得性 | ×2 | 附件数据是否完整？缺失多不多？ |
| 题意清晰度 | ×1.5 | 问题是否明确？有无隐藏难点？ |
| 团队匹配度 | ×1.5 | 有无相关领域知识？有无现成代码？ |
| 工作量 | ×1 | 72h 能否完成？有无明显耗时环节？ |
| 创新空间 | ×0.5 | 是否容易做出差异化？ |

### 1.6 A/B/C 题型路线速判（教材 §13.3/§14.3 真题精讲结论）
| 题 | 建模起点 | 核心方法 | 选型建议 |
|---|---|---|---|
| A（机理） | 物理定律推导方程 | 微分方程+有限差分数值求解 | 物理/力学/热学背景强、不怕数值计算的团队 |
| B（优化） | 工艺数据（参数→结果表） | 代理模型（XGBoost）+多目标优化（GA/PSO） | 擅长把问题抽象为"三要素"+数据驱动映射的团队 |
| C（大数据） | 基因/种植等真实数据 | 分类+类别不平衡处理；**"预测+优化"两阶段融合** | 数据处理能力强、能做特征工程与模型融合的团队 |
| 共同要求 | 假设合理 + 模型清晰 + 求解有效 + 灵敏度分析完整 | | |

> C 题融合模式值得注意：近年 C 题常为"先用预测模型产出参数，再进优化模型决策"的两阶段结构，
> 单一模型拿不下。路线细节见教材第 13/14 章真题精讲。

## 2. 阶段①：审题与问题拆解（至少 1 小时）

> 老哥讲义第一步。核心警告：**题目读错，后面全白做；慢就是快。**

### 2.1 动作清单
- **精读 3 遍**：一通读大意 → 二圈关键信息 → 三确认理解正确
- 圈定五要素：已知条件（数据/参数/约束）、决策目标（最优解/预测/评价？）、问题类型（优化/评价/预测/机理）、数据需求（给了吗？要自己找吗？）
- **拆解子问题**：题目通常 3-4 问，逐问分析；画问题关系图（哪些递进、哪些并列）
- 团队各自读题→讨论→确认理解一致；不熟悉的概念快速查资料（可查本知识库）
- 产出 → `11_建模/11-1_题目分析/`

### 2.2 题目理解坑（常见错误）
1. 只读一遍就开始建模
2. 只看问题不看背景介绍，遗漏关键信息
3. 成员理解不一致，产出南辕北辙
4. 把"求最优"理解成"求可行"，目标搞错
5. 忽略约束条件，结果不符合实际

### 2.3 时间纪律（老哥讲义）
- 审题至少 1 小时；**不要在审题花太多时间，也不要在建模上卡死，遇到瓶颈及时换思路**

## 3. 阶段②：方法路线与找坑（选型）

### 3.1 首选推荐模型（速成讲义 §2.2.5，附参数注意）
| 类 | 模型 | 适用 | 关键注意 |
|---|---|---|---|
| 评价 | TOPSIS | 多属性决策，覆盖 90% 多指标评价场景 | 先标准化消量纲；负向指标转正向；结合实际解释 |
| 评价 | 熵权法 | 指标定权基础工具，纯数据驱动 | 先标准化；熵值接近补 CRITIC；权重匹配实际逻辑 |
| 预测 | XGBoost | 多特征数值预测 | 缺失值填充+独热；学习率 0.01-0.1、树深 3-10；5 折交叉验证 |
| 预测 | Prophet | 时序预测（自动趋势/季节性） | 先除异常值；长期预测补外部变量；残差白噪声检验 |
| 分类 | 随机森林 | 80% 分类场景，可输出特征重要性 | 树 100-200；类别不平衡用 SMOTE；OOB 验证 |
| 分类 | LightGBM | 大数据分类 | 防过拟合；交叉验证调参 |
| 优化 | GA | 多约束单目标（非线性） | 种群 50-200、迭代 100-500、交叉 0.6-0.9；约束转惩罚项 |
| 优化 | PSO | 连续空间优化 | 粒子 20-50、惯性权重 0.4-0.9；边界反弹法 |
| 优化 | ACO | 离散优化（路径/指派/调度） | 挥发系数 0.1-0.5、启发因子 2-5；防早熟 |
| 优化 | NSGA-II | 多目标冲突优化 | 种群 50-100；拥挤度保多样性；Pareto 解结合偏好 |
| 机理 | 系统动力学 SD | 带反馈复杂系统 | 明确系统边界；因果回路分正/负反馈；参数需校准 |
| 机理 | 微分方程 | 物理/生物机理 | 基于物理定律建方程；欧拉/龙格-库塔求解；参数拟合 |
| 预处理 | t-SNE / IQR | 降维可视化 / 异常值检测 | 先 PCA 降到 50-100 维再 t-SNE；IQR 阈值 Q1-1.5IQR~Q3+1.5IQR |

### 3.2 十大避坑算法（10大避坑算法文档 + 速成讲义 §2.2.4，两源合并）
> 单独使用 = 自降档次。用前必须加改进/组合，或直接换替代。

| # | 模型 | 核心坑 | 替代/修正 |
|---|---|---|---|
| 1 | 层次分析法 AHP | 主观强、一致性检验易失效、无法处理指标相关性 | 必用则结合熵权法；替代 CRITIC、TOPSIS |
| 2 | 灰色预测 GM(1,1) | 仅适配严格指数数据、非线性误差剧增、无严谨检验 | 仅纯指数小样本(4-5个)可试+残差验证；替代 Prophet、LSTM |
| 3 | 标准 BP 神经网络 | 黑箱难解释、小样本过拟合、调参耗时 | 仅大数据(>1000 组)+正则化；替代 XGBoost、LightGBM |
| 4 | SVM | 参数难调、高维表现差、大数据训练慢 | 仅小样本低维(3-5 特征)；替代 XGBoost、核岭回归 |
| 5 | K-means | （对初值/离群点敏感，需 K 值论证） | 层次聚类/高斯混合；或说明 K 选择依据 |
| 6 | 模糊综合评价 | 隶属函数主观、合成算子随意 | 与客观赋权组合；明确算子选择依据 |
| 7 | 简单/多元线性回归 | 难处理非线性、残差要求严、模型太浅 | 多项式回归、GAM、随机森林 |
| 8 | 朴素贝叶斯 | 特征独立性假设不成立、零概率问题 | 随机森林、XGBoost |
| 9 | 单棵决策树 ID3/C4.5 | 过拟合极高、稳定性差、无概率输出 | 随机森林、GBDT |
| 10 | 熵权法（单独用） | 只反映数据离散性非重要性、极端值主导权重 | 与 TOPSIS/AHP 组合；补 CRITIC |

> ⚠ 与 §3.1 对照可见：同一模型"推荐/避坑"取决于**用法**——AHP 单独用是坑，
> 与熵权法组合可用；熵权法单独定权是坑，与 TOPSIS 组合是推荐方案。选型时写明组合方式。

### 3.3 模型建立三原则（速成讲义 §2.3.2）
- 每个模型的选择必须有**明确问题导向**（"因变量非线性关系显著，故选随机森林而非线性回归"）
- 模型间要有**逻辑衔接**（先聚类分组，再分组回归），不堆砌
- 不刻意追求高难度复杂模型，**实用优先**

### 3.4 创新改进三方向（速成讲义 §2.3.1，评奖关键）
1. **模型融合**：机器学习+传统统计（如灰色-BP、PCA+随机森林）
2. **参数优化**：经典模型引入自适应参数（如自适应粒子群，避免局部最优）
3. **场景适配**：增加贴合题目的约束（如供应链模型加"双碳"目标约束）
- 产出 → `11_建模/11-3_算法与管线/`（选型决策链记录）

## 4. 阶段③：假设与符号

### 4.1 模型假设（老哥讲义第二步）
- **3-5 条为宜**；四标准：合理性（不违背常识/物理定律）、必要性（无多余）、明确性（无模糊表述）、可验证性（可数据验证）
- 每条假设都要**在模型中用到**；假设后用括号注明依据
- 坑：写 10 条多数多余 / 只写 1-2 条关键因素缺失 / "假设影响不大"式模糊表述 / 假设了但模型没用
- 产出 → `20_交付包/03_假设清单/`

### 4.2 符号说明（老哥讲义第三步）
- **建模之前就建好符号表**，边建模边补充；全文统一
- 命名：决策变量小写(x,y,z)；参数大写/希腊字母；集合大写；下标小写；向量矩阵粗体
- 每个符号：含义 + **单位**；三线表呈现，公式中用到的每个符号都可在表中查到
- 产出 → `20_交付包/02_符号表/`

## 5. 阶段④：模型建立（核心中的核心）

### 5.1 建立动作（老哥讲义第四步）
- 按题型选模型类型（查 §1.4 对照表）→ 建目标函数（优化题明确最大化/最小化什么）→ 列约束（资源/物理/逻辑）→ 从基本原理一步步推导，不跳步
- 每个重要公式编号；每个公式配文字说明（含义与由来）

### 5.2 五原则
问题导向（不堆砌高级模型，合适就好）｜由简到繁（先基础模型再改进）｜推导严谨（不跳步）｜创新点明确（改进了什么、为什么）｜公式规范（编号右对齐，变量与符号表一致）

### 5.3 常见坑
1. 模型堆砌——多个复杂模型都不深入
2. 推导跳步——"经过复杂计算可得"
3. 模型与问题脱节——模型漂亮但不解决问题
4. 没有创新——直接套用现成模型
5. 公式不规范——图片拼凑、无编号、变量混乱

## 6. 阶段⑤：求解实现

> ⚠ **本阶段设卡口**：进入前必须通过授权门禁——见《工作约束》**§12 计算任务分级授权**。
> 求解属 **T2／T3 级**任务，**必须先提交申请单（§12.3 六栏）并获明确批准**；
> **未经批准，不得启动任何 T2 以上的计算**（含后台启动、含"先跑个小的试一试"）。

### 6.1 动作清单（老哥讲义第五步）
- 选算法（精确/启发式/智能，依据模型特点）→ 选软件（MATLAB/Python/Lingo/SPSS，用最熟的）→ 编码调试 → **参数设置及依据要写明**（种群大小/迭代次数/学习率等）→ 结果整理（表格+图形）
- 写作要求：算法说明（为什么选它）、参数说明、步骤清晰可复现、结果完整（不只有最终值）、核心代码入附录

### 6.2 红线（与官方规范联动）
- 论文附录 = **全部完整可运行源程序**（缺源程序/不能运行/结果与论文不符 → 可能取消评奖资格）
- 求解结果与《数值口径总表》逐项一致；支撑材料包另见交付规范

### 6.3 常见坑
算法不说明（只说"用遗传算法求解"）｜结果不完整｜代码不放附录｜结果违背常识却不分析原因｜只给数字不给图
- 产出 → `11_建模/11-3_算法与管线/`、`20_交付包/09_代码与复现/`

## 7. 阶段⑥：检验与分析（拉开档次的关键）

> 老哥讲义第六步：**很多队伍不做检验——做了的明显高一个档次。至少做两种。**

### 7.1 四种基本方法
1. **误差分析**：MAE/RMSE/MAPE 量化精度
2. **灵敏度分析**：关键参数 ±1%、±2% 观察结果变化；**不要用"参数变化 10%，结果变化 2%"纯文字**——用龙卷风图展示各参数影响排序（获奖要点）
3. **稳健性检验**：换方法求解/换数据集测试，观察结果稳定性
4. **对比验证**：与真实值/文献结果/简化模型对比

### 7.2 强化手段（获奖要点 29 条）
- **重要结果用两种独立方法求解验证**（如规划解 + 启发式解互验）
- 多方案/多组参数做**对比分析**，给出推荐方案并说明理由

### 7.3 常见坑
不做检验｜检验太简单（只说"结果合理"）｜只做一种｜检验数据不给分析结论｜发现问题直接回避
- 产出 → `20_交付包/06_可靠性与方法学/`、图表 → `20_交付包/04_图表包/`

## 8. 阶段⑦：模型评价与改进（收尾）

（老哥讲义第七步）
- 评价**优点**（特色/创新）+ **不足**（局限/问题）→ **改进方向**（对应不足，具体可行）→ **推广价值**与**适用范围**
- 原则：客观公正、具体详细、有数据支撑（不空泛说"精度高速度快"）
- 坑：只写优点自吹自擂｜优缺点空泛｜不足与改进不对应
- 产出 → `20_交付包/10_摘要与结论要点/`

## 9. 分题型标准步骤（速成讲义 §2.4-2.7）

**数据处理类**（3 步 + 教材细化，教材 §1.3-1.7/§15.1.3）：
- 缺失值（<5% 均值/中位数；5-30% 插值；>30% 删除或 ML 填充）；按机制分：MCAR→直接删除、MAR→KNN/MICE 填补、MNAR→建模填补或标记；缺失>50% 的列直接删；**目标变量缺失只能删样本，绝不填补**
- 异常值（箱线图/IQR/3σ + 业务逻辑判断）——"异常"可能是关键信号（如疫情年份数据），先理解业务含义再决定
- 标准化**按模型选**：距离类（KNN/SVM/K-Means）→标准化；梯度类→归一化；树模型（RF/XGBoost）→不需要；训练/测试集必须共用同一套参数
- 编码：One-Hot（类别≤10）/Label（有序）/目标编码（10-20）/>20 慎用 One-Hot（维度爆炸）；日期拆分年月日星期节假日
- D2 上午三个"绝对不能"：不能跳过数据探查直接建模；不能不做备份就覆盖原始数据（保留 `data_raw` 与 `data_clean` 双版本）；不能数据没洗干净就开始建模

**数据探索（建模前必做，教材第 2 章）**：基础统计量（偏度/峰度判分布形态）→ 描述性可视化（箱线/直方/热力图）→ 正态性检验（Q-Q 图/Shapiro-Wilk，决定参数检验与非参数检验路线）→ 特征工程（特征选择/降维/构造/**多重共线性诊断**）。产出数据质量报告，直接作为论文"数据说明"素材。

**评价类**（5 步）：定评价目的（分类/排序/实现程度）→ 建指标体系（可计算、独立、能区分、全面）→ 指标预处理（一致化+无量纲化）→ 定权重 → 求综合评价值

**预测类**（6 步）：定目标 → 收集分析资料+预处理 → 选方法预测 → 分析评价方法与结果 → 误差分析并修正 → 提交预测报告

**优化类**（5 步）：确认属优化类 → 找决策变量/约束/目标函数 → 定优化类型（线性/非线性/整数…）→ 定求解函数类型（梯度法/智能优化）→ 给结果并回答题目

## 10. 四天时间锚点与应急预案（教材第 15 章）

### 10.1 时间锚点（贴在电脑旁）
- D1 23:00 ——必须定题，绝不超过午夜
- D2 23:00 ——主力+对比模型必须跑通，论文骨架完成
- D3 23:00 ——全文初稿完成（宁可草稿级，不能空白；摘要今晚定稿 80%）
- D4 19:00 ——最终 PDF 提交成功，绝不拖到最后半小时

### 10.2 四天节奏概要（教材 §15.1）
| 天 | 主题 | 关键产出 |
|---|---|---|
| D1 晚 20:00-23:00 | 选题+审题 | 下载题目附件并备份→三题独立通读→讨论投票锁题→逐小问拆解画关系图→关键词提取+文献速查（知网确认有文献支撑，否则仍在可换题窗口） |
| D2 | 数据预处理+建模 | 上午清洗（全天最重要 4h）→特征编码→数据质量报告→Baseline 模型（只求流水线通）→主力模型→对比模型→论文骨架 |
| D3 | 灵敏度+论文全文 | 灵敏度（参数±10%/±20%、删 5-10% 数据、切换方法三向）→论文前半→后半+误差讨论→三审互查→中期编译 |
| D4 | 润色+提交 | 通读润色→补漏→最终编译（连续两遍、双设备验证 PDF）→12 项提交检查→提交 |

### 10.3 应急四原则（教材 §15.3.2）
1. **限时止损**：每个问题设硬性时间上限，超时换方案（反例：跟 Bug 死磕 6 小时，结果是数据路径写错）
2. **降级保底**：复杂方案不通立即降级简单方案，先有结果再优化（反例：XGBoost 调参到 D3 下午没结果，不如早换线性回归）
3. **诚实记录**：所有问题与处理写入论文"数据说明/讨论"（掩盖数据问题=诚信问题，比技术问题严重百倍）
4. **冷静决策**：紧急时刻按预案执行，不"灵机一动"（反例：D3 上午重构模型=自杀）

> 六大突发状况标准化流程（数据附件异常/代码 Bug/结果不合理/时间落后/队员状况/环境故障）
> 见教材 §15.3，赛前打印备用。数据附件异常决策树：换工具 15min→换思路 15min→
> 累计 30min 果断放弃附件（手动录入/合理假设模拟数据并说明）→诚实记录。

### 10.4 协作底线（教材 §15.2.4）
关键决策留痕（选型/数据丢弃/假设变更→群聊文字确认）｜符号统一（全队一套命名规范）｜
版本管理（文件名+时间戳，可回滚）｜静默时段（每天 2-3 个深度工作时段）｜情绪管理（对事不对人）
