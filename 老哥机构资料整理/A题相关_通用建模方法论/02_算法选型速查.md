# 算法选型速查（A题药材烘干专用）

## 一、A题建模路线判断

A题"药材烘干"是典型的**机理建模 + 传热传质耦合**问题：

```
物理过程：
  烘房热风 → 对流换热 → 药材升温 → 水分扩散 → 水分蒸发
                           ↑              ↑
                       热传导方程    Fick扩散方程
                     （圆柱坐标）    （圆柱坐标）
```

**判断**：有明确物理机理（传热+传质+相变）→ 首选微分方程/机理模型，非纯数据驱动。

## 二、老哥机构推荐的高分算法（针对A题场景）

### 第一梯队：核心建模必须用

| 算法 | 用在A题哪里 | 加分理由 |
|------|-----------|---------|
| 圆柱坐标热传导方程（PDE） | Q1-Q4全部：药材内部温度场 | 机理清晰，推导过程可写两页 |
| Fick第二定律（PDE） | Q1-Q4全部：药材内部水分浓度场 | 传质标准方程，和热传导对称 |
| 对流边界条件 | Q1高质量建模：烘房→药材表面的热/质交换 | 题目附件1直接提供烘房数据 |
| 有限差分法（FDM） | 数值求解PDE（Crank-Nicolson或隐式） | 推导+稳定性分析占篇幅 |

### 第二梯队：加分/创新可用（机构推荐的小众高分算法）

| 算法 | 在A题的创新用法 | 老哥评分 |
|------|---------------|---------|
| 龙格-库塔法（RK4/RK45） | 时域推进求解 | ★★★★ |
| 自适应时间步长 | 温度/浓度变化快时自动缩小步长 | ★★★★★ |
| 蒙特卡洛模拟 | 参数不确定性的传播分析 | ★★★★ |
| 参数反演/估计 | 从附件1数据反推未知参数（如对流传质系数校准） | ★★★★ |

### 第三梯队：模型检验必做

| 检验 | 做法 |
|------|------|
| 网格独立性验证 | 不同网格密度（如Δr=0.1/0.05/0.02cm），结果收敛 |
| 时间步长独立性验证 | 不同Δt（如1s/0.5s/0.1s），结果稳定 |
| 参数灵敏度分析 | k/cp/D/对流系数 ±10%/±20% 扰动 |
| 与附件数据对比 | Q1模型计算结果 vs 附件1实测温度数据 |

## 三、机构明确避坑清单（A题特别注意）

| 避坑算法 | 为什么A题不要用 | 正确做法 |
|---------|---------------|---------|
| 灰色预测GM(1,1) | A题不是纯预测题，附件2数据是物理过程结果不是时间序列 | 用PDE数值解，不用统计预测 |
| BP神经网络 | 用NN拟合传热过程=黑箱替代机理，评委不认可 | 机理建模+数值求解 |
| 层次分析法AHP | A题没有多指标评价需求 | 不需要 |
| 多元线性回归 | 传热传质是非线性的，线性回归无法描述 | 用PDE数值解 |

## 四、机构特别提醒：A题写作关键

1. **符号体系统一**：温度T、水分浓度C、半径r、时间t、热传导系数k——全篇一致
2. **物理假设要有依据**：如"假设药材为各向同性圆柱体"→理由：大多数根茎类药材纤维沿轴向，径向截面近似均匀
3. **数值方法交代清楚**：网格数、时间步长、收敛判据、稳定性条件（如显式格式的Δr和Δt约束）
4. **结果要与附件对比**：Q1算出的温度和附件1数据对比，算误差百分比——这是模型可信度的直接证据
