# A题通用建模方法论（老哥讲义精华提炼）

## 一、十大避坑算法（机构明确不推荐单独使用）

| 算法 | 不推荐原因 | 替代方案 |
|------|-----------|---------|
| 层次分析法AHP | 主观赋权、一致性检验造假重灾区 | CRITIC法、TOPSIS、熵权+CRITIC |
| 灰色预测GM(1,1) | 仅适合单调指数、多变量无法处理 | LSTM、Prophet、小波+LSTM |
| BP神经网络 | 小样本必过拟合、黑箱不可解释 | LightGBM、高斯过程回归 |
| SVM | 大样本慢、核函数全靠猜 | LightGBM、XGBoost、随机森林 |
| K-means聚类 | 须预设K、假设球形簇 | DBSCAN、层次聚类、高斯混合 |
| 模糊综合评价 | 隶属函数全主观、权重又回AHP | TOPSIS、灰色关联、VIKOR |
| 多元线性回归 | 假设线性、无建模深度 | LightGBM、高斯过程回归 |
| 朴素贝叶斯 | 特征独立假设不成立 | LightGBM、逻辑回归、随机森林 |
| 单棵决策树 | 过拟合、已被集成学习取代 | 随机森林、XGBoost |
| 熵权法（单独用） | 差异大≠重要，极端值主导权重 | CRITIC法、熵权+AHP组合 |

**核心结论**：老算法不是不能用，但不能单独作为核心方法。组合/改进/升级后可用。

## 二、A题机理建模标准流程（机构方法）

A题核心：物理规律→数学方程→求解分析

### 五步流程
1. **物理/工程背景分析**：读懂题目中的物理过程（传热、扩散、相变等）
2. **提取基本定律**：找出题目涉及的物理定律（牛顿定律、傅里叶热传导、Fick扩散、能量守恒等）
3. **建立微分方程**：写出控制方程（ODE/PDE）及边界条件/初始条件
4. **求解**：解析解（简单情况）或数值解（龙格-库塔、有限差分、有限元）
5. **参数分析与灵敏度检验**：关键参数扰动对结果的影响

### 机理题常驻模型速查
| 场景 | 首选模型 | 备选 |
|------|---------|------|
| 固体传热 | 傅里叶热传导方程（PDE） | 集总参数法（Bi<0.1时） |
| 水分扩散 | Fick第二定律（PDE） | 经验干燥模型（Page/Lewis） |
| 对流边界 | Newton冷却定律 | — |
| 相变/蒸发 | 相变传热传质耦合 | — |
| 数值求解 | 有限差分（显式/隐式）、Crank-Nicolson | 有限元（FEniCS） |

## 三、五大创新路径（机构推荐的加分策略）

| 路径 | 做法 | 适合A题吗 |
|------|------|----------|
| 参数自适应优化 | 动态参数替代固定参数 | 适合——物性参数随温湿变化（ρ/cp/k/D） |
| 多模型对比择优 | 多个模型跑同题，量化对比 | 适合——不同简化程度的传热模型对比 |
| 求解算法升级 | 显式→隐式、欧拉→RK4→自适应步长 | 适合——数值方法升级 |
| 同领域模型融合 | 优势互补 | 适合——传热+传质耦合本身就是融合 |
| 跨领域交叉迁移 | 他领域模型迁移 | 谨慎——A题机理明确，不必硬套 |

## 四、三大必做检验（国奖必备）

| 检验类型 | 查什么 | 做法 | 适配A题 |
|---------|--------|------|---------|
| 误差分析 | 模型准不准 | 与实验/附件数据对比，MAE/RMSE/R² | 对照附件1温度数据验证 |
| 灵敏度分析 | 参数变结果稳不稳 | 关键参数±5%/±10%扰动，看结果变化 | 热传导系数、扩散系数灵敏度 |
| 稳健性分析 | 结论是不是偶然 | 缩样本、换算法、数据扰动 | 不同时间步长/网格密度验证 |

## 五、论文写作速记

- 摘要：背景→方法→结果（具体数值）→验证→价值，不超过1页
- 正文每节五步闭环：模型适配分析→公式推导→变量定义→算法设计→结果解读
- 图表：矢量图、编号连续、三线表、题在表上图在下
- 去AI味：加思考过程（试过什么、为什么换）、具体数值替代空话、长短句交替
- 匿名：全文（含页眉页脚、代码注释、PDF属性）不得出现学校/姓名
