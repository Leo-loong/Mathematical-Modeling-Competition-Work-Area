## 二、最关键的几个提示词要点

### 赛题分析提示词（A题专用版）
核心指令：逐句拆题→判题型（机理题）→给出物理定律候选项→数据注意事项→3天工作清单

### 问题求解提示词
模板：任务描述 + 输入数据格式 + 输出要求 + 边界情况处理 + 代码注释 + 自检纠错点

### AI痕迹检测（V5.0版，10大维度）
| 维度 | 检测重点 |
|------|---------|
| 1. 词汇层 | AI高频词：在此基础上/进一步分析表明/值得注意的是 / 的字密度 |
| 2. 句式层 | 句式单一（全是陈述句）、过渡词密度过高、被动语态过多 |
| 3. 段落层 | 段落长度过于均匀（每段100-200字） |
| 4. 逻辑层 | 逻辑过于完美（无真实思考的试错痕迹）、过渡衔接过于工整 |
| 5. 人味层 | 无个人判断、无不确定性表述、无真实实验中的意外发现 |
| 6. 结构层 | 章节结构模板化（标准八股文） |
| 7. 引用层 | 文献像是编的（查不到）、引用年份集中、无具体页码 |
| 8. 图表层 | 图表描述与图内容脱节、图表标题模板化 |
| 9. 摘要层 | 摘要像是正文的机械压缩、缺乏真正的提炼 |
| 10. 整体感 | 通篇读下来"不像人写的" |

**严重程度判断标准**：评委看到后会不会怀疑是AI写的。会→严重（必须改），仔细看才会→中等（建议改），基本不会→轻微（可选改）。

## 三、模拟演练中的AI使用经验

### 已知坑（LEARNINGS.md记录）

1. **参考文献幻觉**：AI会编造无法核实的引用条目。对策：引用必须逐条追溯交接材料中的题录原始信息，标记为"[待补]"的条目不放入正式参考文献
2. **LaTeX宏定义错误**：`\degree`在数学模式中使用导致乱码。对策：用`\ensuremath{^\circ}`定义

### 模拟演练的图表分工模式
- AI不直接画论文用图——写作者自绘
- AI生成图数据（CSV）+ 基准图（复核用）
- 复核：叠加自检（自己画的图和CSV数据叠画）+ 数字核对（对照数值口径总表）

## 四、使用建议

- 每个提示词都要求AI"给出理由和来源，不只要结论"
- AI给代码后必须自己跑一遍——不跑的代码等于不存在
- 论文摘要不要让AI定稿——人定稿，AI只给修改建议
- AI痕迹检测报告出来后逐条改，不要一键替换
