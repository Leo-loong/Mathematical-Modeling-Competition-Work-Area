# A题 MATLAB 程序说明

## 文件结构

- `run_q1.m` 至 `run_q4.m`：四个小问的独立入口文件。
- `drying_common.m`：四问共同使用的读数、物性、有限体积、非线性迭代、Excel 导出和绘图函数。
- `data/`：附件 1、附件 2 与四个结果模板。
- `result/`：运行各主程序后生成的 Excel 结果和 PNG 图片。

## 使用方法

在 MATLAB 中将当前文件夹设为本目录，按题号依次运行 `run_q1.m`、`run_q2.m`、`run_q3.m`、`run_q4.m`。建议使用 MATLAB R2019a 或更高版本；程序使用 `readmatrix`、`writematrix` 和 `writecell` 写入 Excel。

## 数值方法与口径

1. 半径方向被划分为 20 个等距单元，结果节点正好为 `0, 0.1, ..., 2.0 cm`。
2. 空气温度与空气水分浓度按附件 1 作 PCHIP 插值；在附件结束的 4 h 之后，按最后一个工况保持不变。这是第 3、4 问必须在论文中明确的延拓假设。
3. 第 1、2、3 问的边界为固定半径圆柱；第 4 问使用 `x=r/R(t)` 变换，并加入收缩速度导致的迁移项。
4. 第 3 问的结束条件是 `max(C)<0.15`，即中心和表面等所有离散位置同时达标，而非平均含水率达标。
5. 第 4 问由于半径随时间减小，模板中的固定距离输出自动截取到全过程最小半径之内，最后一列“药材表面”给出真实移动边界的数值；`q4_半径历史.xlsx` 给出相应半径。

## 生成文件

每问产生 `resultN.xlsx` 和两张 PNG 图。第 3 问另生成“每 6 小时含水率汇总”；第 4 问另生成半径历史表。重复运行会覆盖同名的本题结果文件。
