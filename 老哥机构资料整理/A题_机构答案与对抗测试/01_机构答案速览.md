## 机构核心观点

### 降维依据

药材长25cm、半径2cm，L/R=12.5→忽略轴向，**一维轴对称径向模型**（圆柱坐标）

**四个问题 = 同一模型的三次加码：**

| 问题 | 数学本质 | 物性 | 半径 |
|------|---------|------|------|
| Q1 | 定物性·固定边界·变边界条件 | 附录2(ρ/cp/k常数, D随C变) | 固定2cm |
| Q2 | 变物性·分阶段切换 | 附录3(全随C,T变) | 固定2cm |
| Q3 | 加终止判据max(C)<0.15 | 同Q2 | 固定2cm |
| Q4 | 移动边界·坐标变换 | 附录4 | R(t)收缩 |

### 控制方程（圆柱坐标）

```
ρ·cp·∂T/∂t = (1/r)·∂/∂r(k·r·∂T/∂r)   热传导
∂C/∂t = (1/r)·∂/∂r(D·r·∂C/∂r)         水分扩散(Fick)
```

### 无量纲预判（机构做了但很多队伍会漏）

| 指标 | 数值 | 含义 |
|------|------|------|
| Fo_T (1800s) | 0.76 | 温度已走大半程 |
| Fo_C (1800s) | 0.022 | 水分几乎只在表层变化 |
| Bi_h | 1.39 | >1，内外部传热阻力相当，不能用集总参数 |
| Bi_m | 3.24 | >1，浓度降变显著 |
| 热扩散率α | 1.69×10⁻⁷ m²/s | 热特征时间~2369s |
| D_initial | 4.94×10⁻⁹ m²/s | 质扩散特征时间~81000s |

**关键结论**：热扩散比质扩散快34倍，预热阶段(1800s)温度场显著变化但水分仅在表层变化。

### 数值方法

- **格式**：守恒型有限体积法 + **全隐式**时间积分（非显式！）
- **非线性**：Picard迭代(最多3次)，松弛因子0.85，收敛容差1e-7
- **边界插值**：PCHIP（保形三次Hermite）
- **Q4坐标变换**：x=r/R(t)，守恒形式+迎风差分处理收缩对流项
- **矩阵求解**：每步组装三对角稀疏矩阵并直接求解（`A\rhs`）

### GS03明确说为什么不显式

```
显式稳定性条件：Δt ≤ Δr²/(2D)
Δr=0.1cm, D≈5×10⁻⁹ → Δt≤100s 看起来还行？
但问题：C很小时D急剧下降，且为精度减半Δr则Δt变1/4
温度/质扩散时间尺度差34倍，显式被最严条件卡死
结论：必须隐式
```

## 机构验证体系（GT03）

**三层验证：**

1. **解析解对照**：常物性下圆柱非稳态导热有Bessel级数解析解，代码与此对照
2. **网格无关性**：Δr从0.1→0.05→0.025cm，相邻两次最大相对偏差<0.5%即收敛
3. **物理守恒检查**：
   - 温度不能超过烘房温度
   - 含水率必须单调不增
   - 表面C始终低于中心C
   - 总水分损失速率随时间递减

## 机构的9个高频错误提醒（GT03）

| # | 错误 | 后果 |
