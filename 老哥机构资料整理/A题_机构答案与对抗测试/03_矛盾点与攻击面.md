# 03 矛盾点与攻击面

## 攻击面1：球坐标 vs 圆柱坐标 — 机构内部分裂

| 文件 | 坐标系 | 对错 |
|------|--------|------|
| GS03, GS06, GS09, GT03, 成品论文 | **圆柱坐标** | ✓ |
| **GS05, GT04** | **球坐标** | ✗ **错误！** |

药材长25cm是圆柱体，不是球。GS05的球坐标方程是 ∂T/∂t = (α/r²)·∂/∂r(r²·∂T/∂r)，正确的圆柱方程是 ∂T/∂t = (α/r)·∂/∂r(r·∂T/∂r)，差了1/r² vs 1/r。

**对抗方向**：两种坐标下的T(r,t)和C(r,t)差异多大？1800s表面温度差多少？

## 攻击面2：论文写"显式"但代码是隐式 — 自相矛盾

成品论文：
> "采用**显式有限差分法**在0.1 cm空间步长、1 s时间步长下离散并求解"

GS03思路解析明确分析：
> "为什么不能用显式差分：显式稳定性 Δt ≤ Δr²/(2D)，C很小时D急剧下降，温度/质扩散时间尺度差34倍，显式被最严条件卡死。结论：必须隐式"

GT02代码：**全隐式有限体积法** + Picard迭代 + 每一步解稀疏线性方程组

**结论**：论文方法描述是错的。如果真用显式差分在1s步长下求解变物性问题，大概率会发散。

**对抗方向**：机构为什么要这样写？是为了"显得简单"还是论文和代码是不同人写的？队长论文的方法描述必须和实际代码一致。

## 攻击面3：Q4用已知数据作弊？

机构Q4：直接PCHIP插值附件2半径数据作为R(t)函数

**问题**：附件2是题目提供的实测结果（146个时间点，半径2→1.198cm）。直接插值使用意味着：
- Q4的R(t)不是从第一原理推导出来的
- 提前"知道"了收缩规律
- 这不是预测，是回代

**更好的做法**（GS09提出的备选）：
- 从水分流失质量出发建立"含水率↓→密度↓→体积收缩→R(t)"的机理链
- 独立推导R(t)，然后用附件2验证

**对抗方向**：机构Q4是预测还是"已知答案后的后见之明"？

## 攻击面4：边界外推假设缺乏灵敏度验证

机构Q3/Q4的共同假设：4h后烘房恒温50°C、恒湿0.05 kg/kg

**GS09的改进做法**：用指数饱和拟合 T∞(t)=a-b·e^(-t/τ)，τ_T=2359.5s, R²=0.99729，自然渐近T∞→50.15°C, C∞→0.0507。这个做法比简单"恒温恒湿"更合理。

**但问题依然存在**：
- 指数拟合的渐近值依赖拟合方式
- 题目从未说恒温阶段温度是50°C
- 如果恒温阶段实际是55°C或45°C？

**对抗方向**：T_steady ±5°C, C_steady ±0.01 → 烘干时间变化多少小时？如果差超过5h，说明结果对假设高度敏感。

## 攻击面7：热扩散率数值可能算错

机构计算的α = k/(ρ·cp) = 0.36/(820×2600) = 1.69×10⁻⁷ m²/s

**验证**：0.36/(820×2600) = 0.36/2,132,000 = 1.688...×10⁻⁷ ✓ 计算本身没错

**但**k=0.36 W/(m·K)是否合理？木材的导热系数通常约0.1~0.2 W/(m·K)，0.36可能偏高（药材含水时导热系数会高）。这影响Fo_T的大小和"热扩散比质扩散快34倍"的结论。

## 攻击面8：中心点1/r奇异性的处理

GS03和GS09都提到中心点需要特殊处理（"中心点1/r未特殊处理→出现NaN"）。

机构GT02代码的处理方式（`diffuse_radial()`函数）：
```
K(1,1) = -g(1);  K(1,2) = g(1);  % 中心节点只和第一个邻居有通量
```

这是利用对称条件做的简化，等价于将导热方程的1/r曲率项在r→0处用L'Hôpital法则求极限。不处理就会NaN。

**对抗方向**：队长代码的中心节点处理是否正确？如果没处理，在Crank-Nicolson/隐式格式下会不会累积出问题？

## 攻击面9：GS06提出的D公式OCR错误警告

GS06指出题目PDF中D = 2.4×10⁻³ e⁻⁰·⁴⁵/ᶜ e⁻³⁸⁵⁰/ᵀ 可能有OCR解析错误，出现了重复的乱码。

机构GT02代码直接用了这个公式，没有质疑。如果原题确实有OCR错误，那机构的D计算可能有误。
