### solve_fixed() — Q1/Q2/Q3固定半径求解

```
for step = 0:nSteps:
    t = step × dt
    输出当前时间步的T,C
    检查终止条件(Q3: max(C) < 0.15?)
    从附件1插值得到 Ta(t), Ca(t)
    调用 nonlinear_fixed_step() 推进一个时间步
```

### solve_shrink() — Q4移动边界求解

```
for step = 0:nSteps:
    t = step × dt
    从附件2插值得到 R(t), Rdot(t)
    r = R(t) × x    (x是0~1的归一化坐标)
    调用 nonlinear_shrink_step() 推进
```

### nonlinear_fixed_step() — 非线性迭代

```
Picard迭代 (最多3次):
    (1) 用当前C,T更新物性ρ/cp/k/D
    (2) 隐式求解 T: [M/Δt - K]·T_new = M/Δt·T_old + source
    (3) 隐式求解 C: [M/Δt - K_c]·C_new = M/Δt·C_old + source_c
    (4) 松弛: T = 0.85×T_new + 0.15×T_old
    (5) 检查收敛: |T_new-T_old| < 1e-7
```

### diffuse_radial() — 有限体积法核心

```
空间离散: r = linspace(0, R, N+1), N=20
控制体体积: vol_i = 0.5×(r_{i+1/2}² - r_{i-1/2}²)
界面扩散系数: 调和平均 coefFace = 2×k_i×k_{i+1}/(k_i+k_{i+1})
通量项: g_i = rFace_i × coefFace_i / dr

组装三对角矩阵:
对角线: mass_i - g_{i-1} - g_i + BC修正
上下对角线: g_i
边界修正: K(n,n) -= r(n)×h (对流边界)
源项: source(n) = r(n)×h×T_ambient
```

## 关键发现

1. **非线性处理是必需的**：ρ/cp/k/D全部随C/T变化，不能线性化
2. **Picard迭代3次**：这是工程上的折中，不保证严格收敛但够快
3. **附件的D单位**：代码中不转换——D·∂C/∂r 直接用，假设D单位为m²/s
4. **Q4的坐标变换**：x=r/R(t)，控制方程需要加额外的对流项 -β·x·∂C/∂x，机构用迎风差分处理
5. **Q3的停止条件**：max(C) < 0.15 在所有节点同时满足，不是平均值
