## 二、机构统一建模框架

### 2.1 核心降维

**关键假设**：长径比 L/R = 25/2 = 12.5 >> 1，轴向端面散热可忽略

→ **一维轴对称径向模型**（只沿半径方向变化）

→ 温度场 T(r,t) 和含水率场 C(r,t)，用**圆柱坐标**下的PDE描述

### 2.2 控制方程

**热传导方程**（圆柱坐标）：
```
ρ·cp·∂T/∂t = (1/r)·∂/∂r(k·r·∂T/∂r)
```

**水分扩散方程**（圆柱坐标）：
```
∂C/∂t = (1/r)·∂/∂r(D·r·∂C/∂r)
```

### 2.3 边界条件

**中心** (r=0)：对称条件 ∂T/∂r = 0, ∂C/∂r = 0

**表面** (r=R)：第三类边界
```
-k·∂T/∂r|_{r=R} = h·(T - T_air(t))
-D·∂C/∂r|_{r=R} = h_m·(C - C_air(t))
```
其中 T_air(t)、C_air(t) 由附件1 PCHIP插值得到

### 2.4 初值

T(r,0) = 28°C, C(r,0) = 2.55 kg/kg

### 2.5 四个问题的递进

| 问题 | 物性 | 半径 | 时间尺度 | 特殊处理 |
|------|------|------|---------|---------|
| Q1 | 附录2 常数 | 固定2cm | 1800s | 预热阶段 |
| Q2 | 附录3 ρ/cp/k/D随C,T变 | 固定2cm | 3h | 每步更新物性 |
| Q3 | 附录3 | 固定2cm | 直到C<0.15 | 加终止判据，边界外推 |
| Q4 | 附录4 | R(t)收缩 | 72h | x=r/R(t)归一化坐标 |

## 四、机构成品论文的核心数值结果

| 时间 | 表面温度 | 表面含水率 | 中心温度 | 中心含水率 |

| 1800s | ~36.89°C | ~1.39 kg/kg | 接近28°C | 接近2.55 |

**关键发现**：1800s内温度变化显著而水分只在表层薄层内变化（热扩散远快于质扩散）

## 五、机构资料中的重要矛盾（对抗测试关键攻击面）

### 矛盾1：坐标系选择

| 资料 | 坐标系 | 是否正确 |
|------|--------|---------|
| GS03, GS06, GS09, GT03 | **圆柱坐标** | ✓ 正确 |
| GS05, GT04 | **球坐标** | ✗ **错误！**药材是圆柱体不是球体！ |

**对抗测试**：如果用球坐标求解，结果和圆柱坐标差多少？

### 矛盾2：物性处理不一致

- GS06明确说"Q1物性为常数"
- 但GT03代码中Q1的D = 7e-9·e^(-0.89/C)，D仍随C变化（非纯常数）
- 问题：Q1该用必然变物性还是纯常数？

### 矛盾3：Q3/Q4边界外推假设

机构统一假设"4h后烘房恒温50°C、恒湿0.05 kg/kg"
- 这个假设合理吗？题目没说恒温干燥阶段的参数是什么
- 如果实际恒温阶段是不同参数，烘干时间会差多少？

### 矛盾4：Q4半径数据的使用方式

- 机构用PCHIP插值附件2数据作为R(t)
- 但附件2数据是实测结果——这意味着Q4用的是"已知答案"反推
- 真要独立建模，应该从机理推导出R(t)而非直接使用测量数据

### 矛盾5：成品论文vs代码

成品论文声称用的是"显式有限差分法"，但GT02代码实际用的是**全隐式有限体积法+矩阵求解**——二者完全不同。论文写法可能是为了"显得简单"。
