## 一、机构方法论推演的 A题建模框架

### 1.1 机构会怎么建模型

根据机构的机理分析五步法，A题的建模路线：

```
物理分析 → 提取定律 → 建立方程 → 数值求解 → 检验验证
```

**机构会建立的方程体系：**

| 方程 | 内容 | 机构依据（哪条方法论） |
|------|------|----------------------|
| 热传导方程 | ρ·cp·∂T/∂t = (1/r)·∂/∂r(r·k·∂T/∂r)  （圆柱坐标） | "机理题从基本物理定律出发建立控制方程" |
| 水分扩散方程 | ∂C/∂t = (1/r)·∂/∂r(r·D·∂C/∂r)  （Fick第二定律） | "传质过程用Fick扩散" |
| 对流边界条件（热） | -k·∂T/∂r\|_{r=R} = h·(T_bake - T_surface) | "边界条件必须合理，对流换热用牛顿冷却" |
| 对流边界条件（质） | -D·∂C/∂r\|_{r=R} = h_m·(C_bake - C_surface) | "传质边界用对流传质" |
| 初始条件 | T(r,0)=28°C, C(r,0)=2.55 kg/kg | "初始条件直接来自题目" |

**机构会用的数值方法：**
- 空间离散：有限差分（中心差分，圆柱坐标径向一维）
- 时间推进：Crank-Nicolson 或隐式 Euler（"选择合适算法，不盲目求难"）
- 网格密度：至少让 Δr=0.1cm（对应题目输出要求）
- 时间步长：1s（对应题目输出要求）

**机构会用的物性参数处理：**
- Q1：附录2的简化公式（ρ/cp/k常数，D仅随C变）
- Q2/Q3：附录3的经验公式（ρ/cp/k/D全部随C/T动态变化）
- Q4：附录4的经验公式（加入尺寸收缩效应）

### 1.2 机构认为的"创新点"在哪

根据机构的五大创新路径：

| 创新路径 | 在A题的具体应用 |
|---------|---------------|
| **参数自适应** | 物性参数从Q1的定常→Q2的随C/T变化→Q4的随收缩变化，每个问题逐级引入更多动态参数 |
| **求解算法升级** | 显式Euler → Crank-Nicolson → 自适应时间步长（浓度梯度大时自动缩小Δt） |
| **多模型对比** | Q1做两个版本：集总参数法（Bi<0.1）vs 分布参数法（PDE），对比差异说明为什么选分布参数 |
| **模型融合** | 传热+传质耦合——热方程中的物性参数随水分浓度变化，水分扩散系数随温度变化 |
| **跨领域迁移** | 机构不推荐A题用这个（"A题机理明确，不必硬套"） |

## 二、机构要求的检验体系（对抗测试的评判标准）

### 2.1 三大必做检验

根据机构明确要求"灵敏度+稳健性+误差必做"：

| 检验类型 | 机构期望的做法 | 评判标准 | 对抗测试：验证队长模型是否满足 |
|---------|-------------|---------|--------------------------|
| **误差分析** | 模型计算结果 vs 附件1实测温度数据对比 | MAE/RMSE/R²要具体，要有表格 | [ ] 队长模型是否对照附件1验证 |
| **灵敏度分析** | 关键参数±5%/±10%/±20%扰动（k/cp/D/h/h_m至少3-4个参数） | 每个参数要有表格，变化百分比要具体 | [ ] 队长有没有做/做到了什么程度 |
| **稳健性分析** | 换网格密度/时间步长/数值格式，结果是否收敛 | 网格独立性验证+时间步长独立性验证 | [ ] 队长有没有做收敛性验证 |

### 2.2 机构评分标准

机构引用的国赛评审维度：

| 维度 | 分值 | 机构对A题的解读 |
|------|------|--------------|
| 假设合理性 | 10分 | "少而精，每条有依据"。A题至少要有：各向同性圆柱体/忽略辐射（预热阶段温度不高）/忽略轴向传热（长径比大）等 |
| 建模创新性 | 15分 | "有改进点、有对比、有创新"。不要直接套——要有改进，例如显式vs隐式对比、定常vs变物性对比 |
| 结果正确性 | 20分 | "结果完整、有验证、有分析"。所有表（表1-6）都要填满，附件数据要对比，烘干时间要合理 |
| 文字表述 | 35分 | "结构规范、逻辑清晰、图表精美"。图要矢量图、表要三线表 |
| 格式规范 | 20分 | "格式规范、引用正确、附录完整" |

## 三、机构隐含的"避坑指导"

### A题特别容易踩的坑（来自机构的大避坑算法逻辑）

| 坑 | 机构态度 | 为什么 | 如果队长掉进去了 → |
|----|---------|--------|------------------|
| 用统计/ML做核心 | 忌讳 | A题本质是物理机理，不是数据驱动 | 方向错，高分无望 |
| 忽略附件数据验证 | 忌讳 | 机构强调"结果必须有验证" | 致命——论文里说模型好但没有和附件数据对比 |
| 模型假设没依据 | 扣分 | "每条假设必须有理由" | 评阅老师一眼看出AI味 |

| Q1-Q4模型互不关联 | 大失误 | 机构的"层层递进"思路：Q1是基础→Q2是扩展→Q3是应用→Q4是修正 | 四问割裂，缺乏整体性 |

## 五、机构可能出错的地方（对抗时需要警惕）

机构的方法论是通用的，应用到A题具体场景可能有问题：

| 机构可能低估的 | 实际可能发生 | 验证方式 |
|-------------|------------|---------|
| 非线性耦合强度 | ρ/cp/k/D随C/T大幅变化，可能导致数值不稳定 | 跑一次Q2/Q3，看是否需要极小的Δt |
| 附件1水分浓度数据的可靠性 | 机构强调"数据真实可靠"假设，但附件数据可能有测量噪声 | 附件1水分浓度曲线是否光滑？波动是真实物理还是噪声？ |
| Q4收缩模型与传热传质耦合的复杂度 | 半径随时间变化→网格移动→需要坐标变换或动网格 | 试试看能不能直接用固定网格求解 |
| "2-3天"的实际数字 | 机构说"一般持续2-3天"，但你们的计算结果可能偏离 | Q3跑出来的结果如果在24h或100h，需要解释 |
