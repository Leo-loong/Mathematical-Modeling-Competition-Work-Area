# 通用 Markdown 知识库模板

> 定位：与具体题目/项目无关的可复用模板。任何竞赛/项目资料均可套用。
> 工作流：**raw 投放 → 分类归档 → 整理加工 → 索引检索**（四阶段，每阶段可由不同 Agent 会话接力）。

## 目录结构

```
kb/
├── README.md              # 本文件：总说明 + 工作流
├── _raw/                  # ① 投放区：所有 raw markdown 先放这里，不做任何加工
│   └── _intake_log.md     #    投放登记表（谁、何时、来自哪、初步类型）
├── _meta/                 # ② 规范层：分类体系、条目规范、索引规范（模板自带，可按项目裁剪）
│   ├── 01_分类体系.md
│   ├── 02_条目规范.md
│   └── 03_索引规范.md
├── library/               # ③ 归档区：分类后的知识条目（子目录按分类体系创建）
├── index/                 # ④ 索引区：MOC（Map of Content）+ 检索入口
│   └── MOC.md
└── _trash/                # 处理过程中的废弃稿暂存（定期清理，不直接删除）
```

## 各阶段职责

| 阶段 | 输入 | 输出 | 规则 |
|---|---|---|---|
| ① 投放 | 任意原始资料（md/PDF/代码/数据） | `_raw/*.md` + `_intake_log.md` 登记 | 只转化格式，不改内容、不判断价值 |
| ② 分类 | `_raw/` 条目 | `library/<分类>/` 下的条目文件 | 按 `_meta/01_分类体系.md` 归类；一文件一主题；带 front-matter |
| ③ 整理 | library 条目 | 加工稿（摘要、要点、公式块、跨条目链接） | 遵守 `_meta/02_条目规范.md`；原文可追溯 |
| ④ 索引 | library 全貌 | `index/MOC.md` 及专题索引 | 遵守 `_meta/03_索引规范.md`；每次归档后增量更新 |

## Agent 操作约定（每个会话先读本文件）

1. **只在工作区内写 `kb/`**，源资料目录零改动。
2. 投放区文件**只增不删**；分类=移动到 `library/` 并登记，不是复制后不处理。
3. 每个条目文件头部必须带 front-matter（见 `_meta/02_条目规范.md`）。
4. 索引文件是唯一检索入口：查资料先查 `index/MOC.md`，再进条目。
5. 数字/公式等硬结论摘录时标注来源路径，冲突时以来源原始文件为准。
