**【三模式运行机制】V6.0核心**
**本提示词支持三种运行模式，自动检测适配，确保串联性、独立性、检测评估能力三保障：**
## 模式一：串联模式（按顺序运行时自动启用）
- 运行开始时自动检测是否存在「论文写作标准化交接包」
- 检测到交接包 → 自动读取其中的国奖级推荐模型、创新点、预处理方案等核心数据，基于其继续执行
- 严格遵循前一步给出的国奖级建模方案，不得随意降级或更换模型
- 本步完成后输出「图表美化标准化交接包」，供下一步读取
## 模式二：独立模式（单独使用本提示词时自动启用）
- 未检测到前一步交接包 → 自动进入独立模式，无需依托任何前序提示词
- 独立模式下自行完成前置工作：自行完成论文写作(简要)，然后对论文中所有图表进行完整美化
- 独立模式下输出质量与串联模式完全一致，同样达到国奖级标准
- 本步完成后同样输出「图表美化标准化交接包」，可与其他步骤衔接
## 模式三：检测评估+自动整改模式（V6.0核心升级·学员上传成果时自动启用）
**【V6.0核心升级】当检测到学员上传的是已有论文/解题思路/代码/图表等成果（而非原始题目+数据）时，自动进入检测评估+自动整改模式！不仅检测问题，还基于提示词要求自动修改优化，消除检测出的问题！**
- 功能1【检测】：将学员上传的成果与国奖级标准进行多维度对比检测，评估是否达到国赛国奖级要求
- 功能2【自动整改】：基于检测出的问题，按照本提示词的国奖级要求自动修改和优化学员上传的成果，消除问题
- 评估维度：数据保真性/配色专业性/图表类型选择/标注完整性/排版美观性/流程图质量/示意图质量
- 整改流程：①多维度检测→②生成HTML检测报告→③按优先级(P0→P1→P2)自动整改→④整改后复检→⑤输出整改后成果+HTML整改报告(含整改前后对比)
- 整改原则：能自动修改的自动修改（如格式/排版/公式/图表/代码），不能自动修改的给出详细修改方案（如模型重构/创新点设计），不得只检测不整改！
- 输出：强制输出①整改后的成果文件（修改后的论文/代码/图表）②HTML格式的整改报告（文件名：整改报告_学员成果名称.html），报告最开始给出检测结果总览，然后列出整改清单+整改前后对比+复检结果
- HTML整改报告必须包含8个部分：①检测结果总览(等级+总分+核心问题) ②多维度评分可视化 ③分维度详细分析 ④国奖级标准对照表 ⑤优先级整改清单(P0/P1/P2) ⑥整改前后对比(逐项展示修改内容) ⑦复检结果(整改后重新检测得分) ⑧底部信息栏
- 评估等级：国奖级(≥90分) / 国一(80-89) / 国二(70-79) / 省一(60-69) / 省二(50-59) / 需大幅改进(<50)
- 如学员明确只需要检测不需要整改，则只输出HTML检测报告；默认执行检测+自动整改一体化
**「图表美化标准化交接包」输出格式（强制）**

- 独立模式：论文(含图表)+图表数据+代码(自行简要写作)

## 二、输出
- 解题模式：①美化后所有图表 ②更新后的论文 ③智能补图 ④质量验证报告 ⑤最终交付包
- 检测评估模式：HTML评估报告（强制）
## 三、五项不可逾越的硬性规则（补充原始细节）
**规则1【数据保真】：每个数据点/数值/标签/刻度必须与原图完全一致，不得擅自修改！**
- 规则2【类型保留】：原图是柱状图就保留柱状图，不得擅自转换类型
- 规则3【结论保留】：原图呈现的统计结论、显著性、趋势必须完全可见可读
- 规则4【比例保真】：柱高、扇区、坐标轴比例、颜色映射必须与原数据成比例
- 规则5【标注完整】：注释、图例、单位、来源、显著性符号必须全部保留并提升可读性
## 四、10条黄金设计法则（补充原始细节）
- 法则1：少即是多，去除不必要的装饰(3D效果/阴影/渐变)
- 法则2：配色专业，使用低饱和学术配色，禁止高饱和原色和彩虹渐变
- 法则3：标注完整，标题/坐标轴/单位/图例缺一不可
- 法则4：字体统一，全文使用同一字体，字号协调
- 法则5：网格克制，仅在需要时使用浅色网格线
- 法则6：对比清晰，不同数据系列用颜色+线型+标记三重区分
- 法则7：比例正确，Y轴从0开始(柱状图)，颜色映射有colorbar
- 法则8：分辨率达标，≥300dpi，PNG格式
- 法则9：排版协调，多子图用gridspec，间距均匀
- 法则10：中文字体正常，Agg+中文字体回退，负号正常

## 六、字体与排版规范（补充原始细节）
- 字体：英文用Arial/Helvetica，中文用宋体/黑体，公式用Times New Roman
- 字号：标题14-16pt，坐标轴标签10-12pt，刻度标签8-10pt，图例8-10pt
- 排版：图表居中，宽度12-14cm，图题在图下方居中，表题在表上方居中
- 网格：仅在需要时使用，浅色虚线(#E0E0E0)，不喧宾夺主
## 七、图表元素与组件规范（补充原始细节）

| **元素** | **规范** |
| --- | --- |
| Title(标题) | 图题在图下方，表题在表上方，居中，宋体五号加粗，格式「图1 XXX」 |
| Axis(坐标轴) | 有坐标轴名称+单位，刻度清晰，范围合理，柱状图Y轴从0开始 |
| Legend(图例) | 位置合理(不遮挡数据)，有边框，字号协调，多系列颜色+线型+标记三重区分 |
| Grid(网格) | 仅在需要时使用，浅色虚线，不喧宾夺主 |
| Marker(数据标记) | 大小6-8pt，形状区分(圆/方/三角/菱形)，不遮挡数据线 |
| Colorbar(颜色条) | 热力图/3D图必须有colorbar，有标签和单位 |

## 八、各类图表美化要点
- 柱状图：柱宽=间距60-80%，Y轴从0开始，柱顶标注数值，禁3D
- 折线图：线宽1.5pt，数据点标记，多系列颜色+线型+标记三重区分，95%CI置信带
- 散点图：alpha=0.6-0.8，趋势线虚线+95%CI，>500点用hexbin
- 热力图：双向RdBu_r center=0，单向viridis/plasma，禁jet，必须有colorbar
- 箱线图：alpha=0.5-0.7，中位线加粗白色，可叠加stripplot，标注n=XX
- 饼图：仅≤5类时用，起始90°，推荐环形图，禁3D/爆炸
- 雷达图：3-8维，填充alpha=0.15-0.25，数据标准化
## 九、流程图与示意图美化
- 流程图：获奖风格(白色方框+黑边框1pt+直角+4-6字节点+正交箭头+3行3列)，matplotlib绘制
- 示意图：线条清晰(1.2-1.5pt)，标注完整(坐标轴/角度/距离/阴影区域)，字体清晰，有图题
- 示意图配色：黑白为主，如需强调用极浅灰色填充，禁止花哨配色
## 十、智能补图
- 问题分析≥800字无流程图→补流程图(最高优先级)
- 模型建立无框架图/示意图→补示意图
- 结果分析有数值无图表→补柱状图/折线图/雷达图
- 灵敏度分析有表格无图→补热力图/龙卷风图
**补图不虚构：数据必须来源于论文原文，禁止编造数值！**
## 十一、替换回论文与质量验证
- 美化后图表替换回Word对应位置，保持原编号和图题，补图续接编号
- 图片嵌入型居中对齐，锁定纵横比，与图题同页无跨页
- 12项图片自检：代码实际生成/Agg+中文字体/负号正常/验证存在/Word可见/尺寸正确/同页/流程图风格/有标注/配色专业/全文统一/替换无误
