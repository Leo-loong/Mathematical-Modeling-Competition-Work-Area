### 2.1  五项不可逾越的硬性规则
**  ① 数据保真  ** — 图表上的每一个数据点、数值、标签、坐标轴刻度，必须与原图完全一致。即使原图有误，也只能标注提示，不能擅自修改。
**  ② 类型保留  ** — 原图是柱状图就必须保留柱状图；原图是热力图就必须保留热力图。不得擅自转换为其他图表类型（如把柱状图改成饼图）。
**  ③ 结论保留  ** — 原图所呈现的统计结论、显著性、趋势、聚类等核心信息，必须在美化后图中完全可见可读。
**  ④ 比例保真  ** — 柱状图柱高、饼图扇区、坐标轴比例、热力图颜色映射必须与原数据成比例。
**  ⑤ 标注完整  ** — 原图中的注释、图例、单位、来源、显著性符号（*、**、***、ns）必须全部保留并提升可读性。

**§ 3   核心设计原则 (10条黄金法则)**
所有图表美化操作，均应严格遵守以下 10 条黄金法则。AI 须逐条对照执行。

| **编号** | **原则** | **具体说明** |
| --- | --- | --- |
| 法则 1 | 数据至上 (Data First) | 数据是主角。颜色、网格、边框都是配角。配色方案的选择，应使数据点的视觉权重最高 (深色数据点 + 浅色背景)。 |
| 法则 2 | 少即是多 (Less is More) | 去除一切非必要元素：去除顶/右边框、去除冗余网格、去除饱和度过高的背景色。留白 = 专业感。 |
| 法则 3 | 色彩克制 (Color Restraint) | 全图最多使用 3-5 种主色。优先选择色盲友好调色板 (viridis / plasma / RdBu)。避免红绿搭配 (色盲不友好)。 |
| 法则 4 | 对比鲜明 (High Contrast) | 数据元素与背景的明度差 ≥ 7:1 (WCAG AAA 标准)。轴线/标签用深灰 (#333) 而非纯黑 (#000)。 |
| 法则 5 | 字体一致 (Font Consistency) | 全图只使用 1-2 种字体。中文用思源黑体 / 微软雅黑，英文用 Arial / Helvetica。字号梯度不超过 3 级。 |
| 法则 6 | 对齐精确 (Pixel-Perfect Alignment) | 多子图 (subplot) 严格对齐：横纵坐标、colorbar、图例位置一致。图例框大小不超过图的 25%。 |
| 法则 7 | 标注清晰 (Annotation Hierarchy) | 优先级：主标题 > 副标题 > 轴标签 > 刻度 > 数据标签 > 脚注。字号梯度按 2:1.5:1.2:1:0.85 缩放。 |
| 法则 8 | 比例正确 (Aspect Ratio) | 单图建议 4:3 或 3:2；多子图建议 16:9 或 2:1。热力图正方形 (1:1) 显示聚类最清晰。 |
| 法则 9 | 可访问性 (Accessibility) | 色盲友好 (避免红绿)、打印友好 (灰度下仍可区分)、屏幕阅读器友好 (提供 alt 文本)。 |
| 法则 10 | 可复现性 (Reproducibility) | 提供完整的绘图代码或参数说明。读者应能基于代码 100% 复现图表。 |

| 🎯 重要提示：以上 10 条法则中，法则 1-5 为必须遵守 (硬约束)；法则 6-10 为推荐遵守 (软约束)。AI 在执行美化时若需违反其中某条，应在输出说明中明确解释原因。 |

**§ 6   图表元素与组件规范**
本节规定图表的 8 大核心元素 (Title / Axis / Legend / Grid / Marker / Errorbar / Annotation / Colorbar) 的统一规范。
### 6.1  Title (标题)
  - 【格式】主标题：粗体、14-16 pt、顶部居中；副标题：常规、11-12 pt、紧贴主标题下方。
  - 【内容】必须包含：研究对象 + 关键变量 + 区域/时间 + 方法。例：'Spatiotemporal Dynamics of NDVI in Yangtze River Basin (2000-2020)'
  - 【避免】'Figure 1'、'Results' 等无信息量标题。
### 6.2  Axis (坐标轴)
  - 【轴标签】必须含单位。例：'Temperature (°C)' 而非 'Temperature'。
  - 【刻度】刻度密度适中，每轴 4-8 个主刻度为佳。
  - 【对数轴】使用 log scale 时，注明 'log scale'；可加 minor ticks。
  - 【比例】默认线性；只有跨数量级数据才用对数。
### 6.3  Legend (图例)
  - 【位置】优先放右上 / 底部 / 图外。
  - 【样式】无边框或淡灰边框；半透明白色背景 (alpha=0.85)；多个图例时使用 legend title 分组。
  - 【顺序】图例顺序与数据系列顺序一致 (按字母 / 数值 / 时间)。
  - 【大小】图例框不超过图区面积的 25%。

### 6.4  Grid (网格)
  - 【必要性】主网格线足够；minor grid 仅在精细数据下使用。
  - 【样式】linestyle='--' 或 ':'；color='#CCCCCC'；alpha=0.4-0.6；linewidth=0.5。
  - 【方向】通常只显示 Y 轴网格，X 轴方向网格可省略。
### 6.5  Marker (数据标记)

| **系列数** | **推荐标记组合** | **推荐线型** |
| --- | --- | --- |
| 1 系列 | ● 圆点 | 实线 - |
| 2 系列 | ● 圆点  ■ 方块 | 实线 / 虚线 -- |
| 3 系列 | ● 圆点  ■ 方块  ▲ 三角 | 实线 / 虚线 / 点线 : |
| 4 系列 | ●  ■  ▲  ▼ | 4 种不同线型 |
| ≥ 5 系列 | 区分标记+线型+颜色 | 使用色板区分为主 |

### 6.6  Error Bar (误差棒)
  - 【样式】capsize=4-6；elinewidth=1.2-1.5；capthick=1.2-1.5。
  - 【颜色】误差棒颜色与数据系列同色，但稍浅 (alpha=0.6)。
  - 【类型】SD (标准差) 用于描述性统计；SEM (标准误) 用于推断；95% CI 用于效应量；箱线图 IQR / 1.5×IQR 须明确说明。
### 6.7  Annotation (注释)
  - 【文本框】facecolor='white'、edgecolor='#999'、alpha=0.9、boxstyle='round,pad=0.3'。
  - 【箭头】FancyArrowPatch，arrowstyle='->'，color='#333333'，linewidth=1.0。
  - 【内容】简明扼要 (≤ 8 词)；避免大段说明文字出现在图中。
### 6.8  Colorbar (颜色条)
  - 【位置】右侧或底部；高度 = 主图高度的 60-80%。
  - 【标签】含单位；字号 9-10 pt；旋转 90° (纵向) 或 0° (横向)。
  - 【刻度】3-7 个主刻度；可加 extend 标记 ('both' / 'min' / 'max')。
  - 【离散化】分类图可用 BoundaryNorm + 离散 colorbar。
**§ 7   12+ 类图表分项美化规范**
*本节是本提示词的核心。AI 应根据识别出的图表类型，调用对应章节的具体规范进行美化。所有规范遵循总原则：美化不修改 + 提质不增项。*
**§ 7.1   柱状图与条形图 (Bar Chart)**
**【识别特征】矩形条形 + 类别型 X 轴 + 数值型 Y 轴**
**🎨 配色规范**
  ▸  【单系列】统一使用一种主色 (例 #1F3A93 海军蓝)。
  ▸  【多系列】≤ 4 系列时使用离散色板 (Set1/Dark2)；≥ 5 系列考虑分组 / 堆叠。
  ▸  【重点突出】将最关键的柱用主色 (#1F3A93)，其余用浅灰 (#CCCCCC) 衬托 (Nature 风格)。
  ▸  【正负值】正值用蓝色 (#1976D2)，负值用红色 (#D32F2F)，0 轴用深灰加粗。
**📐 几何规范**
  ▸  【柱宽】柱宽 = 类别间距的 60-80%；过宽显拥挤，过窄显稀疏。
  ▸  【柱边】edgecolor='#333333'，linewidth=0.5-1.0；可选无边框。
  ▸  【间距】分组柱图：组内间距小，组间间距大 (ratio 1:2 或 1:3)。
  ▸  【排序】类别按数值降序排列 (排名图)；或按时间 / 字母升序 (普通图)。
**📊 标注规范**
  ▸  【数值标签】柱顶上方 0.1-0.2 cm，字号 8-9 pt。
  ▸  【误差棒】必须含 SD/SEM/95%CI，标注于图注。
  ▸  【显著性】使用 *、**、*** 配合横线 (bracket) 标注，p 值在图注说明。
**🚫 常见错误**
  ×  Y 轴不从 0 开始 (会夸大差异，除非明确标注 'broken axis' 或放大插图)。
  ×  3D 柱图 (透视扭曲严重，强烈不推荐)。
  ×  柱图 + 折线图双 Y 轴混乱。
  ×  数据过多导致柱子过密 (< 1 mm 宽)。

**§ 7.2   折线图与面积图 (Line/Area Chart)**
**【识别特征】连续 X 轴 + 折线 / 曲线 + 可选置信区间填充**
**🎨 配色规范**
  ▸  【单系列】主色 #1F3A93，线宽 2.0 pt，可选 0.1-0.2 alpha 阴影填充 (0.95 CI)。
  ▸  【多系列】每系列独立颜色 (Set1/Dark2)；线型辅助区分 (- -- : -.)。
  ▸  【趋势对比】原图用实线，预测/拟合用虚线，置信带半透明填充。
  ▸  【面积图】堆叠面积使用离散色板；渐变面积使用 Sequential 调色板。
**📐 几何规范**
  ▸  【线宽】主线 1.5-2.0 pt，辅助线 (网格/参考) 0.5 pt。
  ▸  【标记】数据点 ≤ 50 个时全部加标记；> 50 个仅关键点标记；标记大小 4-6 pt。
  ▸  【平滑】可使用 spline 平滑但需保留原始数据点；过度平滑会丢失真实波动。
  ▸  【阶梯图】使用 drawstyle='steps-post' 或 'steps-pre'。
**📊 标注规范**
  ▸  【关键点】最高/最低/拐点用注释框 + 箭头突出。
  ▸  【事件标记】用 vertical line + text 标注关键时间事件。
  ▸  【公式区】拟合曲线 / 回归方程 / R² 用 LaTeX 渲染放在图内或图注。
  ▸  【置信带】95% CI 用同色低 alpha 填充 (alpha=0.15-0.25)。
**🚫 常见错误**
  ×  Y 轴不从 0 开始（折线图可接受，但需明确标注 break）。
  ×  过多线系列 (> 5 条) 造成视觉混乱。
  ×  缺失数据不显式标记 (用 NaN gap 或 'N/A' 文本)。
  ×  双 Y 轴共用但比例不当。

**§ 7.3   散点图与气泡图 (Scatter / Bubble Chart)**
**【识别特征】圆形/方形点 + 双向数值轴 + 颜色/大小映射**
**🎨 配色规范**
  ▸  【单变量散点】单色 + alpha 0.6-0.8 (处理重叠)。
  ▸  【分类散点】每类独立颜色 (Set1/Dark2)；alpha 0.7。
  ▸  【连续映射】使用 viridis / plasma；colorbar 必备。
  ▸  【气泡图】气泡大小映射第三个变量；size 范围 20-2000；alpha 0.5-0.7 防遮挡。
**📐 几何规范**
  ▸  【点大小】s=20-100 (面积)；alpha=0.6-0.8。
  ▸  【标记形状】圆形 ● 默认；正方形 ■、三角形 ▲、菱形 ◆、十字 ✕ 区分。
  ▸  【边缘】edgecolors='#333'，linewidth=0.3-0.5。
  ▸  【重叠处理】点数 > 500 时考虑 hexbin / 2D hist / KDE。
**📊 标注规范**
  ▸  【回归线】OLS 拟合虚线 + 95% CI 半透明带；公式 + R² + p 值在图内或图注。
  ▸  【聚类】k-means / DBSCAN 聚类用半透明 ellipse 包围。
  ▸  【Outlier】异常点用红边 + 数字标签 + 图注说明。
  ▸  【Marginal Hist】双轴散点图加边际直方图或 KDE 曲线。
**🚫 常见错误**
  ×  气泡重叠严重无透明度调节。
  ×  气泡大小映射未标准化。
  ×  三维散点图无可读视角。
  ×  未对点重叠进行核密度估计处理。

**§ 7.4   热力图与相关性矩阵 (Heatmap)**
**【识别特征】矩形矩阵 + 颜色映射数值 + 行列标签**
**🎨 配色规范**
  ▸  【双向数据 (相关系数)】RdBu_r / coolwarm：vmin=-1, vmax=+1, center=0。
  ▸  【单向数据 (基因表达等)】viridis / plasma / inferno。
  ▸  【离散分组】用 BoundaryNorm + ListedColormap 离散化。
  ▸  【显著性叠加】用 *、**、*** 标记 p<0.05/0.01/0.001 单元格。
**📐 几何规范**
  ▸  【方格】正方形 cell；aspect='equal'。
  ▸  【聚类】seaborn.clustermap 行列聚类，添加 dendrogram。
  ▸  【上三角】相关性矩阵常用 mask 隐藏上 / 下三角。
  ▸  【边框】linewidth=0.5-1.0，edgecolor='#FFFFFF' 或 '#CCCCCC'。
**📊 标注规范**
  ▸  【数值显示】单元格中央显示数值，字号 7-9 pt；负值加 '-'。
  ▸  【星号叠加】p<0.05 → *；p<0.01 → **；p<0.001 → ***。
  ▸  【colorbar】必备；标注单位 / 含义；放在右侧或下方。
  ▸  【分组边框】用 Rectangle 在矩阵上标记分组区域。
**🚫 常见错误**
  ×  colorbar 范围未与数据范围匹配。
  ×  RdYlGn 在双向数据下误导 (与红绿含义相反)。
  ×  数值与颜色映射不对应。
  ×  行列标签过长未旋转。

**§ 7.5   箱线图 / 小提琴图 / 分布图**
**【识别特征】箱体 (Q1-Q3) + 中位线 + 须线 (1.5×IQR) + 散点 / 密度**
**🎨 配色规范**
  ▸  【箱体】填充色 #1F3A93 alpha=0.5-0.7，描边 #000 0.5 pt。
  ▸  【多组对比】每组独立颜色 (Set1/Dark2)；使用 patch_artist=True。
  ▸  【小提琴图】每组 viridis 单色渐变；可显示内部 boxplot。
  ▸  【散点叠加】stripplot / swarmplot 半透明 (alpha=0.4) 显示原始数据。
**📐 几何规范**
  ▸  【箱体宽度】widths=0.5-0.7。
  ▸  【中位线】color='#000'，linewidth=2.0。
  ▸  【均值标记】可选菱形 ◆ 红色显示均值。
  ▸  【notch 缺口】notch=True 显示中位数 95% CI。
**📊 标注规范**
  ▸  【Outlier 标记】默认飞地点 + fliersize=4。
  ▸  【统计检验】t-test / Mann-Whitney / ANOVA + p 值在图顶用横线标注。
  ▸  【样本量】n=XX 在 X 轴标签下方或图内。
  ▸  【KDE 带宽】小提琴图带宽可调；展示真实分布形状。
**🚫 常见错误**
  ×  未标注样本量与统计方法。
  ×  Y 轴截断导致箱体变形。
  ×  Outlier 误判（应使用 1.5×IQR 规则）。
  ×  小提琴图带宽不反映真实数据密度。

**§ 7.6   饼图 / 环形图 / 旭日图**
**【识别特征】圆形扇区 + 类别 + 百分比**
**🎨 配色规范**
  ▸  【配色】Set2 / Pastel1 / tab10 离散色板。
  ▸  【强调】最关键扇区用主色 + 突出 (explode=0.05)；其余用浅色。
  ▸  【环形图】width=0.3-0.4；中心可放总值或主标题。
  ▸  【多级】旭日图 (sunburst) 用渐变色映射层级深度。
**📐 几何规范**
  ▸  【起始角度】startangle=90 (12 点钟方向)。
  ▸  【方向】counterclock=False (顺时针，符合阅读习惯)。
  ▸  【边框】wedgeprops={'edgecolor': 'white', 'linewidth': 2}。
  ▸  【半径】radius=1.0 默认。
**📊 标注规范**
  ▸  【百分比】autopct='%1.1f%%'，pctdistance=0.7-0.85。
  ▸  【类别】labels + labeldistance=0.85-1.1；过长则用引出线。
  ▸  【数值】可在扇区中央显示具体数值 (sum=100 等)。
**🚫 常见错误**
  ×  类别过多 (> 7) 导致扇区过小。
  ×  3D 饼图 (扭曲严重)。
  ×  非 100% 占比使用饼图 (应改用柱状图)。
  ×  难以比较相似扇区。

**§ 7.7   雷达图 / 极坐标图**
**【识别特征】多边形 + 多维度评分**
**🎨 配色规范**
  ▸  【多边形填充】alpha=0.15-0.25；每组独立颜色。
  ▸  【轮廓线】linewidth=2.0；与填充同色。
  ▸  【网格线】颜色 #CCCCCC，alpha=0.5。
**📐 几何规范**
  ▸  【维度数】3-8 维最佳；过多维度视觉混乱。
  ▸  【刻度】3-5 圈同心多边形。
  ▸  【起始角】90° 顶部，逆时针 (mathematical convention)。
  ▸  【极坐标投影】projection='polar'。
**📊 标注规范**
  ▸  【维度标签】theta 位置 + r 半径处文本。
  ▸  【图例】放在图右侧 / 下方。
  ▸  【数值】在每个数据点附近标注或仅多边形填充。
**🚫 常见错误**
  ×  维度过多 (> 8) 视觉混乱。
  ×  未标准化数据 (不同量纲无法比较)。
  ×  类别过多 (> 4 个多边形重叠) 难以辨认。

**§ 7.8   3D 图 (曲面 / 散点 / 柱 / 等高线)**
**【识别特征】三维坐标系 (X, Y, Z) + 等高线投影**
**🎨 配色规范**
  ▸  【曲面 / 等高线】terrain / viridis / gist_earth (地形) ；coolwarm / RdBu_r (科学数据)。
  ▸  【3D 散点】单色或按 Z 值 viridis 渐变；alpha=0.6-0.8。
  ▸  【3D 柱】离散色板 (Set1)，按高度渐变。
**📐 几何规范**
  ▸  【视角】elev=20-30°，azim=30-60° 最佳。
  ▸  【曲面线框】plot_surface + rstride=cstride=5-10 (避免过密)。
  ▸  【等高线投影】contour(z, offset=min_z) 投影到底面。
  ▸  【光照】cmap + shade=True 增强立体感。
**📊 标注规范**
  ▸  【轴标签】含单位；'X (m)'、'Y (m)'、'Z (m)'。
  ▸  【colorbar】必备；含单位。
  ▸  【视角提示】可加 inset 显示视角示意。
**🚫 常见错误**
  ×  3D 柱图 (透视扭曲严重，强烈不推荐)。
  ×  视角遮挡关键数据点。

**§ 7.12   统计图 (ROC / 森林 / 生存 / 火山 / 曼哈顿)**
**【识别特征】多模型 / 多变量 / 多基因 / 多研究的对比与显著性**
### 7.12.1   ROC 曲线
  ▸  【绘制】每条模型一条曲线；不同颜色；y=x 参考线 (灰色虚线)。
  ▸  【AUC】图例中显示 AUC 值；按降序排列。
  ▸  【置信带】bootstrap 95% CI 半透明阴影。
  ▸  【PR 曲线】同时绘制 Precision-Recall 曲线 (不平衡数据)。
### 7.12.2   森林图
  ▸  【布局】左列：研究名；中列：点+横线 (95% CI)；右列：weight 或 OR/HR (95% CI)。
  ▸  【汇总】底部菱形 ◆ 表示合并效应量。
  ▸  【参考线】x=1 (无效应) 虚线垂直。
  ▸  【异质性】I²、Q 统计量在底部标注。
### 7.12.3   生存曲线 (Kaplan-Meier)
  ▸  【绘制】阶梯线 step plot；不同组不同颜色。
  ▸  【删失点】tick mark (|) 在删失时间点。
  ▸  【风险表】底部 'No. at risk' 表格。
  ▸  【统计检验】Log-rank p 值；HR (95% CI)。
  ▸  【置信带】每组 95% CI 半透明。
### 7.12.4   火山图 (Volcano Plot)
  ▸  【坐标】x: log2(FC)；y: -log10(p)。
  ▸  【颜色】显著上调红色；显著下调蓝色；NS 灰色。
  ▸  【阈值线】水平虚线 p=0.05；垂直虚线 |FC|=1.5 或 2。
  ▸  【标签】关键基因名 (≤ 10 个)，避免重叠。
### 7.12.5   曼哈顿图 (Manhattan Plot)
  ▸  【坐标】x: 染色体位置；y: -log10(p)。
  ▸  【颜色】染色体交替深浅 (黑白 / 蓝灰)。
  ▸  【阈值线】红线 genome-wide significance (e.g. p<5e-8)。
  ▸  【标签】最显著 SNP / 基因名。

**§ 8   统计标注与显著性规范**
顶刊图表的统计标注是科学严谨性的核心体现。AI 必须严格保留并规范化原图所有统计信息。
### 8.1  显著性符号

| **符号** | **含义** | **p 值范围** | **图注说明文字** |
| --- | --- | --- | --- |
| ns | not significant | p > 0.05 | 'ns' |
| * | significant | p < 0.05 | '*' |
| ** | very significant | p < 0.01 | '**' |
| *** | highly significant | p < 0.001 | '***' |
| **** | extremely significant | p < 0.0001 | '****' |

### 8.2  检验方法标注
  ▸  【正态性】Shapiro-Wilk test / Kolmogorov-Smirnov test
  ▸  【方差齐性】Levene's test / Bartlett's test
  ▸  【两组比较】Student's t-test (配对/独立) / Mann-Whitney U test / Wilcoxon signed-rank
  ▸  【多组比较】One-way / Two-way ANOVA + post-hoc (Tukey / Bonferroni / Dunnett) / Kruskal-Wallis + Dunn
  ▸  【相关性】Pearson (线性) / Spearman (单调) / Kendall (小样本)
  ▸  【生存分析】Log-rank test / Cox proportional hazards
  ▸  【多重比较校正】Bonferroni / FDR (Benjamini-Hochberg) / Holm
### 8.3  效应量与置信区间
  ▸  【相关系数 r】标注 r 值与 p 值；r² 反映解释方差。
  ▸  【比值比 OR / 风险比 HR】必须附 95% CI，例如 OR=2.3 (1.5-3.4)。
  ▸  【Cohen's d】小 0.2 / 中 0.5 / 大 0.8。
  ▸  【R² / Adjusted R²】回归模型必标。
### 8.4  样本量与误差棒类型
  ▸  n = XX 必须出现在图注或图中。
  ▸  误差棒类型必须明确：SD / SEM / 95% CI / IQR。
  ▸  三组及以上比较使用 ANOVA 而非多重 t-test (除非明确说明)。

### 10.1  功能概述与触发条件
**🎯 功能定义**
智能补图是指 AI 在美化论文已有图表的基础上，主动发现论文中「该有图但没有图」的空白区域，并根据论文内容自动生成匹配的流程图、示意图或数据图，使论文图文并茂、逻辑可视化程度大幅提升。
### 10.1.1  触发条件一览

| **检测项** | **触发条件** | **补图类型** | **优先级** |
| --- | --- | --- | --- |
| 问题分析流程图缺失 | 问题分析/模型构建章节无任何流程图/框架图 | 整体方法学流程图 | ★★★★★ |
| 模型框架图缺失 | 模型建立章节仅有文字描述无框架图 | 模型架构流程图 | ★★★★★ |

**⚠️ 不触发场景（禁止补图）**
  ×  论文已有同类型图表覆盖该模块内容时，不重复补图。
  ×  该模块内容过于抽象（纯理论推导/公式证明），难以可视化为图表时，不强行补图。
  ×  该模块已有公式/表格充分表达信息，补图反而冗余时，不补图。
  ×  论文为综述/方法论性质，无具体实验数据可供可视化时，不编造数据补图。

### 10.2  问题分析流程图自动补充

### 10.2.3  流程图质量标准 (在 §7.10 基础上的补充)
  ▸  【逻辑完整】流程图必须覆盖问题分析章节的全部核心步骤，不得遗漏关键环节。
  ▸  【层次分明】至少划分 2-3 个分区（如「数据输入」「模型构建」「结果输出」），每区有独立配色。
  ▸  【方向统一】主流程自上而下 (top-to-bottom) 或自左向右 (left-to-right)，全图统一。
  ▸  【节点精炼】每个节点文字 ≤ 8 个词，核心动词开头（如「提取特征」「构建模型」「求解优化」）。
  ▸  【箭头语义】箭头标注流向语义（如「输入」「输出」「反馈」「迭代」），非简单连接。
  ▸  【双语标注】节点文字优先使用中文，关键技术术语可附英文缩写（如「主成分分析 (PCA)」）。
  ▸  【编号体系】若论文已有图 1-图 N，新流程图编号为图 N+1，图注格式与论文统一。
  ▸  【尺寸规范】单栏宽度 8.5 cm 或双栏宽度 17.5 cm；高度根据节点数自适应（建议 ≤ 22 cm）。

### 10.3  全文模块图片智能补充

### 10.3.1  全文扫描策略

| 📡  扫描策略 —— 逐章节扫描全文，按以下规则判断是否需要补图：      1. 遍历论文每个章节（摘要/前言/问题分析/模型建立/求解/结果分析/灵敏度/讨论/结论）     2. 统计该章节字数与已有图片数     3. 计算「图文比」= 章节字数 / 已有图片数     4. 若图文比 > 阈值 → 触发补图判定     5. 根据章节内容类型，选择最合适的图表类型进行补充      📊  图文比阈值参考：       - 问题分析/模型建立：> 800 字/图 → 补图       - 结果分析：> 500 字/图 → 补图       - 灵敏度/参数分析：> 400 字/图 → 补图       - 前言/背景：> 1000 字/图 → 补图（可选）       - 结论：一般不补图（除非有总结性数据对比） |

### 10.3.3  数据提取与图表生成规范
**🛡️ 补图不虚构 — 五条铁律**
  ①  【铁律 1】所有图表数据必须来源于论文原文中的文字描述、表格数据或已有图表数据，禁止编造任何数值。
  ②  【铁律 2】若原文仅有定性描述（如「A方案优于B方案」）无数值数据，则生成定性对比图而非定量图。
  ③  【铁律 3】若原文数据不完整（如仅有部分参数），则在图注中标注「数据来源：论文 §X.X」并注明估算部分。
  ④  【铁律 4】补充图表的风格（配色/字体/DPI/边距）必须与论文已有图表保持一致。
  ⑤  【铁律 5】每张补充图表必须有完整的图题、图注、数据来源说明，格式与论文已有图表统一。
### 10.3.4  补图插入与编号规范
  ▸  【编号续接】若论文已有图 1-图 N，补充图表编号从图 N+1 开始顺序编号。
  ▸  【插入位置】插入到对应章节末尾或该章节中首次提及相关内容的段落之后。
  ▸  【图题格式】与论文已有图题格式统一（如「图 N  XXX描述。」），含句号结尾。
  ▸  【正文引用】在正文中对应位置添加「如图 N 所示」的引用语句，使图文呼应。
  ▸  【图注内容】简要说明图表含义 + 数据来源 + 关键结论提示（≤ 3 句话）。

**§ 12   常见错误与避坑指南**

| **错误类型** | **具体表现** | **正确做法** |
| --- | --- | --- |
| ❌ 数据修改 | AI 擅自改数据点 / 数值 / 趋势 | 严格保持数据原貌；如原图有错仅提示用户 |
| ❌ 类型转换 | 把柱状图改饼图 / 把折线图改柱状图 | 保留原图类型；如需改必须先与用户确认 |
| ❌ 3D 柱图 | 柱状图加 3D 透视 | 强烈不推荐 3D 柱图；用 2D 替代 |
| ❌ 双 Y 轴滥用 | 两个 Y 轴比例不当 | 最多 1 个 Y 轴；双 Y 轴需比例对应 |
| ❌ 配色混乱 | 使用 jet / rainbow / HSV 等彩虹色 | 用 viridis / plasma / RdBu_r 等感知均匀色板 |
| ❌ 字号过小 | 标签字号 < 6 pt | 最小字号 7 pt；推荐 8-10 pt |
| ❌ 网格过密 | minor grid 满天星 | 仅 major grid；alpha=0.4-0.6 |
| ❌ 缺失单位 | 轴标签无单位 | 必须含单位；例 'Temperature (°C)' |
| ❌ 缺失图例 | 多系列无图例或图例不全 | 图例必须完整；位置不遮挡数据 |
| ❌ colorbar 缺失 | 热力图 / 3D 图无 colorbar | 必须 colorbar 标尺说明 |
| ❌ 显著性缺失 | 比较无 * 或 p 值 | 显著性符号 + p 值双标注 |
| ❌ Outlier 误判 | 箱线图须线规则错误 | 使用 1.5×IQR 标准 |
| ❌ 文字溢出 | 节点 / 标签文字超出框 | 换行 / 缩写 / 缩小字号 ≤ 8 pt |
| ❌ 比例不当 | 子图比例失调 | 严格网格对齐；统一 aspect |
| ❌ 误用饼图 | 饼图表示非 100% 数据 | 饼图仅用于占比；其他用柱状图 |
| ❌ 中国地图 | 缺台湾 / 南海九段线 | 必须包含台湾省 + 南海诸岛 + 九段线 |
| ❌ 时间序列 | X 轴时间格式混乱 | 统一 'YYYY-MM' 或 'YYYY' |
| ❌ 拟合曲线 | 过度平滑掩盖真实波动 | 保留原始数据点 + 拟合线 |
| ❌ 误差棒缺失 | 定量数据无误差棒 | SD/SEM/95%CI 必含其一 |
| ❌ 极坐标误用 | 雷达图维度过多 | 雷达图 ≤ 8 维；> 8 维改用平行坐标 |
