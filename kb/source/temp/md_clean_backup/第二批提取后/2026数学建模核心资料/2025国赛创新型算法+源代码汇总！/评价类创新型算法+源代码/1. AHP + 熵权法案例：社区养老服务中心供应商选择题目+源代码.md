# 1. AHP + 熵权法案例：社区养老服务中心供应商选择
**问题背景**：某社区计划引入 3 家养老服务供应商，提供助餐、医疗护理、文化娱乐 3 类核心服务。社区居民委员会需综合评价 5 家候选供应商，既要体现老年居民代表的主观偏好（如 “医疗护理比助餐更重要”），又要依据供应商的历史服务数据，避免决策片面性。
**数据**：
主观数据：10 位老年居民代表通过 1-9 标度法对 3 项服务的相对重要性打分，形成 AHP 判断矩阵；
客观数据：5 家供应商近 1 年的运营数据（助餐满意度 92%/88%/95%/85%/90%、医疗响应时效 15/20/10/25/18 分钟、文化活动频次 12/8/15/6/10 次 / 月）。
**要求**：综合主客观权重计算得分并排序，选择前 3 家供应商，需说明权重融合的合理性。
### 1. AHP + 熵权法代码：社区养老服务中心供应商选择

| import numpy as np<br>import pandas as pd<br># 数据准备<br># 客观数据：助餐满意度(%)、医疗响应时效(分钟)、文化活动频次(次/月)<br>data = np.array([<br>[92, 15, 12],<br>[88, 20, 8],<br>[95, 10, 15],<br>[85, 25, 6],<br>[90, 18, 10]<br>])<br>suppliers = [f'供应商{i+1}' for i in range(5)]<br>indicators = ['助餐满意度', '医疗响应时效', '文化活动频次']<br># 医疗响应时效为成本型指标，进行正向化处理<br>data[:, 1] = max(data[:, 1]) - data[:, 1]<br># AHP权重计算<br>def ahp_weight(matrix):<br>eigenvalues, eigenvectors = np.linalg.eig(matrix)<br>max_idx = np.argmax(eigenvalues)<br>weights = eigenvectors[:, max_idx].real<br>weights /= np.sum(weights)<br>n = matrix.shape[0]<br>lambda_max = eigenvalues[max_idx].real<br>ci = (lambda_max - n) / (n - 1)<br>ri_table = {1:0,2:0,3:0.58}<br>cr = ci / ri_table[n] if ri_table[n] !=0 else 0<br>return weights, cr<br># 构造判断矩阵（根据10位老年居民代表打分综合）<br>judgment_matrix = np.array([<br>[1, 1/3, 2],   # 助餐满意度相对重要性<br>[3, 1, 4],     # 医疗响应时效相对重要性<br>[1/2, 1/4, 1]  # 文化活动频次相对重要性<br>])<br>ahp_weights, cr = ahp_weight(judgment_matrix)<br>print(f"AHP一致性检验CR={cr:.4f}，{'通过' if cr<0.1 else '未通过'}")<br># 熵权法权重计算<br>def entropy_weight(data):<br>data_norm = data / np.sum(data, axis=0) + 1e-10<br>n, m = data_norm.shape<br>entropy = -np.sum(data_norm * np.log(data_norm) / np.log(n), axis=0)<br>return (1 - entropy) / np.sum(1 - entropy)<br>entropy_weights = entropy_weight(data)<br># 综合评价<br>alpha = 0.5<br>combined_weights = alpha * ahp_weights + (1-alpha) * entropy_weights<br>normalized_data = data / np.sum(data, axis=0)<br>scores = np.dot(normalized_data, combined_weights)<br># 结果展示<br>result = pd.DataFrame({<br>'供应商': suppliers,<br>'综合得分': scores.round(4),<br>'排名': (scores.argsort()[::-1].argsort() + 1)<br>}).sort_values('综合得分', ascending=False)<br>print(result) |
