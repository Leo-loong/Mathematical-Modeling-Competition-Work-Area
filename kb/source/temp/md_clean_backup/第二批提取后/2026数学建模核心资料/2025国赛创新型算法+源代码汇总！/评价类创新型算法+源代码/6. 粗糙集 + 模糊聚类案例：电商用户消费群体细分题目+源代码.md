# 6. 粗糙集 + 模糊聚类案例：电商用户消费群体细分
**问题背景**：某电商平台需对 5000 名用户细分，用于精准营销。用户数据含 10 项特征（如年龄、性别、月消费额、购买频率等），部分特征冗余（如 “月消费额” 与 “购买频率” 高度相关），且用户边界模糊（如 “中等消费” 与 “高消费” 无明确阈值）。
**数据**：
5000 条用户记录，特征包括：年龄（18-60 岁）、性别（男 / 女）、月消费额（0-5000 元）、购买频率（1-30 次 / 月）等。
**要求**：用粗糙集约简特征（保留核心特征），再用模糊聚类分为 3-5 个群体，输出每个群体的特征（如 “25-35 岁女性，月消费 2000-3000 元”）及隶属度。
### 6. 粗糙集 + 模糊聚类代码：电商用户消费群体细分

| import numpy as np<br>import pandas as pd<br>from sklearn.preprocessing import KBinsDiscretizer<br>from roughsets.roughsets import RoughSet  # 需安装：pip install roughsets<br>from fcmeans import FCM  # 需安装：pip install fcmeans<br>import matplotlib.pyplot as plt<br># 1. 数据准备（模拟5000名用户数据）<br>np.random.seed(42)<br>n_users = 5000<br># 特征：年龄(18-60)、性别(0=男,1=女)、月消费额(0-5000)、购买频率(1-30)、浏览时长(小时/周)、收藏数量(个/月)<br>age = np.random.randint(18, 61, n_users)<br>gender = np.random.randint(0, 2, n_users)<br>monthly_spend = np.random.randint(0, 5001, n_users)<br>purchase_freq = np.random.randint(1, 31, n_users)<br>browse_time = np.random.uniform(1, 20, n_users)<br>favorite_count = np.random.randint(0, 50, n_users)<br>X = np.column_stack((age, gender, monthly_spend, purchase_freq, browse_time, favorite_count))<br>features = ['年龄', '性别', '月消费额', '购买频率', '浏览时长', '收藏数量']<br># 2. 粗糙集特征约简<br># 数据离散化（粗糙集要求离散数据）<br>discretizer = KBinsDiscretizer(n_bins=5, encode='ordinal', strategy='uniform')<br>X_discrete = discretizer.fit_transform(X).astype(int)<br># 构造决策系统（用月消费额离散值作为伪决策属性）<br>decision = X_discrete[:, 2]  # 以月消费额作为决策属性<br>rs = RoughSet(X_discrete, decision)<br>reduct = rs.reduct()  # 获取约简特征索引<br>print(f"原始特征数：{X.shape[1]}，约简后特征数：{len(reduct)}")<br>print(f"保留的核心特征索引：{reduct}，对应特征：{[features[i] for i in reduct]}")<br># 提取约简后的特征<br>X_reduced = X[:, reduct]<br># 3. 模糊聚类（分为4个群体）<br>fcm = FCM(n_clusters=4, random_state=42)<br>fcm.fit(X_reduced)<br>membership = fcm.u  # 隶属度矩阵<br>labels = np.argmax(membership, axis=1)  # 最终聚类标签<br># 4. 分析聚类结果<br>cluster_centers = fcm.centers<br>result = pd.DataFrame(X_reduced, columns=[features[i] for i in reduct])<br>result['聚类标签'] = labels<br># 输出每个群体的特征描述<br>print("\n各消费群体特征：")<br>for i in range(4):<br>cluster_data = result[result['聚类标签'] == i]<br>print(f"\n群体{i+1}（样本数：{len(cluster_data)}）：")<br>print(cluster_data.iloc[:, :-1].describe().round(2).loc[['mean']])<br># 5. 可视化聚类结果（取前2个特征）<br>plt.figure(figsize=(10, 6))<br>plt.scatter(X_reduced[:, 0], X_reduced[:, 1], c=labels, cmap='viridis', alpha=0.6)<br>plt.scatter(cluster_centers[:, 0], cluster_centers[:, 1], marker='X', s=200, c='red', label='聚类中心')<br>plt.xlabel(features[reduct[0]])<br>plt.ylabel(features[reduct[1]])<br>plt.title('电商用户消费群体聚类')<br>plt.legend()<br>plt.show() |
