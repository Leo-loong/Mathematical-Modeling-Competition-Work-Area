灰色预测的检验
有三种方法，相对误差大小检验法，关联度检验法和后验差检验法。

后验差检验法：
计算残差，残差=实际值-预测值
计算原始数据的方差S1
计算残差的方差S2
后验差C=S2/S1
C越小越好，C越小表示S1大而S2小。S1大表示原始数据方差大，即原始数据离散程度大。S2小表示残差方差小，即残差离散程度小。C小表示尽管数据很离散，而模型所得计算值与实际值之差并不太离散。
后验精度检验等级参照表

| **精度等级** | **C** |
| --- | --- |
| 1级（好） | C<=0.35 |
| 2级（合格） | 0.35<C<=0.5 |
| 3级（勉强） | 0.5<C<=0.65 |
| 4级（不合格） | C>0.65 |
