# AI 工具使用详情

| --- |
| 二、具体使用目的与环节 |
| **ChatGPT（GPT-4）**<br>在问题二模型建[1]立环节，用于提供多种交通流量预测模型的对比分析，帮助确定初步的模型选择范围。<br>（2）在问题分析阶段，针对题目要求和已知条件及参数，给出参考的解题思路，帮助更好的分析题目。 |
| **豆包（V3.5）**<br>在论文撰写环节，用于优化文字表达，使描述更简洁准确。 |
| **DeepSeek（V3.1）**<br>在问题三模型求解阶段，用于对所建立的编程代码进行优化和修改，使代码运行的准确度和效率更高。 |
| 三、关键交互记录（重要提示词与回复） |
| **ChatGPT（GPT-4）**<br>**Query1: **请对比分析 ARIMA 模型、LSTM 模型、随机森林在城市交通流量短期预测中的优缺点及适用场景<br>**Output:**以下是对 ARIMA 模型、LSTM 模型和随机森林在城市交通流量短期预测中的优缺点对比分析：<br>ARIMA 模型：适用于数据量较小、线性趋势明显的短期预测（如常规工作日的流量预测）。<br>LSTM 模型：适合数据量大、非线性模式复杂的场景（如大型城市多路段流量实时预测）。<br>随机森林：适用于需结合多源特征（如天气、事件）且对可解释性有要求的预测任务。 |
| **豆包（V3.5）**<br>**Query1: **将‘我们通过对大量历史交通数据的分析，发现交通流量在早高峰 7-9 点和晚高峰 17-19 点会出现明显拥堵’这句话优化得更专业<br>**Output:**通过对历史交通流量数据的时序分析，发现早间 7-9 时与晚间 17-19 时时段存在显著的周期性流量峰值特征，该时段路网饱和度超过临界阈值，呈现典型的交通拥堵状态。 |
| 四、采纳和人工修改情况 |
