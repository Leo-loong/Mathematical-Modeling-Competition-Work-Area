System Requirements and Installation
---

Requirements
---
  Microsoft Visio 2000/2002/2003/2007 (Standard, Professional or Enterprise).

Installation
---
  Visio 2000
---
    1. Find the Visio folder, probably c:\Program Files\Visio
    2. Open the Solutions folder and create a new folder called 'electronics'
    3. Unzip the template and stencils into this new folder
    4. Electronics will now be available as a new drawing type
    5. The stencils are available from the Open Stencil menu

  Visio 2002/2003/2007
---
    1. Find the folder 'My Shapes' in My Documents
    2. Create a new folder called 'electronics'
    3. Unzip the template and stencils into this new folder
    4. Double-click on the template file
    5. Visio will now start and you will have an empty drawing with all the stencils open
    6. The stencils are available from the Open Stencil menu

  To add Sandrila electronics to the list of available diagrams
---
    For Visio 2002/2003
---
      1. Start Visio.
      2. From the 'Tools' menu select 'Options | Advanced' then select the 'File Paths' button.
         Add the path to the newly created folder e.g.
              'My Documents\My Shapes\electronics'
            to the Stencils and Template file path.
         If the path already contains data then separate the 2 paths with a ;.
      3. The 'New' menu will now include Sandrila electronics.
    For Visio 2000/2007
---
      There is nothing more to do!

Uninstall
---
  1. Remove the folder and files containing the stencils.
  2. Remove any paths to the folder in Options | FilePaths
