# 案例 12：基于 SARIMA-GARCH 模型的黄金期货价格波动率预测
**问题背景**：黄金期货是重要的投资和避险工具，其价格波动率受全球经济形势、地缘政治风险、通货膨胀预期、美元指数等因素影响，呈现出明显的聚类特性（即高波动率之后往往跟随高波动率，低波动率之后往往跟随低波动率），且具有季节性特征。
**问题描述**：某金融投资机构需要对黄金期货未来 3 个月的日价格波动率进行预测。要求模型能够捕捉价格的季节性趋势、线性自相关以及波动率聚类特性，为投资组合风险管理和交易策略制定提供依据。
**数据情况**：提供过去 10 年的黄金期货日收盘价数据，同时提供美元指数、全球主要经济体的利率、通货膨胀率、地缘政治事件记录等。数据量约 2500 条，存在部分交易日因节假日缺失的情况。
案例 12：SARIMA-GARCH 模型黄金期货价格波动率预测代码

| import pandas as pd<br>import numpy as np<br>import matplotlib.pyplot as plt<br>from statsmodels.tsa.statespace.sarimax import SARIMAX<br>from arch import arch_model<br>from sklearn.metrics import mean_squared_error<br>import statsmodels.api as sm<br># 数据加载与预处理<br>data = pd.read_csv('gold_futures.csv', parse_dates=['date'], index_col='date')<br>price_data = data['price'].dropna()<br># 计算收益率（波动率基础）<br>returns = 100 * price_data.pct_change().dropna()  # 百分比收益率<br># 划分训练集和测试集<br>train_size = int(len(returns) * 0.8)<br>train_returns, test_returns = returns[:train_size], returns[train_size:]<br># SARIMA模型拟合均值方程<br># 选择最优参数（此处简化为手动指定，实际可通过AIC筛选）<br>sarima_order = (1, 0, 1)<br>seasonal_order = (1, 0, 1, 22)  # 22个交易日为月度周期<br>sarima_model = SARIMAX(train_returns, order=sarima_order, seasonal_order=seasonal_order)<br>sarima_result = sarima_model.fit(disp=False)<br># 获取SARIMA残差，用于GARCH模型<br>sarima_residuals = sarima_result.resid<br># GARCH模型拟合波动率<br>garch_model = arch_model(sarima_residuals, vol='GARCH', p=1, q=1)<br>garch_result = garch_model.fit(disp='off')<br># 组合预测：先预测均值，再预测波动率<br># SARIMA预测均值<br>sarima_pred = sarima_result.get_forecast(steps=len(test_returns))<br>mean_forecast = sarima_pred.predicted_mean<br># GARCH预测波动率（条件方差）<br>garch_forecast = garch_result.forecast(horizon=len(test_returns))<br>volatility_forecast = np.sqrt(garch_forecast.variance.values[-1, :])<br># 最终预测（均值±1.96*波动率，95%置信区间）<br>upper_bound = mean_forecast + 1.96 * volatility_forecast<br>lower_bound = mean_forecast - 1.96 * volatility_forecast<br># 评估波动率预测效果（使用实际收益率的绝对值作为真实波动率近似）<br>actual_volatility = np.abs(test_returns)<br>mse_vol = mean_squared_error(actual_volatility, volatility_forecast)<br>print(f'波动率预测MSE: {mse_vol}')<br># 可视化结果<br>plt.figure(figsize=(12, 6))<br>plt.plot(test_returns.index, test_returns, label='实际收益率')<br>plt.plot(test_returns.index, mean_forecast, label='均值预测', color='red')<br>plt.fill_between(test_returns.index, lower_bound, upper_bound, color='pink', alpha=0.3, label='95%置信区间')<br>plt.legend()<br>plt.savefig('gold_volatility_prediction.png')<br>plt.show() |
