# 案例 7：基于 XGBoost - 贝叶斯优化模型的电商平台 “618” 大促销量预测
**问题背景**：电商平台的大型促销活动（如 “618”“双十一”）期间，商品销量会出现爆发式增长，准确预测销量对平台库存管理、物流调度和营销策略制定至关重要。销量受商品价格、促销力度、用户评价、历史销量、竞争对手活动等多因素影响，呈现强非线性关系。
**问题描述**：某大型电商平台需要对平台上 1000 款热销商品在即将到来的 “618” 大促期间（15 天）的日销量进行预测。要求模型能够自动优化超参数，充分利用高维特征数据，精准预测各商品的销量变化，避免库存积压或缺货。
**数据情况**：提供各商品过去 3 年的日常销量及过往 “618”“双十一” 期间的销量数据，同时提供商品的属性信息（类别、价格、品牌、规格等）、促销方案（折扣力度、满减活动等）、用户评价数据（评分、好评率等）、平台流量数据等。数据量庞大，特征维度超过 50 维。
案例 7：XGBoost - 贝叶斯优化模型电商大促销量预测代码

| import pandas as pd<br>import numpy as np<br>from sklearn.preprocessing import LabelEncoder, MinMaxScaler<br>from sklearn.model_selection import train_test_split, cross_val_score<br>from xgboost import XGBRegressor<br>from skopt import BayesSearchCV<br>from skopt.space import Real, Integer<br>from sklearn.metrics import mean_squared_error<br>import joblib<br># 数据加载与预处理<br>data = pd.read_csv('ecommerce_sales.csv')<br>data = data.dropna()<br># 类别特征编码<br>le = LabelEncoder()<br>for col in ['product_category', 'brand']:<br>data[col] = le.fit_transform(data[col])<br># 特征与目标变量<br>X = data.drop(['sales', 'product_id'], axis=1)<br>y = data['sales']<br># 数据归一化<br>scaler = MinMaxScaler()<br>X_scaled = scaler.fit_transform(X)<br># 划分训练集和测试集<br>X_train, X_test, y_train, y_test = train_test_split(X_scaled, y, test_size=0.2, random_state=42)<br># 定义XGBoost参数空间<br>param_space = {<br>'n_estimators': Integer(50, 500),<br>'max_depth': Integer(3, 10),<br>'learning_rate': Real(0.01, 0.3, 'log-uniform'),<br>'subsample': Real(0.6, 1.0),<br>'colsample_bytree': Real(0.6, 1.0),<br>'gamma': Real(0, 5)<br>}<br># 贝叶斯优化<br>xgb = XGBRegressor(objective='reg:squarederror', random_state=42)<br>bayes_search = BayesSearchCV(<br>estimator=xgb,<br>search_spaces=param_space,<br>cv=5,<br>n_iter=30,<br>scoring='neg_mean_squared_error',<br>random_state=42,<br>verbose=1<br>)<br>bayes_search.fit(X_train, y_train)<br>best_xgb = bayes_search.best_estimator_<br># 模型预测<br>y_pred = best_xgb.predict(X_test)<br># 评估模型<br>print(f'最优参数: {bayes_search.best_params_}')<br>print(f'MSE: {mean_squared_error(y_test, y_pred)}')<br># 保存模型<br>joblib.dump(best_xgb, 'xgb_bayes_sales.pkl')<br>joblib.dump(scaler, 'scaler_sales.pkl') |
