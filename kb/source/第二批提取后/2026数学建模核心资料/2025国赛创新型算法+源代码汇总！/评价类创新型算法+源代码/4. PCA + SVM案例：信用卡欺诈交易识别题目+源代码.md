# 4. PCA + SVM案例：信用卡欺诈交易识别
**问题背景**：某银行需构建模型识别信用卡欺诈交易，交易数据含 20 项特征（如交易金额、时段、地点、商户类型等），存在高维冗余（如 “交易时段” 与 “商户类型” 强相关），且欺诈样本占比低（仅 3%）。
**数据**：
10000 条交易记录，每条含 20 项特征及标签（1 = 欺诈，0 = 正常），其中欺诈样本 300 条。
**要求**：用 PCA 降维至保留 95% 信息的维度，再用 SVM 分类，对比降维前后的识别准确率（尤其是欺诈样本的召回率），说明降维对模型效率的提升。
### 4. PCA + SVM代码：信用卡欺诈交易识别

| import numpy as np<br>import pandas as pd<br>from sklearn.decomposition import PCA<br>from sklearn.svm import SVC<br>from sklearn.model_selection import train_test_split<br>from sklearn.preprocessing import StandardScaler<br>from sklearn.metrics import classification_report<br># 生成模拟数据（10000条交易，20项特征）<br>np.random.seed(42)<br>n_samples = 10000<br>n_features = 20<br>X = np.random.randn(n_samples, n_features)<br># 生成欺诈标签（3%欺诈率）<br>weights = np.random.randn(n_features)<br>y = np.where(np.dot(X, weights) + np.random.randn(n_samples) > 2, 1, 0)<br>print(f"欺诈样本比例：{sum(y)/n_samples:.2%}")<br># 数据划分与标准化<br>X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)<br>scaler = StandardScaler()<br>X_train_scaled = scaler.fit_transform(X_train)<br>X_test_scaled = scaler.transform(X_test)<br># PCA降维<br>pca = PCA(n_components=0.95, random_state=42)<br>X_train_pca = pca.fit_transform(X_train_scaled)<br>X_test_pca = pca.transform(X_test_scaled)<br>print(f"降维前特征数：{n_features}，降维后：{pca.n_components_}")<br># SVM分类与评估<br>svm = SVC(kernel='rbf', class_weight='balanced', random_state=42)<br>svm.fit(X_train_pca, y_train)<br>y_pred = svm.predict(X_test_pca)<br>print("\n降维后分类报告：")<br>print(classification_report(y_test, y_pred))<br># 对比不降维的情况<br>svm_raw = SVC(kernel='rbf', class_weight='balanced', random_state=42)<br>svm_raw.fit(X_train_scaled, y_train)<br>y_pred_raw = svm_raw.predict(X_test_scaled)<br>print("\n不降维分类报告：")<br>print(classification_report(y_test, y_pred_raw)) |
