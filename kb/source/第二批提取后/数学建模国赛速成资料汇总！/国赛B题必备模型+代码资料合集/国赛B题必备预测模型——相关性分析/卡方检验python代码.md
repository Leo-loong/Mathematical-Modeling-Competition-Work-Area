# 卡方检验python代码
  卡方检验（Chi-squared test）是一种常用的统计方法，用来判断观测到的数据是否符合预期的值。在数据分析领域，卡方检验是一种非常实用的工具。在Python中，我们可以使用scipy.stats.chisquare()函数进行卡方检验。  以下是卡方检验在Python中的相关步骤：  1. 导入必要的库  在进行卡方检验之前，需要导入一些必要的库。其中，scipy库是必须的。  ```python import scipy from scipy import stats ```  2. 输入数据  接下来，需要输入数据。首先，输入观测值和预期值，将它们保存为两个列表。在这里，我们使用一个示例数据。示例数据包含50个人，其中10个人是A型血，30个人是B型血，10个人是O型血。  ```python observed = [10, 30, 10] expected = [16.67, 33.33, 16.67] ```  3. 计算卡方值  现在，我们可以使用scipy库中的chisquare()函数来计算卡方值。该函数需要两个参数：观测值列表和预期值列表。chisquare()函数返回的是一个元组，其中包含卡方值和P值。  ```python chi_squared, p_value = stats.chisquare(f_obs=observed, f_exp=expected) ```  4. 结果解读  计算完毕之后，需要对卡方检验的结果进行解读。卡方值表示观测值和预期值之间的偏离程度。如果卡方值很小，说明观测值和预期值非常接近，反之则说明两者存在较大差异。P值表示观测值和预期值之间的偏离程度由随机因素造成的可能性。如果P值很小，说明偏离程度非常显著，反之则偏离程度不太显著。  ```python print("卡方值为：", chi_squared) print("P值为：", p_value) ```  通过以上代码输出结果为：卡方值为： 3.75，P值为： 0.153。  这说明观测值和预期值之间存在一定偏离，但是偏离程度不太显著。P值大于0.05，说明该偏离程度有可能是由随机因素造成的。  综上，卡方检验在数据分析中是一种非常有用的工具，Python中有完整的函数库支持，方便快捷。我们需要注意使用时数据输入的正确性，对结果进行正确的解读，保持数据分析的准确性。
