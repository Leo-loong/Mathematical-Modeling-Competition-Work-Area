Index of Functions of GEA Toolbox for Matlab

## Help text

 Demo of GEA toolbox, Multi Population Evolutionary Algorithm

 This script was written for an older version of the GEA Toolbox and

 is not supported currently. However, it was included into the toolbox

 for educational purpose.

 This script implements the Multi Population Evolutionary Algorithm.

 Real valued or binary representation for the individuals is used.

 The script is called by the graphical interface of the

 GEA Toolbox (dgagraf).

 Syntax:  dgampga

 See also: dgagraf, dganew, dgamesh
