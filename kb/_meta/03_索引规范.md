# 索引规范

> `index/` 是知识库的唯一检索入口。条目可以很多，索引必须始终反映全库现状。

## 1. MOC.md（主索引）

维护一张全库条目总表，每次 `library/` 增删后**增量更新**：

```markdown
# MOC — 全库地图

| id | 标题 | 分类 | type | tags | status | 一句话说明 |
|---|---|---|---|---|---|---|
| M001 | 双光束干涉模型推导 | M | derivation | 干涉,厚度反演 | final | 正向模型与级数关系 |
```

排序：分类代码 → 序号。

## 2. 专题索引（可选）

当某主题条目 ≥5 时，可为它建 `index/topic_<主题>.md`，内容为：

- 该主题下的条目 id 列表 + 推荐阅读顺序；
- 条目间的依赖/推导链（A → B 表示 B 依赖 A）；
- 该主题的权威条目（冲突时的裁定者）。

## 3. 检索路径约定

- 按主题查 → MOC 或专题索引 → 条目。
- 按来源查 → 专题索引 `source` 反查，或全库 grep `source:` 字段。
- 按标签查 → front-matter `tags`，索引不单独建标签表（由 Agent 现场汇总）。

## 4. 一致性检查（每次更新索引后执行）

1. MOC 中每个 id 都能在 `library/` 找到对应文件，反之亦然。
2. `links` 引用的 id 均存在。
3. `status: final` 的条目必须有已核对的 `source`。
